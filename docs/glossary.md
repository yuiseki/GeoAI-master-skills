# 用語集

地理空間のデータ分析で、このリポジトリのスキルが使う言葉。細かい手順は各スキルの SKILL.md にある。

## 機械学習の基礎

| 用語 | 意味 |
|---|---|
| 目的変数、特徴量 | 目的変数は予測したい値 (平均寿命)。特徴量は、それを予測する材料にする列 (1 人あたり GDP、人口) |
| 学習データ、試験データ | モデルを当てはめるのに使う行と、点数を測るのに使う行。同じ行で測ると、覚えただけの点数になる |
| 過学習 | 学習データの雑音まで覚えて、試験データで点数が落ちること。行が少なく、モデルが複雑なほど起きやすい |
| 標準化 | 各列を、平均 0、標準偏差 1 に揃えること。尺度の違う列を同じ土俵で扱う |
| 線形回帰 | 特徴量の重みつき和で目的変数を予測する、最も単純なモデル。複雑なモデルの基準にする |
| 勾配ブースティング (hgb) | 小さな決定木を次々に足して誤差を減らすモデル。表データで強いが、行が少ないと過学習しやすい |

## 座標と地理データ

| 用語 | 意味 |
|---|---|
| CRS (座標参照系) | 座標の値が地球上のどこかを決める約束。同じ数字でも、CRS が違えば別の場所になる。結合の前に、両方の CRS を確かめる |
| 経度 (lon)、緯度 (lat) | 地球を球と見た角度。緯度は赤道から南北に -90〜90 度、経度は東西に -180〜180 度。`EPSG:4326` (または `OGC:CRS84`) がこの座標を表す CRS の名前。座標の順 (経度が先か、緯度が先か) はツールごとに違い、取り違えると別の場所になる |
| 緯度経度の距離の歪み | 経度 1 度の長さは、赤道で約 111 km、高緯度ほど短い。度のまま距離や格子を作ると、高緯度ほど細くなる。距離はメートルかキロメートルで測る |
| 大円距離 (haversine) | 球の表面に沿った 2 点間の最短距離。このリポジトリの近傍や距離は、半径 6,371 km の球での大円距離 |
| ジオメトリ | 点、線、面などの形。1 行に 1 つ持たせる |
| GeoParquet | ジオメトリを持てる列指向のファイル形式 (Parquet)。必要な列だけ読める。大きな表の標準的な置き方 |
| DuckDB spatial | DuckDB の空間拡張。SQL で空間結合や距離を計算できる。ファイルや URL を直接読める |
| STAC | 衛星画像や地理データを探すための目録の決まり。目録の中のデータごとに、場所、時刻、ファイルへのリンクが付く |
| COG | 必要な範囲だけを読めるように作られたラスタ (格子) の画像ファイル |
| ラスタ、ベクタ | ラスタは格子状の値 (人口の格子、衛星画像)。ベクタは点、線、面 |
| 代表点 | 面の中の 1 点。重心は面の外に出ることがあるので、面の中に必ず入る点 (`ST_PointOnSurface`) を使うことがある |
| 空間結合 | 位置の関係 (点が面に入る、近い) でデータを結ぶ。キーで結ぶ普通の結合と区別する |
| 按分 | 区域の値を、面積や人口の比で、細かい単位に配ること。仮定が入る |

## 単位とデータの形

| 用語 | 意味 |
|---|---|
| 分析の単位 | 分析の 1 行が何を表すか (点、格子、行政区、国、それぞれ × 時間)。最初に決める |
| MAUP (可変単位地区問題) | 集計する単位の大きさや区切り方を変えると、相関や係数などの結果が変わること。単位の選び方が結論の一部になる |
| 格子 (グリッド) | 地表を同じ形のセルに切ったもの。事象の無いセルは元のデータに行が無いので、セルを全部作ってから 0 を埋める |
| パネル | 同じ単位 (国、地点) を何時点も観測した表 (国 × 年) |
| 縦持ち | 1 行が 1 つの値 (国、指標、年、値)。横持ちは指標を列に並べた形 |

## 空間の構造

| 用語 | 意味 |
|---|---|
| 空間自己相関 | 近い単位どうしの値が似ている (または逆) こと。地理のデータの普通の性質 |
| Moran's I | 空間自己相関の大きさを表す 1 つの数。およそ -1 から 1。正なら似た値が近くに固まり、0 付近なら場所と値が無関係。何以上が強いという決まった値は無く、p 値と距離ごとの並びで読む |
| コレログラム | 距離の帯ごとの Moran's I。どの距離まで似ているかが分かる |
| LISA (local Moran) | 単位ごとの Moran's I。どの単位が、似た値の集まり (HH、LL) や、周りと逆の値 (HL、LH) にあるかを分ける |
| Getis-Ord Gi* | 高い値、低い値が集まっている場所 (ホットスポット) を見つける統計量 |
| 近傍、重み | どの単位を「近い」とみなすか (k 個の最近傍、距離の帯)。重みは近傍の寄与の割り振り |
| 並べ替え検定、pseudo p | 値を並べ替えて統計量を作り直し、観測した値より極端な割合を p 値とする方法 |
| クラスタ (群) | 似た単位のまとまり。k-means、密度に基づく手法 (HDBSCAN) などで作る。k-means は群の数 k を先に決める必要がある |
| DPMM (ディリクレ過程混合モデル) | 群の数をデータに合わせて決める混合正規分布。k-means の k の候補を出すのに使う。ただし群の数は事前分布の選び方に強く左右される |
| 点パターン、Ripley の K | 点の分布が、ランダムか、集まっているか、散らばっているかを、距離ごとに調べる方法 |

## 予測と評価

| 用語 | 意味 |
|---|---|
| 基準 (ベースライン) | 単純な予測 (平均、前の値、線形回帰)。複雑なモデルは、基準を超えて初めて意味を持つ |
| RMSE、MAE、R2 | 回帰の点数。RMSE と MAE は誤差の大きさ (小さいほど良い)。R2 は、平均で予測した場合を 0、完全な予測を 1 としたときの位置。基準より悪いと負になる |
| 交差検証 | データを学習側と試験側に分け、試験側で点数を出すことを、分け方を変えて繰り返す |
| 分割表 | 交差検証の分け方をファイルに残したもの。基準もモデルも同じ表で採点する |
| 外側の予測 (out-of-fold) | 各行を、その行を学習に使わなかったモデルで予測した値。学習に使った行の予測は、誤差が小さく見える |
| リーク | 本番で手に入らない情報が、学習や特徴量に入っていること。近い単位や同じ単位の別の行を学習側に見て当てるのも、リークの一種 |
| 空間ブロック、緩衝帯 | 地表をブロックに切って、ブロック単位で試験側を決める分け方。試験側と学習側の間に空ける距離が緩衝帯 |
| 実効的な標本の数 (Kish) | 重みが偏ったとき、同じ重みの何行分の情報があるか。重みが偏るほど、行の数より小さい |
| 独立な単位の数 | 近い行や同じ月の行は独立でない。点数の揺れは、行の数ではなく、独立に近い単位の数で考える |
| 天井 (ノイズの天井) | 測定の雑音のために、どんなモデルでも超えられない点数。同じものを 2 回測ったときの一致度で見積もる |
| 較正 (calibration) | 「0.3 と予測した行の 3 割が実際に陽性か」。ECE はそのずれの大きさ。isotonic、Platt は較正し直す方法 |
| 共形予測 | 試験側の残差の分位点から、予測の区間を作る方法。区間が実際に覆った割合 (被覆率) で確かめる |
| 部分依存、ICE | 1 つの特徴量を動かしたとき、予測がどう動くか。部分依存は平均の曲線、ICE は行ごとの曲線 |
| permutation importance | 試験側で、ある特徴量の値を並べ替えたときの点数の落ち方。落ちるほど、その特徴量が効いている |
