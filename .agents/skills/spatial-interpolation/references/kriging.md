# variogram と通常クリギング

## variogram

距離 h だけ離れた 2 点の値の差の 2 乗の半分の平均 γ(h)。近い点ほど似ていれば、h が小さいほど γ は小さい。

| 言葉 | 意味 |
|---|---|
| 経験 variogram | 点の組を距離の区間に分け、区間ごとに γ を計算したもの |
| ナゲット | h → 0 の γ。測定の誤差と、観測の間隔より細かいばらつき |
| シル | γ が頭打ちになる値。値の分散に近い |
| レンジ | γ が頭打ちになる距離。それより離れた点は、値の推定に役立たない。指数モデルの `range` は尺度で、実際に頭打ちになるのは約 3 倍の距離 |
| モデル | 経験 variogram に当てはめる関数 (指数、球) |

`scripts/interpolate_points.py` は、経験 variogram (最大距離の半分までを 15 区間) に、区間の組の数で重みを付けた最小二乗で、ナゲット、シル、レンジを当てはめる。`--variogram MODEL NUGGET SILL RANGE` で与えることもできる。ライブラリの既定の当てはめをそのまま使わず、経験 variogram と当てはめた曲線を並べて見る。

大域的な勾配があると、γ は距離とともに増え続け、頭打ちにならない。当てはめたシルは、勾配の分も含んだ大きな値になる (山梨県の標高で、シル 13,406 m²、値の分散とほぼ同じ)。

方向によって似かたが違う (異方性) なら、東西の組と南北の組で別々に経験 variogram を作って比べる。異方性のあるクリギングはスクリプトに無い。

## 通常クリギング

平均が未知で一定と仮定し、重みの和が 1 になる条件のもとで、variogram から推定の分散が最小になる重み λ を解く。観測と同じ地点では、その値を返す。推定の分散は Σ λ_i γ(d_i0) + μ (μ はラグランジュ乗数)。1 点だけで推定するなら、重みは 1 で、分散は 2 γ(d)。

## レンジの外

予測地点から観測までの距離がレンジを超えると、どの観測も γ がシルに達し、予測地点について何も教えない。通常クリギングの予測は、観測の重み付きの平均 (一般化最小二乗の平均) に戻り、分散はシルとナゲットの近くで頭打ちになる。正三角形の 3 つの観測 (10、20、60) から、レンジの千倍以上離れた地点を予測すると、3 つの重みは等しく、予測は算術平均の 30 になった (`scripts/test_interpolate_points.py`)。レンジの外の予測は、平均を返しているだけで、空間の情報を使っていない。最寄りの観測までの距離をレンジと並べて書き、レンジの外の予測は分けて報告する。

## 区間の被覆率

クリギングの標準偏差 (`kriging_sd`) は、variogram のモデルが正しいときの値。そのまま予測区間と読まない。抜いた点で、名目 90% の区間 (± 1.645 sd) に入った割合を確かめる (`evaluate_interpolation.py` の `coverage_90`)。

山梨県の標高では、ランダムな分け方で 96.4%、ブロックで 94.8%、答え合わせの 300 点で 97.0% (2026-10-14)。名目の 90% より広い。勾配の分まで含んだ大きなシルで、分散を大きめに見積もったためと考えられる (推測)。
