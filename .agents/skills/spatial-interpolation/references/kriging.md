# variogram と通常クリギング、ユニバーサルクリギング

## variogram

距離 h だけ離れた 2 点の値の差の 2 乗の半分の平均 γ(h)。近い点ほど似ていれば、h が小さいほど γ は小さい。

| 言葉 | 意味 |
|---|---|
| 経験 variogram | 点の組を距離の区間に分け、区間ごとに γ を計算したもの |
| ナゲット | h → 0 の γ。測定の誤差と、観測の間隔より細かいばらつき |
| シル | γ が頭打ちになる値。値の分散に近い |
| レンジ | γ が頭打ちになる距離。それより離れた点は、値の推定に役立たない。指数モデルの `range` は尺度で、実際に頭打ちになるのは約 3 倍の距離 |
| モデル | 経験 variogram に当てはめる関数 (指数、球) |

`scripts/interpolate_points.py` は、経験 variogram (最大距離の半分までを 15 区間) に、区間の組の数で重みを付けた最小二乗で、ナゲット、シル、レンジを当てはめる。`--variogram MODEL NUGGET SILL RANGE` で与えることもできる。ライブラリの既定の当てはめをそのまま使わず、経験 variogram と当てはめた曲線を並べて見る。

大域的な勾配があると、γ は距離とともに増え続け、頭打ちにならない。当てはめたシルは、勾配の分も含んだ大きな値になる (山梨県の標高で、シル 13,406 m²、値の分散とほぼ同じ)。

方向によって似かたが違う (異方性) なら、下の「異方性」で扱う。

## 通常クリギング

平均が未知で一定と仮定し、重みの和が 1 になる条件のもとで、variogram から推定の分散が最小になる重み λ を解く。観測と同じ地点では、その値を返す。推定の分散は Σ λ_i γ(d_i0) + μ (μ はラグランジュ乗数)。1 点だけで推定するなら、重みは 1 で、分散は 2 γ(d)。

## レンジの外

予測地点から観測までの距離がレンジを超えると、どの観測も γ がシルに達し、予測地点について何も教えない。通常クリギングの予測は、観測の重み付きの平均 (一般化最小二乗の平均) に戻り、分散はシルとナゲットの近くで頭打ちになる。正三角形の 3 つの観測 (10、20、60) から、レンジの千倍以上離れた地点を予測すると、3 つの重みは等しく、予測は算術平均の 30 になった (`scripts/test_interpolate_points.py`)。レンジの外の予測は、平均を返しているだけで、空間の情報を使っていない。最寄りの観測までの距離をレンジと並べて書き、レンジの外の予測は分けて報告する。

## 区間の被覆率

クリギングの標準偏差 (`kriging_sd`) は、variogram のモデルが正しいときの値。そのまま予測区間と読まない。抜いた点で、名目 90% の区間 (± 1.645 sd) に入った割合を確かめる (`evaluate_interpolation.py` の `coverage_90`)。

山梨県の標高では、ランダムな分け方で 96.4%、ブロックで 94.8%、答え合わせの 300 点で 97.0% (2026-10-14)。名目の 90% より広い。勾配の分まで含んだ大きなシルで、分散を大きめに見積もったためと考え、下のユニバーサルクリギングで確かめた。

## ユニバーサルクリギング (大域的な勾配を除く)

`--method universal` は、平均を a + b x + c y (係数は未知) とし、近い --k 点の中で、重みの和が 1、重みで重ねた x と y が予測地点の x と y になる条件で解く。平面の係数を推定せずに消す。variogram は、全ての観測に最小二乗で当てた平面の残差から当てる (残差の variogram は、遠い距離で少し小さく出る。回帰クリギングと同じ近似)。推定の分散は Σ λ_i γ(d_i0) + μ · (1, x0, y0)。

- 手の計算の代わりに: 雑音の無い平面は、観測の外のどこでも正確に戻る (1e-8)。通常クリギングは遠くで平均に戻り、ある地点で真値 53 に対して 8.2 (テスト)。
- 平面の勾配 + 滑らかな場 (300 点、5 回): 西の半分で学習し東の 4 分の 1 を予測すると、RMSE はユニバーサル 1.21〜4.04、通常 3.46〜5.41。西の半分の中の抜いた点では、0.53〜0.72 と 0.55〜0.74 で同じくらい。勾配が効くのは、勾配の向きに外へ出るとき。
- 勾配のある値の経験 variogram は遠くで上がり続け (最後の区間が最初の 5 倍超)、平面の残差の variogram は平ら (テスト)。
- 平面は外挿する。外で勾配が続くと仮定している。山の向こうで下る地形のように、窓の外で勾配が変わるなら、外の予測は通常クリギングより悪くなりうる。

山梨県の標高 (上と同じタイル、2026-10-16 に取り直し、seed 42 で画素を 800 選び直した。前の 10-14 の標本とは同じ点ではない):

| | 通常 | ユニバーサル |
|---|---:|---:|
| variogram (ナゲット、シル、レンジ) | 0、13,429 m²、6,990 m | 29、4,444 m²、5,276 m |
| ランダムな分け方の RMSE (凸包の外) | 14.83 (30.65) | 14.49 (22.74) |
| ブロックの RMSE | 25.28 | 26.70 |
| 90% の区間の被覆: ランダム、ブロック | 0.958、0.942 | 0.914、0.916 |
| 答え合わせの 300 点: RMSE、被覆、sd の平均 | 13.65、0.960、20.0 m | 14.03、0.897、14.8 m |

- シルは 3 分の 1 になり、区間は約束の 90% に近づいた。通常クリギングの区間が広すぎたのは、勾配の分を含んだシルのためという推測と合う。
- 当たり (RMSE) はほとんど変わらない。凸包の外の点ではユニバーサルが良く、ブロックではわずかに悪い。

## 異方性

`--anisotropy 角度 比` は、相関が最も遠くまで届く向き (東から反時計回りの度) と、その向きの範囲と直交する向きの範囲の比を与え、座標を回して直交する向きを比の倍に伸ばした距離でクリギングする (PyKrige と同じ約束: 角度の分だけ逆に回し、回した後の y に比を掛ける)。variogram の範囲は、その向きの範囲になる。近い点の選び方も変換した距離で行う。`nearest_m` と凸包は元のメートルのまま。

`--anisotropy auto` は、角度 15° ごと × 比 (1、1.5、2、3、4、6) の 67 通りの格子から、400 点の標本の 1 点ずつ抜いた通常クリギングの RMSE が最小の組を選ぶ。

- 最初の方式 (8 方向の経験 variogram に指数の範囲を当て、最も長い向きを選ぶ) は使えなかった。合成の場 (向き 30°、比 3、500 点) で、6 回のうち向きが 22.5° 以内に入ったのは 3 回、外れは最大 37.5°、1 回は全ての向きの範囲が 1 万 m を超えた。範囲を楕円 (1/r(θ)² の 2 次形式) に当てる方式も、8 回のうち 5 回で楕円にならなかった (固有値が負)。
- 1 点ずつ抜く方式では、6 回で向き 30、30、30、45、30、90、比 4、2、4、2、3、1.5。伏せた 100 点の RMSE は、等方の 0.921〜0.985 倍 (3 回)。改善は本物だが小さい (最短の範囲 500 m、点の間隔もおよそ 500 m)。
- 山梨県の標高 (上の 500 点): 選ばれたのは 165°、比 1.5。1 点ずつ抜いた RMSE は 14.29 で、等方の 14.36 と 0.5% しか違わない。答え合わせの 300 点では、異方の 14.84 が等方の 13.65 より悪かった。67 通りから最小を選ぶので、選んだ組の誤差は楽観的になる。この程度の差なら等方のままにする。
- 回す向きの符号の誤りは、手の計算 (90°) でも、同じ変換で作った合成の場でも捕まらず、PyKrige との照合だけが捕まえる。

## 外部の実装との照合

PyKrige 1.7.3 の `OrdinaryKriging` と `UniversalKriging` (`drift_terms=["regional_linear"]`) と照合した (`scripts/test_interpolate_points_crosscheck.py`)。60 点、全ての観測を使い (k = n)、同じ指数の variogram (PyKrige のレンジはこちらの 3 倍) で、ナゲット 0 と 0.05、凸包の外の 2 点を含む 22 点の予測と推定の分散が 1e-8 以内で一致した。異方性は `anisotropy_scaling` と `anisotropy_angle` で、(30°、3) と (120°、2) の予測と分散が 1e-8 以内で一致した。variogram の当てはめ (区間の取り方、重み) と、異方性の推定は照合していない。
