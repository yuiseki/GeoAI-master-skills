# HSGP: ガウス過程を基底の和で近似し、パラメータの不確かさまで引く

通常クリギングは、variogram を 1 つの値に決めてから重みを解く。variogram の不確かさは区間に入らない。ガウス過程 (GP) のパラメータ (尺度 σ、長さ ℓ、ノイズ) まで事後分布で引けば入るが、厳密な GP は観測 n に対して n³ の計算で、数千点を超えると MCMC の中で回せない。

HSGP (Hilbert 空間の近似、Solin と Särkkä 2020、Riutort-Mayol ら arXiv:2004.11408v2) は、箱 [−L1, L1] × [−L2, L2] の上のラプラシアンの固有関数で、定常なカーネルを書き直す。

  k(x, x') ≈ Σ_j S(√λ_j) φ_j(x) φ_j(x')
  φ_j(x) = Π_d sin(π j_d (x_d + L_d) / (2 L_d)) / √L_d、√λ_j = |(π j_d / (2 L_d))_d|

S はカーネルのスペクトル密度で、j_d は軸ごとに 1 から m (2 次元で m² 個)。GP は m² 個の重みの線形モデル (w_j ~ N(0, S(√λ_j))) になり、計算は n m² で伸びる。

`scripts/hsgp.py` (numpy: 基底、スペクトル密度、近似の共分散、パラメータを固定した事後、比べるための厳密な GP)、`scripts/hsgp_numpyro.py` (NumPyro の NUTS でパラメータまで引く)。

## 決めるもの: 箱の広さ c と基底の数 m

c = L / S (S は点の範囲の半分)。箱の端で基底は 0 に縛られるので、箱は点より広くする (c > 1)。ℓ が短いほど、細かい凹凸を描くのに多くの基底が要る。論文の目安 (式 18〜23、1 次元で測ったもの) は `rule`。

| カーネル | m | c |
|---|---|---|
| 2 乗指数 | 1.75 c / (ℓ / S) | max(3.2 ℓ / S, 1.2) |
| Matérn 5/2 | 2.65 c / (ℓ / S) | max(4.1 ℓ / S, 1.2) |
| Matérn 3/2 | 3.42 c / (ℓ / S) | max(4.5 ℓ / S, 1.2) |

指数カーネル (Matérn 1/2、このスキルのクリギングの既定) の目安は論文に無い。スペクトル密度の裾が重く、多くの基底でも近似の誤差が残る (10 × 10 の範囲、ℓ = 2 で、軸に 48 個でも共分散の差が 0.08)。

ℓ は先に分からないので、論文の手順で回す。ℓ の見当から c と m を決めて当て、推定した ℓ が、その m と c で描ける最も短い ℓ (`ell_min`) を超えるかを見る。超えなければ、推定した ℓ で c と m を決め直す。超えたら、m を増やしても予測の精度が良くならないことを確かめる。

## 2 次元で測ったこと

論文の目安は 1 次元で測ったもの。2 次元に軸ごとに当てはめると足りなかった (`scripts/test_hsgp.py`、`scripts/test_hsgp_numpyro.py`、10 × 10 の範囲の 400 点)。

- 目安の最小の c は、箱の端で足りない。2 乗指数、ℓ = 2 で c = 1.28 だと、端の点の分散が 0.46 (正しくは 1) で、m を 3 倍にしても戻らない。c = 2 で全体の差が 0.01 以内になった。2 次元では角の点が 2 つの辺に近いので、c は 1.5 から 2 を下限にする。
- 目安の m では、事後の標準偏差が小さすぎる。Matérn 5/2、ℓ = 2、ノイズ 0.1 で、軸に 11 個 (121 個) だと、潜在の面の事後の標準偏差は厳密な GP の約 0.6 倍だった。軸に 33 個 (目安の 3 倍) で、平均の差は事後の標準偏差の 0.2 倍以内、標準偏差の比は 0.9 以上になった。ノイズが大きい (0.3) と、2 倍で足りた。
- パラメータまで引くと、描けない細かい変動はノイズとして取られる。真のノイズ 0.5 の面に、目安の m で当てると、ノイズの推定は 0.68 (90% 区間の下端 0.65)、潜在の面の RMSE は 0.556。2 倍で 0.527 と 0.275、3 倍で区間が真の値を含み (0.49〜0.54)、抜いた 300 点の 90% 予測区間は 0.917 を含んだ。
- 確かめ方: 目安で当てたら、m を 1.5 から 2 倍にしてもう一度当て、ノイズ、ℓ、予測、予測の標準偏差が変わらないことを見る。ノイズが下がるなら、まだ足りない。

## 山梨県の標高での back-test

国土地理院の標高タイル (ズーム 14、x 14493〜14496、y 6449〜6452、2026-11-09 に取得) の画素を無作為に選び、観測と、答え合わせの 300 点に分けた (seed 42、UTM 54N、km)。通常クリギングは近い 12 点と指数モデル、HSGP は Matérn 5/2、c = 1.5、NUTS 2 連鎖、500 + 500。

| 観測の数 | 方法 | m (基底の数) | ℓ の中央値 (km) | ノイズの中央値 (m) | 平均絶対誤差 (m) | 90% 区間の被覆 | 時間 |
|---:|---|---|---:|---:|---:|---:|---:|
| 500 | 通常クリギング | | | 0 (ナゲット) | 6.22 | 0.970 | 1 秒未満 |
| 500 | HSGP | 11 (121) | 2.27 (描ける最短 2.37) | 19.1 | 10.83 | 0.920 | 15 秒 |
| 500 | HSGP | 26 (676) | 1.14 | 11.1 | 6.95 | 0.927 | 42 秒 |
| 500 | HSGP | 39 (1,521) | 1.10 | 10.7 | 6.81 | 0.923 | 78 秒 |
| 500 | HSGP | 78 (6,084) | 1.09 | 10.4 | 6.74 | 0.923 | 188 秒 |
| 5,000 | 通常クリギング | | | 0 (ナゲット) | 2.43 | 0.983 | 1 秒未満 |
| 5,000 | HSGP | 26 (676) | 0.74 | 9.1 | 5.70 | 0.890 | 387 秒 |
| 5,000 | HSGP | 52 (2,704) | 0.48 (描ける最短 0.31) | 5.1 | 3.41 | 0.900 | 7,960 秒 |

- 500 点の最初の行 (ℓ の見当 2.4 km、目安の m) は、推定した ℓ が描ける最短を下回り、診断が通らなかった。ノイズが 19 m に膨らみ、誤差は最近傍 (8.4 m) より悪い。見当を 1 km にして m を増やすと、2 倍から先は ℓ も誤差もほぼ止まった。
- 区間: クリギングの 0.970 と 0.983 は名目の 90% より広い (kriging.md の「区間の被覆率」)。HSGP は 0.92 前後で名目に近い。
- 5,000 点では、m を 26 から 52 にすると ℓ が 0.74 から 0.48 km、ノイズが 9.1 から 5.1 m に下がり、誤差も 5.70 から 3.41 m に縮んだ。診断の「m を増やしても変わらない」は通っておらず、まだ基底が足りない。52 で 2 時間 13 分かかり、これ以上は 1 回の当てはめが半日を超える。観測が密になるほど、描くべき ℓ が短くなり、必要な m が増える。
- 平均絶対誤差は、500 点でも 5,000 点でもクリギングが小さかった。地形には、観測の間隔 (5,000 点で 1 点あたり約 110 m 四方) と同じくらいの細かさの起伏がある。近い 12 点だけを使う局所のクリギングはそれを拾い、全域で 1 つの ℓ と、限られた数の基底で描く HSGP は拾えず、ノイズに回す。

## 使いどころ

- 向く: 面が全域で滑らかで、ℓ が範囲に比べて長い値 (気温、広域の濃度、地下水位の広い傾向)。パラメータの不確かさまで区間に入れたいとき。観測が数千から数万で、厳密な GP を MCMC で回せないとき。階層モデルの中の空間の項 (BYM2 の代わりに連続の空間で)。
- 向かない: 観測の間隔ほどの細かい起伏が値の大部分を占めるとき (地形、細かい土地利用)。局所のクリギングか、最近傍が勝つ。ℓ が範囲の数 % まで短くなると、必要な基底は軸あたり数百になる。
- 2 次元まで。次元が増えると基底は m^D で増える (論文は D ≤ 4 を勧める)。
- 箱の外は予測しない (`hsgp_posterior` と `predict` は止まる)。予測する点も箱に入るように c を決める。

## NumPyro について

- JAX は読み込んだときに GPU のメモリの 75% を取る。GPU を他と分け合う機械では `JAX_PLATFORMS=cpu` にする (スクリプトは既定でそうする)。
- `numpyro.contrib.hsgp` にも同じ近似がある。こちらの基底は、それと共分散で 1e-5 以内で一致した (`test_hsgp_numpyro.py`)。NumPyro の `alpha` は分散 σ² で、σ ではない。σ を渡すと共分散が σ 倍小さくなる。

## 必ず出すもの

HSGP の予測を報告するときは、次を診断の表 (`| 診断 | 実測 | 基準 | 判定 | 次の手 |`) に置く。

| 診断 | 出し方 | 基準 (OK と読む条件) | 外れたとき |
|---|---|---|---|
| ℓ の診断 | 推定した ℓ と `ell_min` | ℓ の中央値が `ell_min` を超える | 推定した ℓ で c と m を決め直して当て直す |
| m を増やしても変わらないか | m を 1.5〜2 倍にして当て直す | ノイズ、ℓ、予測の標準偏差が変わらない (数 % 以内) | m を増やし続ける。止まらないなら HSGP をやめる |
| 箱の広さ | c と、予測する点が箱に入るか | c ≥ 1.5、全ての予測点が箱の中 | c を広げる |
| 連鎖 | R-hat、ESS、発散 | R-hat < 1.01、発散 0 | 長く引く、target_accept を上げる |
| 抜いた点での区間の被覆 (名目 90%) | 答え合わせの点 | 0.9 に近い | 広すぎ、狭すぎを書く |
| 局所の基準との比較 | 同じ答え合わせの点で、最近傍と通常クリギング | HSGP の誤差が大きく劣らない | 劣るなら、その理由 (細かい起伏) を書き、HSGP を区間のためだけに使うかを決める |
