# raster-data-integration

ラスタの集計は、黙って値の意味を変える。人口を平均すると人口でなくなり、クラスのコードを補間すると存在しないクラスができ、NoData を 0 と読むと平均が下がる。処理の前に、画素が何を表すかを決め、それに合う方法だけを使う。

## 扱う範囲

扱うのは、値の意味がすでに決まっているラスタ。人口の格子、標高、土地被覆のクラスの地図、気温や降水量の格子、距離や密度や確率の連続値。GeoTIFF や COG で配られることが多い。人工衛星から作られたものでもよい。分類済みの土地被覆の地図は扱う。

扱わないもの: 衛星画像そのものの解析。RGB、マルチスペクトル、ハイパースペクトル、SAR の画像の解釈、シーンの選び方、雲のマスク、大気補正、放射量の補正、NDVI などの指標の作り方、画像の分類、セグメンテーション、物体検出、画像の基盤モデル、変化検出、パンシャープン、オルソ補正。バンドの値から土地被覆を推定する処理は、このスキルの外にある。

このスキルが答えるのは、意味の決まったラスタの値を、決まった分析の単位にどう対応付けるか、まで。何を 1 行にするかは、使う前に決めておく。単位に付けた値から特徴量を作ること、結論全体の頑健性を確かめることは、このスキルの外。

## 手順

1. 使い道を 1 行で書き、ラスタの値を単位にどう付けたいかを書く。「区ごとの人口」なら区の面に人口を足す。「地点の標高」なら点の位置の値を読む。
2. ラスタの中身を数える。`scripts/inspect_raster.py` で、CRS、画素の大きさ (地理座標なら中心でのメートル)、範囲、affine の変換 (回転の項が 0 で、北が上か。`aggregate_raster.py` は回転したラスタを扱わずに止まる)、型、NoData の値、scale と offset、有効な画素と NoData と NaN の数、有効な値の中の 0 の数、最小、最大、合計、整数なら値ごとの数を出す。大きなファイルは `--bbox` で窓だけを読む (範囲はラスタの CRS で書く)。
3. 画素の意味を決めて書く (下の表と [raster-semantics](references/raster-semantics.md))。1 画素が何を表すか、値の単位、連続値かクラスか、量 (面積に比例して足せる。人口、件数) か水準 (足せない。標高、気温、密度)、NoData が何を指すか (観測が無い、海、人が住んでいない)、空間の支持 (画素の面積の代表値か、中心の点の値か)、時点か期間か。説明に書いてなければ「未確認」と書き、手順 2 の数字から推した理由を添える。
4. 単位とラスタの関係を数える。単位あたりの画素の数 (単位の面積を画素の面積で割る)、単位がラスタの範囲から出ていないか。単位が数画素しか持たないなら、どの規則で数えても値は荒い (手順 6)。
5. 単位に付ける。単位が細かい規則格子 (投影座標系の正方形のセルが数十万以上) なら、セルを多角形として測る代わりに、画素の中心を格子の座標系に移して、入ったセルで数える (`scripts/raster_to_grid.py`、[regular-grid](references/regular-grid.md))。それ以外は、ラスタは動かさず、単位の座標をラスタの CRS に移す。`scripts/aggregate_raster.py` に、ラスタ、単位の表、単位の ID、量か水準かクラスか (`--kind`、既定値は無い)、単位の CRS (`--units-crs`、既定値は無い) を渡す。
   - 量は合計、水準は面積で重みを付けた平均と最小と最大、クラスは面積の割合と最も多いクラス。
   - 画素を面に入れる規則は、中心が面の中にあるか (`--method centre`)、画素の面積のうち面に入る割合を細かい格子で測るか (`--method fraction`)、画素と面の交差の面積で重みを付けるか (`--method exact`)。`all_touched` は多めに数える幅を測るためだけに使う。単位が画素に比べて小さいとき、細長いときは exact か fraction を使う。単位が十分大きければ中心の規則との差は小さいが、一度測って書く ([zonal-aggregation](references/zonal-aggregation.md))。
   - 点に値を付けるなら、点を含む画素の値を読む。点が画素の境界にあるとき、点の位置の精度が画素より粗いときは、周りの画素の値の幅も書く。
6. 数える。全ての単位が 1 行ずつ出ていて、`status` が ok でない単位 (`no_valid_pixels`、`outside_raster`、`no_pixel_centre`、`empty_geometry`) を全部見る。単位ごとに、有効、NoData、範囲外の画素 (`cells_*`) と面積 (`area_*_km2`) を書く。有効な画素の面積と単位の面積 (`unit_area_km2`) を比べ、離れていれば、規則の近似か、NoData の多さか、範囲外かを分ける。
7. 量なら総量を確かめる。単位の合計と、全ての単位を合わせた範囲のラスタの合計 (`raster_total_in_units`) を比べる。重なる単位は同じ画素を 2 回数える (`counted_twice`)。差が許す幅 (`--tolerance`) を超えると、スクリプトは終了コード 2 で止まる。合わないまま先に進まない。別の資料の総数 (国勢調査など) があれば並べ、差を書く。
8. 時間の次元があるなら (月ごと、日ごとのスライス)、期間へのまとめ方を値の種類で決める。量は足し、率は日数を掛けて足し、状態は時間で重みを付けて平均する。`scripts/aggregate_time.py` に、スライスの表 (path、start、end、時間帯つき) と種類を渡し、画素ごとの覆われた割合 (`coverage`) を見る。月の長さ、閏年、欠けた月、時間帯の境界、空間と時間の順序は [time-aggregation](references/time-aggregation.md)。
9. 解像度で動くかを確かめる。`scripts/coarsen_raster.py` で、同じラスタを 2 段以上粗くし (量は合計、水準は平均、クラスは最も多いクラス)、同じ単位に付け直して、単位ごとの値の変わり方 (最大と中央値) を書く。総量はほとんど動かなくても、小さな単位の値は大きく動くことがある。
10. 書き出す (下の節)。

## 種類で決まる方法

| 種類 | 例 | 粗くする | 単位への集計 | 使ってはいけない |
|---|---|---|---|---|
| 量 (連続値、足せる) | 人口、件数、降水量の総量 | ブロックの合計 | 合計。密度にするなら、有効な画素の面積で割る | 平均 (人口でなく密度になる)、最近傍と双一次 (画素の面積の比で総量が変わる) |
| 水準 (連続値、足せない) | 標高、気温、密度、確率 | ブロックの平均 | 面積で重みを付けた平均、最小、最大 | 合計 (面積で値が増える) |
| クラス | 土地被覆、都市化度、行政区のコード | ブロックで最も多いクラス | クラスごとの面積の割合 | 平均、双一次 (存在しないクラスができる) |

再投影しないで済むなら、しない。単位の座標をラスタの CRS へ移せば、値は 1 度も補間されない。再投影するなら、上の表の方法を使い、前後で総量 (量)、値の範囲 (水準)、クラスの集合 (クラス) を比べる ([resampling](references/resampling.md))。

## NoData、0、範囲外

この 3 つは別のもの。黙って 0 に置き換えない。

- NoData: ラスタの中で、値が無いと宣言された画素。観測が無い、海、人が住んでいない、など意味はデータで違う。
- 0: 測って 0 だった画素。人口 0 の画素は人口の合計に影響しないが、平均や密度の分母には入る。
- 範囲外: 単位がラスタの範囲から出ている部分。

平均や割合は、有効な画素だけで計算し、NoData と範囲外の画素の数と面積を並べて書く。NoData を 0 と読んでよいのは、データの説明でそう決まっているときだけ。そのときも、読み替えたことを書く。

## 面積と CRS

経緯度の度を面積に使わない。経緯度のラスタでは、画素の面積は緯度で変わる (1 度の画素は、赤道で約 12,300 km²、北緯 60 度で約半分)。`aggregate_raster.py` は、画素の面積を楕円体の上で行ごとに測る。投影されたラスタでは、CRS の長さの単位をメートルに直して測る。単位の面積は、単位の多角形を経緯度に直して、楕円体の上で測る。

## 書き出すもの

- ラスタ (版、時点)、手順 3 で決めた画素の意味と、確かめた方法 (説明か実測か推測か)
- 単位の表 (版)、単位の CRS、単位あたりの画素の数の分布
- 種類 (量、水準、クラス)、集計の方法、画素を面に入れる規則
- `status` ごとの単位の数と、ok でない単位の一覧
- 単位ごとの有効、NoData、範囲外の画素の数と面積
- 量なら総量の照合 (ラスタの合計、単位の合計、差、2 回数えた分、NoData の面積)。別の資料の総数との差
- 解像度を変えたときの、単位ごとの値の変わり方
- 時間の次元があれば、スライスの期間と時間帯、種類 (量、率、状態)、期間、覆われた割合、欠けたスライスの扱い
- 道具の版 (rasterio と GDAL、pyproj、shapely)
