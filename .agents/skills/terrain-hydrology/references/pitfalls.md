# 落とし穴と罠

どれも、エラーも警告も出ずに違う答えになる。測った日と版を添える。測っていないことは未確認と書く。

## 地形と範囲

### 流域が範囲の端で切れて、公表値に偶然近くなる

2026-11-06、AW3D30 v4.1 を東経 138.70〜139.35 度、北緯 35.35〜35.75 度で切ると、相模ダムの流域は 1,003.4 km² (国土交通省の 1,016 km² に対し -1.2%) で、一見よく合った。`edge_cells` は 130 で、流域は範囲の西の端で切れていた。東経 138.55〜139.45 度、北緯 35.25〜35.85 度に広げると端から離れ、1,112.4 km² (+9.5%) になった。切れた分と、次の節の閉じた盆地の分が、たまたま打ち消し合っていた。公表値との一致を、範囲が足りていることの証拠にしない。`edge_cells` が 0 になるまで広げてから比べる。

### 閉じた盆地が埋められて、隣の流域に足される

窪地を全部埋める処理は、外へ川の流れ出ない湖や盆地も、縁を越えてどこかへ流す。富士山の北麓の河口湖、西湖、精進湖、本栖湖は、AW3D30 の上では、4 つとも相模ダムの流域に入った (2026-11-06)。埋めた深さは最大 89 m だった。4 つの湖へ集まる面積は、河口湖 108.2 km²、西湖 27.6 km²、精進湖 21.1 km²、本栖湖 25.2 km² だった。

深さの閾値 (一定より深い窪地は埋めない) では分けられない。相模川へ流れ出る山中湖も、DSM の上では深さ 43 m の窪地に見えた。湖の面が DSM で正しく表されないためと考える (未確認)。閉じた盆地は、資料で確かめて点で渡す (`--sinks`)。

河口湖は、自然には流れ出ないが、1994 年に完成した嘯放水路で桂川の支川の宮川とつながっている。国土交通省の相模川の概要は、河口湖の浸水を流域の出来事として書いている (p.54〜64)。人工の水路でつながった湖をどちらに数えるかは、比べる相手の定義に合わせる。西湖、精進湖、本栖湖を国土交通省の流域面積に含めるかは、概要からは分からなかった (未確認)。この 3 つを sink にしたときの差は、相模ダム +2.2%、城山ダム -0.2% だった。この組み合わせは差を見た後に決めたので、評価としては甘い。

### DSM の上の流れ

AW3D30 は DSM で、建物や木の上の高さを含む。山地の流域界には使えたが、市街地では建物が流れを堰き止め、道路の溝を消す。湖の面も平らにならない。市街地の流れと HAND は DTM で作る。DSM のまま作ったなら、そう書く。

### CRS と面積

- 経緯度のままでは、セルの面積が緯度で変わる。`hydro.py` は止める。
- Web メルカトル (EPSG:3857) は、北緯 35 度で面積を約 1.5 倍にする。`hydro.py` は面積の尺度を 9 点で測り、1 から 0.02 より離れると止める。
- CRS がメートルでない (米国測量フィートなど) と、km² の換算が狂う。止める。
- CRS の無い GeoTIFF がある。JAXA Earth の月別 GSMaP の COG には CRS が無く、AW3D30 v4.1 の COG にはあった (2026-11-06)。メタデータ (STAC の `proj:epsg`) から付けてから使う。

## 流向

### pyflwdir の向きは最急降下ではない

pyflwdir 0.5.12 の `from_dem` と `dem.fill_depressions` が返す D8 は、隣のうち最も低いセルへ向く。落差を中心間の距離で割らない。谷の横の斜面 (横へ 1 m、斜め下へ 1.1 m 下がる) で、最急降下なら横 (傾き 0.1) へ流れるところを、斜め (傾き 0.078) へ流した。合成の V 字の谷では、内側 1,131 セルのうち 1,092 セルで最急降下と向きが違った。流域の面積はほとんど変わらないが、流れの道と HAND が変わる。`hydro.py` は、埋めた面の上で最急降下を取り直し、下りの無いセルだけ pyflwdir の向きを使う。

### 削る (breach) と埋める (fill) で面積が変わる

whitebox_workflows 2.0.6 の `breach_depressions_least_cost` (残った窪地は埋める) と `fill_depressions` で、同じ DEM の相模ダムの流域が 973.0 km² と 1,006.4 km² になった (狭い範囲、2026-11-06)。どちらが正しいかは、この比較だけでは決められない。方法を書き、比べるなら同じ方法で比べる。

## 流出点

### 範囲の中で集水面積の最大のセルに寄せると、下流へ飛ぶ

ダムの点を、半径 300 m の中で集水面積の最大のセルに寄せると、ダムより下流のセルを拾う。合成の谷で、谷の脇 3 セルの点は、最寄りの川のセルでなく 10 行下流のセルに寄った。`hydro.py` は、集水面積が閾値以上のセルのうち最も近いものに寄せる。閾値を小さくしすぎると、近くの小さな支川に寄る。相模川では `--snap-min-km2 50` で、寄せた距離は 0〜67 m だった。

### 入れ子の流出点

pyflwdir の `basins` に複数の点を一度に渡すと、各セルは下流で最初に出会う点の流域になる (上流のダムの流域は、下流のダムの流域から抜かれる)。`hydro.py` は点ごとに流域を作るので、下流の流域は上流を含む。

## ツールの罠

### pyflwdir: 自分で窪地を指定すると、範囲の端が流出口でなくなる

`dem.fill_depressions(..., idxs_pit=...)` に点を渡すと、既定の `outlets='edge'` が効かなくなり、渡した点だけが流出口になる (0.5.12、2026-11-06)。湖 4 つを渡したら、範囲全体が河口湖 (4,479.8 km²) と本栖湖 (904.0 km²) へ流れ込んだ。`hydro.py` は、範囲の端と NoData の隣のセルを一緒に渡す。

### whitebox_workflows: 向きのラスタからの集水量が 32,767 で止まる

whitebox_workflows 2.0.6 の `d8_flow_accum` に、`d8_pointer` の出力 (int16) を `input_is_pointer=True` で渡すと、集水量が 32,767 (int16 の最大) で止まる。出力ファイルは float32 で、エラーも警告も無い。相模川の狭い範囲で 9,892 セルが 32,767 に張り付いた。`out_type="ca"` でも止まる。DEM を渡せば止まらない (最大 1,371,517 セル)。`test_hydro_crosscheck.py` がこの挙動を固定している。上流で直ればテストが落ちるので、この節を直す。

### whitebox_workflows 2.x の呼び方

- `env.fill_depressions(...)` のような平らな呼び方は、`RuntimeError: Flat WbEnvironment tool methods are disabled in this build` で止まる。`env.hydrology.fill_depressions(dem=...)` のように分類から呼ぶ。
- 位置引数は受け付けない (`category tool calls only accept keyword arguments`)。
- `watershed` の流出点はベクタで、CRS が要る。GeoPackage は通り、ラスタは `Unknown or unsupported vector format`、GeoJSON の `crs` メンバーは読まれず `pour_points vector has no CRS metadata` で止まった。
- 有償の拡張があり、`describe_tool(..., include_locked=True)` でロックされたツールも見える。このスキルで使う関数は、ライセンスキーなし (`license_type()` は `WbW`) で動いた。

### 旧 WhiteboxTools の Python パッケージ (whitebox) は使わない

PyPI の `whitebox` 2.3.6 は、初めて使うときに WhiteboxTools の本体を zip で取りに行く。取得先は whiteboxgeo.com か、第三者の GitHub リポジトリの `raw/master` で、版が固定されず、チェックサムの照合も無い (`download_wbt.py` を読んだ、2026-11-06)。同じコマンドで同じ本体が入る保証が無い。

## 環境の罠

anaconda の `GDAL_DATA`、`PROJ_LIB`、`PROJ_DATA` が設定されていると、uvx で入れた rasterio が別の版の `proj.db` を読み、`CRSError: The EPSG code is unknown` で止まる。`env -u GDAL_DATA -u PROJ_LIB -u PROJ_DATA uvx ...` で流す。
