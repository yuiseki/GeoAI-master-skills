# 文献の扱い

論文、著者、DOI、URL、主張を推測で補わない。文献の実在だけでなく、本文で述べる内容を実際に読んで確かめたものだけ引用する。project の既存資料に文献があっても、参照先を確認できなければ内容の要約に使わない。

文献調査はこの執筆スキルの必須工程ではない。十分な確認済み文献が無ければ、Introduction または Discussion に「関連研究は十分に調査していない」と書く。References には確認済みのデータ・方法・文献だけを載せ、空の書誌事項や仮の DOI を置かない。

本文の外部知識には近くに Markdown リンクを付ける。References に載せるなら、同じ資料と分かる題名、発行元または著者、年または版、URL を、確認できた範囲で書く。データセットの版や取得日は、一般的な配布ページではなく project で実際に用いたものへ結び付ける。確認できない書誌要素は作らない。
