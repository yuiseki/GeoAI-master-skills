# capture@k: 面積の予算で地図を採点する

## 定義

試験の期間に事象のあったセル (陽性) のうち、地図のスコアで上位 k の割合のセルに入ったものの割合。

```math
\mathrm{capture@}k = \frac{\sum_{i \in \mathrm{top}\,k} y_i}{\sum_i y_i}
```

$y_i$ はセル $i$ が陽性なら 1。件数で数えるなら $y_i$ に事象の件数を入れ、事象の何割が上位 k に入ったかになる。セルの面積が同じなので、上位 k は面積の予算そのもの (100 万セルの 5% は 5 万セル、100 m のセルなら 500 km²)。でたらめに選んだ地図の期待値は k。陽性の割合が k より大きいと、どの地図でも 1 に届かない (下の上限)。

`scripts/score_risk_map.py` の `capture` は、上位 k の切れ目にかかるセルを、かかった割合で数える (10 セルの 15% は、1 番目のセル全部と 2 番目の半分)。ブロックの引き直しで重みを付けたときも同じ規則で切る。重み 2 のセルを 2 回並べた場合と一致することを、テストで確かめてある。

## 同点の崩し方で値が変わる

人口や密度で並べる基準は、0 のセルが多く、同点だらけになる。同点のまま並べると、表の並び (番号の順) で上位が決まる。

合成の例 (`numpy`、種 0、2026-10-26)。10 万セルの 75% は人がいない。事象は人のいるセルで 0.02、いないセルで 0.002 の確率で起き、陽性は 664 セル (26.4% は人のいないセル)。「人がいるか」だけの地図 (25% のセルが 1、75% が 0) を採点した。

| 同点の崩し方 | capture@5% | capture@30% |
|---|---:|---:|
| 陽性が先に並ぶ表の順 | 0.736 | 1.000 |
| 陽性が後に並ぶ表の順 | 0.000 | 0.736 |
| 種を変えた乱数 (20 回の平均と標準偏差) | 0.152 (0.0102) | 0.753 (0.0039) |

同じ地図が、表の並びだけで 0.000 から 0.736 まで動く。`rank_order` は、スコア、副キー (人口なら 2 km の人口など、基準ごとに先に決める)、種を固定した乱数の順に並べる。どの地図も同じ規則で崩す。乱数の部分を外すとテストが落ちることを確かめてある。

```python
import numpy as np, score_risk_map as sr
rng = np.random.default_rng(0)
n = 100_000
pop = np.where(rng.random(n) < 0.75, 0.0, rng.gamma(1.0, 50.0, n))
pos = rng.random(n) < np.where(pop > 0, 0.02, 0.002)
binary = (pop > 0).astype(float)
first = np.argsort(-(binary + pos * 1e-9), kind="stable")
print(sr.capture(first, pos, 0.05), np.mean([sr.capture(sr.rank_order(binary, seed=s), pos, 0.05) for s in range(20)]))
```

## 区間: ブロックを引き直し、上位 k を決め直す

近いセルの事象は似る (同じ群れ、同じ集落)。セルを独立とみて区間を付けると狭すぎる。空間の依存が届く範囲より大きなブロック (10 km 四方など) を、復元抽出で引き直す。引き直した標本の中で、上位 k を毎回決め直す (`bootstrap_diff`)。地図どうしの差は、同じ引き直しの重みで両方を採点して取る。

- ブロックが少ないと区間は不安定になる。ブロックの数を書く。
- 試験の期間が 1 つなら、区間は空間の揺れだけで、期間の揺れ (別の年なら違う) は入らない。期間を 2 つ以上試験にして、向きがそろうかを見る。

## 粗い単位では上限が下がる

セルを 5 × 5、10 × 10 にまとめると (`coarsen`。陽性は中のどれかが陽性、確率のスコアは 1 − Π(1 − p)、確率でないスコアは平均)、陽性の割合が上がる。陽性の割合が s なら、capture@k の上限は min(1, k / s)。s が 0.1147 なら 0.436、0.2473 なら 0.202。粗い単位の値を、細かい単位の値と並べて「下がった」と読まない。上限 (`oracle`) と並べる。

## 補助の指標

- AUC は全てのセルの順位を見るので、予算の外の順位の違いも点数になる。陽性がまれだと、ほぼ全て 0.9 を超え、地図の違いが見えにくい。
- 平均適合率 (AP) は上位の当たりを重く見るが、予算の大きさは決めない。
- 確率の当てはまり (Brier、予測の平均と実際の割合) は、期間の水準が変わると大きく外れる。順位の評価とは別に書く。

## 手法の確かめの段

| 段 | 状態 |
|---|---|
| 仮定 | セルの面積が同じ (投影座標系の正方形)。陽性は試験の期間のもの。同点は副キーと乱数で崩す |
| 小さい既知解 | 済み。完全な地図、端のセルの割合、件数で数える場合、粗い単位の手計算 (`test_score_risk_map.py`) |
| 合成で壊す | 済み。同点を乱数で崩さない、端のセルを丸ごと数える、のそれぞれでテストが落ちる |
| 外部の実装との照合 | 重みを、セルを繰り返した総当たりと照合した。capture@k の確立した実装は見つけていない (未確認) |
| 実データ | 秋田県の例 ([history-and-level](history-and-level.md))。環境変数で流す実データのテストは無い |
| 使えない条件 | セルの面積が違う単位 (行政区など) では、上位 k の数は面積の予算にならない。面積で重みを付けるなら、`capture` の重みに面積を入れる (未確認) |
