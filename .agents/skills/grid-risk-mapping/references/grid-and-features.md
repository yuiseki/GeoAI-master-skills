# 格子と、セルへの特徴量の付け方

## 格子

- 投影座標系 (メートル) の正方形にする。経緯度の格子は、緯度でセルの面積が変わり、面積の予算が揃わない。日本なら平面直角座標系の、その地域の系。
- セル (ix, iy) は x0 + ix × size ≤ x < x0 + (ix + 1) × size。行 0 が南。範囲の境界にちょうど乗る点も、その範囲のセルに入るように、セルの数を floor(幅 / size) + 1 にする (`Grid.from_bounds`。境界の点が外に出る作り方を、テストで落とした)。
- 範囲の内外は、セルの中心が面に入るかで決める (`cells_inside`)。面の一部だけにかかるセルは、中心が外なら入らない。セル数 × セルの面積と、面の面積を照合する。
- 行政区の面に、港の水面などの海が入っていることがある。土地被覆の水域の割合や、標高の値の有無で、水面のセルを数えて書く。水面のセルは、リスクが低く出るが、面積の予算の分母に入る。

## ラスタを付ける (`scripts/raster_to_grid.py`)

100 万セルを 1 つずつ多角形として測ると遅い。画素の中心を格子の座標系に移し、入ったセルで数える。ラスタは再標本化しない。値の種類で集め方を変える。

| 種類 | 例 | セルに入れるもの |
|---|---|---|
| クラス | 土地被覆 | クラスごとの画素の割合 (有効な画素の中で) |
| 量 | 人口 | 画素の合計。格子の外に落ちた分を数え、ラスタの窓の合計 = 格子の上 + 格子の外 を確かめる |
| 水準 | 標高 | 有効な画素の平均。画素の無いセルは NaN (0 にしない) |

画素の大きさがセルに近いと、セルに入る画素の中心の数が 1、2、4 とばらつき、セルの値がまだらになる。合成の例 (2026-10-26): 東西 71.4 m、南北 92.5 m の画素 (北緯 39.7 度の 3 秒角) に一様に 10 人ずつ置き、100 m のセルに入れた。本当は 1 セル 15.14 人だが、セルの値は 10 人 (19,836 セル)、20 人 (15,048)、40 人 (1,216) に割れた。周り 500 m (5 × 5) の合計でも最小 350、最大 480 で、平均に対して 34% の幅、1.1 km (11 × 11) で 15% の幅が残る。セル 1 つの値を特徴量や地図にせず、周りの合計を使い、残る幅を書く。

```python
import numpy as np, grid_cells as gc
px, py = 71.4, 92.5
X, Y = np.meshgrid((np.arange(int(20000 / px)) + 0.5) * px, (np.arange(int(20000 / py)) + 0.5) * py)
arr, _ = gc.Grid(0, 0, 200, 200, 100.0).sum_into(X.ravel(), Y.ravel(), np.full(X.size, 10.0))
print(np.unique(arr[5:-5, 5:-5], return_counts=True))
```

## 周りの集計

`box_sum` は (2r + 1) × (2r + 1) の正方形の合計で、格子の外は 0。`box_mean` は有効なセルだけの平均。累積和で計算し、総当たりのループと一致することをテストで確かめた。範囲の外 (隣の県など) のデータが格子に無いと、境界の近くの合計は少なく出る。格子を広げてデータを入れるか、少なく出ることを書く。

## 格子の上の距離 (`scripts/grid_distance.py`)

線 (道路、川) は 20 m ごとの点に分けて、通るセルに印を付ける。点 (建物の重心) は入ったセルに印を付ける。印のあるセルまでの距離を、ユークリッド距離変換で測る (セルの中心から中心、m)。

- 範囲の外の地物が数えられるように、格子を広げて (既定 50 セル) 測り、切り戻す。広げないと、範囲の外を通る道路は見えない (テストで確かめた)。
- 解像度はセル。セルの中のどこにあっても、地物はセルの中心にあるとみなす。
- 地物が 1 つも無ければ NaN。0 にしない。
- scipy の cKDTree で、印のあるセルの中心への最近傍の距離を総当たりで測り、一致を確かめた。線を点に分ける間隔を粗くすると、斜めの線がセルを飛ばし、テストが落ちる。

## 森の縁のような境目の特徴量

クラスの割合で森のセル (樹林 0.5 以上など) を決め、森の外では森までの距離、森の中では負の深さを入れると、1 つの列で境目からの位置を表せる。縁のセルは、森の中では −size、森の外の隣では +size になる。区切りで集計するとき、境目のセルの値がどちらの区切りに入るかを確かめる (−size を「森の中 100〜300 m」に入れてしまう誤りを、実データの集計で一度した)。
