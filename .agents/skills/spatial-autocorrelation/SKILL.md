# spatial-autocorrelation

近い単位どうしの値が似ている度合いを測る。正なら似た値が固まり、負なら高い値と低い値が交互に並び、0 付近なら場所と値が無関係。

## 手順

1. 測る値と、問いを書く。「平均寿命は近い国どうしで似ているか」「モデルの残差に空間の偏りが残っていないか」。残差は spatial-data-modeling の `compare_models.py --predictions-out` で書き出し、目的変数から予測を引く。
2. 近傍の取り方を決める。既定は k 近傍。コレログラムの距離の帯も決める。
3. 測る。
4. 近傍の数や帯を変えて、結論が変わらないかを見る。
5. 局所 Moran のクラスタは、既知の区分 (地域、所得階層) と照合する。区分をなぞっているだけなら、そう書く。
6. 書き出す。

## 何で測るか

| 統計量 | 答える問い | `scripts/spatial_autocorrelation.py` |
|---|---|---|
| global Moran's I | 全体として、近い単位どうしが似ているか | 既定で出す |
| コレログラム (距離の帯ごとの Moran's I) | どの距離まで似ているか | `--bands-km` |
| local Moran (LISA) | どの単位が、似た値の集まり (HH、LL) や、周りと逆の値 (HL、LH) にあるか | `--local-out` |

```sh
uvx --with duckdb --with scikit-learn --with pyarrow python scripts/spatial_autocorrelation.py \
  tmp/table.parquet ID VALUE --lon lon --lat lat --k 6 \
  --bands-km 0 500 1000 2000 4000 8000 --local-out tmp/lisa.parquet
```

## 近傍と重み

- 近傍は球面 (半径 6,371 km) の大円距離で取る。高緯度でも日付変更線をまたいでも正しい。
- k 近傍 (`--k`) は、単位の密度が場所によって違っても全ての単位に近傍がある。距離の帯は、疎な場所の単位に近傍が無いことがある (孤立した単位)。コレログラムでは、帯ごとに近傍のある単位の数を出す。
- 重みは行で標準化する (近傍の平均を取る)。孤立した単位の行は 0。
- 面の単位なら、面の中の 1 点 (`--geometry` で `ST_PointOnSurface`) を位置にする。国のように面積が大きく違う単位では、点どうしの距離は隣接の関係を粗くしか表さない。

## p 値

- 値を並べ替えて統計量を作り直し、観測した値より極端なものの割合を pseudo p とする。999 回なら最小は 0.001。
- 局所 Moran は、その単位の値を固定し、近傍の値を他の単位から抜き直す (条件付きの並べ替え)。
- p 値は、観測した向きの片側を折り返したもの。esda 2.10 の既定 (`alternative='directed'`) と同じ。esda は次の大きな版で両側に変えると予告していて、両側ならおよそ 2 倍になる。
- 局所 Moran は単位の数だけ検定するので、p ≤ 0.05 の単位の一部は偶然。補正していないことを書くか、補正する。

## 確かめたこと

テスト (`uvx --with duckdb --with scikit-learn --with esda --with libpysal --with pytest pytest scripts/test_spatial_autocorrelation.py`) で、同じ近傍を PySAL (esda 2.10.0、libpysal 4.15.0) に渡し、global Moran's I、その期待値、local Moran の値と象限が一致することを確かめている。孤立した単位がある場合も一致する。距離の帯の近傍は総当たりの haversine と一致する。近傍の木への経度と緯度の取り違え、行の標準化の省略、帯の下限の無視、象限の取り違えのそれぞれで落ちることを確かめてある。

## モデリングとのつながり

- 目的変数の自己相関が届く距離は、cross-validation-design の空間ブロックの大きさの目安になる。
- モデルの残差に自己相関が残っていれば、特徴量が拾えていない空間の構造があり、行を無作為に分ける評価は甘い。

実例として、WDI の 2022 年の平均寿命 (207 か国、位置は Natural Earth の `LABEL_X`、`LABEL_Y`、6 近傍、999 回の並べ替え、2026-10-10)。残差は、行を無作為に 5 分割した分割表で `compare_models.py` が出した予測との差を、3 つの repeat で平均したもの。

| 距離の帯 | 平均寿命の I | 線形の残差の I | hgb の残差の I |
|---|---:|---:|---:|
| 6 近傍 | 0.595 | 0.264 | 0.257 |
| 0〜500 km | 0.628 | 0.260 | 0.227 |
| 500〜1,000 km | 0.761 | 0.415 | 0.424 |
| 1,000〜2,000 km | 0.508 | 0.145 | 0.176 |
| 2,000〜4,000 km | 0.206 | 0.005 (p 0.29) | 0.032 |
| 4,000〜8,000 km | -0.165 | -0.029 | -0.048 |

- 1 人あたり GDP などの 3 つの特徴量で説明した後も、残差に I 0.26 の自己相関が残る。
- 線形の残差の自己相関は 2,000 km を超えるとほぼ 0 になる。cross-validation-design の空間ブロックの実験 (references/spatial.md) で、線形の R2 が 2,000 km から 4,000 km のブロックで下がり、その先で下げ止まったことと合う。
- local Moran で p ≤ 0.05 の単位は、高い値の集まり (HH) が欧州・中央アジアに 28、中東・北アフリカに 10、低い値の集まり (LL) がサブサハラ・アフリカに 43。既知の地域の区分をおおむねなぞっている。多重検定の補正はしていない。

## 書き出すもの

- 測った値と問い
- 近傍の取り方、帯、並べ替えの回数
- global Moran's I とコレログラム、近傍や帯を変えたときの結論
- 局所 Moran のクラスタと既知の区分との照合、多重検定の扱い
