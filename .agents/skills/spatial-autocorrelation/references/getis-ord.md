# Getis-Ord Gi* (ホットスポット)

各単位について、その単位と近傍の値の合計が、全体の平均から期待される合計よりどれだけ大きいか (小さいか) を z 得点で表す。z ≥ 1.96 をホットスポット、z ≤ -1.96 をコールドスポットと読むことが多い。`spatial_autocorrelation.py --hotspots-out`。

- 重みは二値 (近傍なら 1) で、その単位自身も含める (Gi* の星)。近傍は球面の距離の k 近傍 (`--k`)。
- z 得点は解析的な式で求める。PySAL の esda の `G_Local(transform="B", star=True)` の `Zs` と一致することをテストで確かめている。
- 局所 Moran (HH、LL、HL、LH) との違い: 局所 Moran は単位の値と近傍の値の組み合わせを見る (周りと逆の値も拾う)。Gi* は単位を含む近傍の合計だけを見るので、高い値の集まりと低い値の集まりだけを拾う。

## 気をつけること

- 近傍が重なるので、隣り合う単位の z は似る。ホットスポットの数を、独立な発見の数として数えない。
- 単位の数だけ検定しているので、z が 1.96 を超える単位の一部は偶然。スクリプトは正規近似の両側 p 値 (`p`) と、Benjamini-Hochberg (`p_fdr`) と Bonferroni (`p_bonferroni`) で補正した値を出す。ホットスポットは補正後の値で決める。
- 値が偏っていると、片側しか出ない。下の例のように 0 が多い値では、事件の無い所が集まっていても平均との差が小さく、コールドスポットは出ない。

## 例: 2024 年の紛争の事件

UCDP GED 26.1 の事件 (位置の精度 1〜2) を PRIO-GRID の 0.5 度格子で数え、2015〜2024 年に事件のあった 4,324 格子の 2024 年の値 (log1p、事件のある格子は 1,791)。格子の中心は PRIO-GRID の番号から求めた。8 近傍 (2026-10-10)。

- 全体の Moran's I は 0.397。
- z ≥ 1.96 は 656 格子、z ≤ -1.96 は 0 (多重比較の補正の前。補正後の数は未確認)。
- ホットスポットの格子が多い国 (格子の中の 2024 年の事件の最頻の国): ウクライナ 88 (平均 z 6.0)、シリア 57 (4.2)、エチオピア 54 (3.0)、ブラジル 48 (2.8)、ミャンマー 39 (3.2)、パキスタン 37 (3.4)、ブルキナファソ 33 (3.0)、メキシコ 32 (3.7)。

## General G (全体)

`spatial_autocorrelation.py --general-g`。0/1 の重み (近傍なら 1、自分は含めない) で、全ての異なる単位の組の積 x_i x_j の和のうち、近傍の組に落ちる割合。期待値 E[G] は、組のうち近傍の組の割合 (重みの和 / (n (n - 1)))。値は 0 以上でなければならない (件数、率、量)。負の値があると止まる。esda 2.10.0 の `G` と、G と E[G] が一致する (テスト)。

G と Moran's I は、問いが違う。Moran's I は、似た値が隣り合うか (高い値どうしでも低い値どうしでも)。G は、大きな値の積が隣り合う組に集まるか。

20 × 20 の格子で測った (2026-10-16、8 近傍、並べ替え 199 回)。

| 並べ方 | Moran's I | G / E[G] | G の pseudo p |
|---|---:|---:|---:|
| 一様に低い (1〜2) 背景に、高い値 (20〜21) の 6 × 6 の塊 | +0.86 | 3.46 | 0.005 |
| 一様に高い (20〜21) 背景に、低い値 (0.01) の 6 × 6 の塊 | +0.86 | 1.09 | 0.005 |
| 東ほど高い勾配に、低い値の塊 | +0.96 | 1.36 | 0.005 |
| 背景がばらばら (対数正規) で、低い値の塊 | +0.01 | 1.03 | 0.235 |
| 高い値と低い値が交互 (4 近傍、チェッカーボード) | -1 に近い | 0.5 未満 (テスト) | < 0.01 |

- 低い値の塊があっても、G は期待値を下回らなかった。低い値が固まると、残りの高い値どうしが隣り合う組が増えるため。G が期待値を下回るのは、高い値が低い値に囲まれて散らばるとき。
- 「G が低いので低い値が集まっている (コールドスポット)」とは読まない。低い値の集まりを見たいなら、局所の Gi* (z が負の単位) か、局所 Moran の LL を見る。
- 背景がばらばらだと、低い値の塊は G にほとんど表れない (1.03、p 0.235)。
