# spatial-pattern-exploration

探索で見つけた構造は、見つけ方の設定 (近傍の取り方、クラスタの数、尺度) を変えると変わることがある。設定を変えても残る構造だけを、構造と呼ぶ。

| reference | 問い |
|---|---|
| [spatial-autocorrelation](references/spatial-autocorrelation.md) | 値が空間的に固まっているか。どの距離まで似ているか。どこに高い値、低い値が集まっているか |

クラスタリング、次元削減、異常検知、点パターンの reference はまだ無い (TODO.md)。

## 手順

1. 探す構造を問いの形で書く。「平均寿命は近い国どうしで似ているか」「モデルの残差に空間的な偏りが残っていないか」。
2. どの空間で探すかを決める。地理の空間 (近い場所どうし) か、特徴量の空間 (似た値どうし) か。特徴量の空間で見つけた群が地図の上でも固まっているかは、別に確かめる。
3. 前処理を決める。尺度を揃えるか、対数を取るか、欠損をどうするか。その reference に従う。
4. 見つける。
5. 設定を変えて、構造が残るかを見る。近傍の数や距離の帯、クラスタの数、乱数の種、標本の取り直し (ブートストラップ)。
6. 使わなかった変数と照合する。見つけた群が既知の区分 (地域、所得階層) をなぞっているだけなら、そう書く。
7. 単位ごとの検定を多数行ったら、多重検定の補正をしていないことを書くか、補正する。
8. 書き出す。

## モデリングとのつながり

- 目的変数の空間自己相関が届く距離は、cross-validation-design の空間ブロックの大きさの目安になる。
- モデルの残差に空間自己相関が残っていれば、特徴量が拾えていない空間の構造があり、行を無作為に分ける評価は甘い。残差は spatial-data-modeling の `compare_models.py --predictions-out` で書き出せる。

## 書き出すもの

- 探した構造の問い、どの空間で探したか
- 前処理と設定 (近傍、帯、クラスタの数、種)
- 見つけた構造と、設定を変えて残ったか
- 既知の区分との照合
- 多重検定の扱い
