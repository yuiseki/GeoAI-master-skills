# 2 段階の浮動する圏域 (2SFCA)

Luo と Wang (2003) の 2SFCA。施設 j の供給 S_j、出発地 i の需要 P_i、i から j へのコスト c_ij、重み W(c) (圏域の中で 1、外で 0、または減る重み)。

1. 施設ごとに、届く需要で割る: R_j = S_j / Σ_k P_k W(c_kj)
2. 出発地ごとに、届く施設の R を足す: A_i = Σ_j R_j W(c_ij)

A は、需要 1 単位あたりの供給 (病床 / 人)。2 つの段で同じ W を使うと、Σ_i P_i A_i は、需要に届く施設の供給の合計に等しい (2 つの和の順序を入れ替えると Σ_j R_j Σ_i P_i W_ij = Σ_j S_j)。供給を 2 回数えず、配っている。`accessibility.py` はこの等式を毎回確かめ、合わなければ止まる。

## 仮定

| 仮定 | 中身 | 確かめられるか |
|---|---|---|
| 圏域 | 圏域の中の施設は使え、外は使えない (または重みで減る) | 一部。通う範囲の調査があれば |
| 全員が全ての施設を等しく使う | 圏域の中なら、どの施設にも同じように需要を出す | できない。混んだ施設を避ける行動は入らない (3SFCA の動機) |
| 容量は使える量 | 病床や医師の数がそのまま使える | 一部 |
| コスト | 表のコストが、実際の移動の負担を表す | 一部 |
| 範囲の外が無い | 範囲の外の需要と施設が計算に入っている | 範囲の外を足すかどうかで決まる ([boundary-effects](boundary-effects.md)) |

## 到達性との違い

到達性 (届くか、何分か) は、施設を共有する人の数を見ない。テストの例: 出発地 0 は 1 分先の施設を 1,000 人と共有し、出発地 2 は 9 分先の施設を自分だけで使う。最寄りまでのコストは 0 のほうが小さいが、取り分は 2 のほうが大きい。足りない場所を探す問いなら取り分を、届かない場所を探す問いなら到達性を報告する。両方を並べる。

## 小さい既知解

需要 3 地点 (100、200、100)、施設 2 つ (容量 10、6)、コスト (地点 × 施設) [[5, 20], [8, 9], [30, 4]]、圏域 10。

- 施設 0 は地点 0 と 1 に届く: R_0 = 10 / 300。施設 1 は地点 1 と 2: R_1 = 6 / 300。
- A = [1/30、1/30 + 0.02、0.02]。Σ P A = 3.33 + 10.67 + 2 = 16 = 10 + 6。

## 状態

| 出発地 | 意味 | A |
|---|---|---|
| served | 重みが正の施設がある | 正 |
| no_facility_in_catchment | 届く施設はあるが、全て圏域の外 | 0 |
| unreachable | コストの表に組が無い | 0 |

A が 0 の出発地を、「遠い」と「届かない」に分けて数える。施設は、allocated (需要に届く) と no_demand_in_catchment (需要に届かず、供給が配られない)。後者の供給は、配られなかった量として報告する。0 で割って無限大や NaN を広げない。

## 外部の実装との照合

`scripts/test_accessibility_crosscheck.py` で、PySAL の access 1.1.10 と照合した (2026-10-16、numpy 2.5.4、30 地点 × 6 施設、種 4 つ)。

| access | こちら | 結果 |
|---|---|---|
| `two_stage_fca(max_cost=12)` | 0/1 の重み、圏域 12 | 相対 1e-12 で一致。整数のコスト (圏域のちょうど端の組がある) でも一致し、どちらも端を内側に数える |
| `enhanced_two_stage_fca(weight_fn=step_fn({6: 1, 12: 0.5}))` | 段階の重み | 一致 |
| `weighted_catchment(weight_fn=gravity(scale=1, alpha=-1))` | 重力型 (累乗 1) | 一致 |
| `weights.gaussian(12)` | ガウスの重み | 定義が違う。access は exp(-d² / 2σ²) で、圏域の端でも 0.607 が残る。こちらは端で 0 になるように直した型 (Dai 2010)。照合していない |

## 手法を足す順序のどこまで済んだか

仮定、小さい既知解、合成データで壊す (到達性との違い、範囲の端、圏域、需要の定義)、外部の実装との照合までは済んだ。実データでの確かめは済んでいない。
