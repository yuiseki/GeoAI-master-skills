# 2 段階の浮動する圏域 (2SFCA)

Luo と Wang (2003) の 2SFCA。施設 j の供給 S_j、出発地 i の需要 P_i、i から j へのコスト c_ij、重み W(c) (圏域の中で 1、外で 0、または減る重み)。

1. 施設ごとに、届く需要で割る: R_j = S_j / Σ_k P_k W(c_kj)
2. 出発地ごとに、届く施設の R を足す: A_i = Σ_j R_j W(c_ij)

A は、需要 1 単位あたりの供給 (病床 / 人)。2 つの段で同じ W を使うと、Σ_i P_i A_i は、需要に届く施設の供給の合計に等しい (2 つの和の順序を入れ替えると Σ_j R_j Σ_i P_i W_ij = Σ_j S_j)。供給を 2 回数えず、配っている。`accessibility.py` はこの等式を毎回確かめ、合わなければ止まる。

## 仮定

| 仮定 | 中身 | 確かめられるか |
|---|---|---|
| 圏域 | 圏域の中の施設は使え、外は使えない (または重みで減る) | 一部。通う範囲の調査があれば |
| 全員が全ての施設を等しく使う | 圏域の中なら、どの施設にも同じように需要を出す | できない。混んだ施設を避ける行動は入らない (3SFCA の動機) |
| 容量は使える量 | 病床や医師の数がそのまま使える | 一部 |
| コスト | 表のコストが、実際の移動の負担を表す | 一部 |
| 範囲の外が無い | 範囲の外の需要と施設が計算に入っている | 範囲の外を足すかどうかで決まる ([boundary-effects](boundary-effects.md)) |

## 到達性との違い

到達性 (届くか、何分か) は、施設を共有する人の数を見ない。テストの例: 出発地 0 は 1 分先の施設を 1,000 人と共有し、出発地 2 は 9 分先の施設を自分だけで使う。最寄りまでのコストは 0 のほうが小さいが、取り分は 2 のほうが大きい。足りない場所を探す問いなら取り分を、届かない場所を探す問いなら到達性を報告する。両方を並べる。

## 小さい既知解

需要 3 地点 (100、200、100)、施設 2 つ (容量 10、6)、コスト (地点 × 施設) [[5, 20], [8, 9], [30, 4]]、圏域 10。

- 施設 0 は地点 0 と 1 に届く: R_0 = 10 / 300。施設 1 は地点 1 と 2: R_1 = 6 / 300。
- A = [1/30、1/30 + 0.02、0.02]。Σ P A = 3.33 + 10.67 + 2 = 16 = 10 + 6。

## 状態

| 出発地 | 意味 | A |
|---|---|---|
| served | 重みが正の施設がある | 正 |
| no_facility_in_catchment | 届く施設はあるが、全て圏域の外 | 0 |
| unreachable | コストの表に組が無い | 0 |

A が 0 の出発地を、「遠い」と「届かない」に分けて数える。施設は、allocated (需要に届く) と no_demand_in_catchment (需要に届かず、供給が配られない)。後者の供給は、配られなかった量として報告する。0 で割って無限大や NaN を広げない。

## 外部の実装との照合

`scripts/test_accessibility_crosscheck.py` で、PySAL の access 1.1.10 と照合した (2026-10-16、numpy 2.5.4、30 地点 × 6 施設、種 4 つ)。

| access | こちら | 結果 |
|---|---|---|
| `two_stage_fca(max_cost=12)` | 0/1 の重み、圏域 12 | 相対 1e-12 で一致。整数のコスト (圏域のちょうど端の組がある) でも一致し、どちらも端を内側に数える |
| `enhanced_two_stage_fca(weight_fn=step_fn({6: 1, 12: 0.5}))` | 段階の重み | 一致 |
| `weighted_catchment(weight_fn=gravity(scale=1, alpha=-1))` | 重力型 (累乗 1) | 一致 |
| `weights.gaussian(12)` | ガウスの重み | 定義が違う。access は exp(-d² / 2σ²) で、圏域の端でも 0.607 が残る。こちらは端で 0 になるように直した型 (Dai 2010)。照合していない |
| `three_stage_fca(max_cost=12, weight_fn=step_fn({12: 1}))` | 3SFCA、0/1 の重み | 相対 1e-10 で一致 |
| `three_stage_fca(max_cost=15, weight_fn=step_fn({5: 1, 10: 0.6, 15: 0.2}))` | 3SFCA、段階の重み | 一致 |

- access の `three_stage_fca` の既定の重みは 0/1 ではなく、段階 {10: 0.962, 20: 0.704, 30: 0.377, 60: 0.042}。最初は既定のまま 0/1 と比べて、4 つとも合わなかった。重みを明示すると一致した。
- access は選択の重み G の分母を、圏域で切る前の全ての施設について足す。圏域の外で 0 になる重み (0/1、圏域で終わる段階) なら、Wan らの定義 (圏域の中だけ) と同じ。圏域の外にも重みが残る関数では違う。
- M2SFCA は access に無い。手で計算した例と、供給を保存しないこと (下) で確かめた。

## 3SFCA と M2SFCA

- 3SFCA (`--method 3sfca`、Wan、Zou、Sternberg 2012): 出発地ごとに、届く施設への選択の重み G_ij = W_ij / Σ_k W_ik を作り、2 つの段の両方で W の代わりに G W を使う。多くの施設に届く需要が、各施設で丸ごと数えられなくなる。供給は保存される。
- M2SFCA (`--method m2sfca`、Delamater 2013): 1 段目は 2SFCA と同じ、2 段目は A_i = Σ_j R_j W_ij²。距離を 2 段目でも割り引くので、Σ P_i A_i は割り当てた供給より小さい。スクリプトは、その割合を出す。
- 手の計算 (テスト): 出発地 2 つ (需要 10 と 20)、施設 2 つ (供給 6 と 9)、出発地 0 は両方に、出発地 1 は施設 1 だけに届く 0/1 の重み。3SFCA の比は 1.2 と 0.36、アクセスは 0.78 と 0.36。M2SFCA は線形の重みの 2 地点の例で (1.5、0.375)、需要で重ねた和 2.25 は供給 3 より小さい。
- 大きな町が全ての施設に、村が 1 つの施設に届く例で、3SFCA は村のアクセスを 2SFCA の 1.5 倍超にした。町の需要が分けられ、村の近くの施設の混み方が減る。

## 実データ: 東京の小学校と子ども

供給は小学校 (OpenStreetMap の東京 23 区の凍結版、名前でまとめた学校、1 校を 1)、需要は令和 2 年国勢調査の 1 km メッシュの 0〜14 歳の人口 (dataset-discovery/references/estat-census-mesh-2020.md、`T001140004`、東京都と埼玉県の行をメッシュでまとめた)。メッシュの中心 (カードの式で緯度と経度、JGD2011) と学校の重心を EPSG:6677 にし、直線距離をコストにした。報告は 10 km × 8 km の範囲 (x −18,000〜−8,000、y −34,000〜−26,000、81 メッシュ、子ども 167,540 人) で、その外側 3 km の帯 (合わせて 210 メッシュ、子ども 380,450 人、学校 307) も競争に含めた。圏域 1 km の線形の重み (2026-10-16)。秘匿 (`*`) の行は無かった。

| 方法 | 需要で重ねた平均 | 10% 点 | 中央値 | 90% 点 | 割り当てた供給に対する Σ P A |
|---|---:|---:|---:|---:|---:|
| 2SFCA | 0.000883 | 0.000528 | 0.000879 | 0.00124 | 1 |
| 3SFCA | 0.000879 | 0.000586 | 0.000879 | 0.00119 | 1 |
| M2SFCA | 0.000438 | 0.000221 | 0.000441 | 0.00064 | 0.499 |

- 子ども 1 人あたりの学校の数は約 0.00088 (学校 1 校に子ども約 1,130 人)。210 メッシュのうち 9 は 1 km 以内に学校が無い (帯の中の、学校を区の外で数えていないメッシュを含む)。
- 3SFCA は、場所の間のばらつきを少し縮めた。M2SFCA は、供給の半分を距離で割り引いた。M2SFCA の値は、比の大きさを 2SFCA と比べるものではなく、場所どうしを比べるもの。
- 外側の帯を除いて、範囲の中のメッシュと学校だけで解くと、平均は 0.000818 (帯ありの 0.000883 より 7% 低い)。メッシュごとの値の、帯ありとの相関は 0.56、比は 0.08〜3.1 倍。範囲の端は、メッシュの単位で強く結果を変える (references/boundary-effects.md)。
- 需要を 1 km のメッシュの中心に置き、圏域も 1 km なので、メッシュの中のどこに子どもがいるかで、届く学校が変わる。この集計の粗さは測っていない。
- 私立の学校は学区で需要を分け合わない。全ての学校を同じ 1 として数えた。

## 手法を足す順序のどこまで済んだか

仮定、小さい既知解、合成データで壊す (到達性との違い、範囲の端、圏域、需要の定義)、外部の実装との照合、実データ (上) まで済んだ。実データの道のりの時間 (道路のネットワーク) では確かめていない。
