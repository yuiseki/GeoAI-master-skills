# spatial-accessibility-analysis

近くに施設があることと、その施設を使えることは違う。近くの病院を 1 万人が共有していれば、遠くても空いている病院のほうが取り分は大きい。このスキルは、移動のコストの表 (出発地 × 施設) と、需要と供給の量から、出発地ごとの取り分 (供給の単位 / 需要の単位、たとえば病床 / 人) を出す。

このスキルが答えるのは、「この需要の定義、この供給、このコストと圏域で、誰がどれだけ使えるか、足りないのはどこか」まで。移動のコスト (道のり、所要時間、面の上の累積コスト) を作ること、施設をどこに置くかを決めることは、このスキルの外。

## 手順

1. 需要と供給を問いの言葉で定義する。需要は「人口」と決めつけない。出産の医療なら出産の年齢の女性、学校なら学齢の子ども。供給は容量 (病床、医師、定員)。施設の数を容量の代わりにするなら、そう書く。
2. 移動のコストの表を用意する。出発地、施設、コストの 3 列 (CSV か Parquet)。表に無い組は届かない組として扱う。コストの単位 (分、m) と、その出どころ (道のり、時間、面の上の累積コスト、直線) を書く。直線の距離なら、川や山を越える近道が入ることを書く。
3. 範囲を決める。分析の範囲の外にも、圏域の 2 倍の幅で需要と施設を足し、計算には入れて、報告からは外す (`--report`、[boundary-effects](references/boundary-effects.md))。
4. 方法と圏域を決める。既定は 2SFCA (`--method 2sfca`)。圏域 (`--catchment`、コストと同じ単位) は、問いの基準 (2 時間以内など) か、実際に人が通う範囲から決め、固定の値を置かない。圏域の中で近いほど使われやすいなら、減る重み (`--decay`)。競争を入れない重力型 (`--method hansen`) は、取り分ではなく、近さで重み付けた供給の量になる。行政区ごとの比 (`--method ratio`) は、境界を越えて通う人を無視する。
5. 解く。

   ```sh
   uvx --with numpy --with duckdb python scripts/accessibility.py tmp/origins.csv tmp/facilities.csv tmp/costs.csv \
       --demand women_15_49 --supply beds --catchment 120 --report interior --sensitivity 60 90 150 \
       --out tmp/access.csv
   ```

6. 数える。出発地を、届く (圏域の中に施設がある)、圏域の外 (届くが遠い)、届かない (コストが無い) に分ける。施設を、需要に届く、届かない (供給が配られない) に分ける。需要で重み付けた取り分の合計が、配られた供給の合計と合うことをスクリプトが確かめる。
7. 感度を見る。圏域を 2〜3 段変え (`--sensitivity`)、取り分が 0 の需要の割合、取り分の分布、足りない場所の並びが変わるかを書く。需要の定義を変えて (総人口と対象の人口) 並べる。
8. 書き出す (下の節)。

テストは `uvx --with numpy --with duckdb --with pytest pytest scripts/test_accessibility.py`。手で計算できる 3 地点 × 2 施設の 2SFCA、需要で重み付けた取り分の合計が供給に合うこと (0/1、線形、ガウス)、近いが混んだ施設より遠いが空いた施設の取り分が大きいこと、届かないと圏域の外の区別、需要の届かない施設、段階の重み、ガウスと線形の重みの値、重力型、0 のコストでの累乗の拒否、地域ごとの比、圏域で状態が変わること、コストの表の重複や知らない組や負の値で止まること、コマンドの出力を確かめている。競争を外す、2 段目で重みを使わない、届かないと圏域の外を混ぜる、段階の重みの並べ方を誤る、のそれぞれで落ちることを確かめてある。

PySAL の access との照合は `uvx --with numpy --with duckdb --with pandas --with access --with pytest pytest scripts/test_accessibility_crosscheck.py` ([2sfca](references/2sfca.md))。

## まだできないこと

- 3 段階の浮動する圏域 (3SFCA、施設の選ばれやすさで需要を配る) と、修正型 (M2SFCA)。
- 交通の手段ごと (車、公共交通、歩き) に分けた圏域。
- 施設の質や開いている時間。容量の数字は、実際に使える量と違いうる。
- 移動のコストの不確かさ。

## 書き出すもの

- 需要と供給の定義 (列、出どころ、版、時点)。人口を需要にしたなら、それで良い理由
- コストの表の出どころと単位、届かない組の数
- 方法、圏域、重みの型と理由
- 出発地の状態ごとの数と需要、需要の届かない施設の数と供給
- 取り分の分布と、取り分が 0 の需要の割合 (報告の範囲で)
- 圏域と需要の定義を変えた感度
- 範囲の外に足した帯の幅と、報告から外した出発地の数
