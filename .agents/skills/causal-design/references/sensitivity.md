# 未観測の交絡への感度

正しい調整の集合を選んでも、それは DAG に描いた変数の中での話。描かなかった、測っていない交絡は残りうる。「全部調整したので因果」とは書かない。

## 隠れた交絡の強さを変える

2 値の隠れた交絡 U が、結果に γ を足し、処置ありと処置なしで U を持つ割合が δ 違うとき (調整した層の中で)、推定の偏りは γ × δ になる (線形で足し算の効果を仮定)。`bias_grid` は、γ と δ の組ごとに、推定から γ × δ を引いた値と、推定を 0 (か逆の符号) にするかを表にする。

テストの例 (`scripts/test_design_checks.py`):
- U は処置ありの 7 割、処置なしの 2 割が持ち (δ = 0.5)、結果に 1.2 を足す (γ = 1.2)。処置は何もしない。
- 平均の差は 0.6 で、ちょうど γ × δ。
- 推定 0.6 は、γ × δ ≥ 0.6 の隠れた交絡で消える。γ = 0.5 なら δ が 1 を超える必要があり、ありえない。γ = 1 なら δ = 0.6 で消える。

もっともらしい強さの決め方:
- 測った交絡の強さを手がかりにする。最も強い測った交絡 (たとえば 2010 年の人口密度) が持つ γ と δ と同じくらいの、測っていない交絡がありうるかを考える。
- その分野で知られている交絡 (需要の見込み、住民の所得) の大きさを、別のデータや文献から当てる。
- 結論が消える強さを書き、それがもっともらしいかを読み手が判断できるようにする。

## 負の対照

処置が動かせないはずの結果 (負の対照の結果、negative control outcome) や、結果を動かせないはずの処置 (負の対照の処置) があれば、それに対する「効果」を同じ調整で測る。0 から離れていれば、調整で除けていない交絡がある手がかりになる。

テストの例: 測った L で調整し、測っていない U は残る。負の対照の結果 N は U と同じで、処置では動かない。L の層で標準化した N の「効果」は 0.6 で、0 でなかった。同じ調整で出した本来の結果の推定にも、交絡が残っていると疑う。

負の対照の例:
- 駅の開業の前の年の地価 (開業は過去を動かせない)。開業より前に差があれば、駅の選ばれ方に交絡がある。
- 処置と関係のない死因 (医療施設の効果を見るとき)。

負の対照は、本来の結果と同じ交絡を共有していなければ意味が無い。それも仮定で、確かめられない。負の対照で 0 が出ても、交絡が無い証明にはならない。

## 感度の分析にできないこと

- 感度の分析は仮定を消さない。「γ × δ が 0.6 より小さければ結論は保たれる」という、別の形の仮定に言い換えるだけ。
- 隣への波及、支えの欠け、一貫性の崩れは、隠れた交絡の表では扱えない。それぞれ別に考える。
- 表の形 (線形、足し算、2 値の U) も仮定。効果が掛け算で効くなら、別の式が要る。E-value など、別の仮定に立つ感度の指標もあるが、ここでは実装していない。
