# causal-design

「駅ができると地価が上がるか」「避難所の近くでは被害が少ないか」は、関連でなく因果の問い。答えは、同じ単位が処置を受けた場合と受けなかった場合の結果の差だが、片方しか観測できない。観測できない側を、何の仮定で、どのデータから補うのかを先に決める。補えないなら、推定の手法を変えても補えない。

このスキルの問いは「この因果効果を、このデータと仮定から識別できるか」だけ。予測の精度を比べること、パネルの固定効果を推定すること、入れ子の構造を扱うこと、結論の頑健性を試すこと、特徴量の重要度を測ることは、それぞれ別の問い。予測の精度、重要度、固定効果の係数の良さは、どれも識別の根拠にならない。合流点で調整したモデルは、当てはまり (R2 = 1) が最も良いまま、効果 0 を -1 と答えた ([dag-adjustment](references/dag-adjustment.md))。

## 手順

1. 因果の問いを 1 行で書き、下の「設計の表」を埋める。埋められない欄があれば、そこで止まり、関連の問いとして書き直すか、欄を埋めるデータを探す。
2. 処置が決まった時点を決め、各変数がその前に決まったか後かを分ける。後に決まった変数は、総効果のための調整に使わない。
3. DAG を書く。データに入っていない変数 (需要、住民の意識、行政の判断) も書き、`latent:` に挙げる。`scripts/dag_check.py` で、巡回が無いこと、各変数の役割、開いたバックドアの経路、選んだ調整の集合が正しいか、測った変数だけで正しい集合があるかを確かめる。正しい集合が無ければ、調整では識別できない。
4. 支えを確かめる。調整の層 (地域、都市か農村か、格子) ごとに、処置ありと無しの両方の行があるかを `scripts/design_checks.py` で数え、地図に描く。片方しか無い層の効果は、データでなくモデルの形が答える。推定の対象を、支えのある層に限るなら、対象の集団が変わったと書く。
5. 隣への波及を考える。処置が隣の単位の結果を動かしうるなら (駅、道路、公園、規制、施設)、自分の処置だけで曝露を表せない。曝露の写像 (自分の処置、処置された隣の割合、最も近い処置までの距離) を書き、写像を変えて結論が動くかを見る ([spatial](references/spatial.md))。
6. 空間的な交絡を考える。処置も結果も同じ方向に空間的に偏っていれば、因果が無くても関連が出る。どの空間の細かさで交絡が変わるかを考え、調整の細かさと支えの両立を確かめる。残差の Moran's I を測っても、交絡が除けたかは分からない。
7. 未観測の交絡への感度を書く。測った交絡の強さを手がかりに、もっともらしい強さの隠れた交絡で結論が消えるかを `bias_grid` で表にする。負の対照 (処置が動かせないはずの結果) があれば、その「効果」を測る ([sensitivity](references/sensitivity.md))。
8. 判定を書く。識別できる (どの仮定のもとで)、対象を絞れば識別できる、識別できない (関連として報告する)、のどれか。推定の手法の選択は、識別できると判定した後の別の作業。

## 設計の表

| 欄 | 書くこと | 例 (駅の新設と地価) |
|---|---|---|
| 処置 (treatment、exposure) | 何を、いつ、どの単位が受けたか。強さや版の違い | 2015 年から 2020 年に駅が開業した 500 m 格子 |
| 結果 (outcome) | 何を、いつ測るか。処置より後か | 2023 年の公示地価の対数 |
| 推定の対象 (estimand) | ATE (全ての単位) か ATT (処置された単位) か、どの集団で | 開業した格子での ATT |
| 比べる反事実 | 処置された単位が処置されなかったら | 同じ格子に駅が開業しなかった 2023 年の地価 |
| 処置より前の変数 | 処置が決まる前に測られたもの | 2010 年の人口密度、地価、既存駅までの距離 |
| 調整する変数 | 正しい調整の集合と、その根拠 (DAG) | 2010 年の人口密度、地価 |
| 調整してはいけない変数 | 処置の後の変数、合流点、その子孫 | 開業後の乗降客数 (中間変数)、開業後の報道の数 (合流点) |
| 識別に要る仮定 | 交換可能性、支え、一貫性、SUTVA (と隣への波及の写像) | 鉄道会社の需要の見込みは 2010 年の変数で尽きる (確かめられない)。隣の格子の地価は、自分の格子の駅で動く (SUTVA が崩れる) |

## 書き出すもの

- 設計の表
- DAG (テキスト) と `dag_check.py` の出力。測っていない変数の一覧
- 層ごとの支えの表と地図、支えの無い層にいる対象の割合
- 曝露の写像と、写像を変えたときの結論の変わり方 (波及がありうる場合)
- 空間的な交絡について考えたことと、調整の細かさ
- 隠れた交絡の強さの表と、負の対照の結果
- 判定 (識別できる、対象を絞れば識別できる、識別できない) と、判定が頼る仮定。データで確かめられない仮定は、確かめられないと書く
