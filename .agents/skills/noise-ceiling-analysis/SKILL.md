# noise-ceiling-analysis

目的変数が測定のたびにばらつくなら、そのばらつきはどんな特徴量でも予測できない。モデルの点数は、天井と並べて初めて「どこまで届いたか」が分かる。

| reference | 天井の根拠 | 使える場面 |
|---|---|---|
| [repeat](references/repeat.md) | 同じ単位の独立な 2 回の測定 (別の期間、別の調査、期間の前半と後半) | 繰り返しの測定があるか、目的変数を 2 つに割れる |
| [counts](references/counts.md) | 件数の Poisson の雑音 | 事象が互いに独立に起きる件数 |
| [rounding](references/rounding.md) | 分かっている加工 (丸め、刻み) | 加工の大きさが公表されている |

## 手順

1. 目的変数がどう作られたかを書く。何回の測定の平均か、何件の事象の数か、どんな丸めがされているか (data-variable-semantics)。
2. 使える根拠を選ぶ。繰り返しの測定があるか、目的変数を割れるなら repeat を優先する。仮定 (Poisson、一様な丸め) に頼る方法は、仮定が外れると天井を高く出しすぎる。
3. `scripts/noise_ceiling.py` で天井を見積もる。
4. モデルの点数 (spatial-data-modeling) を天井と並べる。天井の何割に届いたかを書く。
5. 天井が低いなら、目的変数を作り直すことを考える (測定回数の多い単位に絞る、期間を長く集計する、雑音の少ない別の指標にする)。

## 天井と、もう 1 回の測定で予測した点数は違う

同じ単位の 2 回の測定の相関を r とする。雑音が独立で大きさが同じなら、雑音の無い本当の値を完全に知るモデルの R2 (天井) は r。もう一方の測定で予測した R2 は r の 2 乗で、予測に使う測定も雑音を含むぶん低い。r = 0.6 なら天井は 0.6、もう 1 回の測定で予測した R2 は 0.36。もう 1 回の測定の点数を天井と読むと、天井を低く見積もり、モデルが天井に届いたと誤って結論する。

## 書き出すもの

- 目的変数の作られ方と、選んだ根拠
- 天井の見積もりと、その仮定
- モデルの点数と、天井の何割に届いたか
- 天井が低いときの、目的変数の作り直しの案
