# 件数の Poisson の雑音から

事象が互いに独立に、単位ごとの起きやすさ λ で起きるなら、件数の分散は λ の分散と λ の平均の和になる。天井は 1 - 平均 / 分散。`noise_ceiling.py counts TABLE COUNT [--exposure COL] [--by COL]`。

- 分散が平均に近い (dispersion = 分散 / 平均 が 1 に近い) と、天井は 0 に近い。単位の間に起きやすさの違いがほとんど無く、件数の違いは偶然。
- 観測の長さや面積 (exposure) が単位ごとに違っても、Poisson の雑音の分散の平均は件数の平均なので、式は同じ。
- `--by` で、年や地域ごとの天井も出す。

## 仮定が外れると天井を高く出しすぎる

Poisson の仮定は、事象が互いに独立に起きること。紛争の事件のように 1 つの戦闘から多数がまとめて起きる事象では、偶然のばらつきは Poisson より大きく、天井を高く出しすぎる。UCDP の格子 × 年の事件数では、Poisson の天井が 0.997 だったのに対し、折半法では 0.870 だった (repeat.md)。

- まとまって起きる事象には、折半法を使う。
- 件数でなく死者数 (1 件の事件が多数の死者を含む) は Poisson ではない。上の格子 × 年の死者数に式を当てると天井は 1.000 になり、意味を持たない。
