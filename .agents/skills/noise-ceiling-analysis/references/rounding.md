# 分かっている加工から

値が刻み (step) に丸められているなら、丸めの誤差は幅 step の一様分布とみなせ、分散は step² / 12。天井は 1 - (step² / 12) / 分散。`noise_ceiling.py rounding TABLE COL --step STEP`。

- 丸めの誤差が一様とみなせるのは、本当の値が刻みに比べて広く散らばっているとき。値のほとんどが 1 つか 2 つの刻みに集まっていると、一様の近似は崩れる。
- 丸めは、たいてい他の雑音より小さい。丸めの天井が高くても、それは丸め以外の雑音が無い場合の上限にすぎない。
- 例: UNHCR の難民統計は 5 未満の値だけを 5 の倍数に丸める (dataset-discovery の references/unhcr-refugee-stats.md)。全ての値が丸められているわけではないので、`noise_ceiling.py rounding` はそのままでは当てはまらない。丸めの雑音の分散は、5 未満だった行にだけ加わる。件数が数十以下の流れを目的変数にするときに効く。
