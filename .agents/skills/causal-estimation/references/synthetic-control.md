# 合成対照

`scripts/synth.py`。処置された単位が 1 つ (1 つの州、1 つの地域) のとき、処置されない単位 (対照) の重み付き平均で、処置の前の結果を再現し、処置の後の反事実とする。

## 仮定と決めごと

| 項目 | 中身 |
|---|---|
| 識別 | 処置が無ければ、処置された単位と合成対照は、処置の後も同じ (潜在の) 要因に従って動いた |
| 対照の汚れ | 対照は処置の影響を受けず (波及が無い)、同じ時期に似た処置を受けていない |
| 重み | 0 以上、和が 1 (対照の凸結合)。処置の前の全ての期の結果を、等しい重みで合わせる (V は単位行列)。共変量で合わせる型、V を選ぶ型は無い |
| 解き方 | 和の制約を重い 1 行にした非負最小二乗 (厳密な有効制約法) |
| 推論 | 対照を 1 つずつ処置されたとみなし (処置された単位は対照から外す)、処置の後と前の RMSPE の比で順位を付ける。p = 順位 / (対照の数 + 1) |

凸結合なので、処置された単位が対照の範囲の外 (最も大きい、最も小さい) にあると再現できない。処置の前の RMSPE が、それを告げる。

## 小さい既知解

処置の前の 8 期で、処置された単位が対照 1 と 3 の 0.3 と 0.7 の凸結合なら、重みは (0、0.3、0、0.7) に戻る (誤差 1e-6)。

## 合成データで壊す

2 つの共通の要因 (乱歩) に、単位ごとの負荷、25 期のうち 15 期が処置の前、対照 20 (2026-10-16)。

| 世界 | 結果 |
|---|---|
| 効果 3 | 処置の後の差の平均 2.95 (20 回の標準偏差 0.25) |
| 処置された単位の負荷が対照の範囲の外 | 処置の前の RMSPE 1.42 (範囲の中なら 0.27)。処置の後の差は 4.07 で、効果 3 に 1 足りない分が乗る |
| 効果 0、対照 12 | 置換の p の平均 0.46、p ≤ 0.1 は 30 回中 13% (ほぼ一様) |
| 効果 1、対照 19 | 置換の p の平均 0.13、p ≤ 0.05 は 30 回中 67% |

- 置換の p は、対照の数で下限が決まる (対照 19 なら 0.05)。対照が少ないと、どんな効果でも小さな p は出ない。
- 当てはまりの悪い対照 (他から外れた単位) は、処置の前も後も外れるので、後の RMSPE だけで並べると上位に来る。比で並べると来ない (テスト)。

## 外部の実装との照合

`scripts/test_synth_crosscheck.py`。pysyncon 1.7.0 の `Synth.fit` に V を固定して与えた。pysyncon は比べる変数を単位の間の標準偏差で割ってから V を当てるので、V にその分散を与えて、同じ問題 (生の処置の前の結果、等しい重み) にした。重みが 1e-3 以内で一致し、こちらの損失は pysyncon 以下だった (対照 10、種 4 つ、2026-10-16)。

## 実データ: バスクのテロと 1 人あたり GDP

Abadie と Gardeazabal (2003) の例 (pysyncon の basque.csv)。スペインの 17 地域 (全国の合計は外す)、1955〜1997 年、処置は 1970 年 (テロの始まり)。`GEOAI_REALDATA=1` で、重みが pysyncon と一致することを確かめる。

| | 値 |
|---|---|
| 重み (処置の前の結果だけで合わせる) | マドリード 0.483、バレアレス 0.311、ラ・リオハ 0.206 |
| 処置の前の RMSPE | 0.076 (バスクの処置の前の標準偏差 0.757) |
| 1970 年以降の差の平均 | -0.89 (単位は 1986 年の千ドルとされる、未確認) |
| 置換 | 17 単位のうち 7 位、p 0.41 |

- Abadie と Gardeazabal は、投資や学歴などの共変量でも合わせ、カタルーニャ 0.85、マドリード 0.15 を得た。処置の前の結果だけで合わせると、重みは全く違う単位に乗る。合わせる変数で合成対照は変わる。
- 差は負だが、置換の中では 7 位で、他の地域にも同じくらいの差が出る。この設定では、テロの効果を置換で示せない。処置の前の結果だけで合わせると、当てはまりの良い (RMSPE の小さい) 置換が多く、比が大きくなるためと読める (推測)。

## 適用できない条件

- 処置された単位が対照の範囲の外にあるとき (処置の前の当てはまりが悪い)。
- 処置の前の期が短いとき (2 期未満で止まる)。少ない期に多くの対照を合わせると、当てはまりは良くても後の予測は外れる。
- 対照が波及や似た処置で汚れているとき。
- 処置された単位が複数。共変量や V の選択。偏りを補正する型 (augmented synthetic control)。どれも無い。

## テスト

`uvx --with numpy --with scipy --with pytest pytest scripts/test_synth.py`。凸結合の既知解、重みが単体に乗ること、効果の回復、範囲の外の単位の当てはまりの悪さ、大きな効果の置換の順位、効果 0 の置換の p の広がり、期と対照が足りないと止まること、置換が処置された単位を対照に入れないこと、置換を比で並べることを確かめている。制約の無い最小二乗にする、置換で処置された単位を対照に入れる、後の RMSPE だけで並べる、のそれぞれで落ちる。照合は `uvx --with numpy --with scipy --with pandas --with pysyncon --with pytest pytest scripts/test_synth_crosscheck.py`。
