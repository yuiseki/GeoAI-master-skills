# 波及の効果 (曝露の写像)

`scripts/spillover.py`。自分の処置だけでなく、隣の処置も結果を動かすとき、各単位の曝露を「自分の処置」と「隣に処置された単位がいるか」で決め、曝露ごとの潜在的な結果の平均を比べる (Aronow と Samii 2017)。

## 仮定と決めごと

| 項目 | 中身 |
|---|---|
| 曝露の写像 | 4 つの曝露 (処置で隣に処置なし、処置で隣に処置あり、対照で隣に処置あり、対照で隣に処置なし)。結果は自分の曝露だけで決まる |
| 割り付け | 分かっていること。ここでは各単位が独立に確率 p で処置される (ベルヌーイの無作為化) |
| 曝露の確率 | 設計を何度も引き直して (`--draws`)、単位ごとと、2 単位の組ごとに求める。端の単位や近傍の少ない単位は、確率が違う |
| 推定 | Hajek (観測された曝露の確率の逆数の重み)。対比ごとに、両方の曝露に入りうる単位に限り、入りえない単位を数える |
| 分散 | Aronow と Samii の保守的な推定量を、Hajek の平均からのずれに当てる。組が同時に曝露に入ることが無い組は Young の不等式で上から押さえる。対比の分散は (sd_1 + sd_0)² で、これも保守的 |

| 効果 | 比べる曝露 |
|---|---|
| 直接 | 処置で隣に処置なし - 対照で隣に処置なし |
| 波及 | 対照で隣に処置あり - 対照で隣に処置なし |

曝露の写像そのものが仮定。隣より遠くへ届く波及、隣で処置された数で強さが変わる波及は、この 4 つでは表せない。観察のデータ (割り付けが分からない処置) は扱わない。

## 小さい既知解

4 単位の道 (0 - 1 - 2 - 3)、p 0.4。全ての割り付け (16 通り) を数えた曝露の確率と、20 万回の引き直しの確率が 0.005 以内で一致した。

## 合成データで壊す

20 × 20 の格子 (上下左右の隣)、p 0.3、直接の効果 2、対照に隣の処置があれば +1、20 回の平均 (2026-10-16)。

| 推定 | 値 |
|---|---:|
| 処置群 - 対照群の単純な差 | 1.269 |
| 直接 (曝露の写像) | 1.993 |
| 波及 (曝露の写像) | 0.929 |

- 対照の多くは処置された隣を持ち、+1 を受けている。単純な差は、直接の効果からその分を引いた値になり、2 を大きく下回る。
- 端の単位の結果が高い世界では、曝露の確率の重みを外すと、波及が 1 から外れた (重みありは 1 ± 0.15。テスト)。端の単位は近傍が少なく、隣に処置が無い曝露に入りやすい。

同じ潜在的な結果のまま割り付けだけを引き直した 300 回 (14 × 14) では、推定の標準偏差 (直接 0.62、波及 0.386) に対して、標準誤差の平均は 0.716 と 0.409 で、保守的だった。95% 区間の被覆は、150 回で両方とも 0.93 以上 (テスト)。

2 単位がそろって曝露に入る確率の項を分散から外しても、標準誤差は 1% ほどしか変わらなかった (0.716 と 0.723)。独立な割り付けでは、曝露がそろう組は近傍どうしに限られるため。この項を外す mutant はテストで落ちない。

## 外部の実装との照合

探した範囲 (2026-10-16): Python で曝露の写像 (Aronow と Samii) の推定を持つ確立した実装は見つからなかった。R の interference パッケージはあるが、この環境に R が入っていない。外部の実装との照合はしていない。

代わりに、実装とは独立の 2 つで確かめた。

- 曝露の確率: 4 単位の道で、全ての割り付け (16 通り) を数えた厳密な確率と、引き直しの確率が 0.005 以内で一致する。数え上げは exposure を使うが、確率の推定とは別の計算。
- 推定と標準誤差: 潜在的な結果を固定し、既知の設計で割り付けだけを引き直したときの、推定の偏りと 95% 区間の被覆 (上)。

これらで捕まらない可能性: 曝露の決め方 (exposure) そのものの誤りは、数え上げも同じ関数を通るので捕まらない (3 単位の道の手で書いた答えのテストだけが守る)。分散の 2 単位の同時の確率の項は、外しても標準誤差が 1% しか変わらず、どの検証でも捕まらない。

## 適用できない条件

- 割り付けの仕組みが分からない処置 (観察のデータ)。
- 群ごとの割り付け、層別の割り付け (ベルヌーイ以外の設計)。設計を引き直す関数を差し替えれば同じ枠で扱えるが、実装していない。
- 隣より遠くへの波及、処置された隣の数で強さが変わる波及。
- 単位が 3,000 を超える (2 単位の組の確率を n × n で持つ)。
- 実データでの確かめは済んでいない。

## テスト

`uvx --with numpy --with pytest pytest scripts/test_spillover.py`。曝露の決め方、全ての割り付けを数えた確率との一致、単純な差が直接の効果を外し曝露の写像が直接と波及を戻すこと、割り付けの引き直しでの区間の被覆、曝露に入りえない単位を数えること、結果が近傍の数に沿うとき重みが要ること、対比が両方の曝露に入りうる単位に限られることを確かめている。重みを外す、両方の曝露に入りうる単位に限らない、のそれぞれで落ちる。同時の確率の項を外すと落ちない (上)。
