# 回帰による調整、IPW、AIPW

調整の集合 X で処置と結果の交絡が尽きる (条件付きの交換可能性) と設計で判定したときの推定量。3 つとも、同じ識別の仮定に立つ。違うのは、データのどこをモデルに頼るか。推定量を変えても、識別の仮定は変わらない。

## 仮定

| 仮定 | 中身 | データで確かめられるか |
|---|---|---|
| 条件付きの交換可能性 | X が同じなら、処置の有無は結果の潜在的な値と独立 | できない。設計 (DAG) と知識で決める |
| 支え (positivity) | どの X にも、処置ありと無しの両方がありうる (0 < p(X) < 1) | 一部できる。傾向スコアの分布と重みで見る |
| 一貫性、波及の無さ | 処置は 1 つの版で、自分の結果は自分の処置だけで決まる | できない。隣へ波及するなら、曝露の写像が要る |
| モデルの形 | 回帰による調整は結果のモデル、IPW は傾向のモデル、AIPW はどちらか一方が正しい | 一部できる。推定量の食い違い、バランス |

## 推定量 (`scripts/estimate_effect.py`)

p(X) は処置の確率 (傾向スコア) のロジスティック回帰、μ0(X) と μ1(X) は、処置なしと処置ありの行で別々に当てた線形の結果のモデル。

| 推定量 | ATE (全ての単位) | ATT (処置された単位) |
|---|---|---|
| ra (回帰による調整) | 全ての行の μ1 - μ0 の平均 | 処置群の y - μ0 の平均 |
| ipw (重みを正規化) | 重み 1/p の処置群の平均 - 重み 1/(1-p) の対照群の平均 | 処置群の平均 - 重み p/(1-p) の対照群の平均 |
| aipw (二重頑健) | μ1 - μ0 + t(y - μ1)/p - (1-t)(y - μ0)/(1-p) の平均 | 処置群で y - μ0、対照群で -p/(1-p)(y - μ0) の和を処置群の数で割る |

IPW の重みは、群ごとに合計で割る (Hajek の型)。割らない型 (Horvitz と Thompson の型) は、結果に定数を足すと推定が動く。正規化した型は動かない (テストで確かめている)。

## 小さい既知解

層 A (x = 0) に処置 3、5、対照 1。層 B (x = 1) に処置 12、対照 6、8、7。層ごとの差は 3 と 5。ATE は全ての行の数で重みを付けて (3 × 3 + 4 × 5) / 7 = 29/7、ATT は処置群の数で (2 × 3 + 1 × 5) / 3 = 11/3。x が層の印だけのとき、ロジスティック回帰は層ごとの処置の割合 (2/3 と 1/4) に一致し、3 つの推定量は層ごとの標準化と全く同じ値になる。単純な平均の差は 20/3 - 22/4 = 7/6。

## 合成データで壊す

効果 2、x は -2 から 2 の一様、処置の確率も結果も x の 2 乗に依る世界 (2 万行、種を変えて 20 回の平均)。「誤り」のモデルは、x の 2 乗の代わりに x を入れたもの。x の 2 乗とは線形の相関が無いので、誤りのモデルは何も調整しない。

| 結果のモデル | 傾向のモデル | 単純な差 | ra | ipw | aipw |
|---|---|---:|---:|---:|---:|
| 正しい | 正しい | 5.94 | 2.00 | 2.02 | 2.00 |
| 誤り | 正しい | 5.94 | 5.94 | 2.02 | 2.03 |
| 正しい | 誤り | 5.94 | 2.00 | 5.94 | 2.00 |
| 誤り | 誤り | 5.94 | 5.94 | 5.94 | 5.94 |

- AIPW は、どちらか一方が正しければ 2 に戻り、両方が誤りなら戻らない。二重頑健は「片方の誤りに耐える」であって、「どちらも雑でよい」ではない。
- 種ごとのばらつき (標準偏差) は、両方正しいとき ra 0.017、ipw 0.055、aipw 0.018。正しい傾向のモデルでも、IPW は回帰による調整の 3 倍ばらつく。

### 測っていない交絡

処置と結果の両方に効く u (結果に +3、処置の確率を上げる) を X に入れないと、3 つとも同じだけずれた (2 万行、真の値 2 に対して 3.08、3.08、3.08)。u の効果 × 処置群と対照群の u の割合の差は 1.05 で、ずれとほぼ一致した。推定量がそろうことは、交絡が尽きた証拠にならない。

### 重なりが乏しいとき

効果 2、y = 2t + x + 雑音、処置の確率 1 / (1 + exp(-k x)) で、k を大きくすると重なりが減る (4,000 行、30 回)。

| k | 処置群の重みの実効的な数の割合 | ra の標準偏差 | ipw | aipw |
|---:|---:|---:|---:|---:|
| 0.5 | 0.94 | 0.028 | 0.029 | 0.028 |
| 2 | 0.34 | 0.032 | 0.101 | 0.060 |
| 4 | 0.11 | 0.037 | 0.415 | 0.197 |

重なりが乏しいと、IPW と AIPW は大きくばらつく。回帰による調整はばらつかないが、それは重なりの無い所を直線の外挿で埋めているからで、正しい保証は無い (ここでは結果が本当に直線なので当たった)。

### 処置が地域で決まるとき

40 の地域に 50 行ずつ。処置も結果の衝撃も地域で共有する (効果 2)。行を独立とみなしたブートストラップの標準誤差は 0.089 (影響関数の標準誤差 0.087)、地域ごとに引き直すと 0.528。100 回の模擬で、95% 区間が真の値を覆ったのは、行のブートストラップで 31 回、地域のブートストラップで 96 回。処置や衝撃を共有する単位があるなら、その単位で引き直す。

## 外部の実装との照合

`scripts/test_estimate_effect_crosscheck.py` で、statsmodels 0.15.0 の `TreatmentEffect` (ra、重みを正規化した ipw、aipw) と照合した (2026-10-16)。傾向スコアは相対 1e-6、推定は相対 1e-6 (合成) と 1e-5 (実データ) で一致した。statsmodels の aipw は ATE だけなので、ATT の aipw は照合していない。statsmodels の `TreatmentEffect` は、処置の列が整数でないと ra で落ちた。

## 実データ: NSW の実験と観察の対照

職業訓練の無作為化実験 NSW の男性の処置群 185 人に、実験の対照 (260 人)、PSID の 2,490 人、CPS の 15,992 人を組み合わせた (データセットのカードは `dataset-discovery/references/nsw-lalonde.md`)。GeoAI の分析対象のデータではなく、推定量を検証するための benchmark として使う。調整の集合は、年齢とその 2 乗、教育の年数とその 2 乗、黒人、ヒスパニック、既婚、学位なし、1974 年と 1975 年の所得、それぞれが 0 かの印。実験の答えは 1,794 ドル。標準誤差は行のブートストラップ 300 回 (`GEOAI_REALDATA=1` で照合のテストが流れる)。

ATT:

| 対照 | 単純な差 | ra | ipw | aipw (標準誤差) | 対照の重みの実効的な数 | 最大の重みの割合 |
|---|---:|---:|---:|---:|---:|---:|
| 実験 | 1,794 | 1,820 | 1,795 | 1,801 (673) | 202 / 260 | 0.016 |
| PSID | -15,205 | 906 | 2,768 | 3,506 (2,122) | 11 / 2,490 | 0.248 |
| CPS | -8,498 | 1,263 | 1,593 | 1,496 (764) | 104 / 15,992 | 0.042 |
| PSID、p を 0.05〜0.95 に刈り込む | -898 | 411 | 982 | 1,286 (3,505) | | |
| CPS、刈り込む | 472 | 1,918 | 1,934 | 1,885 (860) | | |

- 実験の対照では、どの推定量も実験の答えのそばにある。
- PSID では、推定量が 906 から 3,506 まで割れた。対照の重みの実効的な数は 2,490 人のうち 11 人で、1 人の対照が重みの 25% を持つ。重み付けの後も、既婚と、1974 年と 1975 年の所得が 0 の印で、標準化平均差が 0.25 から 0.30 残った。推定量の食い違いと重みの偏りが、データが答えを支えていないことを告げている。
- 刈り込むと、PSID の処置群は 185 人から 137 人に減る。刈り込んだ後の推定は、処置群のうち比べる相手のいる人の効果で、実験の答えとは対象が違う。
- ATE は、PSID の組で処置群の重みの実効的な数が 2 人、CPS の組で 10 人になり、推定は -3,719 から -14,030 に散らばった。調査の大多数の人にとっての訓練の効果を、このデータは持たない。

## 適用できない条件

- 調整の集合で交絡が尽きない (測っていない交絡がある) とき。推定量を変えても直らない。
- 支えが無いとき。傾向スコアが 0 か 1 に張り付き、重みの実効的な数が小さく、推定量が食い違う。対象を絞る (ATT、刈り込み) なら、対象が変わったと書く。共変量で処置が分離していれば (どの行にも比べる相手が無ければ)、ロジスティック回帰が収束せずに止まる。
- 処置が二値でないとき (量、強さ、複数の版)。
- 隣へ波及するとき。自分の処置だけで曝露を表せない。
- 処置が時間で変わり、過去の結果が次の処置を決めるとき。
- 結果のモデルは線形、傾向のモデルはロジスティックに限る。柔軟な機械学習のモデルを入れるなら、交差フィット (ここでは実装していない) が要る。
- 標準誤差はブートストラップ。行か、指定したクラスタで引き直す。空間的に連続した依存 (クラスタで区切れない) は扱わない。
