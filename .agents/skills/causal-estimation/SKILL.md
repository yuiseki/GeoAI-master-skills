# causal-estimation

「駅ができると地価がいくら上がったか」のように、因果の効果の大きさを推定する。このスキルが答えるのは「識別できると判定した効果は、どれだけか、どれだけ確かか」。識別できるかどうか (処置、推定の対象、調整の集合、識別の仮定、DAG、支え、波及の写像) は、ここに来る前に決めておく。その設計の表が無ければ、ここで止まり、先に表を作る。

推定量は、識別の仮定を直さない。測っていない交絡があれば、回帰による調整も IPW も AIPW も同じだけずれる。推定量の役目は、識別できた効果を、データの支えの範囲で、モデルの誤りにできるだけ強く、正直な不確かさとともに出すこと。

| reference | 識別の型 | 中身 |
|---|---|---|
| [adjustment-weighting](references/adjustment-weighting.md) | 調整の集合で交絡が尽きる | 回帰による調整、IPW、AIPW。重なり、重み、バランス、地域で引き直す区間 (`scripts/estimate_effect.py`) |
| [matching](references/matching.md) | 調整の集合で交絡が尽きる | ATT の最近傍マッチング (戻して選ぶ)、同点、キャリパー、線形の偏りの補正、Abadie と Imbens の標準誤差、使われた対照の数 (`scripts/match.py`) |
| [did](references/did.md) | 平行な傾向 | 2 × 2、二方向の固定効果、Callaway と Sant'Anna の群 × 時点と集計、処置の前のセル (`scripts/did.py`) |
| [iv](references/iv.md) | 操作変数 (関連、除外、独立) | 2SLS、1 段目の F と偏決定係数、Anderson-Rubin の集合、LATE (`scripts/iv.py`) |
| [rdd](references/rdd.md) | 閾値での連続 | 鋭い RD と曖昧な RD の局所線形、帯域の感度、共変量の跳ね、偽の閾値、密度 (`scripts/rdd.py`) |
| [synthetic-control](references/synthetic-control.md) | 処置された単位 1 つと、要因の共通 | 処置の前の結果を合わせる凸結合の重み、処置の後の差、置換の順位 (`scripts/synth.py`) |

波及の効果は、まだ無い。識別の型がこれらなら、この表の推定量で代用しない。

## 手順

1. 設計の表を読み、推定の対象 (全ての単位の ATE か、処置された単位の ATT か、どの集団か)、調整の集合、調整してはいけない変数、処置の決まった時点を写す。表に無い変数を「精度のため」に足さない。調整してはいけない変数 (処置の後の変数、合流点) が入っていないかを確かめる。
2. 処置は 0 と 1 の二値にする。量や強さの処置、隣への波及があるなら、このスクリプトの範囲の外。
3. 傾向スコアを当て、重なりを見る (`scripts/estimate_effect.py` の出力の前半)。群ごとの傾向スコアの分布、0.05 と 0.95 の外の割合、ほぼ 0 か 1 の行の数、重みの実効的な数、最大の重みの割合。ATE を求めるのに処置群の重みの実効的な数が数人しかなければ、全体の効果をデータは支えていない。ATT にするか、対象を絞る。
4. 重み付けの前と後の、共変量の標準化平均差を見る。重み付けの後に 0.1 を超えて残る共変量があれば、傾向のモデルの形 (2 乗、交互作用) を見直すか、重なりの不足として書く。
5. 回帰による調整、IPW、AIPW を並べる。ATT なら、共変量でのマッチング (`scripts/match.py`、[matching](references/matching.md)) も並べ、使われた対照の数と、1 人の対照が何人分の相手になったかを見る。3 つが食い違うなら、結果のモデルか傾向のモデルが誤っているか、重なりが乏しい。都合のよい 1 つを選んで、他を隠さない。3 つがそろっても、測っていない交絡が無い証拠にはならない。
6. 不確かさを付ける。処置や結果の衝撃を共有する単位 (地域、市区町村、学校区) があれば、その単位で引き直す (`--cluster`)。行を独立とみなした区間は、地域で処置が決まるとき、真の値をほとんど覆わない。
7. 刈り込み (`--trim`) をするなら、残った処置群の数と特徴を書く。推定は、比べる相手のいる単位の効果に変わる。
8. 設計で書いた、測っていない交絡の強さの表と並べて結果を書く。推定値が、もっともらしい強さの隠れた交絡で消えるかを添える。

```sh
uvx --from 'duckdb>=1.5.5' --with numpy python scripts/estimate_effect.py units.parquet outcome treated x1 x2 x3 \
    --target att --cluster region --boot 500
```

## 書き出すもの

- 設計の表から写した、推定の対象、調整の集合、調整してはいけない変数
- 傾向スコアの群ごとの分布、0.05 と 0.95 の外の割合、重みの実効的な数、最大の重みの割合
- 重み付けの前と後の標準化平均差
- 単純な平均の差、回帰による調整、IPW、AIPW と、それぞれの区間 (どの単位で引き直したか)。食い違いと、その解釈
- 刈り込んだなら、残った対象と、対象が変わったこと
- 頼った識別の仮定と、データで確かめられない仮定。測っていない交絡への感度
- 適用できない条件に当たらないこと (二値の処置、波及なし、時間で変わる処置でない)。当たるなら、その推定は出さない
