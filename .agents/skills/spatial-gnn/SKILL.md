# spatial-gnn

感知器ごとの値の系列を、道路網のつながりを使って先まで当てる。グラフのモデルの点数が良くても、それが道路網から来たのか、系列のモデルの力なのかは、点数だけでは分からない。PEMS-BAY で再現した DCRNN (1 時間先の MAE 1.98 mph) から拡散を外すと 2.39 になり、差 0.41 がグラフの分だった。一方、15 分先の差は 0.08 しかなく、最後の値をそのまま答える基準が論文の深層学習の基準 (FC-LSTM) より良かった。基準と、グラフを外した同じモデルを、必ず同じ試験に並べる。

別の問いとの境界:
- 網の無い地点 (雨量計、気象観測所) の値を、距離で近い地点から当てるのは、時空間の値の予測の問い。ここでは道路や川のような、向きとつながりのある網の上の地点を扱う。
- 1 本の系列を先まで当てるだけなら、時系列の予測の問い。ここでは地点どうしのつながりを使う。
- 感知器の無い場所の値を当てるのは、ここでは扱わない (確かめていない)。
- 近傍の重みを統計 (自己相関、空間回帰) に使うなら、重みの設計の問い。ここでは学習に使うグラフを作る。

## 手順

1. 問いを 1 行で書く。どの網の、どの地点の、何の値を、何分先まで、何のために当てるか。使う場面が「今の値から先を当てる」なら、試験は学習の後の時期にする。
2. 値の表を数える。地点の数、時刻の数と間隔、期間、欠けの印 (0 か NaN か) と割合。欠けを 0 で入れているデータでは、0 を欠けとして採点から除く ([evaluation](references/evaluation.md))。
3. グラフを作って数える。道のりの距離から `distance_adjacency` で重みを作り、`graph_summary` で辺の数、孤立した地点、成分の数を数える。地点の順は値の表の列の順にそろえる。配布の隣接行列が pickle なら読まず、距離の表から作り直す ([graph](references/graph.md))。
4. 窓を作り、時刻順に 70、10、20% で分ける (`window_starts`、`split_counts`、`make_xy`)。
5. 基準を先に出す。最後の値 (`last_value`) と過去の平均 (`historical_average`) を、欠けを除いた MAE、RMSE、MAPE で、先ごとに (`masked_metrics`)。論文の値があれば並べ、合わなければ作り方の違いを書く。
6. 試走で 1 エポックの時間とメモリを測り、学習の予算 (エポックの上限、種の数) を、試験の点を見る前に書く ([dcrnn](references/dcrnn.md))。
7. グラフのモデル (`scripts/dcrnn.py` の `DCRNN`、K = 2) と、同じ設定で K = 0 にしたものを学習する。検証の MAE が最良のエポックを使う。
8. 試験で、各モデルの MAE と日ごとの区間 (`day_sums`、`boot_ratio`) を出し、K = 0 − K = 2 と基準 − K = 2 を、同じ点で対にした差 (`paired_day_sums`) と日ごとの区間で出す ([evaluation](references/evaluation.md))。
9. 差がどの点に集まるか (値が大きく変わる点、渋滞の点など) を `share_of_gain` で分ける。区切りは先に決める。決めずに見たなら探索と書く。
10. 書き出す。

## 書き出すもの

- 問い、データの版と期間、地点の数、欠けの割合
- グラフの作り方 (距離の種類、σ、切り捨て、向き) と `graph_summary` の数
- 分け方と、試験の期間 (日数)
- 基準とモデルの MAE (先ごと)、日ごとの区間、論文の値との比
- K = 0 − K = 2 と基準 − K = 2 の対にした差と区間
- 差の集まる点 (区切りを決めた時期を添えて)
- 学習の設定、予算、最良のエポック、計算の装置と時間、種の数
- 確かめていないこと
