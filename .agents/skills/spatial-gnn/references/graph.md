# グラフの作り方と確かめ方

## 道のりの距離から重みを作る

DCRNN の著者の `gen_adj_mx.py` と同じ式 (`distance_adjacency`):

  W_ij = exp(−(d_ij / σ)²)、σ = 有限の距離 d_ij の標準偏差、W_ij < 0.1 なら 0

- d_ij は感知器 i から j への道のりの距離 (直線距離ではない)。道路は向きを持つので、d_ij と d_ji は別の値になり、片方しか無いこともある。W は対称でない。
- 距離の表に無い組は 0。自分自身の距離 (0) が表にあれば W_ii = 1 になる。
- σ はデータから決まるので、感知器を足したり除いたりすると、全ての重みが変わる。学習と試験で同じ W を使う。
- 0.1 の切り捨ては、遠い組を落として行列を疎にする。σ と切り捨ての値は、PEMS-BAY では著者の値をそのまま使った。別のデータでは、近傍の数の分布を見てから決める。

著者の配る `adj_mx_bay.pkl` は pickle で、読むと任意のコードが動きうる。距離の CSV (`distances_bay_2017.csv`) から同じ式で作り直せる。感知器の順は、速度の表の列の順にそろえる。

## 酔歩の行列と、2 つの向き

`random_walk(W) = D_out⁻¹ W` は、各行を出ていく重みの和で割る。拡散畳み込みは、前向き P_f = random_walk(W) と後ろ向き P_b = random_walk(Wᵀ) の 2 つを使う (`diffusion_supports`)。前向きは上流の値が下流へ、後ろ向きは下流の値が上流へ届く。渋滞は下流から上流へさかのぼるので、両方が要る。

出ていく辺の無い感知器の行は 0 のままにする (0 で割らない)。

## 学習の前に数えること

`graph_summary` で数える:

| 量 | PEMS-BAY (325 感知器) |
|---|---|
| 向きのある辺 (対角を除く) | 2,369 |
| 平均の出ていく辺の数 | 7.29 |
| 入る辺の無い感知器 / 出ていく辺の無い感知器 | 17 / 12 |
| 辺の全く無い感知器 | 6 |
| 弱連結の成分 / 最大の成分の割合 | 7 / 0.982 |
| 逆向きの辺もある辺の割合 | 0.245 |

辺の全く無い感知器では、K を何段にしてもグラフの手がかりは届かない。グラフのモデルの差は、そういう感知器では 0 になる。成分が多い、孤立が多いなら、距離の表の範囲 (道路網の切り出し) と、感知器の ID の対応を確かめる。逆向きの辺が 4 分の 1 しか無いので、W を対称にすると別のモデルになる。

## 確かめていないこと

- 道のりでなく直線距離、または k 最近傍で作った W との比較。
- W を学習する方法 (Graph WaveNet の適応的な隣接行列など)。
- σ と切り捨ての値を変えたときの差。
