# 評価: 基準、欠けの扱い、日ごとの区間、グラフの効き

## 分け方

時刻順に、試料 (窓の始まり) の 70% を学習、10% を検証、20% を試験にする (`window_starts`、`split_counts`)。窓は 12 時刻の入力と 12 時刻の出力で、隣の試料と 23 時刻が重なる。境の近くの試料は、学習と検証、検証と試験で時刻を共有するが、著者の手順に合わせてそのままにした。比べるモデルは全て同じ試料で採点する。

PEMS-BAY では、学習が 2017-01-01〜05-07 ごろ、検証が 05-07〜05-25 ごろ、試験が 05-25〜06-30 ごろ (37 日)。試験は学習の後の時期で、季節をまたいだ当てはまりは測らない。

## 欠けの扱い

PEMS-BAY では、欠けた読みが 0 で入っている (割合 0.000031)。採点も学習の損失も、正解が 0 の点を除く (`masked_metrics`、`masked_mae`)。入力の 0 はそのまま入れ、標準化の平均と標準偏差にも 0 を含める (著者と同じ)。欠けの多いデータでは、入力の 0 が「速度 0」と読まれる。欠けの割合を先に数える。

## 基準

| 基準 | 関数 | PEMS-BAY の MAE (15、30、60 分) |
|---|---|---|
| 最後の値 | `last_value` | 1.5976、2.1789、3.0483 |
| 過去の平均 (同じ曜日、同じ時刻、直前の 4 週) | `historical_average` | 2.4394、2.4386、2.4372 |
| 論文の FC-LSTM (参考) | | 2.05、2.20、2.37 |
| 論文の過去の平均 (参考) | | 2.88 |

最後の値は、15 分と 30 分先では論文の FC-LSTM より良い。論文の基準の表だけを見て、深層学習の差を読まない。最後の値は必ず自分で出す。過去の平均は論文の値に戻らなかった (2.44 と 2.88)。作り方 (平均する週の数、欠けの扱い) が論文に書かれていないためで、自分の作り方を書いておく。

## 区間: 日ごとに引き直す

同じ日の時刻どうしは同じ渋滞、同じ事故、同じ天気を共有する。試料ごとに引き直すと区間が狭すぎる。試験の日ごとに、誤差の和と点の数を作り (`day_sums`)、日を引き直して和の比を取る (`boot_ratio`、2,000 回)。試験が 37 日なら、区間の材料は 37 個である。

## グラフの効き: 同じモデルから外す

グラフの効きは、同じモデルの拡散の段を K = 0 にしたもの (各感知器が同じ重みの GRU を回し、隣を見ない) との差で測る。層の数、単位の数、学習の予算、種はそろえる。別の種類のモデル (FC-LSTM など) との差は、グラフの効きとモデルの違いが混ざる。

差は、同じ試料、同じ感知器で対にして出す (`paired_day_sums` のあと `boot_ratio`)。和の比は、2 つのモデルの欠けを除いた MAE の差に等しい (テスト)。

PEMS-BAY (種 1):

| 先 | K = 2 (DCRNN) | K = 0 | K = 0 − K = 2 と区間 |
|---|---|---|---|
| 15 分 | 1.3133 | 1.3976 | 0.0844 [0.0658, 0.1021] |
| 30 分 | 1.6583 | 1.8509 | 0.1927 [0.1529, 0.2302] |
| 60 分 | 1.9813 | 2.3871 | 0.4058 [0.3251, 0.4825] |

差は先が長いほど大きい。K = 0 も、全ての先で最後の値を区間つきで下回った。グラフなしでも、時刻の特徴と GRU で多くを取れる。

## どこで効くかを分ける

平均の差は、少数の点に集まることがある。`share_of_gain` で、全体の差のうち、ある点の集まりが占める割合を出す。PEMS-BAY では、入力の最後の時刻から 10 mph 以上変わる点 (試験の点の 2.4%、4.2%、6.9%) が、差の和の 0.825、0.896、0.848 を占めた (15、30、60 分)。渋滞が始まる、解ける点で、上流と下流の感知器が手がかりになる。この区切り (10 mph、40 mph) は結果を見た後に選んだ。別のデータでは、区切りを先に決めてから数える。

## 種

PEMS-BAY では種を 1 つしか流していない。15 分の差 (0.08) が種の揺れより大きいかは確かめていない。種を 2 つ以上流せるなら、K = 2 と K = 0 を同じ種の組で流し、種ごとの差を並べる。
