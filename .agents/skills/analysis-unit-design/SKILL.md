# analysis-unit-design

分析の単位は、問いが何について答えを求めているかと、各データがどの細かさまで届いているかで決まる。
単位を決めずに結合を始めると、細かいデータを粗い単位に、粗いデータを細かい単位に、その場しのぎで合わせることになる。

## 手順

1. 問いの答えの 1 行が何かを書く。「国ごとの難民の数」なら国 × 年、「紛争の起きやすい場所」なら格子か行政区 × 期間。
2. 使うデータセットごとに、元の単位 (1 行が何か)、空間と時間の細かさ、点なら位置の精度を書き出す。データセットの説明 (リポジトリにデータセットごとの reference があれば、その「粒度と範囲」と位置の精度の記述) を使い、無ければ実データを読んで確かめる。
3. 候補の単位を 2〜3 個挙げ、各データをその単位にどう寄せるかを書く。細かいものを粗い単位に集めるのは集計で済む。粗いものを細かい単位に配るには仮定が要る (面積按分は、区域の値を、重なる面積の比で細かい単位に配る。人口按分は、人口の比で配る)。配るなら、その仮定を書く。
4. 候補ごとに実データで数える。
   - 単位の数 (標本の大きさ)。国なら 200 前後しかない
   - 単位あたりの件数の分布。0 の単位の割合、上位の単位への偏り
   - 単位の大きさのばらつき。行政区や国の面積は何桁も違うので、件数を人口や面積で割るかどうかを決める
   - 位置の精度で、その単位に正しく入る件数 (下の節)
5. 1 つを主の単位に選び、残りを頑健性の確認用に残す。単位で結論が変わるかは、格子の大きさなどを変えて同じ分析を流して確かめる (下の MAUP の節)。

## 単位の種類

| 単位 | 1 行 | 向いている問い | 気をつけること |
|---|---|---|---|
| 点 | 1 件の事象か施設 | 周りの密度、最寄りまでの距離 | 位置の精度。点どうしの空間的な近さで評価がリークする |
| 規則格子 | 1 つのセル | 場所ごとの起きやすさ | 事象の無いセルは元データに行が無い。セルを全部作ってから 0 を埋める。緯度経度の格子は高緯度ほど面積が小さい |
| 行政区 | 1 つの区域 | 統計と結ぶ問い、政策の単位 | 面積と人口のばらつき。境界は年で変わる |
| 地域の組 | 出発地と到着地の組 | 移動、貿易、流れ | 組の数は地域数の 2 乗。ほとんどの組は 0 |
| 上のどれか × 時間 | 単位と期間 | 変化、予測 | 期間の長さ。残高 (年末) と流れ (期間中) を混ぜない |

## MAUP: 単位の選び方が結論の一部になる

同じ点のデータでも、集計する単位の大きさ (格子を細かくするか粗くするか) や区切り方 (行政区か格子か) を変えると、相関や回帰の係数、クラスタが変わる。これを MAUP (可変単位地区問題) と呼ぶ。粗い単位ほど偶然のばらつきが平均されて、相関は強く見えやすい。

例: 紛争の事件数の、前年との相関 (UCDP GED、2015〜2024 年、log1p) は、0.5 度格子で 0.71、1 度で 0.78、2 度で 0.84、4 度で 0.89 になる (2026-10-10)。同じデータで、格子の大きさだけが違う。「前年と同じ場所で起きる」と言える強さは、どの格子で測ったかで決まる。

主の単位を決めたら、粗い単位と細かい単位を 1〜2 段ずつ作って同じ分析を流し、結論が保たれるかを見る。行政区の階層 (市区町村と都道府県) を変えるだけでは、単位の大きさの効果と、形や境界の効果が混ざる。同じ範囲を、大きさをそろえた格子で 3 段以上 (原点を半分ずらしたものも) 切って並べると、大きさの効果だけを取り出せる。保たれないなら、結論は単位の選び方に依存していると書く。

## 位置の精度と単位

点の座標が、単位より粗い精度でしか付いていないなら、その点はその単位に正しく入らない。
行政区の代表点 (重心) に置かれた点を細かい格子に入れると、重心のセルに偽の集積ができる。

精度を表す列があるデータでは、精度の値ごとに正しく入る単位を reference に書いておき、単位を選んだらそれより粗い精度の点を除くか、粗い単位に上げる。どちらを取ったか、除いた件数を書く。精度を表す列が無いデータでは、座標が丸められていないか (小数の桁、同じ座標の重複) を数えて推し量る。

## 書き出すもの

- 主の単位と、1 行が何を表すか
- 単位の数と、期間
- データセットごとに、どうその単位に寄せたか (集計、按分、そのまま) と、寄せられずに落ちた件数
- 0 の単位の割合と、件数を何で割るか
- 頑健性の確認に使う別の単位
