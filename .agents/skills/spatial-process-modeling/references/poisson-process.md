# Poisson 過程と点過程の尤度

## 強度と期待数

点過程の強度 λ(s) は、場所 s のまわりの単位面積あたりの点の期待数。領域 B の点の数の期待値は、B の上の λ の積分。

Poisson 過程は、次の 2 つで決まる。
- 領域 B の点の数は、平均 ∫_B λ の Poisson 分布。
- 重ならない領域の点の数は独立 (点どうしは引き合いも退け合いもしない)。

斉次 (homogeneous) は λ が一定。点の数は平均 λ × 面積の Poisson で、点の数を決めると、場所は窓の中で一様。合成 (単位正方形、λ = 100、2,000 回) で、点の数の平均と分散はどちらも 100 に近かった (`scripts/test_point_process.py`)。

非斉次 (inhomogeneous) は λ が場所で変わる。説明変数 x(s) の対数線形 log λ(s) = β0 + β1 x(s) がよく使われる。exp(β1) は、x が 1 増えたときの強度の倍率。

期待数は強度の積分で、log λ = a + b x の単位正方形の上の積分は e^a (e^b - 1) / b。`expected_count` の求積がこれと一致することをテストで確かめている。

## 点過程の尤度

点 s_1, ..., s_n を窓 W で観測したとき、Poisson 過程の対数尤度は

Σ_i log λ(s_i) - ∫_W λ(s) ds

点の場所で強度が高いほど大きく、窓の全体の期待数が大きいほど小さい。積分は、窓を細かいセルに分けた求積 (`quadrature`) で計算する。`fit_poisson_process` は Newton 法で最大化し、曲率から標準誤差を出す。

手計算の例:
- 斉次: 窓の面積 A で n 点なら、λ の推定は n / A、log λ の標準誤差は 1/√n。2 × 3 の窓の 60 点は、1 あたり 10 (60 ではない)。
- 左右の半分で違う強度: 左に 30 点、右に 10 点 (各面積 0.5) なら、左 60、右 20、β1 = log 3。

### 点の数で条件づける

点の数 n を決めると、点の場所は、密度 λ(s) / ∫λ からの独立な n 回の抽出になる。全体の水準 (β0) は、この条件づけた尤度から消え、傾き (β1 など) だけが残る。対数線形の強度では、条件づけた尤度の傾きの推定は、条件づけない尤度の傾きの推定と一致する (テストで 1e-8 まで)。

- 条件づけないモデル: 点の数も、強度の水準も、データが決める。「この地域では年に何件起きるか」に答える。
- 条件づけたモデル: 点の数は与えられたもの。「起きた点は、どこに起きやすいか」だけに答える。点の数を観測の努力が決めている (調査の件数で点の数が決まる) ときは、こちらが自然なことがある。

### 斉次と非斉次を比べる

合成 (log λ = 5 + 2x、約 470 点) で、非斉次のモデルは β を標準誤差の 3 倍の内に回収し、尤度比 2 × (差) は 10.83 (1 自由度、p < 0.001) を超えた。0.1 の格子の件数のばらつき (Pearson の分散比) は、斉次のモデルの期待数に対して 2 を超え、非斉次のモデルに対して 1 に近かった。

## 格子に数えた Poisson 回帰との違い

点を格子のセルに数え、件数を、log(セルの面積) を offset にした Poisson 回帰で当てるのは、点過程の尤度の近似になる。Poisson 回帰の score は、点過程の尤度の score と同じ形で、点の説明変数がそのセルの説明変数に、積分がセルごとの 1 つの値に置き換わったもの。細かい格子なら近似はよく、粗い格子では、説明変数がセルの中で変わる分を失う。

合成 (単位正方形、説明変数は幅 0.05 ほどで変わる滑らかな場、log λ = 5 + x、約 250 点、種 0〜9 の平均):

| 方法 | β1 (真の値 1) | 0 のセルの割合 |
|---|---:|---:|
| 点過程の尤度 (200 × 200 の求積) | 1.013 (標準誤差 0.054) | |
| 格子 0.02、セルの中心の値 | 1.007 | 0.91 |
| 格子 0.05、中心の値 | 0.977 | 0.64 |
| 格子 0.1、中心の値 (原点 0 / 0.05) | 0.884 / 0.881 | 0.25 / 0.33 |
| 格子 0.25、中心の値 (原点 0 / 0.125) | 0.448 / 0.516 | 0.00 / 0.03 |
| 格子 0.25、セルの平均の値 (原点 0 / 0.125) | 1.081 / 1.177 | |

- 0 のセルが 9 割でも、細かい格子は点過程の尤度とほぼ同じだった。0 が多いこと自体は Poisson 回帰の問題ではない。
- 粗い格子で中心の値を使うと、β1 は半分ほどに縮んだ。中心の値が、セルの中の説明変数の変化を代表しないため。測定の誤差による減衰と同じ形。
- 粗い格子の原点を半セルずらすと、β1 は平均 0.27 動いた (種ごとの差の絶対値の平均)。どのセルの中心がどの値を拾うかが変わる。
- セルの平均の値を使うと、縮みはほぼ消えたが、1 より少し大きくなった。exp の平均は平均の exp と違う (セルの中の強度の平均は、平均の説明変数の強度より大きい)。

細かい格子にするか、点過程の尤度を直接使う。粗い単位 (行政区) でしか数えられないなら、説明変数は単位の平均で取り、単位の大きさと原点 (区切り方) を変えたときの係数の動きを書く。

### 面積と曝露

セルの面積は、窓の中の部分の面積。窓の端で切れたセルに、切れる前の面積を使うと、そのセルは実際より空いて見える。合成 (窓 1 × 0.9、セル 0.25、一様な強度) で、上の列 (高さ 0.15) の印の係数は、正しい面積で 0 に近く、切れる前の面積で log(0.15/0.25) = -0.51 の近くになった (テスト)。行政区のように大きさの違う単位で数えるなら、面積 (や人口などの曝露) の offset を必ず入れる。
