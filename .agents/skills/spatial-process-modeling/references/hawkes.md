# 時空間の自己励起の過程 (Hawkes)

`scripts/hawkes.py`。事件が背景の率で起き、各事件が、その後の近くで事件の起きやすさを上げる過程。紛争、犯罪、地震の余震のような連鎖を問う。

λ(t, s) = μ / A + Σ_{t_i < t} K β exp(−β (t − t_i)) g(s − s_i)

| 記号 | 意味 |
|---|---|
| μ | 背景の率 (時間の単位あたり、範囲全体で)。空間で一様 (面積 A で割る) |
| K | 分岐比。1 つの事件が平均いくつの事件を誘発するか (1 未満) |
| β | 誘発の時間の減衰。1/β が平均の遅れ |
| σ | 誘発の空間の広がり (円い正規) |

## 決めごと

- 最尤 (log μ、logit K、log β、log σ を Nelder-Mead、3 つの初期値)。K = 0 (時間に一様な Poisson、空間に一様) との尤度比検定。K = 0 は境界にあるので、帰無の分布は 0 の点と自由度 1 のカイ二乗の半々 (近似)。
- 期待数の項では、各事件の誘発の空間の核を全平面で 1 とみなす。範囲の外に落ちる子を無視するので、σ が範囲に比べて小さくないと K が小さく出る。
- 同じ時刻の事件どうしは誘発し合わない。日ごとのデータでは、同じ日の事件の連鎖は数えられない。
- σ の下限 (`--min-sigma`、コマンドでは必須)。同じ座標に積まれた事件 (町の代表点) があると、σ → 0 で尤度がいくらでも大きくなる。位置の精度を下限にする。
- 事件ごとの、背景から来た確率 (確率的な declustering)。

## 仮定と、それが崩れると

背景が空間で一様、という仮定が最も強い。前線、市場、国境の検問所のように、固定した理由でよく事件が起きる場所があると、その場所の事件は時間も近くで重なり、モデルはそれを誘発と読む。K を「事件が事件を呼ぶ」証拠と読む前に、背景の空間の形をモデルに入れる (このスクリプトはしない)。

## 小さい既知解

3 事件の小さな例で、対数尤度が、強度の和と、期待数の数値積分 (scipy の quad) から作った値に相対 1e-9 で一致する。同じ時刻の 2 事件は、背景だけの寄与になる (相対 1e-12)。

## 合成データで壊す (50 km × 50 km、2026-10-16)

| 世界 | 結果 |
|---|---|
| μ 0.5/日、K 0.5、β 1/日、σ 1 km、400 日 (分岐で模擬) | 事件の数は μT/(1 − K) に 8% 以内。5 回の平均の推定は μ 15%、K ± 0.08、β 20%、σ 15% 以内 |
| 誘発なし (K 0) | K の推定 0.08 未満、尤度比検定の p > 0.01 |
| 背景から来た確率 | 和が真の背景の事件の数に 15% 以内。背景の事件の確率の平均は、誘発された事件より 0.3 以上高い |
| 誘発なしで、事件の 2 割が 0.5 km の固定した場所に集まる | K > 0.1、尤度比の p < 0.01。動かない集まりが誘発に見える |
| 位置を 5 km の格子に丸める (同じ座標の組ができる) | 下限なしでは σ が 0.1 未満に縮む。下限 2.5 で止まる |

## 実データ: シリアの 2019 年の紛争の事件

UCDP GED 26.1 (dataset-discovery/references/ucdp-ged.md) のシリアの 2019 年の事件のうち、位置の精度 1〜2、日付の精度 1 の 2,068 件。UTM 37N (EPSG:32637) の km、範囲は東 200〜860 km、北 3,580〜4,130 km の長方形、365 日、σ の下限 5 km (2026-10-16、2 分 23 秒)。

| | 値 |
|---|---|
| 同じ日の組、同じ座標の組 | 1,707、11,563 |
| μ (背景、1 日あたり) | 0.37 |
| K | 1.000 (上限) |
| 平均の遅れ 1/β | 25.6 日 |
| σ | 5 km (下限) |
| 背景から来た事件 | 2,068 件のうち 136 |
| Poisson との尤度比 | 12,542 |

- K が上限の 1 に、σ が下限の 5 km に張り付いた。この当てはめは、伝染の強さとは読めない。事件は前線 (イドリブなど) に集中し、範囲の長方形のほとんど (砂漠) には起きない。一様な背景では説明できない集中を、モデルは誘発で説明するしかなく、爆発する境界 (K = 1) に着いた。
- 尤度比が大きいことは、「Poisson (時間に一様、空間に一様) より良い」を示すだけで、誘発の証拠にはならない。
- 同じ座標の組が 11,563 あり、σ は位置の精度で決まった。
- このデータで誘発を問うなら、背景を空間で変える (前の年の事件の密度、前線までの距離) 必要がある。スクリプトは、K が 0.95 を超えると警告を出す。

## 空間で変わる背景

`hawkes.py --background-from 前の期間の事件 --background-h H1 H2 …` は、背景を「一様」と「前の期間の事件のカーネル密度」の混合にする。混ぜる割合 w は、他のパラメータと一緒に最尤で推定する。帯域は候補ごとに当て、尤度の最も高いものを残す。密度は窓の中で積分が 1 になるように格子で正規化するので、補正の項 (期待数) は変わらない。当てはめる期間の事件で密度を作ると、事件が自分を説明するので使わない。

合成データ (50 km 四方、300 日、事件の 2 割が中心の 0.5 km の広がりのホットスポット、残りは一様):

- 誘発の無い世界に一様な背景を当てると K は 0.45〜0.54 (上)。真の背景の密度を与えると、誘発の減衰が 0 に寄り (β → 0)、K = 0 との尤度比は 0 になった (テスト)。
- 前の期間の密度だけを背景にした最初の試みは失敗した。帯域 0.25〜2 km で、K は 0.45〜1.0、尤度比は 27〜10,798。一様な部分 (事件の 8 割) が前の期間の点の場所でだけ高い凸凹の背景になり、今期の点が谷に落ちると誘発で埋める。
- 一様と混ぜると (帯域 0.5 km)、誘発の無い世界の尤度比は 2.1 と 5.7 (一様な背景では 250 と 239)。残った「誘発」の平均の遅れは 2,750 日と 4,960 日で、期間より長い。
- 平均の遅れが期間の 5 分の 1 を超えたら、スクリプトは「誘発の項が時間でほぼ一定で、背景の不足を埋めている」と出す。一様な背景のホットスポットの世界でも、遅れは 160〜196 日で、この警告に掛かる。
- 誘発のある世界 (K 0.5、平均の遅れ 1 日、同じホットスポット) では、混合の背景で K と遅れが戻った (K ± 0.12、遅れ ± 35%、テスト)。
- 背景が間違っていると、K = 0 の尤度比の検定は較正されていない。誘発の無い世界で 5.7 は、χ² の基準では有意に見える。

シリアの 2019 年 (下と同じ 2,068 件) に、2018 年の 3,053 件 (同じ精度の絞り込み、同じ窓) の密度を混ぜた背景を当てた (13 分)。

| 帯域 (km) | 対数尤度 | 密度の重み | K |
|---:|---:|---:|---:|
| 5 | -18,434.7 | 0.91 | 0.847 |
| 10 | -18,540.0 | 0.87 | 0.914 |
| 20 | -18,582.1 | 0.85 | 0.948 |
| 40 | -18,613.5 | 0.81 | 0.975 |

- 帯域 5 km で、K は一様な背景の 1.000 から 0.847 に、平均の遅れは 25.6 日から 16.6 日に下がった。背景から来た事件は 136 件から 409 件。背景だけ (K = 0) の対数尤度は -20,503.8 で、一様な Poisson (-24,956.0) より 4,452 高い。前の年の密度は、事件の場所の多くを説明する。
- それでも、遅れ 16.6 日の誘発が強く残った (尤度比 4,138)。遅れは期間の 5 分の 1 より短く、警告には掛からない。この背景は 1 年の中で動かない。2019 年の前線の動き (北西部の攻勢など) は背景に入らず、誘発に数えられる。0.847 は伝染の大きさの上限と読む。
- 選ばれた帯域 5 km は候補の端で、σ の下限 (5 km) と同じ。もっと細かい帯域は、位置の精度より細かくなるので試していない。

## 外部の実装との照合

探した範囲 (2026-10-16): tick 0.7 (時間だけの Hawkes、BSD-3)、hawkeslib (ビルドが通らない)。時空間の Hawkes (ETAS など) の推定を持ち、この環境で動く Python の実装は見つからなかった。R は入っていない。

- 時間の部分は tick と照合した (`scripts/test_hawkes_crosscheck.py`)。tick は最後の版が Python 3.8 でしか入らない。全ての事件を 1 点に置き、範囲の面積を 2πσ² にすると、空間の核は事件の上で 1 / A になり、時空間の対数尤度は時間の対数尤度から n log A を引いたものになる。344 件の模擬で、3 組のパラメータの対数尤度が相対 1e-12 で一致した。こちらの推定した β で tick の尤度を (μ, K) について最大にすると、μ と K が相対 1e-5 で一致し、β を 0.7 倍、1.5 倍にした尤度は低かった。tick の損失は「-(対数尤度 + T) / 件数」で、定数の分だけ尤度とずれる。
- 空間の核とその正規化は、外部の実装と照合していない。代わりに、小さな例での数値積分との一致、模擬からの回復 (μ、K、β、σ)、仮定を壊した合成データ (固定のホットスポットが誘発に見える) で確かめた。
- これらで捕まらない可能性: 空間の核の形の誤りのうち、模擬と推定で同じように入る誤り (simulate と loglik が同じ誤った核を使えば、回復のテストは通る)。数値積分のテストは核の式を独立に書いているので、正規化の誤りは捕まる。範囲の端で子が外に落ちる分は、どの検証もしていない。

## 適用できない条件

- 背景が空間で一様でないのに、前の期間の事件が無いとき (上)。
- 背景が時間で動くとき (前線の移動、季節、停戦)。前の期間の密度は 1 年の中で固定。
- 誘発の核が時間の指数、空間の円い正規でないとき (長い裾、道路に沿う広がり)。
- 事件が 6,000 を超える (組を全て持つ)。
- 範囲の端で子が外に落ちる分の補正は無い。

## テスト

`uvx --with numpy --with scipy --with pytest pytest scripts/test_hawkes.py`。上の既知解と合成データの 7 つと、σ の下限、空間で変わる背景の 4 つ (一様を明示したときの一致、密度の積分が 1、真の背景で誘発が消える、混合の背景でホットスポットと誘発を分ける)。混合から一様の分を落とすと落ちる。tick との照合は `uvx --python 3.8 --with tick --with numpy --with scipy --with pytest pytest scripts/test_hawkes_crosscheck.py` で、補正の項 (期待数) を誘発の数そのものにすると落ちる。期待数を誘発の数そのものにする、空間の核の 2π を落とす、同じ時刻の事件を親にする、のそれぞれで落ちる。
