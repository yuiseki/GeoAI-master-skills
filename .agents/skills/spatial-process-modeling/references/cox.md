# Cox 過程とクラスタ過程の当てはめ (K 関数の最小コントラスト)

点が集まるパターンに、2 つの仕組みのモデルを当てる。`scripts/cox.py`。

```sh
uvx --from 'duckdb>=1.5.5' --with numpy --with scipy python scripts/cox.py POINTS X Y \
  --window XMIN XMAX YMIN YMAX --rmax R [--steps 20] [--simulate 39]
```

- Thomas 過程 (クラスタ過程): 親が Poisson (単位面積あたり κ)、それぞれが Poisson (μ) 個の子を、標準偏差 σ の円い正規の距離に置く。点どうしの引き合いで集まる。K(r) = πr² + (1 − exp(−r² / 4σ²)) / κ。
- 対数ガウス Cox 過程 (LGCP): 強度が exp(Z(s))、Z は分散 v、尺度 φ の指数の相関のガウスの場。場が決まれば点は独立。観測していない環境で集まる。対の相関 g(r) = exp(v exp(−r / φ))、K(r) = 2π ∫₀ʳ s g(s) ds (数値積分)。
- 推定は最小コントラスト: Σ (K̂(r)^¼ − K(r)^¼)² を 2 つのパラメータ (対数) について最小にする (Diggle の q = 1/4)。出発点は格子で選び、上下限を付けた Nelder-Mead。パラメータが上下限に張り付いたら、そのモデルはパターンを表さないと表示し、模擬を飛ばす。
- K̂ は、窓の面積 / (n(n − 1)) × 近い順序対の数。端の補正は平行移動 (対のずれだけ窓をずらした重なりの面積で割る)。

## 仮定

- 定常 (強度の平均が場所で変わらない) で、等方。強度に傾向があると、それも集まりとして当てはまる (下)。
- 平均の強度は n / |W| で推定する。
- 窓は長方形、座標は投影した座標。rmax は窓の短い辺の 4 分の 1 まで (超えると表示が出る)。

## 小さい既知解と模擬での確かめ

`scripts/test_cox.py`。

- 3 点の K を、補正なしと平行移動の補正で手で計算した例。
- Poisson のパターン (200 点、50 回): 補正ありの K̂ の平均は πr² の 3% 以内。補正なしは r 0.2 で 0.84 倍 (端の外の相手を数えない)。
- Thomas の式と模擬 (κ 25、μ 10、σ 0.03、50 回): K̂ の平均と式が 2.1% 以内。
- LGCP の積分と模擬 (v 1、φ 0.08、平均 200 点、30 回): K̂ の平均は積分の 0.958〜0.989 倍。場を 40 × 40 の格子に置き、セルの中で一様にしているため短い距離の相関が少し落ち、n を同じパターンから推定するため遠い距離も少し低い。格子を 60 × 60 にしても 0.94〜0.95 で、近づかなかった (r 0.01 では 0.84 になった。原因は確かめていない)。v = 0 で πr² に戻る。

## 合成データで壊す

- Thomas の回復 (8 回): κ と σ の中央値は真値の 30% と 25% 以内。
- LGCP の回復: 単位正方形と φ 0.08 (窓が尺度の 12 倍ほど) では、1 回ずつの φ の推定が 0.038〜0.117 (30 回の 10〜90% 点、中央値 0.067)、v は 0.66〜1.29。最初の 3 回がたまたま 0.037〜0.043 に出て、偏りを疑った。仮説「n から推定した強度が K̂ を下げる」は、真の強度で K を計算し直しても 0.039 のままで外れた。30 回の K̂ の平均に当てると φ 0.071、v 0.995 で、1 回の K̂ のばらつきが大きいだけと分かった。窓を 3 × 3 に広げると、6 回の中央値は 0.075。
- 2 つの仕組みを見分けられるか: Thomas のパターンと LGCP のパターンに、それぞれ両方のモデルを当て、19 回の模擬の L(r) − r の包絡と比べた。4 つの組み合わせの全てで、観測は包絡の中に入った。コントラストは真のモデルのほうが小さかった (Thomas のパターンで 0.0007 と 0.0035、LGCP のパターンで 0.00006 と 0.0005) が、模擬の包絡では区別できない。
- 集まりの無い傾向: 相互作用も場も無い Poisson を、exp(3(x − 1)) で西から東へ間引いた。3 回のうち 2 回で、Thomas も LGCP も包絡に入り (Thomas の σ 0.07〜0.08)、1 回は LGCP の尺度が上限に張り付いた。傾向は、定常な集まりとして当てはまる。

## 外部の実装との照合

- K の補正なしの値を、PySAL の pointpats 2.6.0 の `k()` と照合した (`scripts/test_cox_crosscheck.py`)。pointpats は窓ではなく点の外接矩形の面積と n² で割る (端の補正は「未実装」と書かれている)。この 2 つを掛け直すと、Thomas、LGCP、Poisson のパターンで相対 1e-10 で一致した。
- 平行移動の補正、Thomas の式、LGCP の積分、最小コントラストの当てはめは、Python に同じものが見つからなかった (R の spatstat の `kppm` が基準だが、R は入っていない)。代わりに上の模擬との一致と回復で確かめた。これらで捕まらない可能性: 模擬器とモデルの式が同じ誤り (σ の定義を両方で取り違えるなど) を共有すると、模擬との一致は通る。Thomas の式の 4σ² を 2σ² にする誤りは捕まる (模擬器は σ を直接使うため)。

## 実データ: 東京のカフェ

OpenStreetMap の東京 23 区の凍結版 (dataset-discovery/references/osm-tokyo23-src-2026-08.md) の点のうち `amenity = 'cafe'` の 4,249 点 (面として描かれたカフェは含まない)。EPSG:6677、小学校と同じ窓 (x −18,000〜−8,000、y −34,000〜−26,000、10 km × 8 km) の 634 点、rmax 2 km (2026-10-16、13 秒)。

- L(r) − r は r 600 m で最大 +529 m。強く集まる。
- Thomas: 親 0.26 / km²、子 30.9、σ 228 m、コントラスト 10.2。19 回の模擬の包絡から、20 の距離のうち 6 で外れた。
- LGCP: 対数強度の分散 2.7 (強度の標準偏差が 5 倍ほどの幅)、尺度 430 m、コントラスト 1.38。包絡から外れた距離は 0。
- 合成データでは見分けられなかった 2 つが、ここでは分かれた。ただし LGCP が合うことは、集まりの原因が環境 (駅の周りの商業地) であることを示さない。傾向でも同じように合う (上)。駅までの距離を強度の説明変数に入れたモデルと比べるのが次の手 (未実施)。
- LGCP の模擬は 40 × 40 の格子 (セル 250 m × 200 m) で、推定の尺度 430 m と比べて粗い。

## 適用できない条件

- 強度に傾向がある、窓の中で地域の性格が変わる (傾向も集まりに見える)。
- 長方形でない窓。点が数千を超える (n × n の距離を持つ)。
- 尺度が窓の広さに比べて大きい (1 回のパターンから尺度が決まらない)。
- 潜在の場そのものの推定 (場の地図、予測) はしていない。

## テスト

`uvx --from 'duckdb>=1.5.5' --with numpy --with scipy --with pytest pytest scripts/test_cox.py`。平行移動の補正を x の方向だけにする、Thomas の式を 2σ² にする、LGCP の相関を指数からガウスにする、のそれぞれで落ちる。照合は `uvx --from 'duckdb>=1.5.5' --with numpy --with scipy --with pointpats --with pytest pytest scripts/test_cox_crosscheck.py`。
