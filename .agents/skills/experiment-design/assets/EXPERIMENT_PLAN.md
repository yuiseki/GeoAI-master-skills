## 区画

### B1: <名前>

- claim tested: C1
- mode: <confirmatory / exploratory>。確認なら、決め手の結果を見ていないこと: <はい / 見たもの>
- data / analysis unit: <データセットと版、1 行は何か、行数>
- observable quantity: <主張が正しいとき、何がどう動くか>
- comparator / control: <基準、外した版、負の対照>
- evaluation population / split principle: <評価する行と、分け方の原則 (使い道を真似る)。基準と同じ分割を使う>
- primary metric: <主の指標 1 つ。補助の指標は判断に使わない>
- uncertainty: <揺れをどう見るか (fold、repeat、種、区間、置換)。種の数とその理由>
- planned settings: <固定する設定 (モデル、重み、単位、帯域など) と、その選び方の理由>
- decision rule: <どの結果なら支持、どの結果なら退ける。数の閾値なら根拠 (業務の要件、測定の誤差、意味のある最小の差、確立した基準)。根拠が無ければ向きと不確かさで書く>
- failure interpretation: <退けられたら何が分かるか。救済に使わない変更 (分け方、重み、閾値、モデル、単位) をここで名指しする>
- alternative explanation being tested: <この区画が試す別の説明 (リーク、交絡、単位と尺度、多く使ったデータ、モデルの容量、観測の努力、偶然、手法の設定)>
- falsification / robustness: <別の説明が正しいなら結果が変わるはずの比較、設定を変える範囲>
- priority / run order: <sanity / baseline / decisive / falsification / robustness / optional>、順番 <n>
