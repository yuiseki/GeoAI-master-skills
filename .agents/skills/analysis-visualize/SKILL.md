# analysis-visualize

図は、表より速く読まれ、表より強く信じられる。軸の範囲を切れば小さな差が大きく見え、平均の棒だけを並べればばらつきが消え、点が重なれば多いところが少なく見える。このスキルは、分析で既に出た値を、問いに合った型の図にし、図を読む人が「どこまで信じてよいか」を図から判断できるようにする。

このスキルが答えるのは、「この結果を、どの型の図に、どの軸と注記で描けば、問いに対して誤解を生まないか」まで。何を分析するか、どの数字を報告に入れるかは、このスキルの外。地図の塗り分け (区切り方、色の型、凡例) も扱わない。

| reference | 中身 |
|---|---|
| [japanese-text](references/japanese-text.md) | 日本語の文字が抜ける仕組み、eval の環境で測ったこと、フォントの入れ方と使用許諾、`scripts/cjk_font.py` の使い方 |

## 図の型を、問いから決める

| 問い | 図 | 気をつけること |
|---|---|---|
| 1 つの量は、どんな形で散らばっているか | ヒストグラム、累積分布 (ECDF)、箱ひげ | ヒストグラムの形は区切りの幅で変わる。2 つの幅で形が変わらないかを見る。裾が長いなら対数の軸を考え、そう書く。件数 n を書く |
| 2 つの量は、どう関係しているか | 散布図 | 点が多くて重なるなら、透明度か 2 次元のビンにする。当てはめの線を描くなら、何を当てはめたか (線形、平滑) と区間の意味を書く。相関係数だけで形を語らない |
| 条件 (モデル、特徴量、分け方、地域) で、結果はどう違うか | 点と区間、fold ごとの値を並べた点 | 平均の棒だけにしない。同じ fold や同じ地域の値どうしを線で結ぶと、組の差が見える。比べる図は同じ軸の範囲にする |
| 時間とともに、どう変わったか | 線 | 時間の軸の単位と時刻の区切りを書く。欠けた期間を線でつながない。季節があるなら、同じ季節どうしを比べる |
| モデルは、どこで外れているか | 予測値と残差の散布図、残差の分布 | 残差の 0 の線を描く。空間の偏りを地図で見るのは、このスキルの外 |

円グラフ、3 次元の図、2 つの縦軸の図は使わない。比べたい量が読み取りにくくなる。

## 手順

1. 図ごとに、答える問いを 1 文で書く。結論を示す図か、確かめ (診断) の図かも決める。1 枚の図に問いを 2 つ入れない。
2. 値を分析の出力 (表、ログ、保存した予測) から読む。図のために計算し直さない。足りなければ、分析の段階に戻って出す。
3. 型を上の表から選ぶ。
4. 軸を決める。軸の名前に量と単位を書く (「人口 (人)」「RMSE (m)」)。比べる図は、同じ軸の範囲にする (`sharex`、`sharey`)。棒は 0 から始める。対数の軸なら、そう書く。
5. ばらつきを描く。点や線には標本の数 n を添え、区間やひげの意味 (標準偏差、95% の区間、fold の最小と最大) を凡例か題に書く。意味を書けない区間は描かない。
6. 日本語の文字を使うなら、題、軸、凡例、注記、目盛りの全ての文字を `scripts/cjk_font.py` に渡してから描く。フォントが無いか、描けない文字があると止まる。止まったら、フォントを入れるか、その文字を使わない ([japanese-text](references/japanese-text.md))。

   ```python
   import matplotlib
   matplotlib.use("Agg")                    # 画面の無い環境で描く
   from cjk_font import use_cjk_font
   use_cjk_font("23 区の芝生の面積 (m²) 人口 1 人あたり")
   ```

7. 保存する。PNG と、同じ名前の JSON (答える問い、読んだ出力のファイル、データの名前と版、n、区間の意味、軸の範囲、フォント) を並べて置く。描いた後は `plt.close(fig)` で閉じる。
8. 確かめる。保存した PNG を開いて、文字の抜け、重なった目盛り、切れた凡例が無いかを見る。画像を読めない環境なら、描くときの警告 (`missing from font` など) が 0 件だったことを残す。

## やらないこと

- 軸の範囲を切って差を大きく見せる、都合のよい区間だけを描く。結論を図で強めない。
- 図のための計算し直し。分析の出力に無い値を図に足さない。
- 塗り分けの地図、色の区切り方の選択。
- フォントのファイルを成果物に入れて配る (使用許諾の確かめが要る)。

## 書き出すもの

- 図ごとの PNG と、同じ名前の JSON (問い、出どころ、版、n、区間の意味、フォント)
- 日本語を使った図なら、`cjk_font.py` が返したフォントの名前。止まったなら、どう対処したか
- 確かめたこと (開いて見た、または警告が 0 件)
