# 色と値の種類

| 値の種類 | 色の型 | 例 (`--palette`) |
|---|---|---|
| 件数、率、水準 | 順序の色 (明るさが値の順に並ぶ) | viridis、cividis、YlOrRd、Blues |
| 残差、変化 | 中央から分かれる色 (中央を 0 か基準に置く。`--centre`、等間隔なら中央の両側を同じ幅に) | RdBu_r、coolwarm、PiYG |
| クラス | クラスの色 (明るさに順序の無い色) | tab10、Set2、Dark2 |

`classify_map.py` は、種類に合わない色と、虹色 (rainbow、jet、hsv、turbo など) で止まる。

## 虹色を避ける理由

虹色は、色相を順に並べた色で、明るさが値の順に上がらない。黄色や水色のあたりで明るさが跳ねるので、データに無い境界が見え、値の小さな差が大きな差に見える。白黒に印刷すると順序が失われる。

## NoData と 0

- 欠損や NoData を 0 と同じ色で塗らない。0 の人口と、調べていない地域は違う。
- `classify_map.py` は、値の無い単位を灰色の斜線で塗り、凡例に数を書く。
- 0 の多い値を分位で区切ると、0 が複数のクラスに割れないか (同じ値が同じ区切りに当たる) を区切りの値で確かめる。

## 件数をそのまま塗るか

大きな単位ほど件数は多い。密度が一様で、面積だけが違う 300 の単位 (対数正規の面積、ポアソンの件数) を作ると、件数と面積の相関は 0.998、件数の上位 20% の単位の 95% が面積の上位 20% だった (2026-10-16)。件数の地図は、面積の地図になる。密度 (件数 / 面積) にすると、面積との相関は -0.04 だった。

- 問いが件数そのもの (どこに何件あるか) なら、件数を塗る。ただし、大きな単位が目立つことを書く。
- 問いがリスクや密度なら、率か密度にする。分母 (面積、人口、発生の機会) は問いから決める。
- 件数を塗るとき、`classify_map.py` は面積との相関を出す。面積は geometry の CRS の単位で測るので、経緯度のままでは歪む。

## 色覚の多様性での見え方

`scripts/cvd.py` は、1 型 (protan)、2 型 (deutan)、3 型 (tritan) の見え方を模擬し、隣り合うクラスの色の差 (CIELAB の ΔE、CIE76) の最小と、両端の差、明るさ (L*) がクラスの順に並ぶかを、普通の見え方と並べる。模擬は Machado、Oliveira、Fernandes (2009) の重さ 1.0 の行列を線形の sRGB に掛ける。合否の線は置かない。並べて読む (ΔE 2 前後が、並べて見分けられる限り。地図のクラスは離れて小さく見えるので、もっと要る)。

```sh
uvx --with numpy --with matplotlib python scripts/cvd.py --palette viridis --k 7
uvx --with numpy --with matplotlib python scripts/cvd.py --palette RdBu --k 7 --diverging
uvx --with numpy --with matplotlib python scripts/cvd.py --colors '#d73027,#fc8d59,#fee08b,#91cf60,#1a9850' --diverging
```

7 クラスで測った値 (2026-10-16、matplotlib の色表)。

| 色 | 隣の最小の ΔE (普通、1 型、2 型、3 型) | 両端の ΔE (普通、1 型、2 型、3 型) | 明るさの順 |
|---|---|---|---|
| viridis | 23.9、13.9、10.3、12.1 | 150.7、141.8、131.6、67.3 | どれも保つ |
| cividis | 14.7、14.2、15.0、8.3 | 127.8、127.1、127.3、73.3 | どれも保つ |
| jet | 31.6、20.1、18.9、11.3 | 151.9、125.6、149.0、120.2 | どれも保たない |
| RdYlGn (発散) | 23.9、15.9、18.8、15.5 | 109.8、19.4、23.5、116.6 | 保つ |
| RdBu (発散) | 19.0、15.6、18.9、21.6 | 82.9、53.6、75.4、95.3 | 保つ |
| PuOr (発散) | 21.5、20.9、20.8、16.5 | 97.3、92.5、97.3、55.2 | 保つ |

- 赤と緑の発散の色 (RdYlGn) は、1 型と 2 型で両端の差が 109.8 から 19.4 と 23.5 に縮む。発散の地図の「高い側」と「低い側」は色相で分けていて、明るさは左右対称なので、両側の区別が消える。RdBu と PuOr は両側を保つ。
- jet の問題は隣の差ではなく、明るさの順が無いこと。隣の ΔE はどの見え方でも 11 以上ある。値の大小は読めない。
- viridis は 2 型で、暗い端の隣 (1 と 2 のクラス) の差が 10.3 まで縮む。cividis は 1 型と 2 型でほとんど変わらないが、3 型で 8.3。
- 確かめ: 白、黒、灰色はどの模擬でも保たれる (2e-3 以内)。赤 (tab:red) と緑 (tab:green) の差は、1 型と 2 型で普通の 4 割未満、3 型では 6 割を超えて残る (テスト)。線形化せずに行列を掛ける誤りは、5 つのテストで落ちる。
- 外部の実装との照合: colorspacious 1.1.2 の `sRGB1+CVD` (重さ 100) と 1e-12 で一致した。CIELAB は colorspacious と 0.05 以内 (実測 0.02。XYZ の白の値が小数 4 桁目で違う)。模擬は 2 色覚の平均的な見え方の近似で、個人の見え方や、弱い異常 (重さ 1.0 未満) は表さない。
