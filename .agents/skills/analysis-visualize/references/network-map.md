# ネットワークの図

道路網、最短経路の木、流れの量のように、値が線 (辺) に付いている結果を描く。背景の地図は敷かず、辺そのものに場所を語らせる。1 つの値で辺の色と太さを同時に変え、多く通る辺ほど太く、背景から目立つ色にする。描くのは `scripts/network_map.py`。

この描き方は、city2graph (BSD-3-Clause) の `plot_graph` の見た目を参考にした (黒い背景、辺が主役、値で太さを変える)。city2graph そのものは使っていない。その既定に無い、階級の区切り、0 と値なしの描き分け、色の向きの検査、来歴の JSON を足した。

## 入力

- 辺の表: Parquet (DuckDB で読める形式) で、線の列 (`--geometry`、既定 `geometry`) と値の列 (`--value`)。値は 0 以上の量 (通る人数、件数、流量)。1 行 1 本の線で、分析の出力のまま渡す。図のために値を計算し直さない。
- 点の層 (`--points "path,label,marker,colour"`、何度でも): `x` と `y` の列を持つ CSV か Parquet。辺と同じ CRS。
- 強調 (`--highlight`): 真偽の列。切ったら効く橋、ボトルネックなど。白い背景では黒、黒い背景では白の縁で描く。`--label-col` で名前を添える。

## 決めること

| 決めること | 決まり | 理由 |
|---|---|---|
| 階級 | `--bins` に各階級の上端を明示する。最初の階級は 0 より大きいところから | 太さは階級ごとの段で変える。連続の太さは、どの太さがどの値かを凡例で読めない |
| 0 と値なし | 0 は細い基礎の線、値なし (NULL) は点線で、別に数える | 「通らない道」と「測っていない道」を同じに見せない |
| 範囲外 | 負の値、最後の上端を超える値は止める | 黙って最上位の階級に入れると、区切りの意味が変わる |
| 色の向き | 背景に対して、高い階級の端が低い階級の端よりも明るさ (CIELAB の L*) の差が大きいこと。逆なら止める | 黒い背景で YlOrRd を使うと、最も多く通る辺が暗い赤で背景に沈む。白い背景の magma は、最上位が淡い黄色で消える |
| 描く順 | 低い階級から描き、高い階級を上に重ねる | 交差点で太い幹線が細い道に隠れない |
| 文字の重なり | ラベルは、点と他のラベルに重ならない向きを 8 通りまで試す。残った重なりは JSON に記録する | 点の層全体の外接矩形は図のほぼ全部を覆うので、点は 1 つずつ比べる |
| テーマ | `--theme light` (既定) か `dark` | 黒い背景は構造が浮き出て見やすいが、印刷や報告の本文では白い背景のほうが読みやすいことが多い。どちらでも同じ値、同じ階級で描ける |

## 使い方

```sh
uvx --with numpy --with duckdb --with shapely --with matplotlib --with pyarrow --with pandas \
  python scripts/network_map.py edges.parquet --crs EPSG:6677 --source "OSM 2026-08-31" \
  --question "最短経路はどの道に集まるか" --value n_origins --value-label "経路が通る出発点の数" --unit "点" \
  --bins 1 5 20 80 300 --theme dark --highlight cut_matters --highlight-label "外すと伸びる橋" --label-col name \
  --points "sites.csv,避難場所,^,#3aa0ff" --png network.png
```

PNG と同じ名前の JSON に、問い、出どころ、CRS、区切り、階級ごとの辺の数、0 と値なしの数、色、テーマ、点の層の件数、強調した辺の数、ラベル、残った文字の重なり、フォントを書く。

## 確かめたこと

`scripts/test_network_map.py` (2026-11-05、matplotlib と DuckDB は uvx の最新)。合成の 3 x 3 の格子 (12 本の辺) で次を確かめる。

- 全ての辺が、階級、0、値なしのどれか 1 つに数えられ、合計が辺の数に一致する。
- 負の値と、最後の上端を超える値で止まる。
- 黒い背景の YlOrRd と白い背景の magma が止まり、黒い背景の magma、白い背景の YlOrRd と magma_r が通る。
- 階級が上がるほど線が太い。
- 点の層の外接矩形の中にあっても、点から離れたラベルは重なりに数えない。点の上のラベルは数える。
- 既定の位置で点と重なるラベルが、別の向きへ動いて重なりが 0 件になる。向きを 1 つに限ると重なりが記録される。

0 を基礎の線に分ける行、色の向きの検査を、それぞれ外すとテストが落ちることを確かめた。

実データでの例: 台東区の 50 m 格子の出発点 3,900 から洪水の避難場所への最短経路の木で、道 17,736 本 (経路に乗る 5,308 本) を描いた (2026-11-05、OSM 2026-08-31)。重なりは、点の層全体で比べていた版では 7 件、点ごとに比べる版で 1 件 (ラベルが避難場所の印に重なる本物)、向きを変える版で 0 件だった。

## まだできないこと

- 有向の辺 (一方通行、流れの向き) の矢印。
- 節点そのものの値 (次数、中心性) を点の大きさで描くこと。
- 辺の数が数十万を超える図の速さは測っていない。
