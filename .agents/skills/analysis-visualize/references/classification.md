# 区切り方

`scripts/classify_map.py --method`。クラスの上の端を含む (値がちょうど区切りの値なら、下のクラス)。

| 区切り方 | 中身 | 向くとき | 気をつけること |
|---|---|---|---|
| 等間隔 (`equal`) | 最小から最大を同じ幅に | 値の幅そのものに意味があるとき | 歪んだ値では、ほとんどが最も低いクラスに入る |
| 分位 (`quantile`) | 各クラスに同じ数の単位 | 並びの順位を見せたいとき | 小さな差を違う色にし、大きな差を同じ色にする。最も高いクラスの幅が他の何倍にもなる |
| Fisher-Jenks (`jenks`) | 並べた値を、クラスの中の 2 乗和が最小になるように切る (厳密解、5,000 値まで) | 値に自然な群があるとき | データごとに区切りが変わり、地図どうしを比べにくい |
| 固定の線 (`fixed`、`--thresholds`) | 意味のある値で切る | 基準、上限、政策の閾値があるとき | 線の外の範囲にしか値が無いと、クラスが空になる (止まる) |

分布の形 (一様なら等間隔、歪んでいれば分位) から機械的に選ばない。問い (順位か、水準か、基準を超えるか) と、比べる相手から選ぶ。

## 歪んだ値で、区切り方はどれだけ食い違うか (合成)

対数正規 (σ 1.2) の 500 値を 5 クラスに (2026-10-16、種 1)。

| 区切り方 | クラスごとの割合 | 区切りの値 |
|---|---|---|
| 等間隔 | 0.966、0.026、0.004、0.002、0.002 | 0.04、8.28、16.5、24.8、33.0、41.3 |
| 分位 | 0.2 ずつ | 0.04、0.39、0.76、1.24、2.26、41.3 |
| Fisher-Jenks | 0.736、0.220、0.036、0.004、0.004 | 0.04、1.89、6.23、12.9、21.4、41.3 |

| 組 | クラスが入れ替わる単位の割合 |
|---|---:|
| 等間隔と分位 | 0.798 |
| 等間隔と Fisher-Jenks | 0.262 |
| 分位と Fisher-Jenks | 0.796 |

- 等間隔の地図は、97% の単位を同じ色で塗る。
- 分位の地図は、値 0.39 と 0.76 の単位を違う色にし、2.26 と 41.3 の単位を同じ色にする。
- 8 割の単位が、区切り方を変えるだけでクラスを変える。地図の印象を結論にするなら、区切り方を変えた地図でも保たれるかを見る。

## 外部の実装との照合

`scripts/test_classify_map_crosscheck.py` で、mapclassify 2.11.0 (numba なし) の `EqualInterval`、`Quantiles`、`FisherJenks` と照合した。対数正規の 300 値、3、5、7 クラス、種 4 つで、区切りの値 (相対 1e-9) と各値のクラスが全て一致した (2026-10-16)。
