# 測定の誤差と潜在的な真値

測った値は、多くの場合、誰も観測していない真値の、雑音の混じった代わり (proxy) に過ぎない。面積按分で推定した人口、衛星から分類した土地被覆、自己申告の通勤時間、1 回だけ測った大気汚染。このページは、観測値を「潜在的な真値 + 測定の誤差」と見るモデルを扱う。入力の不確かさを結果へ伝える感度の分析 (入力を揺らして結果の幅を見る) より一段進み、誤差の構造を仮定して、係数や率そのものを補正する。`scripts/measurement_error.py` が式を持つ。

## 言葉

| 言葉 | 意味 |
|---|---|
| 潜在的な真値 X | 本当に知りたい値。観測できない |
| 観測値 W | 手元の値。X の代わり |
| 測定の誤差 U | W と X の差 |
| 古典的な誤差 (classical) | W = X + U、U は X と無関係。観測値は真値より散らばる |
| Berkson の誤差 | X = W + U、U は W と無関係。割り当てた値 (格子の値を住民全員に当てる、設計の値) の周りに真値が散らばる |
| 信頼性 (reliability ratio) λ | var(X) / var(W) = var(X) / (var(X) + var(U))。古典的な誤差のとき |
| 非差異的 (non-differential) | 誤差が、結果 (や処置) によらない。差異的なら、結果によって誤差の出方が違う (症例のほうが曝露をよく思い出す) |

測定の誤差は、残差の雑音とも、欠けた値とも違う。
- 残差の雑音は、真値が分かっても残る結果のばらつき。測定の誤差は、変数の値そのものが違うこと。説明変数の測定の誤差は係数を偏らせるが、残差の雑音は偏らせない。
- 欠けた値は、値が無いと分かっている。誤差のある値は、そこにあって、間違っている。補完の方法は誤差を直さない。

## 説明変数の誤差: 減衰

古典的な誤差では、観測値での傾きは、真の傾き × λ になる (0 の方へ縮む、attenuation)。

手計算の例 (`scripts/test_measurement_error.py`): 真値 x ∈ {-1, 1} と誤差 u ∈ {-1, 1} の全ての組 (4 行)。var(x) = var(u) = 1 で λ = 0.5。y = 2x の傾きは、x では 2、w = x + u では cov(w, y) / var(w) = 2 / 2 = 1。乱数で作った 2 万行 (λ = 0.64) でも、傾きは 2λ = 1.28 に一致した。

Berkson の誤差では傾きは偏らない。同じ 4 行で、割り当てた値 w の周りに真値 x = w + u が散らばるとき、傾きは 2 のまま。格子の平均の汚染濃度を、その格子の住民全員に当てる、は Berkson に近い。測定器の値を真値の代わりにする、は古典的に近い。どちらかは、値の作られ方から決める。

説明変数が複数あると、誤差のある変数の縮みが、相関する別の変数の係数に移る (誤差の無い変数の係数も偏る)。向きは相関で決まり、一般には言えない。

## 結果の誤差: 係数でなく標準誤差

結果の側だけの古典的な誤差は、平均的な係数を動かさず、残差を大きくする。合成 (200 行 × 300 回、残差の標準偏差 1 に対し結果の誤差 2) で、傾きの平均は 2.004 と 2.005、標準誤差の平均は 0.071 と 0.160 だった。検出力が落ち、区間が広がる。結果の誤差が説明変数と関係する (差異的) なら、係数も偏る。

## 信頼性を知る方法

### 繰り返しの測定

同じ単位を、誤差が独立になるように k 回測る。単位の中のばらつきが誤差の分散、単位の平均のばらつきから誤差 / k を引いたものが真値の分散 (`reliability_from_repeats`)。

手計算の例: 3 単位 × 2 回 (1, 3)、(5, 7)、(2, 4)。誤差の分散 2、平均 2、6、3 の分散 13/3、真値の分散 13/3 - 1 = 10/3。1 回の信頼性 10/16、2 回の平均の信頼性 10/13。

k 回の平均は誤差の分散を k 分の 1 にする (合成で 4 回の平均の誤差の分散 0.25)。ただし、繰り返しが同じ誤差を共有する (同じ機械、同じ日、同じ調査員) なら、共有する分は平均で減らず、信頼性を高く見積もる。

### 検証用の標本 (validation sample)

一部の行で、真値 (またはずっと正確な値) も測る。その行で真値を観測値に回帰した直線 E[X | W] = a + b W が、補正に使う関係になる (古典的な誤差なら b = λ)。

回帰による較正 (regression calibration) は、観測値を a + b W に置き換えて当てはめ直す。合成 (5,000 行、λ = 0.64、無作為な 1 割で検証) で、観測値の傾き 1.28 が 2.0 に戻った。

検証用の標本の選び方が結果を決める。合成 (200 回の平均):

| 検証の行の選び方 | 補正後の傾き (真値 2) |
|---|---:|
| 無作為 | 2.001 |
| 観測値 W が 0.5 より大きい行 | 2.004 |
| 真値 X が 0.5 より大きい行 | 3.975 |
| 結果 y が 1 より大きい行 | 2.994 |

この合成の較正のモデル (真値を観測値 1 つに直線で回帰する) では、観測値で選んだ検証は偏らず、真値や結果で選んだ検証は補正を壊した。一般に言えるのは、次の程度まで。
- 検証の行の選び方が、較正のモデルで条件づける観測された変数だけに依るなら、選び方を無視できる (ignorable) 場合がある。
- 潜在的な真値、結果、測定の仕組みそのものに直接依る選び方は、較正を偏らせうる。被害の大きかった所だけを検証する、は真値に依る選び方になりうる。
- 較正が直線でない、較正に別の共変量を入れる、といった場合は、無視できる条件が変わる。

「全体と同じに見える」ことは、検証の標本が使えることの十分条件でも必要条件でもない。検証の行の誤差が、他の行と同じ仕組みで生じることも仮定で、別の機器、別の時期、別の地域の検証は、そのまま全体に当てはめない。

報告する区間は、検証の行を作り直す bootstrap で出す。`regression_calibration` の標準誤差は、a と b を推定したことを含まない。

## 誤分類 (0/1 の値の誤差)

0/1 の値 (土地被覆が森林か、感染したか、曝露したか) の誤差は、感度 (本当に 1 の行を 1 と言う割合) と特異度 (本当に 0 の行を 0 と言う割合) で表す。

観測の割合 = 感度 × p + (1 - 特異度) × (1 - p)。逆に解くと補正 (Rogan-Gladen) になる (`correct_prevalence`)。

- 手計算の例: 真の割合 0.2、感度 0.9、特異度 0.95 で、観測は 0.22。
- まれなもの (真の割合 0.01) は、特異度 0.99 でも観測が 0.0199 で、ほぼ 2 倍になる。偽陽性が真の陽性と同じ数だけ出る。まれな土地被覆の面積、まれな病気の率は、特異度に強く左右される。
- 補正が 0 より小さいか 1 より大きくなる (観測 0.03 に、特異度 0.95 を仮定する) のは、仮定した率がデータと合わないということ。`correct_prevalence` は止まる。0 に丸めない。

### 効果への影響

| 誤分類 | 向き | 手計算の例 (真のリスク差 0.2: 0.3 と 0.1、500 行ずつ) |
|---|---|---|
| 曝露の非差異的な誤分類 (感度 0.8、特異度 0.9) | 0 の方へ (0/1 の曝露では) | 0.278 - 0.136 = 0.141 |
| 曝露の差異的な誤分類 (症例の感度 0.95、非症例 0.6) | どちらにも。この例では 0 から離れる | 0.366 - 0.088 = 0.279 |
| 結果の非差異的な誤分類 (感度 0.8、特異度 0.9) | 0 の方へ、(感度 + 特異度 - 1) 倍 | 0.31 - 0.17 = 0.14 = 0.7 × 0.2 |

非差異的なら 0 の方へ、は 0/1 の曝露と結果では成り立つが、3 値以上の曝露や、差異的な誤分類では成り立たない。「誤分類があるので、本当の効果はもっと大きい」は、非差異的であることを確かめられたときだけ言える。

## 止めるべきこと

- 信頼性も誤分類の率も分からないのに「補正済み」と書かない。分からないなら、`correction_grid` のように、もっともらしい範囲で補正の表を作り、結論が保たれる範囲を書く。
- 1 組の感度と特異度を、根拠なしに当てて一点で補正しない。
- 検証用の標本が、真値や結果で選ばれている、別の条件で測られているなら、全体の補正に使わない。
- 測定の誤差を、ただの雑音として無視しない。説明変数の誤差は係数を偏らせる。
- 補正は識別を作らない。誤差を補正した処置の後の変数は、処置の後の変数のまま。補正した係数を因果の効果と読むには、交絡、支え、波及についての設計が別に要る。

## このページで扱わないもの

潜在変数を複数の観測から推定するモデル (因子分析、構造方程式モデル、項目反応理論)、空間的な潜在場 (潜在的なガウス過程)、ベイズの測定の誤差のモデル。ここで扱うのは、観測値が 1 つの真値の雑音まじりの代わりである、という最小の考え方だけ。

## 書き出すもの

- 誤差のある変数と、誤差の種類 (古典的、Berkson、誤分類) と、それを決めた根拠 (値の作られ方)
- 誤差が非差異的と言える根拠
- 信頼性、感度、特異度の値と出どころ (繰り返し、検証用の標本、外部の資料)。検証用の標本の選び方
- 補正の前と後の係数や率。補正の区間 (bootstrap) か、率が未知なら補正の表
