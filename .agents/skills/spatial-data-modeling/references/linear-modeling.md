# 線形モデル

線形回帰、Ridge、Lasso、Elastic Net、ロジスティック回帰。特徴量の重み付き和で予測する。
係数の符号と大きさで、どの特徴量がどちら向きにどれだけ効くかを説明できる。行が少ない表や、関係が単調な問いでは、木やブースティングより強いことがある。

## 前処理

- 欠損を受け付けない。scikit-learn 1.9.1 の `LinearRegression` は NaN を含む入力でエラーになる (2026-10-10 実測)。補完するなら学習側の行だけで値を決め、補完したことを示す 0/1 の列を足す。
- 尺度を揃える。罰則つき (Ridge、Lasso、`C` を有限にしたロジスティック回帰) は、尺度の大きい特徴量ほど罰則が効かなくなる。標準化は学習側の平均と標準偏差で行う (`make_pipeline(StandardScaler(), ...)`)。
- 裾の長い量 (人口、GDP、件数) は対数を取ると線形の関係に近づくことが多い。0 を含むなら `log1p`。
- カテゴリは one-hot にする。水準の多いカテゴリ (国名など) を one-hot にすると、行数に対して列が多くなる。

## 罰則

| 種類 | 罰則 | 使う場面 |
|---|---|---|
| Ridge | 係数の 2 乗の和 | 相関の強い特徴量が多いとき。係数を 0 にはしない |
| Lasso | 係数の絶対値の和 | 効かない特徴量を 0 にして選びたいとき。相関の強い組からは片方を気まぐれに選ぶ |
| Elastic Net | 両方の混ぜ合わせ | Lasso で選ばれ方が不安定なとき |

罰則の強さは学習側の中の交差検証で決める (`RidgeCV`、`LassoCV`、`LogisticRegressionCV`)。

## 係数を説明に使うとき

- 相関の強い特徴量が入ると、係数が不安定になり、符号が反転することもある。特徴量どうしの相関と、分割や種を変えたときの係数のばらつきを見る。
- 標準化した特徴量の係数は、1 標準偏差あたりの効き方。元の単位に戻して書くか、標準化したことを書く。
- 係数は「他の特徴量を固定したとき」の効き方で、因果ではない。
- 空間データでは、近い単位の残差が似る (空間自己相関) と、係数の標準誤差が実際より小さく出る。

## 学習範囲の外

直線のまま外挿する。scikit-learn 1.9.1 で、x を 0 から 1 で学習した y = x を x = 2 で 2.0 と予測した (2026-10-10 実測)。外挿が正しいかどうかは、関係がその範囲の外でも直線である保証による。

## 残差に空間の偏りが残るとき

係数と p 値を説明に使うなら、残差の Moran's I を測る。近い単位の残差が似ていると、OLS の標準誤差は小さすぎ、有意でない係数を有意と読む。目的変数が近傍に左右される構造なら、係数そのものが偏る。確かめ方と、空間回帰のモデルの選び方は [spatial-regression](spatial-regression.md)。

同じ分母で割った比どうし (人口あたりの 2 つの数) を目的変数と説明変数にすると、分子が無関係でも分母の違いだけで相関が出る。分子の数を目的変数にし、分母を説明変数か offset (ポアソン回帰の log(分母)) に入れたモデルと並べる。

## 係数は因果の効果とは限らない

回帰の係数は、他の説明変数を固定したときの関連の大きさ。原因と結果の構造 (どの変数がどれに効くか) を描かずに、変数を全部入れても交絡は調整できない。合成データ (2 万行、2026-10-14) で、x から y への効果が 0 か 2 の構造を作って当てはめた。

| 構造 | y ~ x | y ~ x + 第 3 の変数 | 正しい扱い |
|---|---:|---:|---|
| 交絡 (z が x と y の両方に効く。x から y へは 0) | 1.00 | 0.00 | z を入れる |
| 中間変数 (x が m に効き、m が y に効く。総効果 2) | 2.00 | 0.01 | 総効果を知りたいなら m を入れない |
| 合流点 (x と y の両方が c に効く。x から y へは 0) | −0.01 | −0.50 | c を入れない。c で標本を選んでも (c > 1 だけ) −0.35 が出る |

- 原因と結果の構造の図 (DAG) を描き、どの変数を入れ、どれを入れないかを決める。入れると誤る変数 (中間変数、合流点) がある。
- 逆向きの因果 (y が x に効く) と、標本の選ばれ方 (合流点で選ぶのと同じ) も、係数を作る。
- 関連を因果と書かない。因果を言いたいなら、その主張に要る仮定を書く。
