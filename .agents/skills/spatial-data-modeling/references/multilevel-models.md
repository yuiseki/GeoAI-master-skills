# 階層モデル (入れ子の構造、ランダム効果)

地点は市区町村に、市区町村は都道府県に、年の観測は地域に入る。同じグループの行は、そのグループに共通の何か (気候、制度、測り方) を共有し、独立でない。階層モデル (multilevel model、mixed model、hierarchical model) は、グループの違いを「グループごとの値がある分布から出た」と見て、その分布の広がり (グループの間の分散) を推定する。`scripts/multilevel_fit.py` は、ランダム切片、ランダム傾き、2 段の入れ子、グループの平均の追加 (Mundlak) を扱う。パネルの固定効果は [panel-data](panel-data.md) にある。 ランダム効果を入れても、因果の識別は保証されない。グループの効果と説明変数が無関係という仮定 (後述の取り違え 3) は、それ自体が識別の仮定の一つ。

## 3 つのまとめ方

| まとめ方 | グループの値 | 弱いところ |
|---|---|---|
| まとめない (no pooling) | 各グループの平均。グループごとの回帰、固定効果 | 行の少ないグループの値がノイズで暴れる |
| 全部まとめる (complete pooling) | 全体の平均。グループを無視した回帰 | グループの違いを消す。行を独立とみなし、標準誤差が小さすぎる |
| 部分的にまとめる (partial pooling) | グループの平均を、全体の平均に向けて、信頼できる分だけ戻す | グループの効果が説明変数と関係すると係数が偏る (後述) |

戻す重みは τ² / (τ² + σ² / n)。τ² はグループの間の分散、σ² はグループの中の分散、n はそのグループの行の数。行の少ないグループ、グループの中のばらつきが大きいデータほど、強く全体の平均に戻る (縮小、shrinkage)。

手計算の例 (`scripts/test_multilevel_fit.py`): 3 グループ × 3 行、平均 2、6、3。分散分析で τ² = 4、σ² = 1、ICC = 0.8。重みは 4 / (4 + 1/3) = 12/13 で、平均 2 のグループは 83/39 = 2.13 になる。REML の推定はこの手計算と一致した。

合成の例: 47 グループ、行の数は 2 から 100、τ = 1、σ = 3。真のグループの平均との RMSE (200 回の平均) は次のとおり。

| まとめ方 | 全グループ | 行が 3 以下のグループ |
|---|---:|---:|
| まとめない | 1.305 | 1.888 |
| 全部まとめる | 1.033 | (測っていない) |
| 部分的にまとめる | 0.731 | 0.912 |

小さい地域の率 (人口の少ない町の発生率) を地図にするとき、まとめない値は極端な値が小さい地域に集まる。部分的にまとめた値と、各地域の行の数を並べる。

## ICC (級内相関)

ICC = τ² / (τ² + σ²)。同じグループの 2 行がどれだけ似ているか、全体の分散のうちグループの間の割合。行の数 N、グループあたりの行の数 m のとき、平均の分散は独立のときの 1 + (m - 1) ICC 倍になる (デザイン効果)。ICC が 0.05 でも、m = 60 なら約 4 倍。

- 目的変数だけの ICC (説明変数なし) と、説明変数を入れた後の ICC は違う。どちらかを書く。
- 分散分析の推定が負になる (グループの間の散らばりが偶然より小さい) とき、`icc_anova` は 0 にして `at_zero` を立てる。
- グループの数が少ないと、τ² 自体が不安定。τ² = 0.25 の合成で、REML の τ² の標準偏差は、5 グループで 0.224、10 グループで 0.154、47 グループで 0.066 だった。5 グループの「地域の差は小さい」は、ほとんど何も言っていない。

## 取り違え 1: グループの単位で測った変数の不確かさ

都道府県の変数 (条例の有無、平均気温) を、地点の行に付けて回帰すると、行を独立とみなした標準誤差は、実際より小さい。情報の数は行の数でなくグループの数に近い。

合成 (40 グループ × 25 行、グループの変数の真の係数 0、τ² = σ² = 1、300 回) で、95% の区間が 0 を含んだ割合は次のとおり。

| 方法 | 割合 |
|---|---:|
| 行を独立とみなした OLS | 44.0% |
| グループでクラスタした標準誤差 | 94.3% |
| ランダム切片 | 95.3% |

クラスタの標準誤差とランダム切片は、どちらも直す。違いは、ランダム切片がグループの間の分散を推定し、グループの値 (部分的にまとめた値) も返すこと。

## 取り違え 2: 入れ子の上の段を落とす

地点 → 市区町村 → 都道府県で、都道府県の変数を説明に使うのに、市区町村のランダム切片だけを入れると、都道府県の中の市区町村が独立とみなされる。

合成 (20 都道府県 × 6 市区町村 × 10 地点、分散は都道府県 1、市区町村 0.49、地点 1、150 回) で、都道府県の変数の 95% の区間が真の値を含んだ割合は、市区町村だけで 66.0%、2 段の入れ子 (`--group 都道府県 --nested 市区町村`) で 93.3%。2 段のモデルは分散を 1.035、0.490、0.998 と推定した。

- 変数を測った段を、モデルの段に含める。クラスタの標準誤差でも同じで、変数を測った単位以上でクラスタする ([panel-data](panel-data.md) の地域ごとの衝撃と同じ形)。
- 市区町村の番号が都道府県ごとに振られている (区の 1 番が市ごとにある) なら、`--nested` は都道府県の中で番号を読むので正しい。市区町村の番号だけを `--group` に渡すと、別の市の同じ番号の区が 1 つのグループになる。全国で一意のコードを使う。

## 取り違え 3: グループの効果が説明変数と関係するとき

ランダム切片は、グループの効果が説明変数と無関係だと仮定する。所得の高い県ほど別の理由でも目的変数が高い、のように関係すると、ランダム切片の係数は、グループの中の関係とグループの間の関係を混ぜたものになる。

合成 (100 グループ × 8 行、真の傾き 0.5、説明変数とグループの効果が相関、100 回) の傾きの平均:

| 方法 | 傾き |
|---|---:|
| 行を独立とみなした OLS | 1.490 |
| ランダム切片 | 0.568 |
| 固定効果 (グループの平均を引く) | 0.498 |
| ランダム切片 + グループの平均 (Mundlak) | 0.498 |

グループの平均を説明変数に加える (`--mundlak`) と、元の変数の係数は、固定効果の係数と一致する (テストで一致を確かめている)。グループの平均の係数は、グループの間の傾きとグループの中の傾きの差で、0 から離れていれば、ランダム切片だけのモデルは偏っている。グループの値の部分的なまとめや、グループの単位の変数を使いつつ、グループの中の傾きを得られる。

グループの中の行が少ないほど、ランダム切片は単純な回帰に近づき、偏りは大きくなる。同じ設定で、グループあたり 2 行なら 1.069、8 行なら 0.566、30 行なら 0.514 だった。

## ランダム傾き

説明変数の効き方がグループごとに違うなら、傾きもグループごとにばらつく。ランダム切片だけのモデルは、その傾きのばらつきを誤差に入れ、平均の傾きの標準誤差を小さく見積もる。

合成 (40 グループ × 20 行、平均の傾き 0、グループの傾きの標準偏差 0.5、200 回) で、平均の傾きの 95% の区間が 0 を含んだ割合は、ランダム切片だけで 62.5%、ランダム傾きを入れて (`--random-slope x`) 95.0%。

- 傾きのばらつき (`slope_var`) は、グループの数が少ないと推定できない (0 に張り付く、収束しない)。警告は出力に出る。
- 傾きがグループで違うこと自体が答えになる問い (地域によって効き方が違うか) なら、グループごとの傾き (部分的にまとめたもの) を並べる。空間的に滑らかに変わる傾きは GWR の領分 ([spatial-regression](spatial-regression.md))。

## 外部の実装との照合

`multilevel_fit.py` の中身は statsmodels の MixedLM。ランダム切片の REML を、式から独立に書いた実装 (グループごとの V の逆行列と行列式を閉じた形で求め、scipy で最大化) と照合した (`scripts/test_multilevel_fit_crosscheck.py`、statsmodels 0.15.0、scipy 1.18.1、2026-10-15)。R の lme4 はこの環境に無く、比べていない。

- 不揃いな合成データ (80 グループ、1 から 20 行) では、分散成分と係数が一致した。
- WDI の国 × 年 (平均寿命を 1 人あたり GDP の対数と都市人口の割合に回帰、国のランダム切片、`GEOAI_REALDATA=1` で流れる) では、statsmodels の既定の最適化 (L-BFGS) が、τ² を 50.717 で止めた。独立の実装の最大値は 50.725 で、REML の値の差は 2e-6 と小さく、尤度が τ² の方向に平らだった。BFGS で勾配の許容幅を 1e-10 にすると最大値に届いたので、`multilevel_fit.py` はそれを使う。今は分散成分が相対 1e-5 で一致する。

## REML と ML

ML は、グループの間の平方和をグループの数で割る (自由度を引かない) ので、τ² を小さく見積もる。手計算の例では REML 4、ML 23/9 = 2.56。合成 (τ² = 0.25) で、5 グループの平均は REML 0.249、ML 0.193。分散を報告するなら REML を使う。固定効果の違うモデルを尤度で比べるときだけ ML で当てはめ直す。

## 階層モデルが扱わないもの

- 隣のグループどうしの相関: ランダム切片はグループの間を独立とみなす。隣の市が似ているなら、グループの値の残差に空間自己相関が残る。グループの値 (`random_effects`) の Moran's I を測り、残るなら空間のランダム効果 (CAR など) が要る。ここでは扱わない。
- 時間とともに変わる交絡: 固定効果と同じく、グループの中で時間とともに変わる別の要因は残る。
- 新しいグループの予測: 予測に使えるのは固定の部分と τ² だけで、グループの値は無い。評価はグループを丸ごと試験側に置いて行う。

## 書き出すもの

- 段 (行、グループ、その上) と、各段の数。グループあたりの行の数の最小、中央、最大、5 行未満のグループの数
- 目的変数だけの ICC と、説明変数を入れた後の各段の分散の割合
- 推定の方法 (REML か ML) と、収束しなかったこと、分散が 0 になったこと
- 説明変数を測った段と、標準誤差の扱い (行を独立とみなした値と並べる)
- ランダム切片と、グループの平均を入れた場合 (Mundlak) の係数の違い
- 部分的にまとめたグループの値を使うなら、まとめない値と行の数を並べる
