# 木のモデル

決定木とランダムフォレスト。特徴量のしきい値で行を分けることを繰り返し、分けた先の平均 (分類なら割合) で予測する。
非線形な関係と、特徴量どうしの相互作用を、指定しなくても拾う。

## 前処理

- 尺度の変換は要らない。単調な変換 (対数、標準化) をしても分け方は変わらない。
- 欠損: scikit-learn 1.9.1 の `RandomForestRegressor` は NaN を含む入力をそのまま学習した (2026-10-10 実測)。それより古い版や、別の実装では受け付けないことがある。版を書く。
- カテゴリ: scikit-learn の木は数として扱う。順序の無いカテゴリを整数にすると、無い順序で分けることになる。one-hot にするか、カテゴリを扱える実装 (boosting-modeling の CatBoost、LightGBM) を使う。

## 決定木

- 1 本の木は分け方を読める。しきい値 (「1 人あたり GDP が X を超えると」) を説明に使える。
- 深くすると学習側に合わせすぎる。深さか、葉の最小の行数を学習側の中で決める。
- 学習データが少し変わるだけで分け方が大きく変わる。読む前に、分割や種を変えて同じ分け方が出るかを見る。

## ランダムフォレスト

- 行と特徴量を無作為に選んで作った多数の木の平均。1 本の木より安定するが、分け方は読めなくなる。効き方は重要度と部分依存で見る。
- 木の数は多いほど安定する。500 で足りないと思ったら、種を変えたときの点数のばらつきを見る。
- 種への感度: 平均寿命を WDI の 3 特徴量で予測した例 (209 か国、行を無作為に 5 分割) で、種 3 つの R2 の標準偏差が 0.06 だった。分割も種で変わるので、分割のばらつきも含む (2026-10-10)。

## 学習範囲の外

外挿しない。学習した範囲の端の値で平らになる。scikit-learn 1.9.1 で、x を 0 から 1 で学習した y = x を、x = 2 で 1.005、x = -1 で 0.018 と予測した (2026-10-10 実測)。
地域ごとの分割では、試験側の地域の特徴量が学習側の範囲の外に出ることがある。何行が外に出たかを数え、その行の誤差を別に見る。

## 重要度

不純度に基づく重要度 (`feature_importances_`) は、値の種類が多い特徴量を高く出しやすいと報告されている (Strobl et al. 2007、ここでは未実測)。相関の強い特徴量の組では重要度が分け合われる。説明に使うなら permutation importance を、試験側の行で測る。
