# 地理的加重回帰 (GWR)

`scripts/gwr.py`。各単位で、距離が近いほど重い重み付きの最小二乗を当て、係数が場所で違うかを見る。

## 仮定と決めごと

| 項目 | 中身 |
|---|---|
| 仮定 | 係数は場所でなめらかに変わる。帯域の中では、ほぼ一定 |
| 核 | bisquare (帯域の外は 0) か gaussian。適応 (帯域は、自分を含めて bw 番目に近い単位までの距離) か固定 (距離) |
| 帯域の選び方 | AICc の最小。候補の帯域 25 個の粗い曲線を出し、その最小のまわりを黄金分割で探す (適応の帯域は整数)。AICc の曲線は谷が 2 つあることもあるので、曲線を並べて見る |
| 出力 | 局所の係数、標準誤差、t 値、tr(S) (実効的なパラメータの数)、AICc、全ての単位で検定することを調整した臨界の t (da Silva と Fotheringham 2016: α × 係数の数 / tr(S)) |
| 距離 | 投影の座標の直線の距離 (`--x --y`)、または球面の km (`--lon --lat`) |

局所の係数は、場所による過程の違い以外の理由でも動く。

- 帯域が狭いと、局所の係数は雑音を拾う。
- 説明変数が相関すると、2 つの局所の傾きが反対向きに動く (Wheeler と Tiefelsdorf 2005)。
- 場所で変わる変数をモデルから落とすと、その分が局所の係数に乗る。

局所の係数の地図は記述で、この 3 つを念頭に読む。係数を比べやすくするなら、説明変数を標準化する (`--standardise`)。

## 小さい既知解

- 帯域が無限に広い gaussian の核では、全ての局所の係数が OLS と同じで、tr(S) は係数の数 (2) に等しい。
- AICc は、残差平方和と tr(S) から手で計算した値と一致する。

## 局所の共線性

`gwr.py` は、選んだ帯域で `local_collinearity` を計算し、局所の条件数の中央値と最大、30 と 10 を超える単位の数、説明変数ごとの最大の局所の VIF を出す。`--out` には、単位ごとの条件数と、最小の特異値への分散分解の割合 (VDP) が入る (Wheeler 2007)。

- 条件数: 重み付きの計画行列の、最大の特異値 / 最小の特異値。列は単位の長さにそろえる。行に掛ける重みは √w (局所の当てはめが逆行列を取る X'WX の平方根に当たる W^1/2 X)。mgwr 2.2 は w をそのまま掛ける。Georgia の帯域 117 では、中央値 2.21 と 2.45、最大 2.67 と 2.97 で、定義で値が違う。
- VDP: 最小の特異値に、各列の推定の分散のどれだけが乗っているか。条件数が大きく、2 つ以上の列の VDP が 0.5 を超えると、その列どうしが共線。
- 手の計算: 全ての行が同じ重み (無限の帯域のガウス) なら、局所の診断は全体と同じ。直交して中心化した 2 列で条件数 1、VIF 1。相関 r の 2 列で VIF = 1 / (1 − r²)。
- 合成データ (15 × 15、どちらの傾きも 1): 西の 3 分の 1 だけで x2 = x1 + 0.05 × 雑音にした。西の端の 2 列の局所の条件数の中央値は 30 を超え、東の 10 倍以上。局所の傾き (x1) の標準偏差は、西の端で東の 3 倍以上。西の端では両方の傾きの VDP が 0.5 を超えた (テスト)。

## 係数ごとの帯域 (MGWR)

`gwr.py --multiscale` は、係数ごとに帯域を変える MGWR (Fotheringham、Yang、Kang 2017) を当てる。

- 帯域の選択は後退当てはめ: GWR の帯域から始め、列ごとに、その列の部分を残差に戻し、1 列の GWR の AICc で帯域を選び直し、当て直す。部分の変化 (平方和の比の平方根) が 1e-5 を下回るまで。
- 当てはめと推論は、選んだ帯域で閉じた形に解く (Li と Fotheringham 2020): 列ごとの 1 列の GWR の hat 行列 A_j で、ブロックの連立方程式 [I A_1 …; A_2 I …] R = [A_1; A_2; …] を解き、f = R y。R_j の trace がその列の有効なパラメータの数、合計が tr(S)。標準誤差は R_j の行から。調整した臨界の t は列ごとに α / ENP_j。後退当てはめの係数は閉じた形と 1e-4 以内で一致する (テスト)。
- 列ごとに、最後の反復の 1 列の AICc の、最小から 2 以内に入る帯域の幅を出す。広いと、その係数の尺度はデータで決まっていない。
- 計算は n k × n k の連立方程式を 1 回解く。単位が千を超えると重い。

合成データ (15 × 15、β0 = 1、β1 = 1 + x の西から東の傾き、β2 は中央の小さな山):

- 選んだ帯域は、3 つの種で [120, 50, 36]、[225, 45, 37]、[225, 36, 37]。GWR の 1 つの帯域は 43〜57。定数には広い帯域が付いた。ゆるやかな傾きの β1 は、最初の予想 (広い帯域) に反して 36〜50 で、小さな山の β2 と同じくらい。係数の中の線形の傾きは、狭い窓でも偏りが小さいためと考えている。
- 係数の誤差 (RMSE) は、3 つの係数の全てで MGWR が GWR より小さかった (種 9: 0.049、0.094、0.152 と 0.082、0.100、0.159)。

Georgia (上と同じ 159 郡、目的変数と説明変数を標準化):

| | 定数 | 外国生まれ | 黒人 | 農村 |
|---|---:|---:|---:|---:|
| 帯域 (こちら) | 92 | 23 | 94 | 145 |
| AICc 2 以内の帯域 | 70〜114 | 19〜36 | 59〜159 | 59〜159 |
| 有効なパラメータの数 | 3.50 | 15.54 | 3.46 | 1.95 |
| 帯域 (mgwr 2.2.1) | 101 | 101 | 117 | 157 |

- こちらの帯域の組は tr(S) 24.5、AICc 296.1。mgwr の組は tr(S) 11.5、AICc 297.1。全体の AICc はこちらが低いが、モデルの複雑さは 2 倍。外国生まれの 1 列の AICc は帯域 22 で 275.1、114 でも 278.4 と差が小さく、mgwr の黄金分割は最小から 2.9 高い 101 で止まった。この係数が「局所的に強く変わる」という読みは、帯域の選び方に左右される。
- 黒人と農村の帯域は、AICc 2 以内に 59 から全ての郡 (159) までが入る。ほとんど全域で一定と読んでも、AICc の上で区別できない。

## 外部の実装との照合

`scripts/test_gwr_crosscheck.py`。mgwr 2.2.1 と、libpysal 4.15 に同梱の Georgia の郡のデータ (159 郡、UTM のメートル) で照合した。学士の割合を、外国生まれ、黒人、農村の割合 (標準化) で説明する、mgwr の例の組 (2026-10-16)。

- 帯域 117 と 60 の bisquare、90 の gaussian で、局所の係数と標準誤差 (相対 1e-8)、tr(S) と AICc と調整した臨界の t (相対 1e-10) が一致した。
- 帯域の選択は、mgwr の黄金分割が 117 (AICc 851.350)、こちらが 116 (AICc 851.285)。こちらの AICc は mgwr 以下。
- MGWR: mgwr の帯域 [101, 101, 117, 157] で、閉じた形の係数が mgwr の `exact_fit` と 1e-10、標準誤差と ENP と AICc と臨界の t が相対 1e-8 で一致した。mgwr の後退当てはめ (許容 1e-5) の係数とは 1e-4 以内。帯域の選択は上の表のとおり違い、こちらの組の AICc は mgwr 以下。
- 局所の共線性: 同じ 3 つの帯域で、重み付きの相関、VIF、VDP が相対 1e-7 以内で、条件数は mgwr と同じ重み (`root=False`) で相対 1e-8 で一致した。既定の √w の条件数は mgwr と違うこと (相対 1e-3 を超える差) も確かめている。

## 実データ: Georgia の学歴

| | 値 |
|---|---|
| 帯域 | 116 郡 (159 のうち)、tr(S) 11.9 |
| AICc | 851.3 (全体の OLS は 887.5) |
| 調整した α、臨界の \|t\| | 0.0168、2.417 |
| 外国生まれの割合の傾き | 全体 2.60、局所 0.69〜4.22。調整した臨界を超えた郡 116 |
| 黒人の割合の傾き | 全体 -0.48、局所 -0.98〜0.58。超えた郡 0 |
| 農村の割合の傾き | 全体 -2.13、局所 -2.63〜-1.35。超えた郡 159 |
| 局所の傾きどうしの相関 | 外国生まれと黒人 -0.82、外国生まれと農村 +0.86、黒人と農村 -0.75 |

- 帯域は郡の 7 割を含み広いが、AICc は全体の OLS より 36 小さい。
- 説明変数どうしの全体の相関は小さい (外国生まれと黒人 -0.11、外国生まれと農村 -0.55) のに、局所の傾きは強く相関した。
- 局所の共線性 (帯域 116): 局所の条件数は中央値 2.2、最大 2.7 (W^1/2 X、列を単位の長さに)、局所の VIF は最大 2.3。どの郡でも、条件数の目安 (30) にも 10 にも遠い。ただし、外国生まれと農村の重み付きの相関は、郡によって -0.31〜-0.74 と全体 (-0.55) より強くなる。2 つの説明変数が負に相関すると、2 つの傾きの推定は正に相関する。局所の傾きどうしの相関 +0.86 (外国生まれと農村) は、この向きと合う。条件数が低くても、傾きの地図の一部は推定の入れ替わりでありうる (どれだけかは分けていない)。
- 黒人の割合の傾きは、局所で符号が変わるが、調整した臨界を超える郡は無い。符号の変化を、場所で違う関係と読まない。

## 適用できない条件

- 係数を因果の効果と読むこと (GWR は関連の記述)。
- MGWR の帯域の不確かさ: AICc 2 以内の幅を出すだけで、帯域の区間の推定はしない。
- 単位の数 × 単位の数の距離を持つので、数千の単位まで。
- 一般化線形 (ポアソン、ロジスティック) の GWR は無い。

## テスト

`uvx --with numpy --with scipy --with pytest pytest scripts/test_gwr.py`。無限の帯域で OLS に戻ること、場所で変わる傾きを戻すこと、一定の傾きに広い帯域を選ぶこと、tr(S) が帯域で減ること、AICc の手計算、共線の説明変数で局所の傾きが逆に動くこと、調整した臨界の t を確かめている。bisquare の打ち切りを外す、適応の帯域で自分を数えない、臨界の t を調整しない、のそれぞれで落ちる。局所の共線性は、手の計算と、1 つの地域だけ共線の合成データで確かめ、条件数の分母を 2 番目に小さい特異値にすると落ちる。照合は `uvx --with numpy --with scipy --with pandas --with mgwr --with libpysal --with pytest pytest scripts/test_gwr_crosscheck.py`。
