# 回帰の残差と計画行列の診断

`scripts/regression_diagnostics.py`。最小二乗の係数を説明に使う、または検定するときの診断。予測の点数 (交差検証の外側の誤差) でモデルを比べるだけなら、要らない。

| 診断 | 見るもの | 棄却したら |
|---|---|---|
| Breusch-Pagan (Koenker の型) | 残差の 2 乗を特徴量に回帰した n R²。残差の広がりが、特徴量の 1 次式で変わるか | 普通の標準誤差を信じない。HC3 の列を読むか、分散をモデルに入れる |
| White | Breusch-Pagan に、特徴量の 2 乗と積を足したもの | 同上 |
| Jarque-Bera | 残差の歪みと尖り | 標本が小さければ、区間と検定を疑う。大きければ、それだけでは区間は崩れない (下) |
| 条件数 | 計画行列の最大と最小の特異値の比 | 係数のいくつかが、互いに分けて決まらない。どの列が絡むかを見る |

スクリプトは、普通の標準誤差と HC3 (不均一な分散に頑健) の標準誤差を並べて出す。

## 合成データで確かめたこと (2026-10-16、各 300 回)

| 世界 | 普通の 95% 区間が真の傾きを覆った割合 | HC3 の区間 | Breusch-Pagan の棄却 | White の棄却 | Jarque-Bera の棄却 |
|---|---:|---:|---:|---:|---:|
| 雑音が \|x\| で大きくなる (n 200) | 0.800 | 0.957 | 0.37 | 1.00 | |
| 雑音が x で大きくなる (x は 0〜3、n 200、100 回) | | | 0.95 超 | | |
| 雑音が歪む (指数分布 - 1)、分散は一定 (n 1,000) | 0.967 | | | | 1.00 |

- 広がりが \|x\| のように x について左右対称に変わると、Breusch-Pagan は 4 割弱しか気づかない。x の 1 次式しか見ないため。White の検定 (x² を足す) は全て気づいた。広がりの形を決め打ちできないなら、White も見る。
- 気づいても気づかなくても、普通の区間は 8 割しか覆わなかった。係数を検定するなら、検定の結果によらず HC3 の列を並べて読むほうが安全。
- 残差が正規でなくても、標本が大きければ傾きの区間は名目どおり覆った (0.967)。Jarque-Bera は全ての回で棄却した。棄却を、最小二乗を捨てる理由にしない。
- テストの別の例では、ほぼ同じ 2 つの列 (差の標準偏差 0.01) を入れると、長さをそろえた条件数が 50 倍以上になり、傾きの標準誤差が 30 倍以上になった。

## 条件数は単位で変わる

計画行列そのものの条件数は、列の単位で変わる。同じ変数を m から mm にすると、100 倍以上になった (テスト)。各列の長さを 1 にそろえた行列の条件数 (Belsley の型) は変わらない。スクリプトは両方を出す。statsmodels の `condition_number` は、そろえない側 (テストで一致を確かめた)。条件数に「何以上なら悪い」という決まった値は置かない。そろえた条件数が大きいときは、どの列の組が絡んでいるかを、相関と、列を抜いたときの係数の変わり方で見る。

## 外部の実装との照合

`scripts/test_regression_diagnostics_crosscheck.py` で、statsmodels 0.15.0 (scipy 1.18.1) と照合した。係数、普通と HC3 の標準誤差、`het_breuschpagan` (既定の studentised)、`het_white`、`jarque_bera` (統計量、p 値、歪み、尖り)、`condition_number` が、相対 1e-8 以内で一致した (種 5 つ、n 300、4 列)。

## 適用できない条件

- 空間の依存 (近い単位の残差が似る) は、これらの診断では分からない。残差の Moran's I を見る。
- 一般化線形モデル (ポアソン、ロジスティック) の残差には、この形のまま当てない。
- 診断の p 値で手順を分岐させる (棄却したら別の手法へ) と、その後の推論の名目の水準は保たれない。

## テスト

`uvx --with numpy --with scipy --with duckdb --with pytest pytest scripts/test_regression_diagnostics.py`。HC3 と Breusch-Pagan と Jarque-Bera を手で計算した値と比べ、上の表の合成の世界 (不均一な分散、歪んだ雑音、単位を変えた列、ほぼ同じ 2 列、階数の足りない計画行列) を確かめている。HC3 を HC0 にする、Breusch-Pagan で残差を 2 乗しない、条件数で列をそろえない、White から 2 乗と積を抜く、のそれぞれで落ちる。照合は `uvx --with numpy --with scipy --with duckdb --with statsmodels --with pytest pytest scripts/test_regression_diagnostics_crosscheck.py`。
