# MCMC

`scripts/mcmc.py`。解析的に解けない事後分布から、マルコフ連鎖で引く。答えの分かる小さなモデルで確かめ、連鎖の診断を必ず並べる。

## 決めごと

| 項目 | 中身 |
|---|---|
| サンプラー | ランダムウォーク Metropolis。制約の無いパラメータで (正の値は対数で) 引く。連鎖は複数 (既定 4)、ばらした初期値から。ウォームアップで提案の幅を、採択率 0.3 の方へ Robbins-Monro で合わせ、その後は固定し、ウォームアップを捨てる |
| ヤコビアン | 変数を変換して引くなら、対数密度に変換のヤコビアンの対数を足す (率を対数で引くなら + log 率)。足さないと別の事後を引く |
| R-hat | 順位で正規化し、連鎖を前後に分けた R-hat (Vehtari ら 2021)。中心 (bulk) と、中央値からの距離 (tail) の大きいほう。1.01 を超えたら信じない |
| ESS | 順位で正規化し分けた連鎖の、実効的な標本の数 (bulk)。自己相関を Geyer の単調な列で打ち切る |
| モデルの例 | 地域のランダム切片のポアソン回帰: y ~ Poisson(exp(α + u_地域) × 曝露)、u ~ N(0, σ²)、α ~ N(0, 10²)、σ ~ 半正規(1)。(α, log σ, u) で引く |

## 小さい既知解

| モデル | 解析解 | 確かめたこと (2026-10-16) |
|---|---|---|
| 正規の平均 (分散は既知、事前は正規) | 事後も正規 | 平均がモンテカルロの誤差の 4 倍以内、標準偏差が 8% 以内、R-hat 1.01 未満 |
| ポアソンの率 (事前はガンマ、率は対数で引く) | 事後はガンマ (a + Σy、b + n) | 平均が 2%、90% 点が 3% 以内 |

## 合成データで壊す

- ヤコビアンを落とすと、ガンマの事後の平均が 1 / (b + n) ずれた別の事後 (Gamma(a + Σy - 1, b + n)) を引く。データが少ない (n 5) と、ずれは 1/6 で、引いた平均は正しくない事後の平均に一致した。最初は n 40 で 2% ずれると見積もったが、ずれは 0.66% しかなく、見分けられなかった。
- 独立な引きは R-hat 1.00、ESS は引いた数に近い。場所のずれた連鎖は R-hat 1.5 超。自己相関 0.98 の連鎖は ESS 200 未満。
- 各連鎖が前半と後半で動く (連鎖どうしは一致する) と、分けた R-hat は 1.2 を超える。分けない R-hat では見えない。
- 模擬に基づく較正 (SBC): ランダム切片のモデルで、事前から α と σ を引き、件数を作り、当て、真の値の事後での順位を 60 回集めた。順位は α でも σ でも一様 (KS の p > 0.01)。log σ のヤコビアンを落とすと、σ の順位が一様でなくなる。

## 外部の実装との照合

`scripts/test_mcmc_crosscheck.py`。ArviZ 1.3.0 の `az.rhat(method="rank")` と `az.ess(method="bulk")` と、独立な引き、自己相関の強い連鎖、場所のずれた連鎖で、R-hat が相対 1e-8、ESS が 1e-6 で一致した。

最初は順位の正規化の分母を (S - 1/4) と書いていて、R-hat が相対 1e-5、ESS が 1e-3 ずれた。Stan と ArviZ は Blom の式 ((r - 3/8) / (S + 1/4)) を使う。このずれは合成データのテストでは見えず、照合で見つかった。

## 実データ: スコットランドの口唇がん

libpysal の Scotlip (56 地区の 1975〜1980 年の件数と期待数、GeoDa のデータとして配布、`GEOAI_REALDATA` の扱い)。各地区を 1 つのランダム切片にした (58 パラメータ)。

| 引き / ウォームアップ | α の R-hat、ESS | σ の中央値 (90% 区間)、R-hat、ESS | 地区の効果の最悪の R-hat、最小の ESS | 時間 |
|---|---|---|---|---|
| 2,000 / 2,000 | 1.666、6 | 0.80 (0.65〜1.03)、1.395、9 | 1.992、6 | 4 秒 |
| 20,000 / 20,000 | 1.064、55 | 0.78 (0.63〜0.96)、1.027、143 | 1.073、56 | 30 秒 |

- 58 次元のランダムウォーク Metropolis は、20,000 回引いても R-hat が 1.01 に届かない。診断が、信じてはいけないと告げている。数字 (σ の中央値 0.78 など) は、この表では信じない。
- このくらいの次元と相関のある事後には、勾配を使うサンプラーを使う (下の HMC)。

## ハミルトニアン モンテカルロ (HMC) と BYM2

`hmc` は、対数密度とその勾配から引く。軌跡の長さは事後の標準偏差の約 1.5 倍で、ステップの数は毎回 1 からその 2 倍までの一様。ウォームアップでは、ステップ幅を dual averaging (Hoffman と Gelman 2014) で受理率 0.8 に合わせる。前半の終わりに、対角の質量行列を引きの分散にし、ステップ幅を合わせ直す。エネルギーの誤差が 1,000 を超えた軌跡を発散として数える。NUTS (軌跡の長さの自動化) は実装していない。

`poisson_bym2` は BYM2 (Riebler ら 2016) の Poisson の疾病地図: y_i ~ Poisson(E_i exp(α + b_i))、b = σ (√(1 − ρ) θ + √(ρ / s) φ)。θ は独立な N(0, 1)、φ は ICAR (隣どうしの差の 2 乗の和に比例する事前)、s は ICAR の周辺の分散の幾何平均 (尺度の係数)。事前は α ~ N(0, 10²)、σ ~ 半正規 (1)、ρ ~ Beta(0.5, 0.5)。島のある (つながっていない) 隣接では、Freni-Sterrantino ら (2018) に倣い、2 地区以上の成分ごとに ICAR と合計 0 の制約 (標準偏差 0.001 × 成分の大きさの柔らかい制約) と尺度の係数を持ち、1 地区だけの成分の φ は N(0, 1)。パラメータは (α、log σ、logit ρ、θ、φ) で、2 つの変換のヤコビアンを含む。

既知解と確かめ (`scripts/test_mcmc.py`):

- 相関 0.9 の 2 つの軸と、分散 0.01 の細い軸を持つ 3 次元の正規分布: 平均がモンテカルロの誤差の 4 倍以内、共分散が 0.1 以内、R-hat 1.01 未満、発散 0。
- BYM2 の勾配が差分と 1e-5 で一致 (6 地区の輪と島 1 つ)。
- 尺度の係数: 8 地区の輪の ICAR の一般化逆行列の対角は (n² − 1) / (12n) で、全て一致。
- 最初の版は一般化逆行列に `np.linalg.pinv` を使い、Scotlip の 53 地区の成分で負の分散を返した。0 の固有値の丸めの誤差 (−4e-16) を切り捨てない既定の閾値のため。つながった成分のラプラシアンの一般化逆行列は (Q + 11ᵀ/m)⁻¹ − 11ᵀ/m で正確に書けるので、それに変えた (テスト)。
- 模擬からの回復 (6 × 6 の格子、構造化された効果だけ、σ 0.8): ρ の中央値が 0.5 を超え、地区の効果の事後平均と真値の相関が 0.8 を超えた。ρ の事後は上の境界の近く (中央値 0.97) で混ざりにくく、ウォームアップ 800 では σ の R-hat が 1.04、2,000 で 1.005。
- データに情報が無いとき (期待数 1e-9、件数 0) は、引きが事前に従う: σ の中央値 0.674 (半正規)、ρ の中央値 0.5。log σ のヤコビアンを対数密度と勾配の両方から一緒に落とす誤りは、勾配の差分のテストを通り、下の PyMC との照合も通った (事後の中央値のずれが、モンテカルロの誤差の 4 倍に収まる)。この事前に戻るテストだけが捕まえる。
- 件数が全て 0 のとき、最初の版は α の初期値を log(0) にしていた (このテストで見つかった)。

外部の実装との照合 (`scripts/test_mcmc_crosscheck.py`): 同じモデルを PyMC 6.3.2 (NUTS、target_accept 0.9) で書き、5 × 5 の格子と島 1 つの合成データで、α、σ、ρ の事後の中央値が、2 つの連鎖のモンテカルロの誤差の 4 倍以内で一致した。尺度の係数は両方が同じ関数を使うので、照合はその誤りを捕まえない (輪の手計算が守る)。

Scotlip (上と同じ 56 地区、Queen の隣接、島 3 つ、成分 4 つ。共変数は入れていない):

| | こちらの HMC | PyMC の NUTS |
|---|---|---|
| α の中央値 (標準偏差)、R-hat、ESS | 0.053 (0.057)、1.002、2,150 | 0.049 (0.059)、1.001、2,202 |
| σ | 0.644 (0.094)、1.008、417 | 0.654 (0.097)、1.007、730 |
| ρ | 0.968 (0.085)、1.008、408 | 0.969 (0.096)、1.018、280 |
| 地区の効果の事後平均 | 両者の差は最大 0.025 (事後の標準偏差の平均 0.29)、相関 0.9999 | |
| 時間 (4 連鎖、2,000 + 1,000) | 50 秒 | 89 秒 |

- 115 パラメータでも、HMC の R-hat は 1.01 以下。上のランダムウォーク (58 パラメータ、20,000 回で 1.06) とは違う。
- 地区の効果のほとんどは構造化された部分 (ρ の中央値 0.97)。ρ は境界の近くで ESS が 300〜400 と少なく、PyMC の R-hat も 1.018 で 1.01 を超えた。ρ の推定は、どちらでも長く引いて確かめる。

## 適用できない条件

- 数十を超える次元、強く相関した事後 (ランダムウォークでは混ざらない)。
- BYM2 に共変数は無い (切片だけ)。
- NUTS は無い。軌跡の長さは固定の目安からの一様で、事後の形によっては無駄が多い。
- 事前予測と事後予測の確かめは、bayesian-modeling.md の共役なモデルにはあるが、このスクリプトのモデルにはまだ無い。

## テスト

`uvx --with numpy --with scipy --with pytest pytest scripts/test_mcmc.py`。上の診断、既知解、ヤコビアン、SBC、HMC と BYM2 を確かめている。分けない R-hat、ランダム切片のモデルの log σ のヤコビアンを落とす、のそれぞれで落ちる。tail の R-hat を外す、Geyer の単調化を外す、のそれぞれは主のテストでは落ちず、照合のテスト (`uvx --with numpy --with scipy --with arviz --with pymc --with pytensor --with geopandas --with libpysal --with pytest pytest scripts/test_mcmc_crosscheck.py`、Scotlip は `GEOAI_REALDATA=1`) で落ちる。BYM2 の log σ のヤコビアンを落とすと、事前に戻るテストだけで落ちる。
