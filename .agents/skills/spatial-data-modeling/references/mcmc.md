# MCMC

`scripts/mcmc.py`。解析的に解けない事後分布から、マルコフ連鎖で引く。答えの分かる小さなモデルで確かめ、連鎖の診断を必ず並べる。

## 決めごと

| 項目 | 中身 |
|---|---|
| サンプラー | ランダムウォーク Metropolis。制約の無いパラメータで (正の値は対数で) 引く。連鎖は複数 (既定 4)、ばらした初期値から。ウォームアップで提案の幅を、採択率 0.3 の方へ Robbins-Monro で合わせ、その後は固定し、ウォームアップを捨てる |
| ヤコビアン | 変数を変換して引くなら、対数密度に変換のヤコビアンの対数を足す (率を対数で引くなら + log 率)。足さないと別の事後を引く |
| R-hat | 順位で正規化し、連鎖を前後に分けた R-hat (Vehtari ら 2021)。中心 (bulk) と、中央値からの距離 (tail) の大きいほう。1.01 を超えたら信じない |
| ESS | 順位で正規化し分けた連鎖の、実効的な標本の数 (bulk)。自己相関を Geyer の単調な列で打ち切る |
| モデルの例 | 地域のランダム切片のポアソン回帰: y ~ Poisson(exp(α + u_地域) × 曝露)、u ~ N(0, σ²)、α ~ N(0, 10²)、σ ~ 半正規(1)。(α, log σ, u) で引く |

## 小さい既知解

| モデル | 解析解 | 確かめたこと (2026-10-16) |
|---|---|---|
| 正規の平均 (分散は既知、事前は正規) | 事後も正規 | 平均がモンテカルロの誤差の 4 倍以内、標準偏差が 8% 以内、R-hat 1.01 未満 |
| ポアソンの率 (事前はガンマ、率は対数で引く) | 事後はガンマ (a + Σy、b + n) | 平均が 2%、90% 点が 3% 以内 |

## 合成データで壊す

- ヤコビアンを落とすと、ガンマの事後の平均が 1 / (b + n) ずれた別の事後 (Gamma(a + Σy - 1, b + n)) を引く。データが少ない (n 5) と、ずれは 1/6 で、引いた平均は正しくない事後の平均に一致した。最初は n 40 で 2% ずれると見積もったが、ずれは 0.66% しかなく、見分けられなかった。
- 独立な引きは R-hat 1.00、ESS は引いた数に近い。場所のずれた連鎖は R-hat 1.5 超。自己相関 0.98 の連鎖は ESS 200 未満。
- 各連鎖が前半と後半で動く (連鎖どうしは一致する) と、分けた R-hat は 1.2 を超える。分けない R-hat では見えない。
- 模擬に基づく較正 (SBC): ランダム切片のモデルで、事前から α と σ を引き、件数を作り、当て、真の値の事後での順位を 60 回集めた。順位は α でも σ でも一様 (KS の p > 0.01)。log σ のヤコビアンを落とすと、σ の順位が一様でなくなる。

## 外部の実装との照合

`scripts/test_mcmc_crosscheck.py`。ArviZ 1.3.0 の `az.rhat(method="rank")` と `az.ess(method="bulk")` と、独立な引き、自己相関の強い連鎖、場所のずれた連鎖で、R-hat が相対 1e-8、ESS が 1e-6 で一致した。

最初は順位の正規化の分母を (S - 1/4) と書いていて、R-hat が相対 1e-5、ESS が 1e-3 ずれた。Stan と ArviZ は Blom の式 ((r - 3/8) / (S + 1/4)) を使う。このずれは合成データのテストでは見えず、照合で見つかった。

## 実データ: スコットランドの口唇がん

libpysal の Scotlip (56 地区の 1975〜1980 年の件数と期待数、GeoDa のデータとして配布、`GEOAI_REALDATA` の扱い)。各地区を 1 つのランダム切片にした (58 パラメータ)。

| 引き / ウォームアップ | α の R-hat、ESS | σ の中央値 (90% 区間)、R-hat、ESS | 地区の効果の最悪の R-hat、最小の ESS | 時間 |
|---|---|---|---|---|
| 2,000 / 2,000 | 1.666、6 | 0.80 (0.65〜1.03)、1.395、9 | 1.992、6 | 4 秒 |
| 20,000 / 20,000 | 1.064、55 | 0.78 (0.63〜0.96)、1.027、143 | 1.073、56 | 30 秒 |

- 58 次元のランダムウォーク Metropolis は、20,000 回引いても R-hat が 1.01 に届かない。診断が、信じてはいけないと告げている。数字 (σ の中央値 0.78 など) は、この表では信じない。
- このくらいの次元と相関のある事後には、勾配を使うサンプラー (ハミルトニアン モンテカルロ、NUTS) を使う。このスクリプトにはない。

## 適用できない条件

- 数十を超える次元、強く相関した事後 (ランダムウォークでは混ざらない)。
- 空間のランダム効果 (BYM、ICAR) は、まだ無い。
- 事前予測と事後予測の確かめは、bayesian-modeling.md の共役なモデルにはあるが、このスクリプトのモデルにはまだ無い。

## テスト

`uvx --with numpy --with scipy --with pytest pytest scripts/test_mcmc.py`。上の診断、既知解、ヤコビアン、SBC を確かめている。分けない R-hat、ランダム切片のモデルの log σ のヤコビアンを落とす、のそれぞれで落ちる。tail の R-hat を外す、Geyer の単調化を外す、のそれぞれは主のテストでは落ちず、照合のテスト (`uvx --with numpy --with scipy --with arviz --with pytest pytest scripts/test_mcmc_crosscheck.py`) で落ちる。
