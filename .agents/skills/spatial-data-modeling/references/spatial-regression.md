# 空間回帰 (残差に空間の偏りが残るとき)

普通の最小二乗 (OLS) は、行の誤差が互いに独立だと仮定する。近い単位の誤差が似ている (残差に空間的自己相関がある) と、この仮定が崩れる。

## 何が起きるか

- 誤差に自己相関があるだけなら (空間誤差の構造)、係数の推定は偏らないが、標準誤差が小さく出る。p 値が小さすぎ、有意でない係数を有意と読む。
- 目的変数そのものが近傍の目的変数に左右されるなら (空間ラグの構造)、近傍の効果を落とした OLS の係数は偏る。
- 単位を細かくするほど行が増え、標本が大きく見えるが、独立な情報は増えない。

モデルを比べるスクリプト (compare_models.py) は、係数の標準誤差を出さない。係数や p 値を説明に使うときに、この節の確かめ方が要る (残差と計画行列の診断は regression-diagnostics.md、空間ラグと空間誤差は下の実装)。

## 確かめ方

1. 交差検証の外側の予測で残差を作り、残差の Moran's I を測る (`scripts/error_breakdown.py --lon 列 --lat 列 --k 6`)。k を 2〜3 段変えて測る。
2. I が期待値 (−1 / (n − 1)) に近く、並べ替えの p 値が大きければ、空間の偏りは目立たない。そうでなければ、次に進む。
3. 偏りが残るなら、どちらの構造かを、OLS の残差に対するラグランジュ乗数検定 (LM-lag と LM-error、Anselin 1988) で見分ける。片方だけが有意なら、そちらのモデル (空間ラグモデル、空間誤差モデル) を使う。両方が有意なら、頑健な版 (robust LM-lag、robust LM-error、Anselin ら 1996) で大きい方を使う (`scripts/spatial_regression.py`)。ただし、検定の結果だけで構造を決めず、波及の仕組みがもっともらしいかを先に書く。

## モデルの選び方

| 状況 | 候補 | 読み方の注意 |
|---|---|---|
| 誤差だけが空間で似る (観測していない地域の要因) | 空間誤差モデル (SEM) | 係数は OLS とほぼ同じで、標準誤差が正しくなる |
| 目的変数が近傍の目的変数に左右される (波及、競合) | 空間ラグモデル (SLM、SAR) | 係数をそのまま限界効果と読まない。近傍を通じた効果を含む直接効果と間接効果に分けて報告する (LeSage と Pace 2009) |
| 予測が目的で、構造の解釈は要らない | 空間の特徴量 (近傍の値の平均、座標の固有ベクトル、空間フィルタ) を足す | 近傍の値を特徴量にするときは、試験側の目的変数を使わない (リーク) |
| 係数そのものが場所で違うか知りたい | 地理的加重回帰 (GWR) | 帯域幅で結果が変わる。局所の係数の多重比較に注意する |

どのモデルでも、空間の重み (k、距離) の選び方で結果が変わる。重みを 2〜3 通り変えて、結論が保たれるかを書く。

## 実装 (`scripts/spatial_regression.py`)

- OLS と、その残差の LM 検定 4 つ。
- 空間ラグと空間誤差の最尤。β と σ² を集約し、ρ (λ) を (1 / W の最小の固有値, 1) で最大化する。log|I − ρW| は W の固有値から。標準誤差は漸近の情報行列 (ラグでは β と ρ と σ² の全て)。
- ラグのモデルの効果: 直接 = β × mean(diag((I − ρW)⁻¹))、全体 = β / (1 − ρ) (行で標準化した W)、間接 = 全体 − 直接。
- W は (id、近傍) のペアの表か、球面の k 近傍。行で標準化する (近傍の無い単位の行は 0)。密に持つので 3,000 単位まで。

```sh
uvx --from 'duckdb>=1.5.5' --with numpy --with scipy python scripts/spatial_regression.py tmp/units.parquet id y x1 x2 \
    --pairs tmp/queen_pairs.parquet
```

## 合成データで確かめたこと

15 × 15 の格子 (上下左右、行で標準化)、y = ρWy + 1 + 2x + e または y = 1 + 2x + u、u = λWu + e (2026-10-16)。

- 最尤は ρ 0.5 と λ 0.6 を戻した (10 回の平均の誤差 0.05 と 0.06 以内)。ρ の 95% 区間は 60 回で 85% 以上覆った。
- 誤差の構造の世界では LM-error と頑健な LM-error が有意で、頑健な LM-lag は有意でない。ラグの世界では LM-lag と頑健な LM-lag が有意。
- ラグの世界で、場所と無関係な x の OLS の傾きは、β (2) ではなく、近傍を回って戻る分を含む直接効果 (2.1 前後) に近づいた。OLS は間接効果 (近傍への波及) を全く表さない。
- 依存の無い世界では、ρ は 0 に近く、係数は OLS とほぼ同じ。

## 外部の実装との照合

`scripts/test_spatial_regression_crosscheck.py`。spreg 1.9.1 (`ML_Lag`、`ML_Error` の method="full"、`OLS` の spat_diag) と、libpysal 4.15 に同梱の Columbus の犯罪のデータ (49 地区、Queen、行で標準化、犯罪を所得と住宅価格に回帰) で照合した。ρ、λ、係数は相対 1e-5、対数尤度は 1e-8、標準誤差は 1e-3、LM 検定 4 つは 1e-8 で一致した (2026-10-16)。

| | 値 |
|---|---|
| OLS | 定数 68.62、所得 -1.597、住宅価格 -0.274 |
| LM-lag、LM-error | 8.90 (p 0.003)、5.21 (p 0.023) |
| 頑健な LM-lag、頑健な LM-error | 3.74 (p 0.053)、0.04 (p 0.83) |
| 空間ラグ | ρ 0.423 (0.120)、所得 -1.049 (0.307)、住宅価格 -0.266 (0.089)、対数尤度 -182.67、AIC 375.3 |
| 空間誤差 | λ 0.547 (0.138)、所得 -0.957、住宅価格 -0.305、対数尤度 -183.75、AIC 377.5 |
| 所得の効果 (ラグ) | 直接 -1.101、間接 -0.718、全体 -1.819 |

- LM の検定はラグを指し (頑健な LM-error は 0.83)、AIC もラグがわずかに良い。
- ラグの係数 -1.049 は所得の効果ではない。近傍を通じた分を含めると、全体の効果は -1.82 で、その 4 割 (-0.72) が近傍への波及。

## このリポジトリで確かめていないこと

- GWR は gwr.md と `scripts/gwr.py`。
- 空間ダービン (SDM、Wx を足す型)、一般化モーメント法の推定、ラグと誤差を同時に持つ型 (SAC) は無い。
- 効果の標準誤差 (模擬による) は出さない。
- 実データでの、W を変えた感度は測っていない。

## テスト

`uvx --with numpy --with scipy --with pytest pytest scripts/test_spatial_regression.py`。行で標準化した格子の重み、ρ と λ と β の回復、OLS の傾きが直接効果になること、LM 検定が作った構造を指すこと、依存が無いとき、効果の分け方、ρ の区間の被覆を確かめている。対数行列式を落とす、直接効果を β にする、のそれぞれで落ちる。頑健な LM-lag の分母を誤る変更は、このテストでは落ちず、照合のテスト (`uvx --with numpy --with scipy --with spreg --with libpysal --with pytest pytest scripts/test_spatial_regression_crosscheck.py`) で落ちる。小さな密な行列を何度も解くので、テストは BLAS のスレッドを 1 本にしている (作者の機械で、全スレッドでは 60 秒、1 本では 2 秒)。
