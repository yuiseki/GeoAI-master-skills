# 件数と率のモデル

事故、事件、施設、患者、死亡、紛争の数のように、0 以上の整数で、単位の大きさ (人口、道路の長さ、期間) に比例して増える値を目的変数にするとき。

## なぜ普通の回帰では足りないか

- 件数は 0 より下にならず、平均が大きいほどばらつきも大きい。正規分布の誤差を仮定する OLS は、負の予測を出し、大きい単位の誤差に引っ張られる。
- 件数は、単位の大きさ (発生の機会、exposure) に比例して増える。人口の多い単位で件数が多いのは当然で、それを説明変数の効果と取り違える。
- 率 (件数 / 人口) を先に作って OLS すると、分母の小さい単位の率が大きく揺れ、その揺れに回帰が引っ張られる。率が 0 の単位では対数が取れず、小さな数を足すと結果がその数で変わる。

## ポアソン回帰と offset

件数 y が、平均 μ のポアソン分布に従い、log(μ) = log(発生の機会) + β0 + β1 x と書く。log(発生の機会) は係数を推定しない項 (offset) で、率 μ / 発生の機会 を説明変数でモデル化していることになる。

- 係数 β1 は、x が 1 増えたときの率の対数の変化。exp(β1) が発生率比 (incidence rate ratio): x が 1 増えると率が何倍になるか。
- 仮定: 件数が独立に起きる。平均と分散が等しい (等分散でなく、分散 = 平均)。発生の機会に比例する。これが崩れると、係数はおおむね保たれても、標準誤差と信頼区間が狭すぎる。

## 合成データでの比較

500 の単位、発生の機会 (人口) は 200 から 20 万、x の効果 β1 = 0.5 (発生率比 1.649)。x は人口の多い単位で大きい (statsmodels、2026-10-14)。

| 方法 | x の係数 | 読み |
|---|---|---|
| 件数をそのまま OLS (発生の機会なし) | 11.6 | 人口の差を x の効果と取り違え、単位も無い |
| 率 (人口あたり) を OLS | 0.0001 | 率の尺度の差で、倍率でない。小さな分母の揺れが効く |
| log(率 + 1e-6) を OLS | 1.37 | 0 の単位 (184) に足した数で大きく偏る (真の 0.5 の約 2.7 倍) |
| ポアソン、offset log(人口) | 0.512 (発生率比 1.669、95% 区間 1.626〜1.712) | 真の値に近い |

## 過分散

分散が平均より大きい (過分散) と、ポアソンの標準誤差は小さすぎる。確かめ方: ポアソンの当てはめの Pearson χ² / 自由度。1 に近ければよく、大きければ過分散。

同じ作りで、単位ごとの率にガンマ分布の揺れ (負の二項分布、α = 0.5) を加えて 200 回当てはめた結果は次のとおり。

| | 値 |
|---|---|
| Pearson χ² / 自由度の中央値 | 6.1 |
| ポアソンの 95% 区間が真の β1 を含んだ割合 | 21.5% |
| 負の二項分布の 95% 区間が真の β1 を含んだ割合 | 94.5% |

過分散のまま、ポアソンの区間や p 値を報告しない。負の二項分布 (または頑健な標準誤差、準ポアソン) にする。

## ゼロが多いとき

ゼロの数を、当てはめたモデルが期待するゼロの数と比べる。上の過分散のデータでは、観測したゼロが 234、ポアソンの期待が 216、負の二項分布の期待が 232 だった。ゼロが多く見えても、過分散で説明できることが多い。ゼロ過剰モデル (zero-inflated) は、ゼロを生む別の過程 (その単位では起こりえない、記録していない) に根拠があるときだけ使う。根拠なしに使うと、ゼロの過程の係数を解釈できない。

## 気をつけること

- 発生の機会は、現象が起こりうる量。記録のされやすさ (観測の努力) ではない。人口で割っても、記録の偏りは補正されない。
- 分母の小さい単位の率を地図や順位にすると、偶然で上下に並ぶ。率を比べるなら、モデルの予測した率か、縮めた率で比べる。
- 予測区間は、平均の信頼区間より広い。件数の予測区間は、平均の不確かさと、ポアソン (または負の二項) の揺れの両方を含める。
- 残差 (Pearson 残差、逸脱度残差) を、予測値、説明変数、地域に対して見る。残差に空間の偏りが残るなら、行は独立でなく、区間は狭すぎる (残差の Moran's I は `scripts/error_breakdown.py --lon --lat`)。
