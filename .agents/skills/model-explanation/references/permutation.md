# permutation importance

各 fold で学習側の行にモデルを当てはめ、試験側の行で 1 つの特徴量の値を行の間で並べ替え、点数 (回帰は R2、分類は AUC) がどれだけ落ちるかを測る。並べ替えは fold ごとに 5 回 (`--shuffles`) の平均。全ての fold と repeat の平均とばらつきを出す。

## 試験側の行で測る

学習側の行で測ると、モデルが覚えただけの特徴量も重要に見える。ランダムフォレストは純粋な雑音の特徴量も学習側では使うので、学習側で測ると重要度が正になる。試験側の行では、覚えたことは役に立たないので、0 付近になる (テストで確かめている)。scikit-learn の木の `feature_importances_` (不純度に基づく重要度) は学習側の分け方から計算されるので、この問題を避けられない。

## 相関の強い特徴量は群で並べ替える

2 つの特徴量がほぼ同じものを測っていると、片方を並べ替えてももう片方が代わりを務め、どちらも重要でないように見える。`--group NAME=F1,F2` で、群の特徴量を同じ並べ替えでまとめて動かすと、群としての重要度が出る。群の中の組 (緯度と経度の組など) は保ったまま、目的変数との関係だけを壊す。別々に並べ替えると、ありえない組 (北極の緯度と赤道の経度) を作り、点数の落ち方も変わる。

## 分割表で重要度が変わる

WDI の 2022 年の平均寿命 (207 か国) を、1 人あたり GDP (対数)、人口 (対数)、都市人口の割合、位置 (Natural Earth の `LABEL_X`、`LABEL_Y`) で、hgb で予測した (2026-10-10)。

| 特徴量 | 行を無作為に 5 分割、repeat 3 | 地域で 5 分割 |
|---|---:|---:|
| 1 人あたり GDP | +0.991 | +0.851 |
| 緯度と経度 (群) | +0.136 | -0.068 |
| 緯度 | +0.118 | -0.062 |
| 経度 | +0.055 | +0.017 |
| 都市人口の割合 | +0.017 | +0.042 |
| 人口 | +0.009 | -0.012 |

- 位置は、行を無作為に分けると R2 を 0.14 支えるが、地域で分けると支えない (負)。同じ地域の別の国が学習側にいるときだけ、位置から水準を借りられる。位置が近い行を覚えるリークと同じ構図。
- 緯度と経度の群の重要度 (0.136) は、緯度だけ (0.118) より大きい。
- 地域で分けた重要度はばらつきが大きい (1 人あたり GDP で sd 0.512)。fold が地域ごとで、地域によって効き方が違うため。
