# 時空間のクリギング

平均の構造 (地点の効果 + 時刻の効果) を除いた残差を、空間と時間の両方の近さで補う。`scripts/st_kriging.py`。

```sh
uvx --from 'duckdb>=1.5.5' --with numpy --with scipy python scripts/st_kriging.py TABLE LOCATION TIME X Y VALUE \
  --cutoff T [--detrend additive|none] [--space exponential|gaussian] [--time exponential|gaussian] [--blocks]
```

予測先の 3 つ (既知の地点の未来、未知の地点、未知の地点の未来) の分け方ごとに、平均の構造だけの RMSE と、残差をクリギングで補った RMSE、90% の区間の被覆を並べる。平均の構造は既定で時刻の効果だけ (`--detrend time`: 全体の平均 + 時刻ごとの効果)。地点の水準は残差に残し、空間の共分散に任せる (下の「先に除いたものの誤差は区間に入らない」)。分け方は `st_model.py` と同じ。パラメータは fold ごとに学習の行だけで推定し直し、その値を表示する。

## 仮定

- 残差の共分散が分離できる: C(h, u) = 分散 × fs(h / 空間の範囲) × ft(u / 時間の範囲)。fs と ft は指数 (exp(-r)) かガウス (exp(-r²))。時間が指数なら、整数の時刻では AR(1) (φ = exp(-1 / 時間の範囲)) と同じ。
- 空間で等方: 向きで相関の届き方が変わらない。X と Y は同じ単位の投影座標 (緯度経度のままにしない)。
- 定常: 分散と範囲が場所と時刻で変わらない。
- 平均は未知の定数で、一般化最小二乗で推定する (通常クリギング)。残差に残った傾向は、範囲が大きく推定される形で現れる。
- 正規の尤度で推定する。分布の裾が重いと、ナゲットと分散の分け方が変わる。
- これはガウス過程の回帰で、核が空間 × 時間の積のものと同じ。

## 小さい既知解

`scripts/test_st_kriging.py`。

- 共分散の値を手で計算した例。指数の時間の核が、整数の時刻で φ^u になること。
- ナゲットが 0 なら、観測の地点と時刻では観測値そのものを返し、分散が 0。
- 全ての観測から遠い点では、予測は一般化最小二乗の平均、分散は「分散 + 平均の推定の分散」。範囲が小さく共分散の行列が (分散 + ナゲット) I なら、平均は単純な平均、平均の分散は (分散 + ナゲット) / n。
- 経験バリオグラムの 3 点の例。

## 合成データで壊す

- 分離できる世界 (`st_model.simulate("separable")`: 空間は指数で範囲 0.3、時間は AR(1) で φ 0.8、つまり範囲 4.48、分散 1、ナゲット 0.25)。30 地点 × 20 時刻 × 4 回の推定の中央値が、分散 ±35%、空間の範囲 ±40%、時間の範囲 ±35%、ナゲット ±25% に入った。40 地点 × 25 時刻の 3 回では (0.89〜1.23、0.24〜0.44、3.9〜5.4、0.25〜0.30)。
- 動く場 (x の方向にだけ変わる場が、1 時刻に 0.03 ずつ東へ流れる。C = exp(-|dx - 0.03 du| / 0.2)、分離できない) と、同じ異方性で止まった場 (exp(-|dx| / 0.2) exp(-0.15 |du|)、分離できる)。どちらも 30 地点 × 25 時刻で、最後の 5 時刻を既知の地点で予測した。真の共分散でのクリギング (理想) との RMSE の比を取った。

  | 世界 | 既知の地点の未来 | 未知の地点 | 90% の区間の被覆 |
  |---|---|---|---|
  | 分離できる (等方) | 0.94〜1.08 | 1.00〜1.02 | 0.83〜0.96 (1 回ずつ) |
  | 止まった場 (異方) | 1.00〜1.13 | 1.08〜1.32 | 0.89〜0.92 (4 回の平均) |
  | 動く場 | 1.25〜1.50 | 1.28〜1.47 | 0.86〜0.91 (4 回の平均) |

  既知の地点の未来では、損のほとんどは分離できないことから来る。未知の地点では、異方性だけでも 1.1〜1.3 倍の損があり、2 つが混ざる。区間の被覆はどの世界でも 0.83〜0.96 で、損は区間の幅として正直に出た (最初の仮説「分離できない世界では区間が外れる」は外れた)。動く場の最良の予測は上流の地点の値だが、分離できる型は上流を指せない。
- 最初は Nelder-Mead で 3 つの出発点から推定し、1,000 観測で 1 回 100 秒かかった。距離の行列を 1 回だけ作り、L-BFGS-B (対数の空間の範囲に上下限) に変えると、同じ最適値に 9.5 秒で届いた。
- 尤度には範囲について複数の山がある。出発点を初期値の ±e 倍だけ動かす版は、scikit-learn との照合のデータで、時間の範囲 4.3 の山で止まった (対数尤度 -127.43)。scikit-learn は時間の範囲 60 の山 (-125.93) に届いていた。今は、空間と時間の範囲の 5 × 5 の格子と分散の分け方 2 通りで尤度を先に測り、上位の 3 点から L-BFGS-B を走らせる。この変更の後も、上の合成データの推定は全て同じ値になった。1,000 観測の 1 回の当てはめは 18〜22 秒 (CPU 1 スレッド)。山が複数あることは、範囲の推定を報告するときに、別の山がどれだけ低いかも書くべきことを意味する (未実装)。

## 先に除いたものの誤差は区間に入らない

区間の分散は、クリギングの部分の不確かさだけ。先に除いた平均の構造の推定の誤差は入らない。

- 最初は `--detrend additive` (地点の効果 + 時刻の効果を除く) を既定にしていた。WDI の平均寿命 (下) の未知の地点で、90% の区間が 0.42 しか覆わなかった。新しい地点の地点の効果は、近い地点の逆距離の平均で埋まる。その誤差 (RMSE 4.8 歳) は区間のどこにも入らない。クリギングが知っているのは、学習側の地点の効果を除いた後の小さな残差だけ。
- 合成データで確かめた (`st_model.simulate("additive")`、40 地点 × 15 時刻、8 地点を伏せる、3 回)。足し算の分解の後にクリギングすると被覆は 0.55〜0.83。分解せずにクリギングすると 0.82〜0.92、時刻の効果だけを除くと 0.81〜0.94 で、RMSE はほとんど同じだった。時刻の効果だけを除くと、空間の範囲は地点の水準の尺度 (0.3) に近い 0.13〜0.23 になり、時間の範囲は上限に張り付いた (地点の水準は時間で変わらない。表示に出る)。
- そこで既定を `--detrend time` に変えた。未来の時刻の効果 b(t) も、AR(1) の予測の誤差が区間に入らない。この影響は測っていない (未確認)。

## 外部の実装との照合

scikit-learn 1.9.1 の `GaussianProcessRegressor` と照合した (`scripts/test_st_kriging_crosscheck.py`)。ガウスの空間の核とガウスの時間の核の積は、軸ごとに長さの違う 1 つの RBF の核 (長さは (空間の範囲, 空間の範囲, 時間の範囲) / √2) と同じなので、平均を 0 に固定した単純クリギングで比べられる。

- 固定したパラメータで、予測、分散 (scikit-learn の標準偏差は白色雑音を含む)、対数尤度が 1e-8 以内 (尤度は相対 1e-10) で一致した。
- 最尤の推定: scikit-learn は x と y に別々の長さを持つので、2 次元の点では尤度がこちらより高くなる (-58.5 と -61.3)。点を直線の上 (y = 0) に置き、y の長さが効かないようにすると、最大の対数尤度が 1e-4 以内、長さとナゲットが 1% 以内で一致した。こちらの最適値から各パラメータを ±10% 動かすと、scikit-learn の尤度が下がる。
- 指数の核の積に当たる核は scikit-learn に無い (Matern は全ての軸をまとめた 1 つの距離を取るので、分離できない)。指数の族は、手で計算した値と、模擬からの回復だけで確かめた。

## 実データ: 国の平均寿命

WDI の平均寿命 (版 2026-10-01、`SP.DYN.LE00.IN`)、2010〜2019 年、215 か国 × 10 年 = 2,150 行 (欠けなし)。国の位置は Natural Earth 5.1.2 の代表点 (LABEL_X、LABEL_Y) を Mollweide (ESRI:54009) で投影し、1,000 km を単位にした。未来の分け方は 2016 年までで学習、2017〜2019 年で試験。未知の地点は無作為な 5 群 (2026-10-16、1 回の実行は 10〜12 分、CPU 4 コアの上限。最適化の出発点を直した後に流し直し、同じ数字になった)。

| 予測先 | 平均の構造 | 平均の構造だけの RMSE | クリギングを足した RMSE | 90% の区間の被覆 |
|---|---|---:|---:|---:|
| 既知の地点の未来 | 足し算 | 1.72 | 1.55 | 0.876 |
| | 時刻だけ (既定) | 8.01 | 1.59 | 0.980 |
| 未知の地点 | 足し算 | 4.78 | 4.78 | 0.424 |
| | 時刻だけ | 8.29 | 5.13 | 0.940 |
| 未知の地点の未来 | 足し算 | 4.86 | 4.86 | 0.411 |
| | 時刻だけ | 8.02 | 5.43 | 0.950 |

- 足し算の分解の後のクリギングは、未知の地点で RMSE をほとんど変えず、区間は 4 割しか覆わない (上の節)。
- 時刻の効果だけを除くと、区間は約束を超えて覆った (0.94〜0.98)。RMSE は未知の地点で 4.78 から 5.13 に悪くなった。点の予測は、近い国の地点の効果の逆距離の平均のほうが少し良い。区間の正しさと点の当たりが、平均の構造の選び方で入れ替わる。
- 時刻だけを除いたときの 11 個の fold の推定は、空間の範囲 95〜870 km (中央値 560 km)、時間の範囲 51〜330 年、分散 43〜70 (国の間の平均寿命のばらつき)。fold ごとに大きく動くが、時間の範囲はどれも 10 年の観測より長い。国の水準はほとんど時間で変わらない。4 つの fold で、どれかのパラメータが上限か下限に張り付いた (ナゲットが 0 に近いものなど)。
- 足し算の分解の後の残差では、11 個のうち 6 つの fold で、ナゲットが下限 (0) に張り付いた。残差が 10 年で滑らかで、観測の雑音が見えない。

## 適用できない条件

- 観測が 3,000 を超える (n × n の共分散の行列を持つ)。大きなデータの近似 (格子のクロネッカー積、疎な近似、SPDE) は未実装。
- 動く場、向きのある相関 (上の表)。異方性と、分離できない共分散 (Gneiting の族など) は未実装。
- 範囲が上限や下限に張り付いたとき (表示に出る)。残差に傾向が残っているか、相関がデータの広がりより長い。
- 地球全体を投影した座標: 遠い地点の距離は投影で歪む。球面の距離での共分散は未実装。

## テスト

`uvx --from 'duckdb>=1.5.5' --with numpy --with scipy --with pytest pytest scripts/test_st_kriging.py`。平均の推定の分散を落とす、対数行列式を半分にする、時間の核に空間の範囲を使う、のそれぞれで落ちる。照合は `uvx --from 'duckdb>=1.5.5' --with numpy --with scipy --with scikit-learn --with pytest pytest scripts/test_st_kriging_crosscheck.py`。
