# 時空間の構造: 効果の分解と残差の依存

## 分解

y(s, t) = 全体の平均 μ + 空間の効果 a(s) + 時間の効果 b(t) + 相互作用 + 時空間の残差 + 雑音

| 部分 | 意味 | 例 (測定局の濃度) |
|---|---|---|
| 空間の効果 a(s) | 地点ごとの、時間をならした水準。近い地点で似る (空間の依存) | 幹線道路沿いの局は高い |
| 時間の効果 b(t) | 全ての地点に共通の、時刻ごとの水準。近い時刻で似る (時間の依存、AR(1) のように前の時刻を引きずる) | 気圧配置で全域が高い日 |
| 相互作用 | 時間の変わり方が地点で違う部分 | 新しい道路の沿線だけ年々上がる |
| 時空間の残差 | 上で説明しきれず、近い地点と近い時刻の両方で似る部分 | 移動する汚染の塊 |
| 雑音 | 地点にも時刻にも依らない誤差 | 測定の誤差 |

`scripts/st_model.py` は、上の 4 つのモデル (空間だけ、時間だけ、足し算、地点ごとの傾きの相互作用) を、観測のあるセルだけで交互に平均をとって当てはめる。欠けた地点 × 時刻のセルがあっても当てはまる (テストで、2 地点 × 3 時刻の 1 セルを欠いても、足し算の値が手計算と一致する)。

未観測の部分の予測:
- 学習に無い地点の a(s) と傾きは、近い 4 地点の距離の逆数の重みの平均。
- 最後の時刻より後の b(t) は、AR(1) で φ^(間隔) × 最後の b。φ は学習の b(t) から、それぞれの間隔のまま当てはめる (時刻の間隔が不規則でもよい)。学習の時刻の間は直線で補う。

### 外部の実装との照合

`scripts/test_st_model_crosscheck.py` で照合した (2026-10-15)。
- 4 つの分解の当てはめ値は、地点と時刻のダミー変数 (相互作用は地点ごとの傾き) を並べた計画行列の最小二乗の解 (patsy で組み、numpy の lstsq で解く) と、欠けたセルのある合成データで 1e-6 以内で一致した。
- WDI の平均寿命 (2000〜2019 年、国の代表点を Mollweide で投影、4,300 行、`GEOAI_REALDATA=1` で流れる) でも一致した。この計画行列は 441 列で階数 438 (観測 1 行の国の傾きの列は 0)。statsmodels 0.15.0 の OLS はこの計画行列で、残差の平方和が最小値より 0.2 大きい当てはめ値を返したので、照合の基準にしなかった。
- 時刻ごとの Moran's I は、同じ 4 近傍のグラフ (二値、対称化) での PySAL の esda 2.10.0 の値と 1e-10 で一致した。esda の `Moran` は、引数 `transformation` の既定が行の基準化 ("r") で、グラフに設定した変換を上書きする。二値で比べるには `transformation="B"` を渡す。

## 一方のモデルは、もう一方の依存を残す

合成の世界 (50 地点、30 時刻、`simulate`、種 0) で、全ての行に当てはめた残差の依存:

| 世界 | モデル | 空間の自己相関 (Moran's I) | 時間の自己相関 (1 期) |
|---|---|---:|---:|
| 足し算 (地点の場 + AR(1) の時間 + 雑音) | 空間だけ | -0.031 | 0.651 |
| | 時間だけ | 0.643 | -0.039 |
| | 足し算 | -0.031 | -0.039 |
| 相互作用 (足し算 + 地点ごとの滑らかな傾き) | 足し算 | 0.114 | 0.570 |
| | 相互作用 | -0.033 | -0.056 |
| 分離可能な時空間の場 (空間の共分散 × 時間の共分散) | 足し算 | 0.386 | 0.507 |
| | 相互作用 | 0.345 | 0.418 |

- 空間だけのモデルは時間の依存を、時間だけのモデルは空間の依存を、そのまま残した。どちらか片方の自己相関だけを測ると、残りを見落とす。
- 足し算で十分な世界では、相互作用を足しても残差は変わらなかった。
- 相互作用の世界で足し算のモデルの空間の自己相関が 0.114 と小さいのは、傾きの差が中央の時刻の近くで 0 になるため。時刻ごとに見ると、両端の時刻 (0、29) で 0.25 と 0.28、中央 (14、15) で -0.03 だった。
- 時空間の残差がある世界では、どの分解も両方の依存を残した。地点の効果と時刻の効果の和では表せない。残差の過程のモデルが要る (ここでは実装していない)。

## 平均の構造と残差の依存

傾向、季節性、曜日、共通の時間の動きは、平均の構造。取り残すと、残差の自己相関として現れ、「時間の依存がある」と読み違える。依存を測る前に、平均の構造を入れる。

- 全ての地点に共通の季節性は、時間の効果 b(t) に入る。
- 季節の山の時期が地点で違う (南北で花粉の時期がずれる) のは相互作用。`st_model.py` の相互作用は地点ごとの直線の傾きだけで、季節の位相の違いは扱わない。
- 傾向を地点ごとの傾きで入れると、学習の期間の中では残差が減っても、期間の外へ延ばすと外れる ([validation](validation.md) の、分離可能な世界での逆転)。

## 分離可能と分離不能

分離可能な共分散は、C(h, u) = Cs(h) × Ct(u)。距離 h と時間のずれ u の効き方が独立で、どの地点でも時間の相関の形が同じ。分離不能は、場所によって時間の変わり方が違う、または場が動く (風で運ばれる汚染、川を下る濁り)。動く場では、ある地点の値は、少し後の下流の地点の値と最もよく似る。

`separability_ratio` は、C(h, u) C(0, 0) / (C(h, 0) C(0, u)) を測る。分離可能なら 1。

| 世界 (60 地点、60 時刻、距離 0.05〜0.15、3 期、種 0〜9) | 比 (平均、最小〜最大) |
|---|---:|
| 分離可能、東向きの組 | 0.97 (0.67〜1.19) |
| 東へ 1 期 0.03 動く場、東向きの組 | 13.1 (1.52〜107) |
| 同じ動く場、全ての向きの組 | 2.2 (1.15〜8.7) |

- 比は、比の比なので揺れが大きい。分離可能でも 0.67 から 1.19 まで動いた。1 に近いかは、いくつかの距離と時間のずれで見る。
- 動きは向きを持つ。全ての向きの組をまとめると、1 からの離れ方が薄まる。風や川の向きが分かっていれば、その向きの組で測る。
- 分離可能と判断しても、それは測った距離と時間のずれの範囲での話。

## 不規則な地点と時刻、欠けたセル

- 地点は格子でなくてよい。近傍は距離で決める (Moran's I は 4 近傍)。地点の座標は投影した座標 (メートル) で持つ。
- 時刻の間隔が不規則なら、AR(1) は φ^(間隔) で減る。間隔を 1 とみなすと、長い空白の後を前の値に引きずられて当てる。
- 欠けたセルは、無作為なら交互の平均で扱える。偏って欠ける (観測が止まった局、冬に止まる観測) なら、欠けた理由が値と関係しうる。欠けたセルを予測先として評価に入れるなら、どのセルが欠けたかの仕組みを書く。
