# spatiotemporal-modeling

大気の測定局の毎時の濃度、観測所の毎日の雨量、市区町村の毎月の件数。地点 × 時刻の値は、近い地点どうしでも、近い時刻どうしでも似る。このスキルの問いは、その両方の依存を、どの構造でモデル化し、どこへ予測するか。

別の問いとの境界:
- 同じ単位の繰り返しを、固定効果やクラスタの標準誤差でどう扱うか (単位の中の相関) は、単位の統計の構造の問い。ここでは単位の位置と、近い単位どうしの依存を使う。
- 系列ごとに先の期間を当てるだけなら、時系列の予測の問い。ここでは、観測の無い地点への予測と、空間で共有される時間の動きを扱う。
- ある時点の値の空間の依存 (空間ラグ、空間誤差) だけなら、空間回帰の問い。ここでは時間をまたぐ依存も扱う。

| reference | 中身 |
|---|---|
| [structure](references/structure.md) | 空間の効果、時間の効果、相互作用、時空間の残差。分離可能と分離不能、傾向と季節性と残差の依存、不規則な地点と時刻、欠けたセル (合成の数字) |
| [validation](references/validation.md) | 予測先の 3 つと検証の分け方。無作為な行の楽観、時間だけ、空間だけの分け方が測らないもの (合成の数字) |

## 手順

1. 予測先を決める。既知の地点の未来か、未知の地点の既知の時点か、未知の地点の未来か。3 つは難しさも、検証の分け方も違う。行を無作為に分けた点数を基準にしない ([validation](references/validation.md))。
2. データの形を数える。地点の数と置かれ方 (格子か、不規則か)、時刻の数と間隔 (等間隔か)、欠けた地点 × 時刻のセルの割合と偏り (ある地点の冬だけ欠ける、など)。`scripts/st_model.py` が最初に出す。
3. 平均の構造 (全体の傾向、季節性、共通の時間の動き、地点ごとの水準) と、残差の依存を分ける。傾向や季節性が残ったままの残差の自己相関は、依存でなく、平均の構造の取り残し。
4. 小さい分解から比べる。空間だけ (地点の効果)、時間だけ (時刻の効果)、足し算 (地点 + 時刻)、相互作用 (地点ごとの傾き)。`st_model.py` は、予測先ごとの分け方で、全てのモデルの RMSE を並べる。
5. 選んだモデルの残差で、空間の自己相関 (時刻ごとの Moran's I) と時間の自己相関 (地点ごとの 1 期のずれの自己相関) の両方を測る。片方だけ測ると、もう片方の取り残しを見落とす。
6. 残差に両方の依存が残るなら、時空間の残差の過程がある。共分散が空間 × 時間に分けられるか (分離可能か) を `separability_ratio` で粗く確かめる。流れ (風、川) がある現象は、その向きで確かめる。残差の過程のモデル (時空間のクリギング、ガウス過程、SPDE) はこのスキルでは実装していない。残ることを書く。
7. 書き出す。

## 書き出すもの

- 予測先と、それに合わせた検証の分け方 (時間の区切り、残した地点の選び方、地点のかたまりの大きさ)
- 地点の数と置かれ方、時刻の数と間隔、欠けたセルの割合
- モデル × 分け方の RMSE の表。行を無作為に分けた点数は、参考として別に書く
- 選んだモデルの残差の、空間と時間の自己相関
- 分離可能性の確かめ方と結果。残った時空間の依存と、それが予測の区間や係数の標準誤差に与える影響 (行は独立でない)
