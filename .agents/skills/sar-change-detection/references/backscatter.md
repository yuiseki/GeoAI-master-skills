# 変化の向きの読み方

C バンドの後方散乱が、出来事でどちらへ動くか。測った例と、外の知識による解釈を分けて書く。解釈の行は、このリポジトリでは確かめていない。

| 地表の変化 | 向き | 理由 (解釈) | 測った例 |
|---|---|---|---|
| 開けた所 (河川敷、田畑、草地) が水をかぶる | 暗くなる | 水面は鏡のように電波を前へ反射し、衛星へ返らない | 台風第 19 号の多摩川の河道 (堤防の間): 雨の後に 35.6 % の画素が −3 dB 以下、土地被覆をそろえた対照の 8.0 倍 |
| 市街地に水が溜まる | 明るくなる | 水面と建物の壁で電波が二回反射し、衛星へ強く返る | 同じ台風の記録の面の市街地: 10.3 % が +3 dB 以上、対照の 5.6 倍。暗くなった割合は対照と同じ (2.1 % 対 1.8 %) |
| 雨の最中 | 広い範囲が明るくなる | 濡れた地面と屋根の誘電率が上がる。雨滴の散乱 | 同じ台風の雨の最中の撮影 (軌道 39、17 時 41 分): 対照の VV の差の中央値 +1.546 dB、対照の市街地の 34.2 % が +3 dB 以上 |
| 林や背の高い作物の下が水をかぶる | 明るくなることがある | 水面と幹や茎の二回反射 | 未確認 |
| 土砂崩れ、建物の倒壊 | どちらにも動く | 表面の粗さと向きが変わる | 未確認 |

## 読み方の決まり

- 浸水を問うなら、暗くなる向きと明るくなる向きの両方を、計画の時点で主張にする。暗くなる向きだけを数えると、市街地の浸水を「見えなかった」と読み違える。
- 明るくなった画素を「浸水した」と断定しない。工事、車、片付けの物、雨でも明るくなる。偽の日付と、後の撮影で戻るかで、出来事に結びつく変化かを確かめる ([controls](controls.md))。
- 雨の最中の撮影は、浸水の変化と全体の明るさが混ざる。対照の差の中央値を見て、全体が動いていないかを先に確かめる。同じ台風の雨の最中の撮影では、記録の面の市街地の明るさの比は 1.143 で、全体が明るくなった分に埋もれた。
- 恒常的な水の面 (WorldCover の水など) は、組から外す。もともと暗く、変化の割合の分母を薄める。
- 偏波: 交差偏波 (VH) は体積散乱 (植生) に強く、同一偏波 (VV) は表面と二回反射に強い。同じ台風では VH でも判断は同じだった (河道の暗くなった割合 0.3542、市街地の明るさの比 4.102)。
