# 入力と前処理の不確かさが後へ伝わる

このスキルの他の節は、モデルの予測の不確かさを扱う。ここで扱うのは、その前の段階で作った値の不確かさ。位置の誤差、ラスタの分類の誤り、面積按分の推定値、ジオコーディングの候補、境界の年の取り違えで作った値を、真の値として固定して次の段階に渡すと、後の段階の不確かさを小さく見積もる。

## 実例: 駅の位置の誤差と区ごとの数

東京 23 区の運行中の駅 743 (`ekidata-jp`、路線ごと) の位置に、標準偏差 20 m の誤差 (GPS 程度) を加えて区に入れ直すことを 200 回繰り返した (`jp-admin-2026-09` の区の面、shapely 2.2.0、2026-10-14)。

- 1 回あたり、平均 1.06% の駅が別の区に移った。
- 23 区のうち 21 区で、区ごとの駅の数が回によって変わった。最大の幅は千代田区 (71 駅) の 7。
- 駅の数を固定すると幅は 0。誤差を伝えると、区ごとの数の 95% の幅の中央値は 2。

区ごとの数を目的変数や説明変数にするなら、この幅は、モデルの外にある不確かさ。

## 実例: 推定した値を説明変数に使う

前処理で推定した値 (面積按分の人口、ラスタから集めた値) は、真の値に誤差が加わったもの。説明変数の誤差は、回帰の傾きを 0 の方へ縮める (減衰)。真の傾き 2 の合成データ (5,000 行、numpy):

| 説明変数の誤差の標準偏差 (真の値の標準偏差 1 に対し) | 信頼性 (真の分散 / 観測の分散) | 傾き |
|---|---:|---:|
| 0 | 1.00 | 2.01 |
| 0.5 | 0.80 | 1.61 |
| 1.0 | 0.50 | 0.99 |

傾きは、ほぼ信頼性の倍だけ縮む。効果が無いように見えるのは、効果が無いからでなく、説明変数が粗いからかもしれない。

## 伝え方

1. 前処理の段階ごとに、作った値の不確かさの源を書く (位置の誤差、分類の誤り、按分の仮定、候補の多いジオコーディング、境界の年)。
2. 大きさが分かるものは、その分布から入力を作り直して (位置を揺らす、分類を混同行列に従って入れ替える、按分の方法を変える、候補を選び直す)、後の段階の結果を繰り返し計算する (モンテカルロ)。
3. 結果の幅を、モデルの区間と並べて書く。入力の幅を含めない区間は、狭すぎると書く。
4. 大きさが分からないものは、仮定を変えて結果が変わるかを見る (感度分析)。
