# CV+ と CQR

予測のファイル (1 つのモデル、または fold ごとに違うモデルの外側の予測) から作る区間と違い、`scripts/conformal.py` は自分でモデルを当てはめる。fold のモデルが新しい行に出す予測が要るため。表と特徴量の列を渡す。

```sh
uvx --with duckdb --with numpy --with scikit-learn --with pyarrow python scripts/conformal.py cv-plus TABLE \
  --target Y --features A,B,C --test-by region --model linear --by region
uvx --with duckdb --with numpy --with scikit-learn --with pyarrow python scripts/conformal.py cqr TABLE \
  --target Y --features A,B,C --test-by region --model hgb [--scaled] --by region
```

`--role 列` (cv-plus は `train` と `test`、cqr は `train`、`calibration`、`test`) で行の役割を決めるか、`--test-by 列` で、その列の値ごとに順に試験の行にする。cqr の `--test-by` は、残りの行の 3 行に 1 行を較正用にする (`--calibration-every`)。

## 仮定

- 学習の行と新しい行が交換可能 (同じ仕組みで生まれ、並べ替えても分布が変わらない)。確かめられない。地域や時期で分けた試験で、崩れたときに何が起きるかを測ることはできる (下)。
- 保証は全ての行で平均した被覆 (周辺の被覆)。地域ごと、行ごとの保証ではない。
- CV+ (Barber、Candès、Ramdas、Tibshirani、"Predictive inference with the jackknife+"、Annals of Statistics、2021): fold k のモデルを μ_k、行 i の外側の絶対残差を R_i、行 i の fold を k(i) とする。新しい行 x の区間の下は、μ_k(i)(x) - R_i の小さいほうから floor(α(n + 1)) 番目、上は μ_k(i)(x) + R_i の小さいほうから ceil((1 - α)(n + 1)) 番目。保証は 1 - 2α 以上 (fold の数が少ないと、もう少し緩む)、実際には 1 - α 前後。モデルが不安定でも保証は変わらない。fold を 1 行ずつにすると jackknife+。
- CQR (Romano、Patterson、Candès、"Conformalized quantile regression"、NeurIPS、2019): 学習用の行で α/2 と 1 - α/2 の分位点のモデルを当て、較正用の行で score = max(下 - y, y - 上) を取り、新しい行の区間を [下 - Q, 上 + Q] にする (Q は score の ceil((1 - α)(m + 1)) 番目)。保証は 1 - α 以上。
- `--scaled` (Sesia と Candès、"A comparison of some conformal quantile regression methods"、Stat、2020 の CQR-r): score を区間の幅で割り、新しい行の区間を、自分の幅に比例して広げる。保証は同じ。2 つの分位点のモデルが交差した行 (上が下より小さい) は、2 つを入れ替える (rearrangement)。

## グループごとの較正 (Mondrian)

`--mondrian 列` を付けると、新しい行の区間を、同じ値 (地域など) の行だけで作る (Vovk、Gammerman、Shafer 2005 の Mondrian の共形予測)。CV+ は同じ値の学習の行の残差と fold のモデルを、CQR は同じ値の較正の行の score を使う。その値の中で交換可能なら、被覆は値ごとに約束される。行の少ない値では、区間が広くなるか無限になる (順位が行の数を超える)。

- 手の計算: 4 行の値 "a" は上の CV+ の例と同じ [7, 14]、2 行の値 "b" は ceil(0.8 × 3) = 3 > 2 で無限。
- 雑音がグループで違う世界 (0.3 と 3、モデルはグループを知らない、10 回): 全ての行で 1 つの補正をする CQR は、うるさいグループを 85% 未満、静かなグループを 95% 超で覆った。グループごとの補正は両方を 0.9 ± 0.025 で覆った (テスト)。
- WDI の 2022 年の平均寿命 (下と同じ条件、無作為な 5 分割、`--mondrian region`):

  | 方法 | 全体 | サブサハラ・アフリカ (46) | その幅の中央値 (歳) | 無限の区間の行 |
  |---|---:|---:|---:|---:|
  | CV+ (線形)、全体で 1 つ | 0.904 | 0.826 | 13.6 | 0 |
  | CV+ (線形)、地域ごと | 0.933 | 0.935 | 18.2 | 9 (北米 3、南アジア 6) |
  | CQR (hgb)、全体で 1 つ | 0.928 | 0.891 | 20.7 | 0 |
  | CQR (hgb)、地域ごと | 0.957 | 0.957 | 36.6 | 65 |

  CQR は較正の行が学習側の 3 分の 1 しかないため、東アジア・太平洋、中東・北アフリカでも区間が無限になった。地域ごとの約束が要るなら、行の少ない地域を報告から外すのではなく、無限であることを報告する。地域を丸ごと伏せる分け方 (`--test-by region`) では、その地域の行が学習側に無いので、地域ごとの較正はできない。

## 小さい既知解

テスト (`scripts/test_conformal.py`) に、手で計算した例を置いた。

- 順位: 5 つの値で、α 0.2 の上は 5 番目、α 0.1 は 6 番目で n を超えるので無限大。下は 1 番目と、0 番目なので負の無限大。
- CV+: 2 つの fold、4 行、新しい行で fold 0 のモデルが 10、fold 1 が 12 を出すとき、α 0.2 で [7, 14]。
- 全ての fold のモデルが同じなら、区間は予測 ± 残差の順位統計量で、上下対称になる (floor(α(n + 1)) = n + 1 - ceil((1 - α)(n + 1)))。
- CQR: 4 行の score が -1、0.5、0.5、-1 で、α 0.4 の Q は 0.5。
- 交差の入れ替え: 下 3、上 2 の行は [2, 3] として幅 1 で割る。

## 合成データで壊す

- 交換可能な線形の世界 (60 行、5 fold、200 回): 新しい行の被覆の平均は 0.88 を超えた。
- 不安定なモデル (Barber らの例に倣う): ridge (罰則 0.001)、60 行、60 特徴量、10 fold、60 回。全データのモデルの予測 ± 外側の残差の分位点 (fold のモデルを使わない素朴な区間) は、被覆の平均が 0.54 (最小 0.18) で、CV+ は 0.97。全データのモデルは 60 行 60 特徴量で、補間のちょうど境目にあり、予測が大きく暴れる。fold のモデル (54 行) は境目の外にある。特徴量を 40 や 80 にすると、素朴な区間も 0.86〜0.93 を覆った。素朴な区間が崩れるのは、全データのモデルが fold のモデルと大きく違うときに限られる。
- 雑音が行で違う世界 (特徴量 3、雑音の標準偏差が半分の行で 0.3、残りで 3。1,500 行、1,000 行の試験、10 回):

  | | 静かな半分 | うるさい半分 |
  |---|---:|---:|
  | CV+ (線形) | 1.00 | 0.78 |
  | CQR (hgb) | 0.98 | 0.80 |
  | CQR、`--scaled` (hgb) | 0.90 | 0.88 |
  | 較正の前の分位点のモデル (hgb) | 0.75 | 0.70 |

  最初の仮説 (CQR は 2 つの半分をどちらも 90% 前後覆う) は外れた。分位点の GBDT は雑音に沿った幅 (0.8 と 8.5) を出すが、過学習で両方の半分を 75% 前後しか覆わない。CQR は全ての行に同じ Q を足すので、狭い区間には大きすぎ、広い区間には小さすぎる補正になる。幅で割る score は、補正も幅に比例させるので両方を直した。hgb の葉の行の数 (既定 20) を 200 に増やすと、較正の前の被覆は 0.89 と 0.85 に上がり、足す型でも 0.93 と 0.87 になった。100 では 0.94 と 0.85 (2026-10-16、scikit-learn 1.9.1)。全体の被覆は、どの方法も 0.9 前後に保たれた (テスト)。
- 新しい行の雑音が学習の行の 2 倍の世界 (200 行、30 回): CV+ の 90% の区間の被覆は 0.65 未満 (理論では約 0.59)。

## 外部の実装との照合

MAPIE 1.5.0 と照合した (`scripts/test_conformal_crosscheck.py`)。

- CV+: `CrossConformalRegressor(method="plus")`。5 fold と、1 行ずつの 57 fold (jackknife+) で、区間の上下が 1e-10 以内で一致。
- CQR: `ConformalizedQuantileRegressor` に、当てはめ済みの分位点の線形モデルを渡して、α 0.1 と 0.2 で一致。MAPIE の既定は下と上をそれぞれの 1 - α/2 の分位点で別々に補正する型で、そのままでは一致しない。`symmetric_correction=True` で、このスクリプトの対称な score と同じになる。
- `--scaled` は外部の実装と照合していない。手で計算した例と、合成データでの被覆で確かめた。

## 実データ: 国の平均寿命

WDI の 2022 年の平均寿命 (版 2026-10-01、`tmp/wdi_2022.parquet`、217 か国のうち特徴量の欠ける 8 か国を除いた 209 か国)、特徴量は 1 人あたり GDP の対数、人口の対数、都市人口の割合、90% の区間 (2026-10-16)。無作為な 5 分割は DuckDB 1.5.5 の `hash(iso3) % 5`。

| 分け方 | 方法 | 全体 | サブサハラ・アフリカ (46) | 区間の幅の中央値 (歳)、全体 / サブサハラ・アフリカ |
|---|---|---:|---:|---|
| 無作為な 5 分割 | CV+ (線形) | 0.904 | 0.826 | 13.6 / 13.6 |
| | CV+ (hgb) | 0.919 | 0.826 | 15.5 / 16.0 |
| | CQR (hgb) | 0.928 | 0.891 | 16.4 / 20.7 |
| | CQR、`--scaled` | 0.947 | 0.913 | 18.5 / 24.4 |
| 地域ごとに伏せる (7 地域) | CV+ (線形) | 0.818 | 0.457 | 13.7 / 10.6 |
| | CV+ (hgb) | 0.789 | 0.304 | 15.0 / 11.4 |
| | CQR (hgb) | 0.737 | 0.370 | 14.0 / 14.4 |
| | CQR、`--scaled` | 0.756 | 0.370 | 14.3 / 14.3 |

- 無作為な分割では、CV+ の全体の被覆は約束どおり。サブサハラ・アフリカは 83% で足りない。CQR はこの地域の区間を広げ (20.7 歳)、89〜91% を覆った。
- 地域ごとに伏せると、どの方法も約束を守らない。サブサハラ・アフリカは 3〜5 割しか覆わない。よその地域だけで当てたモデルの外れ方と幅を、この地域に持ち込むため。CQR の分位点のモデルも、よその地域の雑音を学ぶ。地域で交換可能でないことは、どの型の共形予測でも直らない。
- 分位点の hgb は、較正の前に較正用の行の 75〜78% しか覆わなかった (スクリプトが表示する)。学習の行が 110〜140 と少なく、過学習している。
- 「データの無い国を埋める」使い道なら、地域ごとに伏せた行を報告する。

## 適用できない条件

- 学習の行と新しい行が、地域や時期で違う仕組みから来るとき (上の地域ごとの表)。
- 地域ごとの被覆を約束したいのに、その地域の行が少ないとき (`--mondrian` の区間が無限になる)。
- 時系列の未来の行 (交換可能でない)。
- 2 つの分位点のモデルが多くの行で交差するとき (入れ替えた行の数を表示する)。
- モデルは線形と hgb (scikit-learn の既定の設定) だけ。Python からは scikit-learn の推定量を渡せる。
- CV+ は fold のモデルの予測を n × m で持つ。学習の行 n と新しい行 m の積が 1 億を超えるとメモリが足りない。

## テスト

`uvx --with duckdb --with numpy --with scikit-learn --with pytest pytest scripts/test_conformal.py`。上の既知解と合成データ。fold のモデルの代わりに平均のモデルを使う、順位の n + 1 を n にする、幅で割る型で幅を掛け戻さない、のそれぞれで落ちる。照合は `uvx --with mapie --with duckdb --with numpy --with scikit-learn --with pytest pytest scripts/test_conformal_crosscheck.py`。
