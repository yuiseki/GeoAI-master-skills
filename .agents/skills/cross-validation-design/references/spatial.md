# 空間で分ける

近い単位どうしは似ている (空間自己相関)。試験側の単位のすぐ隣が学習側にあると、モデルは隣の値を借りて当てる。学習データから離れた場所を予測するのが使い道なら、評価でも試験側を学習側から離す。

## 空間ブロック

`make_folds.py --scheme spatial-block --lon COL --lat COL --block-km KM [--buffer-km KM]`。面の単位なら `--geometry COL` で、面の中の 1 点 (`ST_PointOnSurface`) を位置にする。

- 地表をほぼ等面積のブロックに切る。緯度の帯の高さが `--block-km`、帯の中は、帯の中央の緯線の長さを `--block-km` で割った数に切る。経度と緯度の度で切ると、高緯度ほどブロックが細くなるため。
- ブロックを repeat ごとに無作為に並べ、行数の少ない fold から順に入れる。ブロックの数が fold の数より少ないと止まる。実行すると、ブロックの数を出す。
- `--buffer-km` を付けると、試験側のどの行からもその距離以内にある学習側の行を、その fold では使わない。距離は球面 (半径 6,371 km) の大円距離。

## ブロックの大きさ

ブロックは、残差が似ている距離 (空間自己相関の届く範囲) より大きくする。小さいブロックは行の無作為な分割とほとんど変わらない。

国の平均寿命の例 (WDI、2022 年、207 か国、位置は Natural Earth の `LABEL_X`、`LABEL_Y`、5 fold、repeat 3 つの平均、2026-10-10):

| ブロック | linear の R2 | hgb の R2 | group_mean (地域) の R2 |
|---:|---:|---:|---:|
| 500 km | 0.622 | 0.585 | 0.472 |
| 1,000 km | 0.625 | 0.564 | 0.458 |
| 2,000 km | 0.614 | 0.542 | 0.429 |
| 4,000 km | 0.597 | 0.539 | 0.428 |
| 8,000 km | 0.599 | 0.517 | 0.441 |
| 参考: 行を無作為に | 0.627 | 0.576 | 0.470 |
| 参考: 地域で分ける | 0.524 | 0.361 | -0.340 |

8,000 km のブロックでも、地域で分けたほど点数は下がらなかった。group_mean (学習側の同じ地域の平均) が 0.44 前後を保っていることから、ブロックが地域の境界とずれていて、試験側の地域の国が学習側にも残ると読める。距離で離すことと、地域を丸ごと伏せることは、別の問いに答える。

2,000 km のブロックに 500 km の緩衝帯を付けても、linear は 0.614 から 0.611、hgb は 0.542 から 0.549 で、ほとんど変わらなかった。緩衝帯で使わなくなった行は fold ごとに 3〜10 行。

## 選び方

- ブロックの大きさを 2〜3 段で作り、点数が下がり止まる大きさを探す。下がり止まった大きさが、依存の届く範囲の目安になる。
- 先に、モデルの残差のコレログラム (spatial-autocorrelation) で、自己相関が 0 付近になる距離を測っておくと、段の選び方の目安になる。上の例では、線形の残差の自己相関は 2,000 km を超えるとほぼ 0 になり、点数の下げ止まりと合った。
- 使い道が「別の地域に当てはめる」なら、ブロックより地域のグループ (group.md) のほうが問いに合う。
- 点が密な場所と疎な場所が混ざると、ブロックごとの行数が大きく違う。fold ごとの行数を確かめる。
