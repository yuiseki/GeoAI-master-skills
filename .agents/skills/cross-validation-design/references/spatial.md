# 空間で分ける

近い単位どうしは似ている (空間自己相関)。試験側の単位のすぐ隣が学習側にあると、モデルは隣の値を借りて当てる。学習データから離れた場所を予測するのが使い道なら、評価でも試験側を学習側から離す。

## 空間ブロック

`make_folds.py --scheme spatial-block --lon COL --lat COL --block-km KM [--buffer-km KM]`。面の単位なら `--geometry COL` で、面の中の 1 点 (`ST_PointOnSurface`) を位置にする。

- 地表をほぼ等面積のブロックに切る。緯度の帯の高さが `--block-km`、帯の中は、帯の中央の緯線の長さを `--block-km` で割った数に切る。経度と緯度の度で切ると、高緯度ほどブロックが細くなるため。
- ブロックを repeat ごとに無作為に並べ、行数の少ない fold から順に入れる。ブロックの数が fold の数より少ないと止まる。実行すると、ブロックの数を出す。
- `--buffer-km` を付けると、試験側のどの行からもその距離以内にある学習側の行を、その fold では使わない。距離は球面 (半径 6,371 km) の大円距離。

## ブロックの大きさ

ブロックは、残差が似ている距離 (空間自己相関の届く範囲) より大きくする。小さいブロックは行の無作為な分割とほとんど変わらない。

国の平均寿命の例 (WDI、2022 年、207 か国、5 fold、repeat 3 つの平均、2026-10-16)。条件は WDI の版 2026-10-01、Natural Earth v5.1.2 の `LABEL_X`、`LABEL_Y`、`make_folds.py` の分割表 (5 fold、repeat 0、1、2)、scikit-learn 1.9.1、`compare_models.py` は d133d92 の版。hgb (旧) は、同じ分割表を d133d92 より前の `compare_models.py` (学習側から無作為に取った 1 割で早期打ち切り) で測ったもの。hgb (現行) は、分割表から作った内側の分割で木の数を選ぶ。

| ブロック | linear の R2 | hgb (旧) の R2 | hgb (現行) の R2 | group_mean (地域) の R2 |
|---:|---:|---:|---:|---:|
| 500 km | 0.622 | 0.585 | 0.587 | 0.471 |
| 1,000 km | 0.625 | 0.564 | 0.568 | 0.458 |
| 2,000 km | 0.614 | 0.542 | 0.561 | 0.429 |
| 4,000 km | 0.597 | 0.539 | 0.545 | 0.428 |
| 8,000 km | 0.599 | 0.517 | 0.510 | 0.441 |
| 参考: 行を無作為に | 0.626 | 0.582 | 0.590 | 0.464 |
| 参考: 地域で分ける | 0.524 | 0.338 | 0.374 | -0.340 |

- 旧の列は、2026-10-10 に書いた表 (この表の以前の版) をブロックの 5 行で再現した。行を無作為に分けた参考の行は、以前の表の値 (linear 0.627、hgb 0.576、group_mean 0.470) を再現できず、地域で分けた行の hgb も以前の 0.361 にならなかった (原因は分かっていない)。上の表は、どちらも今の分割表で測り直した値。
- 現行の hgb が内側で選んだ木の数 (15 の fold の最小、中央値、最大) は、500 km で 20、31、85、2,000 km で 22、36、60、8,000 km で 25、83、100、地域で分けると 44、58、94。
- 順位 (linear > hgb > group_mean) は、どのブロックの大きさでも、旧と現行の両方で同じ。hgb とブロックの大きさの関係 (大きいほど下がる) も変わらない。

8,000 km のブロックでも、地域で分けたほど点数は下がらなかった。group_mean (学習側の同じ地域の平均) が 0.44 前後を保っていることから、ブロックが地域の境界とずれていて、試験側の地域の国が学習側にも残ると読める。距離で離すことと、地域を丸ごと伏せることは、別の問いに答える。

2,000 km のブロックに 500 km の緩衝帯を付けても、linear は 0.614 から 0.611、hgb は 0.542 から 0.549 (旧)、0.561 から 0.559 (現行) で、ほとんど変わらなかった。緩衝帯で使わなくなった行は fold ごとに 3〜10 行。

## 選び方

- ブロックの大きさを 2〜3 段で作り、点数が下がり止まる大きさを探す。下がり止まった大きさが、依存の届く範囲の目安になる。
- 先に、モデルの残差のコレログラム (距離の帯ごとの Moran's I) で、自己相関が 0 付近になる距離を測っておくと、段の選び方の目安になる。上の例では、線形の残差の自己相関は 2,000 km を超えるとほぼ 0 になり、点数の下げ止まりと合った。
- 使い道が「別の地域に当てはめる」なら、ブロックより地域のグループ (group.md) のほうが問いに合う。
- 点が密な場所と疎な場所が混ざると、ブロックごとの行数が大きく違う。fold ごとの行数を確かめる。
