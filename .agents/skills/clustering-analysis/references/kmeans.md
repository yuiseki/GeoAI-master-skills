# k-means

群の数 k を決め、各単位を最も近い中心の群に入れ、中心を群の平均に動かすことを繰り返す。

- 群は、特徴量の空間で丸く、大きさの近いものになりやすい。細長い群や、大きさの大きく違う群は分けられない。
- 全ての単位をどれかの群に入れる。外れた単位も、どこかの群の端に入る。外れた単位が 1 つで群を作ることもある (SKILL.md の例の k=6)。
- 初期値で結果が変わる。`cluster_units.py` は scikit-learn の `KMeans(n_init=10)` で、10 通りの初期値から最もまとまった結果を取る。
- k の選び方: シルエットだけで選ぶと k=2 が選ばれやすい (SKILL.md の例で k=2 が 0.459 で最大)。安定性と、群を言葉にできるかを合わせて選ぶ。
- 距離はユークリッド距離なので、尺度を揃えないと値の大きい特徴量が群を決める。`cluster_units.py` は標準化する。
