# ディリクレ過程の混合正規分布 (DPMM)

単位が、いくつかの正規分布の混合から出たと考え、群の数をデータに合わせて決める。上限 (`max_components`) を大きめに与えると、使われない成分の重みが 0 に近づく。

- `cluster_units.py` は scikit-learn の `BayesianGaussianMixture(weight_concentration_prior_type="dirichlet_process")` を使い、各単位を最も確からしい成分に入れる。実際に使われた成分だけを 0 から番号を振り直す。
- 群の数が決まる、といっても、事前分布の強さ (`weight_concentration_prior`、既定のまま) と上限に左右される。上限を変えて群の数が変わらないかを見る。
- 楕円の群を取れるが、行が少ないと共分散の推定が不安定になる。SKILL.md の例 (207 か国、4 特徴量、上限 10) では 6 つの群ができ、1 か国と 2 か国だけの群を含み、安定性の ARI は 0.512 で、k-means の k=3 (0.954) より大きく低かった。
- 各単位がどの群にどれだけの確率で入るかも出せる (`predict_proba`)。境界にいる単位を見つけるのに使える (`cluster_units.py` には未実装)。

## 群の数を決めているもの

`BayesianGaussianMixture` の 3 つの設定を変えて、使われた群の数を数えた (WDI の 2022 年の 207 か国、4 特徴量を標準化、2026-10-10)。

| 変えたもの | 値 | 使われた群の数 |
|---|---|---|
| 上限 (`n_components`) | 5、10、20、40 | 5、6、4、6 |
| 集中度 (`weight_concentration_prior`、上限 20) | 0.001、0.1、1、10、1000 | 4、4、5、8、10 |
| 共分散の事前分布 (`covariance_prior` = 単位行列 × s、上限 20) | 0.1、1、3、10、30 | 16、5、3、3、2 |

study-geoai-algo-py の 005-D (23 区の町丁目) の記録では、既定の設定で群の数は上限にほぼ比例し (上限 10 で 10、40 で 26)、集中度は 0.001 から 1000 までほとんど効かず、共分散の事前分布を 1 から 30 にすると群は 17 から 3 に減った。

- 共分散の事前分布 (1 つの群がどれだけ広がってよいか) が群の数を強く決める点は、どちらのデータでも同じ。
- 上限への比例と、集中度の効かなさは、ここでは再現しなかった。データの大きさや次元の違いによると推測しているが、確かめていない。
- 「群の数をデータが決める」と言っても、事前分布を決めた人が決めている。事前分布の値と、変えたときの群の数を一緒に書く。
