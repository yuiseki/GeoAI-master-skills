# clustering-analysis

クラスタリングは、構造が無いデータにも群を返す。群ができたことは、構造がある証拠にならない。設定を変えても同じ群が戻ってくるか、既知の区分と何が違うかを確かめてから、群に名前を付ける。

| reference | 手法 |
|---|---|
| [kmeans](references/kmeans.md) | 群の数 k を決めて、中心からの距離で分ける |
| [density-based](references/density-based.md) | DBSCAN、HDBSCAN。密な所を群にし、疎な点を雑音とする |
| [dpmm](references/dpmm.md) | ディリクレ過程の混合正規分布。群の数をデータに合わせる |

## 手順

1. 何の型を探すかを書き、使う特徴量を選ぶ。特徴量の選び方が群を決める。似たものを測る特徴量を重ねると、その側面が重く数えられる。
   経度と緯度そのものを特徴量にしない。k-means で位置だけを分けると、範囲をほぼ同じ大きさに切るだけで、街の中身と関係の無い群になる (以前の分析)。場所の集まりを探すなら spatial-autocorrelation や point-pattern-analysis を使い、群が地図の上で固まるかは、下の「地図の上での固まり方」で確かめる。
2. 前処理を決める。裾の長い量は対数を取る。`scripts/cluster_units.py` は特徴量を標準化 (平均 0、標準偏差 1) してから分ける。
   `cluster_units.py` は欠損のある行で止まる。行を除くか、埋めるかを決める。埋めるなら中央値などで埋め、埋めた数を特徴量ごとに書く (004 では 23 区の町丁目のうち、無電柱化の割合を 97、緑の割合を 89 埋めた)。埋めた値は群の中心に寄るので、埋めた行の多い特徴量は群を分ける力が弱まる。分母の小さい割合は、先に spatial-feature-engineering の `shrink_rates.py` で縮める。
3. 手法と設定の候補を決め、全て試す (k を 2〜6、HDBSCAN の最小の群の大きさを 2〜3 段)。
4. 各設定について、下の 4 つを見る。
5. 安定していて、既知の区分と違う何かを示す設定を選ぶ。選んだ群の特徴量の平均を並べて、群の中身を言葉にする。
6. 1 単位だけの群や、雑音とされた単位は、外れ値の候補として anomaly-detection に回す。データの誤りのことがある。

## 見るもの

| 指標 | 何を見るか | 読み方 |
|---|---|---|
| 群の数と雑音 | 群がいくつできたか、どれにも入らない単位の数 | 群が 2 つ未満なら、構造は見つからなかった。`cluster_units.py` はそのとき他の指標を出さない |
| シルエット | 特徴量の空間で群がどれだけ離れているか | 高いほど離れている。群の数を比べる目安 |
| 安定性 | 単位の 8 割を抜き出して分け直し、全体で分けた結果と、重なる単位で比べた調整ランド指数 (ARI) の平均 | 1 に近ければ同じ群が戻る。低い設定の群に名前を付けない |
| 既知の区分との ARI | 地域、所得階層などとの一致 | 1 に近ければ既知の区分をなぞっているだけ。0 に近ければ別の分け方 |
| 地図の上での固まり方 | 各単位の地理的な近傍 k 個のうち、同じ群の割合を、群のラベルを並べ替えた場合と比べる | 並べ替えより高ければ、群は地図の上でも固まっている |

```sh
uvx --with duckdb --with scikit-learn --with pyarrow python scripts/cluster_units.py \
  tmp/table.parquet ID F1 F2 F3 --method kmeans --k 2,3,4,5,6 \
  --compare-with region income --lon lon --lat lat --labels-out tmp/labels.parquet
```

地理的な近傍は spatial-autocorrelation のスクリプトの関数 (球面の距離の k 近傍) を使う。

テストは `uvx --with duckdb --with scikit-learn --with pytest pytest scripts/test_cluster_units.py`。よく分かれた 3 つの塊を 4 つの手法が取り戻すこと、標準化をしないと大きな尺度の雑音に負けること、構造の無いデータで安定性が下がること、群が 1 つもできないときに安定性を満点と言わないことを確かめている。標準化の省略、安定性を重ならない単位で比べること、並べ替えの省略のそれぞれで落ちることを確かめてある。

## 実例: 国の型

WDI の 2022 年の 207 か国を、平均寿命、1 人あたり GDP (対数)、都市人口の割合、合計特殊出生率で分けた (2026-10-10)。

| 設定 | 群 | シルエット | 安定性 ARI | 地域との ARI | 所得階層との ARI | 近傍 6 か国のうち同じ群 (並べ替え) |
|---|---:|---:|---:|---:|---:|---|
| k-means k=2 | 2 | 0.459 | 0.863 | 0.157 | 0.367 | 0.79 (0.55) |
| k-means k=3 | 3 | 0.355 | 0.954 | 0.180 | 0.461 | 0.64 (0.34) |
| k-means k=4 | 4 | 0.321 | 0.834 | 0.219 | 0.449 | 0.57 (0.27) |
| k-means k=6 | 6 | 0.310 | 0.789 | 0.213 | 0.383 | 0.47 (0.21) |
| HDBSCAN 最小 10 | 2 (雑音 73) | 0.553 | 0.601 | 0.120 | 0.217 | 0.63 (0.44) |
| HDBSCAN 最小 20 | 0 (全て雑音) | | | | | |
| DPMM 上限 10 | 6 | 0.100 | 0.512 | 0.223 | 0.299 | 0.59 (0.36) |

- いちばん安定したのは k-means の k=3。群の平均は、平均寿命 80.5 歳、1 人あたり GDP 約 53,000 ドル、出生率 1.53 の群 (66 か国、うち高所得 64)、73.3 歳、約 8,800 ドル、2.02 の群 (85 か国)、63.9 歳、約 1,900 ドル、4.05 の群 (56 か国、うち低所得 20、低中所得 32)。
- 所得階層との ARI は 0.46 で、所得階層をおおむねなぞるが、一致はしない。地域との ARI は 0.18。
- 群は地図の上でも固まっている (近傍 6 か国のうち同じ群 0.64、並べ替えなら 0.34)。
- k=6 では中央アフリカ共和国だけの群ができた。平均寿命が 18.8 歳と他から極端に外れているため。WDI の版で系列の形が変わっていて、データの側を疑うべき値だった (dataset-discovery の references/worldbank-wdi.md)。
- HDBSCAN は 207 か国の 3 分の 1 以上を雑音とし、最小の群を 20 にすると群が 1 つもできなかった。行が少なく密度の差がはっきりしない表には向かない。
