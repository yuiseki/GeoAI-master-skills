# 地域の比較 (`poi_compare.py`)

| 列 | 定義 | 注意 |
|---|---|---|
| poi | 地域の面に入る POI の数 | 面に入らない POI は in_no_region に数える。面が重なっていたら止まる |
| area_km2、per_km2 | 面の面積 (ランベルト正積方位図法、面の重心の緯度を中心) と、面積あたりの数 | 水面を含む面では密度が低く出る |
| population、poi_per_10k | 人口の格子のセルの中心が入る地域の人口と、1 万人あたりの数 | 住む人の数で、働く人と訪れる人を含まない。住む人の少ない中心部では大きく出る |
| branded_share、top_brand、top_brand_share | ブランドのある店の割合、最も多いブランドと、その割合 | ブランドの表記の揺れはそのまま |
| hhi | ハーフィンダール・ハーシュマン指数 Σ (各社の割合)²。ブランドの無い店はそれぞれ 1 社 | 店の数の割合で、売上ではない。ブランドの無い店を除くと、寡占が強く出る |
| unknown_status_share | 営業状態が不明の割合 | 地域で違えば、店の数の比較も歪む |
| median_m_to_other_brand | 各店から、別のブランド (かブランド無し) の最寄りの店までの直線距離の中央値 | 全ての店から探すので、境界の向こうの競合も数える |
| pop_share_within_m | 人口のうち、どれかの店から直線で --within-m 以内に住む人の割合 | 道のりではない。セルの人口はセルの中心に置く |

距離は、全ての点の緯度の中央値で正距円筒の近似をした平面で測る。都市の範囲 (数十 km) での誤差は 0.5% 未満。

答えの分かる小さな例 (2 つの正方形の地域、店 6 つ、人口のセル 2 つ) をテストにした (`test_poi_compare.py`)。
