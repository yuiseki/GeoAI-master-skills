# observation-bias-audit

記録が多い場所は、現象が多い場所とは限らない。よく見られている場所かもしれない。記録の分布を現象の分布として使う前に、記録の過程を書き、記録が観測の努力に沿っていないかを測る。

扱うのは、記録の数や密度を現象の強さとして読んでよいかの監査。欠けた値の埋め方、リーク、列の意味の取り違え、点が集まっているかの検定、因果の推定、標本の重み付け一般は、このスキルの外。

| reference | 中身 |
|---|---|
| [proxies](references/proxies.md) | 観測の努力の代わりになるものの選び方と、実データでの測定 (OSM の東京 23 区) |
| [two-records](references/two-records.md) | 独立した 2 つの記録の重なり: 1 対 1 の照合、半径の感度、独立を仮定した総数 (Chapman) と、それが下限になる理由 (`scripts/record_overlap.py`) |

## 3 つを分ける

| | 意味 | 例 |
|---|---|---|
| 知りたい現象 | 本当に起きていること。普通は全部は見えない | 実際の事故、実際の店、実際にいる動物 |
| 発生の機会 (exposure) | 現象が起きうる量 | 人口、道路の長さ、建物の数、滞在時間 |
| 記録の過程 (observation effort) | 現象がデータに入る機会や確率 | 調査員の訪問、センサーの数、地図の描き込み、通報のしやすさ、報道の届きやすさ |

人口で割るのは、発生の機会で割ること。記録の過程の補正ではない。人口が多い場所で記録が多いのは、発生が多いからかもしれないし、よく見られているからかもしれない。

## 手順

1. 記録の過程を 1 行ずつ書く。知りたい現象。データに入る条件。記録されない理由。記録されやすさが場所で変わる理由。観測の努力を直接測れるか。測れないなら何を代わりにするか。分からなければ「この分布を現象の分布として使えるかは未確認」と書く。
2. 分析の単位ごとに、記録の数、面積、発生の機会、観測の努力 (か代わり) をそろえる。欠けた値と 0 を分けて数える。
3. 意味のある分母だけで率を作る。記録 / 面積、記録 / 発生の機会、記録 / 努力。記録 / 努力は、記録される確率が努力に比例するときだけ意味を持つ (普通は頭打ちになる)。
4. 記録と努力の関係を測る (`scripts/audit_observation_bias.py`)。努力の層 (値が少なければ値ごと、多ければ分位) ごとの率、努力と率の順位相関、努力と率の空間の偏り (Moran's I)。p 値ではなく、効果の大きさと層の間の差で読む。努力も空間で固まっているので、相関の p 値は当てにならない。
5. 努力をそろえて比べる。同じ努力の層の中で、率の高い単位と低い単位を見る。層の間の比較 (よく見られた地域とそうでない地域) は、現象と記録のしやすさを分けられない。
6. 努力と発生の機会が一緒に動いていないかを確かめる。強く一緒に動くなら、その努力の列は、記録の機会ではなく発生の機会を測っているかもしれない。
7. 反証を試す。現象と関係が無いはずの努力の代わりが、記録を強く予測するなら、記録の過程の影響を疑う。その代わりが本当に現象と無関係かも確かめる。
8. 別の記録 (独立に集めた同じ現象のデータ) があれば、単位ごとに、両方にあるもの、片方だけのものを数える (`scripts/record_overlap.py`)。どちらかを真値とはしない。両方が同じ偏りを持つこともある。重なりから出す総数と完全性は、2 つの記録が独立という確かめられない仮定の上の値で、両方に載りやすい物があれば総数は小さく出る。下限として書き、照合の半径を変えた値と、層ごとの値を並べる ([two-records](references/two-records.md))。
9. 書き出す (下の節)。

## 言えることと言えないこと

- 努力と記録の率が強く結び付いていたら (層の間で 1.5 倍以上、または順位相関 0.5 以上)、記録の数や密度をそのまま現象の強さとして読まない。
- ただし、努力と結び付いたことは、全てが観測の偏りだという意味ではない。現象も努力も都市に集まることはある。真値か、記録される確率の模型が無ければ、2 つは分けられない (スクリプトは `separable: False` を返す)。
- 努力の層の中での違いは、努力の違いでは説明されない。それでも、層の中に残った努力の違い (代わりの指標が拾えていない部分) は残る。
- 真値が無いなら、完全性を数字で言わない。

## 書き出すもの

1. 知りたい現象
2. 記録の過程 (データに入る条件と、入らない理由)
3. 発生の機会と、その出所
4. 観測の努力か、その代わりと、それを選んだ理由
5. 努力の空間の分布
6. 記録と努力の関係 (層ごとの率、順位相関、層の中で高い単位と低い単位)
7. 観測の偏りに弱い結論 (層の間の比較、生の数や密度の順位)
8. 真値が無いため分からないこと
