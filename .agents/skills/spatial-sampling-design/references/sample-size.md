# 標本の大きさを精度の目標から決める

「100 地点なら十分」は、何の推定に、どの精度で、どの設計で、という条件が無いと意味が無い。標本の大きさは、ほしい精度、値のばらつき、信頼の水準、設計、測れない地点の割合から、順に計算する。`scripts/sample_size.py` は各段を表示する。

## 計算の段

| 段 | 式 | 何を仮定しているか |
|---|---|---|
| 1. 単純無作為の n0 (平均) | (z × 標準偏差 / 誤差の幅)² | 標準偏差が分かっている。z は信頼の水準で決まる (95% で 1.96、90% で 1.645) |
| 1. 単純無作為の n0 (割合) | z² × p (1 − p) / 誤差の幅² | p の見込み。分からなければ 0.5 (n が最大) |
| 2. 設計の効果を掛ける | n0 × deff | 集落なら deff = 1 + (集落の中の地点の数 − 1) × 集落の中の相関 |
| 3. 有限母集団の修正 | n / (1 + (n − 1) / N) | 枠の地点の数 N が n に比べて小さいとき。N が大きければ変わらない |
| 4. 測れない地点を見込む | n / 測れる割合 | 測れない地点が、値と関係なく欠ける |

誤差の幅は、信頼区間の片側の幅 (平均 ± 2 なら 2)。幅を半分にすると、n は 4 倍になる。

```sh
uvx --with scipy python scripts/sample_size.py mean --sd 10 --margin 2 --deff 1.9 --response 0.8
# n0 96.0 -> x 1.9 -> 182.5 -> / 0.8 -> 228.1 -> plan 229 sites
uvx --with scipy python scripts/sample_size.py proportion --margin 0.05 --population 1000
# n0 384.1 -> finite population 1000 -> 277.7 -> plan 278 sites
```

## 下見 (pilot) の標準偏差

標準偏差は、計算に入れる値で、スクリプトは知らない。下見、過去の調査、根拠を書いた見込みから取る。小さな下見の標準偏差は、真の値より小さく出ることが多く、そのまま使うと n が足りない。

合成の場 (60 × 60 の 3,600 地点、平均 50.0、標準偏差 9.91、近い地点ほど似る) で、誤差の幅 2 に要る n は 95。10 地点の下見を 2,000 回繰り返し、下見の標準偏差から n を計算した。

| 下見の標準偏差の使い方 | 計算した n の中央値 | 10% 点 | 90% 点 | 要る n (95) を下回った割合 |
|---|---:|---:|---:|---:|
| そのまま | 94 | 39 | 160 | 51.1% |
| 80% の上側の信頼限界 (`--pilot-n 10`) | 157 | | | 22.1% |

下見の標準偏差をそのまま使うと、半分の計画で n が足りなかった。上側の信頼限界を使うと、足りない計画は 2 割に減るが、n は増える。どちらを取るかは、足りないときの損と、測る費用で決めて書く。

真の標準偏差から計算した n = 95 の単純無作為を 2,000 回繰り返すと、推定が真の平均 ± 2 に入ったのは 95.3% だった。標準誤差は 1.005 (式では 1.003)。

## 設計の効果と実効的な標本の数

集落の中の地点は似ているので、集落の抽出では、地点の数ほどの情報が無い。実効的な標本の数は n / deff。

同じ場を 6 × 6 地点 (600 m 四方) の 100 の集落に分け、集落を丸ごと選んだ。集落の中の相関は 0.948 で、1 + 35 × 0.948 = 34.2。

| 設計 | 地点 | RMSE | 同じ n の単純無作為 | 実測の deff | 実効的な n |
|---|---:|---:|---:|---:|---:|
| 3 集落 | 108 | 5.56 | 0.91 | 37.6 | 2.9 |
| 6 集落 | 216 | 3.83 | 0.67 | 33.0 | 6.5 |

216 地点を測っても、独立な 6.5 地点ほどの情報しか無かった。式の deff (34.2) と、繰り返しで測った deff (33〜38) は近かった。集落を増やすほうが、集落の中の地点を増やすより効く。

## 空間自己相関と近い地点

近い地点ほど値が似るとき、すでに選んだ地点のすぐ隣を足しても、新しい情報はほとんど増えない。この効果に万能の閉じた式は無い。値の似かたの距離と、地点の配置の両方で決まる。

上と同じ場で、空間的に均衡した 25 地点に、各地点の隣の 3 地点 (100 m 先) を足して 100 地点にした (各 300 回)。

| 設計 | 地点 | RMSE |
|---|---:|---:|
| 空間的に均衡 | 25 | 0.86 |
| 均衡した 25 地点 + 各地点の隣 3 地点 | 100 | 0.89 |
| 空間的に均衡 | 100 | 0.24 |
| 単純無作為 | 100 | 1.06 |

隣を足した 100 地点の精度は、元の 25 地点と変わらなかった。同じ 100 地点を散らばらせると、誤差は 4 分の 1 になった。

母集団の地点から単純無作為に選ぶなら、標準誤差の式 (標準偏差 / √n) は空間自己相関があっても成り立つ (上の 95.3%)。地点が無作為に選ばれていることが、式の根拠になる。式が外れるのは、地点が固まる設計 (集落、隣を足す、行きやすい所だけ) と、値を生んだ過程の平均 (場の背後の平均) を推定したいとき。後者では、近い地点が似るほど、実効的な n は小さい。

自己相関のある場で n を決めるには、次の手順で模擬する。

1. 下見か過去のデータで、経験 variogram (値の似かたと距離の関係) を測る。
2. 似かたの距離が同じ合成の場を作るか、過去のデータそのものを場にする。
3. 計画した配置 (設計と n) で何百回も選び、推定の誤差を測る。
4. 誤差が目標を満たす最小の n を選ぶ。単純無作為の n との比が、その配置の設計の効果。

## 層別と均衡した抽出

層の平均が違えば、層別にすると層の間の違いが誤差から消え、n が減る。同じ場を南北の 2 つの層に分けると、層の中の標準偏差は 9.64 と 5.38 になり、誤差の幅 2 に要る n は、単純無作為 94.3、比例配分の層別 58.5、Neyman 配分 (層の大きさ × 標準偏差に比例) 54.1 だった。比例配分の 59 地点を 2,000 回選ぶと、95% の幅に入ったのは 94.8%。

空間的に均衡した抽出は、上の表で 100 地点の誤差を単純無作為の 4 分の 1 にした。n を決めるときには、単純無作為の式で n を出し、均衡した抽出で減らせる分を模擬で確かめる。均衡した抽出の分散を、単純無作為の式で推定すると大きめに出る (designs.md)。

## 測れない地点

測れない地点 (立ち入れない、断られた、水没) を見込んで、n を測れる割合で割る。これは数を補うだけで、偏りは直らない。測れない地点が値と関係するなら、地点を増やしても偏りは残る。

同じ場で、値の高い側の端 (北の 20% の行) に行けないとき、単純無作為の偏りは、計画した n が 95、119、400 のどれでも −1.0 だった。95% の幅 (± 2) に入った割合は、95 地点で 80.0%、119 地点で 82.0%。400 地点で 96.2% に上がったのは偏りが減ったからではなく、ばらつきが減って、偏り (1.05) が幅 (2) の中に収まったから。行けない場所は枠の外として書き、推定の対象から外したと書くか、別の方法で測る。

## 書き出すもの

- 推定したいもの、誤差の幅、信頼の水準
- 標準偏差か割合の見込みと、その出どころ (下見の地点の数、上側の限界を使ったか)
- 設計の効果の値と根拠 (式か模擬か)、有限母集団の修正の有無
- 測れる割合の見込み、測れない地点が値と関係しうるか
- 計画した n と、測れると見込む n
