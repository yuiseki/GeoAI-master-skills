# GSI DEM10B: 富士山周辺の約100 m標高格子

## ライセンスと出典表示

国土地理院の[地理院タイル一覧](https://maps.gsi.go.jp/development/ichiran.html)は、基盤地図情報数値標高モデル由来の標高タイルを「基本測量成果以外で出典の記載のみで利用可能なもの」に掲げています。国土地理院の[コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)は、特段の記載がないコンテンツに公共データ利用規約1.0 (PDL1.0)を適用し、出典と加工した旨を明記するよう定めています。標高タイル一覧では `dem` は DEM10B テキスト形式で、元となる基盤地図情報数値標高モデルを線形平滑化した値と説明されています。

この配布は上記の出典・加工明記を README と LICENSE に記載し、原典タイルも出所と改変履歴を保持して同梱しています。出典表示:「出典：国土地理院ウェブサイト（地理院タイル一覧）。地理院タイル（標高タイル（基盤地図情報数値標高モデル））を加工して作成」。本GeoParquetは国土地理院が作成・承認した公式成果ではありません。

## 実測値

- 読んだ配布先: `https://cyberjapandata.gsi.go.jp/xyz/dem/14/{x}/{y}.txt`
- 取得範囲: z14、x=14500〜14509、y=6465〜6474 (富士山を含む10×10タイル)
- 取得した100タイルはすべて256×256で、合計6,553,600画素。全画素に数値標高値があり、`e` 欠損は0画素だった (2026-10-25)
- タイルの画素格子はEPSG:3857。10×10ソース画素を1行とし、`grid_x, grid_y` は65,536組で一意
- GeoParquetは65,536行、EPSG:3857、Polygon 65,536件、無効ジオメトリ0。`valid_pixels` は全件100
- 原典画素から全行の平均・最小・最大値を再計算し、公開表と一致することを検証。原典・GeoParquetのSHA-256はHubマニフェストに記録
- 約95.55 mはWeb Mercator投影上の辺長。地上の東西幅は緯度に応じて短くなるため、厳密な100 m地上格子ではない
- 国土地理院はテキスト形式の標高タイルを2024年10月以降更新停止と案内している。2026-10-25は取得日であり、値の測量時点を示さない
