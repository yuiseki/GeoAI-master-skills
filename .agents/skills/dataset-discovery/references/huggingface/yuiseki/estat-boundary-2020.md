# 2020年国勢調査 小地域境界

232,019ポリゴン、47都道府県別の Parquet。人口・世帯数、町丁字名、代表点、面積等を含む。座標値は JGD2000 の経度・緯度だが、GeoParquet CRS metadata は未確認のため変換前に元 CRS を明示する。`KEY_CODE` は文字列キー。`PREF` と `CITY` で自治体コードの先頭部分を構成する。住所ベースレジストリと小地域名を結ぶには正規化が要り、完全な共通キーではない。属性は文字列型で秘匿記号もある。CC BY 4.0 の出典と加工を明記する。

## 町丁ごとに集計する前に (東京 23 区で数えた、2026-11-03)

`r2ka13.parquet` の 23 区 (`PREF = '13'`、`CITY` 101〜123) は 3,192 行。行は町丁ではなくポリゴンで、そのまま町丁として数えると数と値がずれる。

- 1 つの `KEY_CODE` が複数の行になる: 神田紺屋町 (2 行)、浜離宮庭園 (3)、台場一丁目 (2)、山吹町 (2)、江東区の水面 (16)、港区の水面 (22)、江東区の名前の無い陸 131089990 (2)。町丁を単位にするなら `KEY_CODE` で形を結合し、人口を足す。行数の検査と、結合した後の単位の数の検査を分ける (江東区は 173 行で 157 単位)。
- `HCODE` は 8101 (町丁・字等) と 8154 (水面調査区)。8154 は 41 行で、中央区、港区、江東区、品川区、大田区にある。人口はほぼ 0 (合計 5 人)。水面は町丁ではないので、道路あたりや人口あたりの値を付けない。
- `S_NAME` は水面で揃っていない: 「水面調査区」(中央区)、「‐」(港区)、空 (江東区、品川区)。8101 にも空が 2 行ある (江東区 131089990)。名前で町丁を選ぶ前に `HCODE` と空の名前を確かめる。
- 穴のあるポリゴンがある: 中央区の水面調査区 (月島、勝どき、佃を囲む)、港区と江東区の水面。地図は穴を残して塗る。外周だけを塗ると、穴の中の町丁を覆う。ファイルの環の向きは外周が時計回り、穴が反時計回りだった。結合や投影の変換のあとは向きを確かめない限り当てにしない。
