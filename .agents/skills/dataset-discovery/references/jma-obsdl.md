# 気象庁 過去の気象データ・ダウンロード (jma-obsdl)

気象庁の[過去の気象データ・ダウンロード](https://www.data.jma.go.jp/risk/obsdl/index.php)は、画面で観測所、要素、期間を選んで CSV を落とすサービス。画面の裏で、上の `table` に form を POST している (2026-10-26 に画面の JavaScript `top.bundle.js` を読んで確かめた)。API として公開された仕様ではなく、画面が変われば要求の形も変わりうる。

## 値の付き方 (配布元のヘルプによる)

| 欄 | 値 | 意味 |
|---|---|---|
| 品質情報 | 8 | 正常値 |
| | 5 | 準正常値 (統計のもとの資料が許容範囲で欠けている。必要な資料はおよそ 80%) |
| | 4 | 資料不足値 (許容範囲を超えて欠けている) |
| | 2 | 疑問値 |
| | 1 | 欠測 |
| | 0 | 観測、統計の項目でない |
| 現象なし情報 | 1 | 現象なし (降水が無かった) |
| | 0 | 現象あり |
| 均質番号 | 1、2、… | 番号が変わったところで観測の環境が変わった。番号の違う値どうしは、そのまま比べられない |

## 実測: 東京都の 31 観測所、日別の降水量 1974〜2025 年 (2026-10-26)

要素は、降水量の合計、1 時間降水量の最大、10 分間降水量の最大。観測所ごとに 1974-01-01〜2025-12-31 を 1 回で要求し、31 個の CSV を Parquet の 1 表 (観測所 × 日、588,783 行) にした。CSV の行数と表の行数は一致し、(観測所、日) の重複は 0。値の列に数でない文字は無かった。

| 観測所 | 種類 | 降水量の値のある期間 | 1 時間最大 | 10 分間最大 | 均質番号 |
|---|---|---|---|---|---|
| 東京 s47662 | 気象台 | 1974-01-01〜2025-12-31 | 1974 から | 1974 から | 1 のまま |
| 練馬 a1002 | アメダス | 1976-01-01〜 | 1976 から | 2009-03-03 から | 2012-12-26 に 1 から 2 |
| 世田谷 a0368 | アメダス (雨だけ) | 1976-01-01〜 | 1976 から | 2009-03-18 から | 1 |
| 江戸川臨海 a0370 | アメダス | 1976-01-01〜 | 1976 から | 2009-01-30 から | 1 |
| 羽田 a0371 | アメダス | 1976-01-01〜 | 1976 から | 2009-01-30 から | 1 |
| 府中 a1133 | アメダス | 1976-12-15〜 | 1976 から | 2008-03-26 から | 1 |
| 八王子 a0366、青梅 a1001、小河内 a0365、小沢 a1180 | アメダス | 1976 (小沢は 1977-08-02)〜 | 同じ | 2008〜2009 から | 1 |
| 調布 a0367 | アメダス (雨だけ) | 1976-01-01〜1976-12-13 (観測終了) | | 無し | 1 |

島しょの 20 観測所 (気象台 5、アメダス 15) も同じ表にある。

- 23 区と多摩の本土で、1974〜1975 年に値があるのは東京だけ。アメダスは 1976 年から。
- 日別の 10 分間最大は、アメダスでは 2008〜2009 年からしか無い。気象台の東京は 1974 年からある。1 時間最大は全ての観測所で降水量と同じ期間にある。
- 気象台の 0 には 2 種類ある。現象なし (39,169 日、値は全て 0) と、現象ありで 0 (29,679 日、0.5 mm に届かない降水と推測)。アメダスは現象なし情報を持たないので、0 がどちらかを区別できない。
- 品質情報は、本土の観測所では観測期間の中のほとんどの日で 8。欠測 (1) は東京 1 日、練馬 5 日など。三宅島は 2000〜2005 年に 410 日の欠測がある (2000 年の噴火の時期と重なるが、原因は確かめていない)。
- 東京の観測所は今の位置 (北の丸公園、北緯 35.692 度、東経 139.750 度) を返す。観測所の一覧は、移転の前の位置を返さない。東京の降水量の均質番号は 1974〜2025 年で変わらなかった。移転の有無と時期は、このサービスからは分からない (未確認)。
- 緯度経度は度と 0.1 分の刻み (およそ 185 m) で返る。
- 例: 2019-10-12 (台風第19号) の日降水量は 東京 209.5 mm、練馬 282.0 mm。東京の 1 時間最大の最大値は 82.5 mm (2000-07-04)。

## 使うとき

- この取得は、版を固定して Hugging Face に置いた ([jma-tokyo-daily-rain](huggingface/yuiseki/jma-tokyo-daily-rain.md))。東京都の日別の降水量なら、そちらを使う。
- 更新される入口で、同じ要求が後日同じ値を返す保証は無い。分析に使うなら、取得の時刻 (CSV の 1 行目) と、CSV のハッシュを残す。
- 期間を分けて取るなら、均質番号を期間をまたいで比べない。全期間を 1 回で取るのが簡単。
- 観測所はまばら。23 区の中で長い記録を持つのは、東京、練馬、世田谷、江戸川臨海、羽田の 5 つ。区より細かい場所の雨は、ここからは分からない。
- アメダスの雨だけの観測所 (kansoku が 100000) は、気温などを持たない。
