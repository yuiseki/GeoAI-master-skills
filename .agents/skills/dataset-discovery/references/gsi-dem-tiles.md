# 国土地理院の標高タイル (gsi-dem-tiles)

国土地理院が配る標高のタイル。ズーム z とタイルの番号 x、y で、256 × 256 画素の標高 (m) をカンマ区切りのテキストで返す。1 行が画素の 1 行 (北から南)、1 列が画素の 1 列 (西から東)。認証は要らない。

```
https://cyberjapandata.gsi.go.jp/xyz/dem/14/{x}/{y}.txt
```

## 測ったこと

2026-10-14 に、ズーム 14 の 32 枚 (長野県と山梨県の 4 × 4 枚ずつ) を読んだ。

| 項目 | 値 |
|---|---|
| 形 | 256 行 × 256 列。値は小数 2 桁の m (`1551.00`) |
| 速さ | 1 枚 0.25 秒 (1 回の取得) |
| 値なし | `e` (海などで使うとされる。読んだ 32 枚には無かった) |
| 例 | x 14458、y 6419 (長野県、北アルプスの東の縁) は 1,539.4〜2,333.8 m |

2026-10-26 に、ズーム 12 で秋田県の範囲 (東経 139.69〜141.0 度、北緯 38.87〜40.52 度、x 3637〜3652、y 1542〜1567 の 416 枚) を読んだ。

| 港の水面 | 市町村の面 (`jp-admin-2026-09`) に入っている港の海面は `e` で、値が無い |

## 画素の位置

画素 (行 r、列 c) の中心の経度と緯度は、タイル全体での画素の番号 X = 256 x + c + 0.5、Y = 256 y + r + 0.5、N = 256 × 2^z として、経度 = X / N × 360 − 180、緯度 = atan(sinh(π (1 − 2 Y / N)))。タイルは Web メルカトルの格子なので、画素は地上で正方形ではなく、緯度が上がるほど東西に縮む。距離や面積は、メートルの座標系に移してから測る。

## 気をつけること

- 公開のサーバー。広い範囲を一度に取らず、使う枚数だけ取って手元に保存する。
- ズーム 14 の元の DEM の種類 (5 m か 10 m か) と、場所ごとの作り方は確かめていない (未確認)。
- 陸の無いタイルは 404 を返す。404 は「値の無いタイル」として数え、ほかの HTTP のエラーで止める。
- 版の番号が無い。取得した日を書き、取ったテキストを保存して、後で同じ値を使えるようにする。
