# 全体と比べる: Isolation Forest、LOF

期待値を作らず、複数の特徴量の空間で、他の単位から孤立している度合いを測る。`find_anomalies.py --context global --features F1 F2 ...`。特徴量は標準化してから使う。

| 手法 | 測るもの | 向いているもの |
|---|---|---|
| Isolation Forest | 無作為な分割で、その単位を他から切り離すのに要る回数の少なさ | 全体から離れた単位 |
| LOF | 近傍 (20 単位) と比べた、その単位の周りの密度の低さ | 密な群のすぐ外にいる単位。密度の違う群が混ざるとき |

- `find_anomalies.py` は scikit-learn の `IsolationForest(n_estimators=500)` と `LocalOutlierFactor(n_neighbors=20)` を使い、どちらも高いほど外れとして出す。並べるのは Isolation Forest。
- どの特徴量の組み合わせで外れているかは、得点からは分からない。上位の単位の特徴量を、全体の分布と並べて見る。
- 群に分けたとき 1 単位だけの群になった単位や、密度に基づく手法で雑音とされた単位は、ここでも上位に来ることが多い。

## 例

WDI の 2022 年の 207 か国を、平均寿命、1 人あたり GDP (対数)、都市人口の割合、合計特殊出生率で見た (2026-10-10)。Isolation Forest の上位は、中央アフリカ共和国 (0.741、LOF 4.17)、リヒテンシュタイン、モナコ、ソマリア、ナウル、チャド、ニジェール、ブルンジ。小さな高所得国と、出生率の高い低所得国が並ぶ。
