# 似た条件と比べる: モデルの予測からの外れ

特徴量の似た単位から期待される値として、モデルの予測を使う。`find_anomalies.py --context expected --expected COL`。

- 予測は、交差検証の外側の予測を使う (各行を、その行を学習に使わなかったモデルで予測して集めた値。sklearn の `cross_val_predict` で得られる)。外側の予測なので、外れた単位が自分の予測を引き寄せない。学習に使ったモデルの予測を使うと、外れが小さく見える。
- repeat が複数あるなら、単位ごとに予測を平均してから使う。
- 得点は「この特徴量の割に」外れている度合い。特徴量の選び方で、何の割にかが変わる。

## 例

WDI の 2022 年の平均寿命を、1 人あたり GDP (対数)、人口 (対数)、都市人口の割合の線形モデルで予測し (行を無作為に 5 分割、3 つの repeat の平均)、予測から外れた国 (2026-10-10):

| 国 | 平均寿命 | 予測 | 得点 |
|---|---:|---:|---:|
| 中央アフリカ共和国 | 18.8 | 61.4 | 12.4 |
| ナイジェリア | 54.1 | 70.7 | 4.84 |
| ナウル | 61.9 | 73.9 | 3.50 |
| チャド | 54.5 | 63.8 | 2.71 |

ナイジェリアは、所得と都市化から期待されるより平均寿命が 16 歳低い。誤りか出来事かは、まだ突き合わせていない。
