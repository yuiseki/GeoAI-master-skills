# anomaly-detection

異常は「比べる相手から期待される値からの外れ」。何と比べるかで、同じ観測が異常にも普通にもなる。比べる相手を先に決め、それを書く。

| reference | 比べる相手 | 期待値の作り方 |
|---|---|---|
| [time](references/time.md) | 同じ単位の前後 (または過去) の時点 | 前後の時点の中央値 |
| [space](references/space.md) | 地理的に近い単位 | 近傍の中央値 |
| [expected](references/expected.md) | 似た条件の単位 | モデルの予測 (交差検証の外側) |
| [global](references/global.md) | 全ての単位 | 期待値を作らず、特徴量の空間での孤立の度合い (Isolation Forest、LOF) |

## 手順

1. 何と比べたときの外れを探すかを書く。「その国のいつもの推移から外れた年」「所得の割に平均寿命が低い国」。
2. `scripts/find_anomalies.py` で、比べる相手から期待値を作り、外れの得点で並べる。
3. 上位の観測を 1 つずつ見る。得点の順位は候補の並びで、結論ではない。
4. 各候補を、データの誤りか、本当の出来事かに分ける (下の節)。
5. 誤りなら、直すか除き、どのデータの何をどうしたかを書く。本当の出来事なら、分析の対象として残す。分析から除くかどうかは、問いで決める。
6. 書き出す。

## 外れの得点

`find_anomalies.py` は、time、space、expected では、観測と期待値の差を、全ての差の中央値絶対偏差 (MAD) の 1.4826 倍で割った値を得点にする (外れにくい z 得点)。標準偏差で割ると、1 つの巨大な外れが尺度を膨らませ、他の外れを隠す。差の半分以上が同じ値で MAD が 0 になる (件数の大半が 0 など) ときは、平均絶対偏差の 1.2533 倍で代え、そのことを出力に書く。global では、Isolation Forest と LOF の得点を出し、Isolation Forest で並べる。

```sh
uvx --with duckdb --with scikit-learn --with pyarrow python scripts/find_anomalies.py \
  tmp/series.parquet ID VALUE --context time --unit iso3 --time year --window 2 --top 25
```

テストは `uvx --with duckdb --with scikit-learn --with pytest pytest scripts/test_find_anomalies.py`。期待値が単位をまたがないこと、自分自身を含まないこと、過去だけのときに後の時点を使わないこと、行の順ではなく時点の順に従うこと、1 つの巨大な外れが尺度を膨らませないことを確かめている。それぞれを壊すと落ちることを確かめてある。


得点にしきい値を掛けて「外れ」を数えるときは、偶然で超える数を並べて書く。得点が正規分布に従うなら、|得点| ≥ 3 の外側は 0.27% なので、1,000 単位を並べれば、外れが無くても約 3 単位が超える。単位の数だけ判定している (多重比較) ことを忘れない。超えた数がこの期待の数と変わらないなら、外れが多いとは言えない。近傍と比べる得点 (space) は、隣り合う単位の得点が似るので、超えた単位が固まっても、独立な外れの数ではない。
## まれな事象の割合の外れ

比べる相手が「似た条件の単位」で、値がまれな事象の件数 (事故のうちの死亡、検査のうちの陽性) のときは、上の MAD の得点でなく、件数の確率で並べる。件数の大半が 0 か 1 で、MAD は 0 になり、平均絶対偏差で代えても 1 件の差が大きな得点になる。

1. 期待値を条件の層の割合から作る。単位 u の事象 i の確率を、i の層の割合とし、期待 E_u は確率の和。観測 O_u がそれ以上になる確率 P_u を、確率の違う独立な試行の和 (Poisson 二項分布) の正確な上側で出す。全ての単位で多重比較を補正する (BH)。
2. 層の割合から、その単位自身の事象を除く (自分を除く)。含めると、事象の多い単位ほど自分で期待を引き上げ、外れが小さく出る。
3. 自分を除くと、層の事象がその単位にしか無いとき、割合が 0、期待が 0、P が 0 になる。これは「この層では起きない」と言い切りすぎた縮退で、外れではない。細かい単位 (小さい格子、道路の区間) ほど起きる。割合を親の層 (条件を 1 つ外した層) へ寄せて防ぐ: p_s = (F_s + m p_親) / (N_s + m)。m は結果を見る前に決め、決めた理由を書く。P = 0 の単位の数を出力に書き、0 でなければ縮退を疑う。
4. 小さい層は親へまとめる。下限の例は、全体の割合の逆数 (層の中で期待される事象が 1 件に届かない大きさ)。親へ送った後の残りも下限を下回れば、さらに上へ送る。子が残った後の残りを、親の全体の件数で判定しない。
5. 検出力を数える。BH で首位の単位が有意になるには P ≤ α / M (M は単位の数) が要る。単位ごとに、そこへ届くのに要る事象の数を出し、観測の最多と比べる。届かないなら、答えは「外れが無い」ではなく「この件数では検出できない」。単位を細かくすると M が増え、1 単位の件数が減るので、検出力は下がる。
6. 1 つずつは言えなくても、場所の差があるかは別に測れる。T = Σ (O - E)^2 / V (V は確率の分散の和) を、層の中で事象の印を並べ替えた分布と比べる。並べ替えは層ごとの事象の数と単位の層の構成を保ち、どの単位で起きたかを壊す。
7. 上位が続くかを確かめる。期間を分け、前の期間の上位の単位を、後の期間の事象と期待で数え直す。上位が偶然の当たりなら、後の期間で O / E は 1 前後へ戻る (平均への回帰)。

例: 東京 23 区の 2019〜2025 年の人身事故 144,123 件と、うち 24 時間以内の死亡事故 688 件で、道路形状、車道幅員、中央分離帯の層をそろえ、500 m 格子 2,454 で探した (2026-11-06)。BH で有意な格子は 0 だった。首位に要る P は 2.04e-05 で、格子の半分は死亡事故 5 件以上が要るのに、観測の最多は 4 件だった。並べ替えとの比較では、場所の差がある (p 0.006)。前の期間の上位 20 は 41 件 (期待 2.8) だったが、後の期間は 1 件 (期待 1.9) だった。道路の区間を単位にすると、自分を除いた割合の縮退で P = 0 の区間が 4 つ出て、親の層へ m = 210 で寄せると全て消えた。

## 誤りか、出来事か

| 手がかり | 誤りを疑う | 出来事を疑う |
|---|---|---|
| 同じデータの別の版 | 版によって値が大きく違う | 版をまたいで同じ |
| 別のデータセット | 対応する変化が無い | 対応する変化がある (紛争の死者、災害の記録) |
| 前後の形 | 1 時点だけ跳ね、すぐ戻る。あり得ない大きさ | 原因の時期と合う形で落ちて戻る |
| 定義と単位 | 単位の取り違え、桁のずれ、座標の入れ替え | 定義どおりの値 |

例: WDI の平均寿命の全系列 (217 か国、1960〜2024 年、14,071 行、前後 2 年と比べる) で上位に来たもの (2026-10-10)。

| 観測 | 値 (期待値) | 突き合わせ | 読み |
|---|---|---|---|
| ルワンダ 1994 | 12.2 (42.7) | UCDP の死者 約 77 万人 | 出来事 |
| ボスニア 1992、1993 | 52.0、50.9 (69.1、68.4) | UCDP の死者 25,171、13,787 | 出来事 |
| ソマリア 1991、1992 | 25.4、25.0 (46.8、48.6) | UCDP の死者 8,455、4,729 | 出来事 |
| 中央アフリカ共和国 2009、2019、2022 | 14.7、31.5、18.8 (49.6、47.9、54.0) | UCDP の死者 244、507、773。最多は 2013〜14 年 (約 3,400)。版 2024-05-30 では 2022 年は 54.5 | 誤りを疑う (原因は未確認) |

上位にはほかに、レバノン 1976、バングラデシュ 1971、ブルンジ 1972、ハイチ 2010、キプロス 1974、アルメニア 1988、カンボジア 1974〜78 が並ぶ。UCDP は 1989 年以降しか無いので、これらは突き合わせていない。

## 書き出すもの

- 何と比べたか、期待値の作り方と設定 (窓、近傍の数、モデル、層と寄せる重み)
- 得点の上位と、その尺度 (MAD か平均絶対偏差か、件数の上側確率か)
- まれな事象の割合なら、検出力 (首位に要る P と事象の数)、P = 0 の単位の数、期間を分けた持続
- 各候補を誤りか出来事かに分けた理由と、突き合わせた資料
- 誤りの扱い (直した、除いた) と、それで結論が変わるか
