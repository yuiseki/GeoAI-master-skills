# data-variable-semantics

問いの言葉 (「難民」「紛争が多い場所」「人口」) と、それに当てる列が同じものを指しているかを確かめる。
列名が問いの言葉に似ていても、数えている対象、単位、時点、場所の意味が違えば、分析は別の問いに答えてしまう。

## 手順

1. 問いの言葉を書き出し、それぞれに当てる列を決める。目的変数、説明変数、絞り込みと集計に使う列のすべてについて。
2. 列ごとに、一次資料の定義を読んで引用する。一次資料はコードブック、指標の定義表 (WDI の `series` など)、配布元の方法論のページ。データセットカードや reference は手がかりで、正本ではない。どの資料のどこから引いたかも書く。
3. 定義と問いの言葉を、下の観点で突き合わせる。
4. 食い違いの疑いを実データで数える。カテゴリごとの件数、値の範囲、合計が合うか、年ごとに値が途切れたり跳ねたりしていないか。
5. 列ごとに扱いを決める。そのまま使う、行を絞る、別の列に替える、問いの言葉のほうを定義に合わせて言い直す、のいずれか。

## 突き合わせる観点

| 観点 | 問うこと | 例 |
|---|---|---|
| 対象 | 誰を、何を数えているか。全数か、一部か | UNHCR の `IDPs of concern to UNHCR` は、UNHCR が支援する国内避難民だけで、全数ではない |
| 単位 | 件か人か。数か率か。何の通貨、何年の価格か | UNHCR の庇護申請は `Cases / Persons` で件と人が混ざる |
| 時点 | 年末の残高 (stock) か、期間中の流れ (flow) か | UNHCR の `population` は年末の人数、`solutions` はその年の流れ |
| 場所 | 座標や国が何を表すか | UCDP GED の `where_prec` が 3 以上の点は、事件の場所ではなく行政区の代表点 |
| 集計 | 個体の行に集計の行が混ざっていないか | WDI の `data` には World、地域、所得階層の行がある |
| 欠損 | 欠損がどう表されているか。0 と区別できるか | UNHCR の `-` は NULL で、0 ではない。WDI は欠損を行の不在で表す |
| 加工 | 丸め、推定、補間がされていないか | UNHCR は 5 未満を 5 の倍数に丸める |
| 定義の変化 | 年や版で定義が変わっていないか | UNHCR の無国籍の難民は 2017 年と 2020 年から二重に数えられる |

データセットごとの既知の食い違いは、dataset-discovery の reference (`../dataset-discovery/references/`) の「気をつけること」にある。そこに無い食い違いを見つけたら、reference にも書き足す。

## 書き出すもの

使う列ごとに 1 行。

| 問いの言葉 | 列 | 一次資料の定義 (引用と出典) | 食い違い | 実データで数えたこと | 扱い |
|---|---|---|---|---|---|

扱いで問いを言い直したなら、言い直した問いを報告の冒頭に書く。食い違いを残したまま使うなら、それが結論をどちらに偏らせうるかを書く。
