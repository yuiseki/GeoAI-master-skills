# 欠けた値、0、打ち切り

値が無いことにも種類があり、種類ごとに意味が違う。区別せずに 0 で埋めたり、行を除いたりすると、結論が変わる。

## 種類

| 種類 | 意味 | 例 | 0 と読んでよいか |
|---|---|---|---|
| 欠測 (missing) | 値があるはずだが、記録が無い | 回答が無い | いいえ |
| 不明 (unknown) | 記録したが、値が分からない | 年齢不詳 | いいえ |
| 該当なし (not applicable) | その単位には意味が無い | 駅の無い町の駅の利用者数 | 問いによる。多くは別に扱う |
| 測った 0 | 測ったら無かった | 事故 0 件の格子 | はい |
| 構造的な 0 | そもそも起こりえない | 海の上の人口 | はい。ただし分析の対象から外すことも多い |
| 調べていない | 調査の範囲や対象に入っていない | 調査しなかった地域 | いいえ |
| 範囲の外 | データの覆う範囲の外 | ラスタの外 | いいえ |
| 検出の限界より下 | ある値より小さいことしか分からない | 濃度が定量下限未満 | いいえ (0 と限界の間のどこか) |
| 打ち切り (censored) | ある値より大きい (小さい) ことしか分からない | 観測の期間の終わりまで起きなかった | いいえ |

データの符号 (NULL、空欄、-99、9999、「*」、「-」) が、どの種類を指すかを、データの説明で確かめる。同じ符号が、表によって違う種類を指すこともある。

## 0 で埋めると意味が変わる

合成のデータ (1 万単位、平均 22.8、numpy、2026-10-14) で、値を 3 割ほど欠けさせて全体の平均を推定した。

| 欠け方 | 欠けた割合 | 欠けた行を除く | 0 で埋める | 平均で埋める |
|---|---:|---:|---:|---:|
| 無作為 (MCAR) | 28.4% | +0.2% | −28.2% | 22.84 (平均は同じ、ばらつきは小さくなる) |
| 値の低い単位ほど欠ける (MNAR) | 38.5% | +21.5% | −25.3% | +21.5% |

- 0 で埋めると、欠け方によらず平均が大きく下がる。
- 無作為に欠けるなら、欠けた行を除いても平均は偏らない。値と関係して欠けるなら、除いても、平均で埋めても偏る。

検出の限界 (15) より下の値 (27.9%) の置き換えで、平均は次のようになった。

| 置き換え | 平均の偏り |
|---|---:|
| 0 | −13.9% |
| 限界の半分 | −4.7% |
| 限界そのもの | +4.4% |

検出の限界より下を 0 にしない。どの値に置き換えても仮定が入るので、置き換えた値と、その割合を書く。割合が大きいなら、打ち切りを扱う方法 (打ち切りのある回帰、生存時間の方法) を検討する。

## 欠け方の 3 つ

- 無作為 (MCAR): 欠けるかどうかが、どの値とも無関係。欠けた行を除いても偏らない (標本が減るだけ)。
- 観測した値で説明できる (MAR): 欠けるかどうかが、観測している別の変数 (地域、年齢層) で決まる。その変数を使った補完やモデルで偏りを減らせる。
- 欠けた値そのものに関係する (MNAR): 欠けるかどうかが、欠けた値自身に関係する (所得の低い人ほど答えない)。観測したデータだけからは見分けられず、補完のアルゴリズムでは解決しない。感度分析 (欠けた値が観測より x% 低かったら、結論は保たれるか) で幅を示す。

どれに当たるかは、データからは完全には決まらない。欠けた理由を、データの作り方から推して書く。

## 欠けた値の扱い方

- 欠けた行を除く (complete-case): 単純。欠け方が無作為でなければ偏る。除いた行の数と、除いた行の性質 (地域、時期) を書く。
- 欠けの印 (missing indicator) を足して 0 などで埋める: 予測には役立つことがあるが、係数の解釈には使わない。欠けたこと自体が情報を持つ (調べなかった地域) 場合に限る。
- 単純な補完 (平均、中央値): ばらつきを小さく見せ、相関を弱める。
- 補完のモデル (中央値も含む) は、学習側のデータだけで決める。試験側の値で補完の値を決めると、試験側の情報が学習に漏れる。

## 欠け方を分けて見る

欠けた割合は、全体だけでなく、地域、時期、群ごとに数える。全体で 5% でも、ある地域で 50% なら、その地域の結論は欠け方に左右される。欠けた割合の地図を作り、欠けが固まる場所を書く。
