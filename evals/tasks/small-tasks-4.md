# 小さい課題 その 4 (エージェントに渡す側)

問いは、人が尋ねる言葉のまま。使うデータと提出の形だけを書いた。1 回の実行では 1 つだけ渡す。

## 課題 28: 東京 23 区のアンダーパスを推測する

問い: 東京 23 区で、道路のアンダーパスはどこにある？ 公式の一覧を見ずに、公開のデータから推測してほしい。
アンダーパス: 道路や鉄道と立体交差して、前後の区間より急に低くなる道路の区間。国と地方公共団体が管理する道路に限る (高速道路会社の道路は含めない)。
使い道: 大雨のときに冠水しやすい場所の候補を、公式の一覧の無い地域でも挙げられるかを確かめたい。公式の一覧は答え合わせに使う。
使うデータ: 道路と鉄道は Hugging Face の `yuiseki/osm-tokyo23-src-2026-08` (OpenStreetMap、2026-08-31 で凍結)。23 区の範囲は `yuiseki/jp-admin-2026-09` の市区町村の面。ほかのデータ、Web の検索や取得、OpenStreetMap の公開のサーバー (Overpass API など) は使わない。国土交通省のアンダーパスの一覧と、その複製 (Hugging Face のものも含む) は答えなので、読まない、探さない、使わない。
提出: 推測した地点を、報告と同じディレクトリの `predictions.csv` に、1 行 1 地点で、`lon` と `lat` の列 (WGS84 の経度と緯度) で置く。1 つのアンダーパスには 1 地点。
採点: 公式の一覧の地点と、100 m 以内で 1 対 1 に組にして、当たった数を数える。地点を増やすと外れも増える。
範囲: 東京 23 区。
