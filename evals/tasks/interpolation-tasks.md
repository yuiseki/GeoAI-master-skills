# 地点の値から、ほかの地点の値を推定する課題 (エージェントに渡す側)

1 回の実行では 1 つだけ渡す。

## 課題 24: 観測した地点の標高から、ほかの地点の標高を推定する

使い道: 限られた地点でしか測っていない値を、測っていない地点についてどこまで当てられるかを知る。
使うデータ: 国土地理院の標高タイル (DEM)。ズーム 14 の `https://cyberjapandata.gsi.go.jp/xyz/dem/14/{x}/{y}.txt` (256 × 256 の数値の表。`e` は値なし)。x は 14463 から 14466、y は 6417 から 6420 の 16 枚を、縦横に並べて 1,024 × 1,024 画素の格子とする (行 r は上から、列 c は左から、0 から数える)。画素 (r, c) の位置は、その画素の中心: タイル全体での画素の番号 X = 14463 × 256 + c + 0.5、Y = 6417 × 256 + r + 0.5、N = 256 × 2^14 として、経度 = X / N × 360 − 180、緯度 = atan(sinh(π × (1 − 2 Y / N))) (度)。画素の値をその地点の標高とする。

観測点: k = 0, 1, 2, ... の順に r = (397 k + 13) mod 1024、c = (613 k + 71) mod 1024 を作り、c < 768 のものだけを、すでに選んだ点と重ならない限り、300 点になるまで取る。
予測点: k = 0, 1, 2, ... の順に r = (271 k + 500) mod 1024、c = (449 k + 37) mod 1024 を作り、観測点とも、すでに選んだ点とも重ならない限り、200 点になるまで取る。

求めるもの:
1. 観測点の標高だけを使って、予測点を推定したときの誤差 (平均絶対誤差、m) を、予測点の標高を見る前に見積もる。方法と設定は自分で選ぶ。
2. 予測点の標高を推定し、DEM の値と比べた平均絶対誤差を報告する。
3. 使った方法が、より単純な方法と比べてどれだけ良いか。1 の見積もりは当たったか。
範囲: 上の 16 枚のタイル (長野県)。
