# 横浜市の区ごとの津波の避難場所

- 落とし穴: 政令指定都市の場所は、区でなく市のコード (`common_id` の 2 文字目から 14100) で登録されている。区ごとに数えるには、点を区の面に空間結合する。津波の指定 (`tsunami`) で絞る (横浜市の避難場所は 1,796 で、全てが地震に指定されているが、津波は 100)。
- 解答: 鶴見区 28、神奈川区 8、西区 6、中区 10、南区 9、磯子区 17、金沢区 22、ほかの 11 区は 0。合計 100。区に入らない場所は 0。区の面は `jp-admin-2026-09` の code5 14101 から 14118 (ward が空でない行)。
- 合格: 区ごとの数が上と一致する (面の取り方で 1 から 2 件動くのは許す)。
- 不合格: 横浜市全体の数だけで区に分けていない。津波で絞っていない (区の合計が 1,796)。
