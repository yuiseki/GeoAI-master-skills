# 小さい課題 その 2 (エージェントに渡す側)

使うデータと、答えの定義を課題文に書いた。1 課題に、答えを変える落とし穴が 1 つ。1 回の実行では 1 つだけ渡す。

## 課題 19: 人口 1 万人以上の 1 km メッシュ

使い道: 人の集まる場所の数を、大きさのそろった格子で数える。
使うデータ: Hugging Face の `yuiseki/estat-census-mesh-2020` の表 `T001140` (令和 2 年国勢調査、人口及び世帯、JGD2011)。人口は列 `T001140001`。
求めるもの: 人の住む 1 km メッシュの数、人口が 10,000 人以上のメッシュの数、人口が最も多いメッシュのコードとその人口。
範囲: 日本。

## 課題 20: 横浜市の区ごとの津波の避難場所

使い道: 津波のときに逃げる場所が、区ごとにいくつあるかを知る。
使うデータ: Hugging Face の `yuiseki/gsi-evacuation-sites-jp` の `sites` (指定緊急避難場所)。区の範囲は `yuiseki/jp-admin-2026-09` の市区町村の面。
求めるもの: 横浜市の 18 区それぞれの、津波に指定された指定緊急避難場所の数。区に入らない場所があれば、その数。
範囲: 横浜市。

## 課題 21: 2018 年の世界の人口

使い道: 長期の経済統計で、世界全体の規模を知る。
使うデータ: Hugging Face の `yuiseki/maddison-project` の 2023 年版 (`parquet/2023/full_data.parquet`)。
求めるもの: 2018 年の世界の人口 (人)。この表の国の値から計算する。
範囲: 世界。

## 課題 22: 23 区で建物が地面を覆う割合

使い道: 区ごとの建て込み具合を比べる。
使うデータ: Hugging Face の `yuiseki/osm-tokyo23-src-2026-08` の `planet_osm_polygon` (OpenStreetMap の建物)。区の範囲と面積は `yuiseki/jp-admin-2026-09` の市区町村の面。
求めるもの: 区ごとの、建物のフットプリントの面積の合計を区の面積で割った割合。建物は、その代表点 (面の中に必ず入る点) が入る区に、丸ごと数える。割合が最も高い区とその割合、23 区全体の割合。
範囲: 東京 23 区。
