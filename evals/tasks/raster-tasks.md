# ラスタの課題 (エージェントに渡す側)

意味の決まったラスタを、分析の単位にそろえられるかを見る。1 回の実行では 1 つだけ渡す。

## 課題 18: 大阪府の人口を 1 km の等積格子に

使い道: 大阪府の人口の分布を、面積のそろった格子で比べる。
使うデータ: Hugging Face の `yuiseki/worldpop-jp-2026-01` の 2020 年の総人口 (100 m)。府の範囲は `yuiseki/jp-admin-2026-09` の都道府県の面を使う。
求めるもの: 大阪府の範囲の人口を、EPSG:6933 の 1 km 格子 (格子の線は 1,000 m の倍数) に作り直した表。人口のある格子の数、人口 1,000 人以上の格子の数、最も人口の多い格子の人口。作り直す前と後の、府の人口の合計。
範囲: 大阪府。
