## 1. 問いと使い道（流域治水・グリーンインフラ・多摩23区広域自治体連携の視点）

- **問い**:
  多摩地域と23区を含む東京都全域において、1974〜1996年（前半23年間）から1997〜2019年（後半23年間）にかけて外水溢水と内水氾濫が激減した自治体・1 km メッシュと、逆に後半期に浸水が増加または高水準で持続（慢性化）している自治体・メッシュは何が違うのか？
  土地被覆の市街地画素率・樹木被覆率（`esa-worldcover-tokyo-2021-100m`）および国勢調査 1 km メッシュ人口（`estat-census-mesh-2020`）と結合したとき、後半期の内水・溢水持続度を規定する空間構造は何か？ またポリゴン行数・調査単位名寄せ・浸水年数・実面積のどれで測るかによって自治体の優先順位はどう変わるか？

- **使い道（誰が何を決めるか）**:
  - **東京都建設局・都市整備局および多摩地域・23区の流域治水・グリーンインフラ担当者**:
    1. **「河川改修で解決した地域」と「都市化・不浸透面飽和で内水が残存・悪化した地域」の切り分け**: 外水溢水が8割以上減った一方で、1997年以降も内水・中小河川溢水が持続している自治体（狛江市・八王子市・台東区・江東区・品川区・中野区・大田区・町田市等）を特定する。
    2. **雨水浸透ます・緑地保全・流域貯留の重点配分**: 市街地画素率（`pixels_50 / valid_pixels`）が高く樹木被覆率（`pixels_10 / valid_pixels`）が低い高密メッシュのうち、後半期浸水持続率が高い流域へグリーンインフラ投資を優先配分する。

## 3. 実データパイロットの主要発見

1. **外水溢水が都全体で8割以上激減する一方、自治体別の後半期浸水持続率は極端に二極化している**:
   - 旧自治体名（`田無市` 68行＋`保谷市` 51行 → 西東京市、`秋川市` 20行＋`五日市町` 12行 → あきる野市、`太田区` 22行 → 大田区、`世田ヶ谷区` 10行 → 世田谷区、`羽村町` 3行 → 羽村市）を正規化した全 `55` 区市町村で前半（1974〜1996年）と後半（1997〜2019年）を比較すると:
     - 外水溢水（`reason LIKE '%溢水%'`）は23区で **`496 -> 91`（`0.183倍`、81.7%減）**、多摩・島しょで **`189 -> 31`（`0.164倍`、83.6%減）** と大幅に減少した。
     - 自治体別では、**葛飾区（`279 -> 0`）、西東京市（`119 -> 0`）、国分寺市（`51 -> 0`）、足立区（`635 -> 10`、`0.02倍`）、江戸川区（`281 -> 6`、`0.02倍`）、稲城市（`71 -> 2`、`0.03倍`）、文京区（`299 -> 17`、`0.06倍`）** で激減した。
     - 対照的に、**狛江市（`2 -> 71`、`35.50倍`、内水72）、八王子市（`36 -> 46`、`1.28倍`、溢水20・内水62）、台東区（`62 -> 71`、`1.15倍`、内水133）、江東区（`33 -> 35`、`1.06倍`、内水68）、品川区（`119 -> 100`、`0.84倍`）、中野区（`176 -> 127`、`0.72倍`、溢水101・内水200）、大田区（`319 -> 189`、`0.59倍`、内水483）** では後半期も浸水が増加または高水準で持続している。

## 4. 方法論上の関門と頑健性チェック

- **旧市町村合併の名寄せと WorldCover 範囲外の厳密な分離**: `munic` 列をそのまま現代の自治体名と結合すると旧田無市・保谷市（計119行）等が脱落する罠を防ぐ。また `esa-worldcover-tokyo-2021-100m` は東経 `139.5〜140.0度` の矩形であるため、東経139.5度より西の自治体・メッシュは「範囲外（Out of Bounds）」として別集計し、0で埋めない。
- **4つの浸水指標と3段階の空間スケール（MAUP検証 + Moran's I）**: ポリゴン行数・重複除去済み調査単位数・浸水発生年数・実面積（`ST_Union_Agg`）の4指標で狛江市等の増加倍率の感度を確かめ、さらに自治体・1 km メッシュ・2 km 格子の3スケールで市街地率・人口密度との相関および Moran's I を検証する。
