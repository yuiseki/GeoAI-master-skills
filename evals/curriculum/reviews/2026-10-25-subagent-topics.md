# 2026-10-25 サブエージェント候補のレビュー

[受領原文](../incoming/2026-10-25-subagent-topics.md)の5件を、社会的な使い道、対象量、利用可能な固定版、最小解法、既存課題との差で再審査した。原文は変更しない。原文が示す pilot 数値・事前予測・形式検査の結果は提供情報・未再検証である。記載された再現コードは指定の作業場所で確認できず、このレビューで実データを再計算していない。形式検査の `critic_review` は正式採用の根拠にしない。

## 候補1: 人口と建物面積の乖離

判定: 現状では正式課題にしない。提案者の pilot が正しければ、GHS-BUILT-S の読んだタイルでは建物面積が減るセルが0件で、「建物が減らない」は土地の観測結果ではなく製品の時系列構成に強く依存する。人口減少との符号の乖離は機械的に生じうる。順位の入れ替わりだけでは、空き家、公共施設の維持費、インフラ負担を直接には測れない。人口・建物の異なる格子と時点のそろえ方も未検証。

修正して再提案するなら、独立した建物・施設台帳や財政指標を入れ、GHS-BUILT-S を感度確認の一つに下げる。単一製品の単調性を社会的なストック増加と読まないことが停止条件。

## 候補2: 建物輪郭と世帯数の食い違い

判定: 保留。Microsoft の建物輪郭は住宅台帳でも現況棟数の完全な観測でもない。全建物数を世帯数で割った値は空き家率ではなく、非住宅建物、検出漏れ、建物内の複数世帯、画像撮影時点に影響される。提案者の pilot では沿岸メッシュの取りこぼしも報告され、自治体間の比較に偏りがある。世帯総数の列 `T001140034` は現在のデータカードの frontmatter に無く、形式検査も reject だった。

次の条件を満たせば再審査する: 世帯列の意味と秘匿を固定版で確認し、使用した建物タイルの URL・取得日を保存する。住宅用途や検出欠けの影響を小さい照合で示し、問いを「建物輪郭／世帯比の観測上の偏りが大きい現地確認候補」に限定する。空き家が多い地域とは呼ばない。提供された銚子市・流山市の数値は未再検証で、正式課題の答えに転記しない。

## 候補3: 土砂災害向け避難場所の公表登録

判定: 修正して[中難易度課題 3](../../tasks/medium-tasks.md)として採用。目的を住民の避難先判断でなく、自治体が公表登録を照会する地域の優先付けに限定した。課題37・43と同じ施設到達性を扱うが、災害種別の登録件数と距離の食い違いが対象である。高難易度の新しい避難到達課題としては既存課題と近く、土砂災害警戒区域も指定データに無いため、中難易度に置いた。

主な修正: 標高差をリスクや危険区域の代用にしない。原案の「標高差100m以上で欠落が多い」は、提案者の熱海市 pilot でも対照群を作れず不支持だったため主仮説から外す。比較は全災害種別の登録と `landslide` 登録に限り、直線距離を徒歩経路と呼ばない。公表データの0件は、自治体の指定0件とは言えない。県境外の地点、自治体コードと地点位置、秘匿人口を検討する。原文の熱海市の件数・距離は未再検証なので課題文と採点観点へは移さない。

## 候補4: GTFS 台帳で確認できない事業者

判定: 現状では正式課題にしない。公開台帳が対象量の必須入力なのに、候補 JSON の `datasets` には P11 と行政界しか挙げられていない。これはデータ統合の hard gate を実質的に通っていない。提案者の佐賀県0%や都営バスの照合漏れが正しければ、未確認を未公開と扱うことはできず、得られる順位は台帳の選択と名寄せ規則に強く支配される。

再提案には、台帳ごとの固定スナップショット、事業者とフィードの対応関係、県の公開資料との照合による見逃し検査が必要。現在の「確認可能性」も台帳限定と明記し、住民が経路検索できるかや利用断念は別の量として扱う。

## 候補5: 農地の持続的な土地被覆変化

判定: 保留。既存の[端点差分と持続判定のカード](../task-cards/2026-10-24-persistent-land-cover-change.md)と同じ年次土地被覆製品・持続規則を使い、新規性の核となる駅距離は提案者の pilot で弱かった。農地からの転用先の構成は別の量だが、現状では高難易度課題としての差が足りない。IO LULC の個別データカードも未レビューである。

再提案するなら、転用先の構成差を自治体の具体的な農地保全判断に結び、クラス定義と年次比較を固定する。持続的な分類変化と実際の農地転用を区別し、分類の揺れを実際の開発・ノイズと断定しない。2026年の駅位置を2017〜2023年の原因として扱わない。原文の面積と割合は未再検証のまま残す。

## 今回の境界

正式課題へ移したのは1件、見送ったのは4件。新しい hard task は追加しなかった。次に進むには、候補2の世帯列と建物検出の照合、候補4の台帳目録、候補5の年次土地被覆カードが必要。どの候補も、原文の pilot 数字を再現したものではない。
