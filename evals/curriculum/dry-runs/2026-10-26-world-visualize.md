# 世界地図で見せる課題を選ぶ dry run (2026-10-26)

依頼: 世界規模で分析し、結果を世界地図の層として重ねたり並べたりする Web サイトに載せる。このリポジトリでは分析の手法と結果までを求める。

入力: [データ目録](../../../.agents/skills/dataset-discovery/references/index.md) のうち全球・国の単位のデータの frontmatter と本文、Parquet の実際の列 (frontmatter に無い列はファイルの末尾のメタデータで確かめた)、課題 30〜44 と中難易度 1〜3、既存の proposal と task card、`research-question-generation` の gate と Critic。社会課題と反証できる作業仮説を問いより先に書いた。

結果: 検討 12 件、棄却 6 件、残す 6 件。残した 6 件は [課題文](../../tasks/world-visualize-tasks.md) と [人間側の記録](../../tasks/world-visualize-rubric.md) に置いた。依頼に合わせて proposal を 1 件に絞らず、課題の候補の一覧として残した。正式な `hard-tasks.md` には足していない。

## 全体の判断

- 地図の層を重ねるために、共通の格子を Kontur の H3 r4 (22 km) にした。粗いので、距離を使う課題では格子の粗さを判断の一つとして扱わせる。
- 人口は 2023-11-01 の 1 時点しか無い。過去の出来事 (嵐、紛争) に今の人口を当てることになるので、どの課題でもそれを書かせる。
- 画像を使う課題は立てていない (このリポジトリの方針)。

## 候補

| 候補 | 判定 | 最も単純な合理的方法と、判定の理由 |
|---|---|---|
| W1 繰り返しの強い熱帯低気圧にさらされる人 (IBTrACS、Kontur、Natural Earth) | 残す | 国ごとの嵐の数では、国の中の場所と、風の記録の違いで人数が動くこと (pilot で 10.8 億人と 7.0 億人) が見えない |
| W2 強風が何度も通るのに救援の空港から遠い人 (W1 + OurAirports) | 残す | 定期便の空港の数では、貨物機が降りられるかが分からない (pilot のマダガスカルで 1% と 27%)。空港だけの候補 F を W1 と合わせて作り直した |
| W3 致死的な暴力の近くに住む人の測り方 (UCDP、Kontur、Natural Earth) | 残す (digging) | 国の死者の比では、人数で数えた地図と死者の地図の食い違い (pilot で精度の除外が死者の 57%、人口の 8% を消す) が示せない。位置精度の task card に近いが、分母と重みの判断で進む |
| W4 基地局の記録の空白の意味 (OpenCelliD、Kontur、Natural Earth、WDI) | 残す | 点の有無を圏外と読むと、インドの国番号の欠け (記録 0 件) を圏外と誤る |
| W5 法定の時刻と太陽の時刻のずれ (timezone、Kontur、Natural Earth) | 条件付きで残す | 首都 1 点のずれでは人口の偏りと夏時間が入らないが、判断の深さは浅い。軽い層と手順の確かめに向く |
| W6 難民の逃れた距離の変化 (UNHCR、Natural Earth、WDI) | 残す | 隣の国の割合や距離の平均だけでは、出身国の構成の変化と行き先の変化を分けられない |
| D Wikipedia の座標つき記事の人口あたりの偏り (Wikipedia、Kontur、Natural Earth、WDI) | 棄却 | pilot で人口あたりの記事の数と 1 人あたり GDP の相関が 0.74 (英語版)、行政区の記事を除いても順位の相関 0.989。人口あたりの塗り分けと GDP でほぼ答えが決まり、誰の判断を変えるかも弱い。地図の軽い層としては使える |
| F 救援の空港からの遠さだけ (OurAirports、Kontur) | 棄却して W2 に統合 | 危険の層が無いと、遠い人の多い所はサハラと内陸の人の少ない所で、使い道が定まらない |
| H1 難民の受け入れの負担の順位 (UNHCR、WDI) | 棄却して W6 に統合 | 人数、人口あたり、GDP あたりの 3 つの比の表で足りる (pilot で上位がドイツ、レバノン、南スーダンと入れ替わることは比を並べれば見える) |
| G 2025 年の地震の揺れにさらされた人 (ComCat、Kontur) | 棄却 | 1 年分だけで、さらされた人の多さは人口の密度でほぼ決まる。検知の網羅性は地域で違い、このデータで確かめられない |
| I 国の温室効果ガスの排出と所得 (EDGAR、WDI) | 棄却 | 国の比の塗り分けで足り、空間の判断が無い |
| J 人の移動の距離の分布 (Meta の移動データ、Natural Earth) | 棄却 | 凍結版に面が無く、地域の ID を Natural Earth の面に結ぶ鍵が無い |

## pilot

スクリプトは [world-visualize-pilots/](world-visualize-pilots/README.md)。数字は人間側の記録に写した。pilot は小さい範囲の存在の確認で、課題の答えではない。予想 (各候補の JSON の `prediction`) は、pilot の後に書き直していない。ただし W2 は、F の pilot で危険の層が要ると分かってから作った探索の候補である。
