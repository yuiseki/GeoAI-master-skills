## 1. 事前固定した4候補と棄却基準

### 候補A（採用候補）: 国連「すべての人に早期警戒を（EW4All）」および OCHA 事前行動（Anticipatory Action）に向けた全球サイクロン人口曝露評価における 3 つの空間・統計バイアス（機関別風速平均時間差 `WMO_WIND` vs `USA_WIND`、H3 セル重心結合による小島嶼国 SIDS の消失、3時間経路点 vs 嵐イベント単位集計）
- **問い**:
  UN Open GIS Initiative（UNDRR Early Warnings for All [EW4All]、UN-SPIDER、OCHA 事前行動、UNDP）が 2001〜2025年の強い熱帯低気圧（カテゴリー3相当以上、最大風速 96 kt 以上、経路から 100 km 圏内）に対する国別・人間開発指数（HDI）階層別の曝露人口と優先支援国を算出する際、
  1. **風速定義の選択**: `WMO_WIND >= 96`（海域ごとに10分平均風速と1分平均風速が混在し欠測も多い列）をそのまま使うか、1分平均最大風速へハーモナイズした風速 `COALESCE(TRY_CAST(USA_WIND AS DOUBLE), WMO_WIND / 0.88) >= 96` を使うか
  2. **空間結合の選択**: Kontur H3 r4 セルと国境ポリゴン（Natural Earth）を「セル重心（`ST_Centroid`）」で結合するか、「六角形ポリゴン交差（`ST_Intersects(poly, geom)`）」で結合するか
  3. **イベント集約の選択**: 「ユニーク曝露人口（少なくとも1回被災）」「年間期待延べ曝露人口（`DISTINCT SID` ベース）」「経路点単純合算（3時間ごとの観測点ベース）」のどれで評価するか
  によって、アジア・アフリカ（低・中 HDI 国）および小島嶼開発途上国（SIDS）の曝露人口と優先順位はどう劇的に逆転するか。
- **事前棄却基準**:
  `WMO_WIND` と `USA_WIND` の違いや重心・ポリゴン結合の違いが曝露人口や上位国順位をほとんど変えない場合は棄却する。

### 候補B（棄却）: Meta Movement Distribution (`yuiseki/meta-move-dist`) の2026年6〜8月データを用いた全球の長期気候変動移住の推定
- **事前棄却基準 (`short_window_and_platform_selection_bias`)**:
  `meta-move-dist` は 2026年6月〜8月の92日間（うち76日分）の短期の日次移動距離シェアであり、かつ位置共有を許可した Facebook 利用者に限定されるため、長期の気候変動移住を識別できないとして**棄却**。

### 候補C（棄却）: EDGAR 国別温室効果ガス排出量 (`yuiseki/edgar-ghg-countries`) と UNDP HDI (`yuiseki/undp-hdr`)・Penn World Table (`yuiseki/pwt`) の国別クズネッツ曲線回帰
- **事前棄却基準 (`no_spatial_necessity`)**:
  すべての変数が国×年の非空間テーブル結合で完結し、座標・距離・空間トポロジーを一切必要としないマクロ経済パネル回帰であるため**棄却**。

### 候補D（棄却）: タイムゾーン境界 (`yuiseki/timezone-boundary-builder-2026d`) と国連人口推計 (`yuiseki/un-wpp`) の重ね合わせによる時間帯別人口集計
- **事前棄却基準 (`trivial_aggregation_without_decision_stakes`)**:
  単純な面積按分・集計で終わり、国連の具体的な人道・防災・開発の意思決定を左右する方法論的判断が含まれないため**棄却**。

## 2. 候補Aの実データパイロット結果（`pilot_un_cyclone_aa.py`）

### 発見1: H3 r4 セルを「重心（Centroid）」で国境に空間結合すると、世界の沿岸人口 3億9,793万人と小島嶼国（SIDS）の人口 100% が消滅する
- `kontur-population-2023-11-01-22km`（CRS は `EPSG:3857` のため `EPSG:4326` へ変換必須）の緯度 ±40度以内の人口セル `48,954` 個を `ne_10m_admin_0_countries` に結合する際：
  - **セル重心交差（`ST_Intersects(ST_Centroid(poly), country.geom)`）** を使うと、沿岸や島嶼にかかる **`4,267` セル・人口 `3億9,793万人` が海に落ちて国コード `NULL` として脱落**する！
  - 特に国連 EW4All の最優先対象である **小島嶼開発途上国（SIDS）** では、H3 r4 六角形（約 1,770 km²）が島より大きいため重心が海上に落ち、**トンガ（`TON` 10.4万人）、ミクロネシア連邦（`FSM` 10.4万人）、キリバス（`KIR` 12.6万人）、セントビンセント（`VCT` 10.3万人）、セントルシア（`LCA` 18.5万人）、グレナダ（`GRD` 12.5万人）、バルバドス（`BRB` 28.2万人）、モーリシャス（`MUS` 130.1万人）、モルディブ（`MDV` 50.7万人）、セーシェル（`SYC` 10.6万人）、シンガポール（`SGP` 273.2万人）で人口の 100.0% が消失**し、**バハマ（`BHS`）でも 98.3%（40.5万/41.2万人）が消失**する。
  - **六角形ポリゴン交差（`ST_Intersects(poly, country.geom)` で最大重なり面積の国を付与）** を使うことで初めてこれら SIDS と沿岸 3.98億人が正しく救済される。

### 発見2: `WMO_WIND` の海域別定義差（10分平均 vs 1分平均）と欠測により、アジア・アフリカ（WP, NI, SI）のカテゴリー3以上サイクロン曝露人口が 74%（3.2億人分）過小評価される
- `ibtracs-v04r01` の 2001〜2025年データにおいて、北大西洋（`NA`）と北東太平洋（`EP`）は米国 NHC が WMO 地域専門気象センター（RSMC）を務めるため `WMO_WIND` が **1分平均風速** であり、`USA_WIND` と `>= 96 kt` の嵐数が完全一致する（`NA`: 88対88、`EP`: 110対110）。
- しかし他海域では RSMC（東京 JMA、ラ・レユニオン MFR、ニューデリー IMD、ナンディ FMS 等）が **10分平均風速（1分平均の約0.88倍）** を報告し、さらに `WMO_WIND` が未収録の期間・経路点が多数存在する。その結果、2001〜2025年の `>= 96 kt`（カテゴリー3相当）の嵐数は以下の通り乖離する：
  - **北西太平洋 (`WP`)**: `WMO_WIND >= 96` では **`99` 個** vs 1分平均統一（`COALESCE(USA_WIND, WMO_WIND/0.88) >= 96`）では **`225` 個（2.27倍、126個の大型台風が脱落！）**
  - **北インド洋 (`NI`)**: `15` 個 vs **`26` 個（1.73倍）**
  - **南インド洋 (`SI`)**: `85` 個 vs **`128` 個（1.51倍）**
  - **南太平洋 (`SP`)**: `41` 個 vs **`56` 個（1.37倍）**
- この結果、2001〜2025年にカテゴリー3相当以上（`>= 96 kt`）の暴風域（経路から 100 km 以内）に入った世界の曝露人口は劇的に変化する：

| 評価指標（2001〜2025年、半径100km圏） | ① ナイーブ `WMO_WIND >= 96 kt` | ② 1分平均統一 `harm_wind_kt >= 96 kt` | 倍率・差分 |
|---|---:|---:|---:|
| **世界ユニーク曝露人口（1回以上被災）** | **1億1,472万人** | **4億3,478万人** | **3.79倍（+3億2,006万人）** |
| **世界年間期待延べ曝露人口（`DISTINCT SID` / 25年）** | **722万人/年** | **3,753万人/年** | **5.20倍（+3,031万人/年）** |
| **フィリピン (`PHL`, High HDI)** ユニーク / 年間延べ | 1,606万人 / 122万人/年 | **9,964万人 / 1,416万人/年** | **年間延べ 11.6倍** |
| **ベトナム (`VNM`, High HDI)** ユニーク / 年間延べ | **0人（完全脱落）** / 0人/年 | **1,001万人 / 45万人/年** | **ゼロから1,001万人出現** |
| **バングラデシュ (`BGD`, Medium HDI)** ユニーク / 年間延べ | 220万人 / 9万人/年 | **2,235万人 / 89万人/年** | **ユニーク 10.2倍** |
| **インド (`IND`, Medium HDI)** ユニーク / 年間延べ | 2,262万人 / 112万人/年 | **4,754万人 / 240万人/年** | **2.1倍** |
| **モザンビーク (`MOZ`, Low HDI)** ユニーク / 年間延べ | 255万人 / 10万人/年 | **726万人 / 38万人/年** | **年間延べ 3.8倍** |
| **マダガスカル (`MDG`, Low HDI)** ユニーク / 年間延べ | 102万人 / 9万人/年 | **627万人 / 38万人/年** | **ユニーク 6.1倍** |
| **ミャンマー (`MMR`, Medium HDI)** ユニーク / 年間延べ | 238万人 / 12万人/年 | **609万人 / 32万人/年** | **ユニーク 2.6倍** |

- すなわち、ナイーブに `WMO_WIND >= 96` を使うと、米国（年間111万人）やキューバ（101万人）・メキシコ（94万人）がフィリピン（122万人）とほぼ同等の最優先国に見え、ベトナム（0人）やバングラデシュ（9万人/年）、マダガスカル（9万人/年）、モザンビーク（10万人/年）は支援対象から落ちる。しかし1分平均風速に統一すると、**Low HDI 国のユニーク曝露人口は `364万人` → `1,360万人`（3.74倍）、Medium HDI 国は `3,004万人` → `7,965万人`（2.65倍）** に跳ね上がり、アジア・東アフリカの途上国こそが最大の反復被災地であることが明らかになる。

### 発見3: 3時間ごとの経路点（Track Points）を単純合算すると、移動速度の遅い嵐が重複計上され年間曝露が約2倍に膨張する
- `ibtracs-v04r01` の1行は「1つの嵐の1時刻（主に3時間ごと）の点」であるため、同じ嵐（`SID`）が 100 km 圏内を通過する間に複数行がヒットする。
- `DISTINCT SID` で嵐単位に集約した世界の年間期待延べ曝露人口は **`3,753万人/年`** だが、経路点行ごとに合算すると **`7,329万人/年`（1.95倍）** に膨らみ、特に進行速度が遅く停滞しやすい地域（ハイチ `HTI`: 5万人/年 → 23万人/年［4.6倍］、香港 `HKG`: 111万人/年 → 467万人/年［4.2倍］）で順位が歪む。
