# 論文化を見据えた課題選別の dry run（2026-10-25）

目的は論文を書くことではなく、論文に必要な対象量・比較・失敗条件を既存データで検査できる問いを1件残すこと。[research-question-generation](../../../.agents/skills/research-question-generation/SKILL.md)の exploration と棄却を用い、[research-paper-writing](../../../.agents/skills/research-paper-writing/SKILL.md)の主張と根拠の対応、データ・方法・結果・頑健性を後から再現できるかを条件にした。関連研究の網羅的な調査はまだ行っていない。

| 候補 | 判定 | 理由 |

4件を検討し3件を棄却、1件を残した。正式課題や論文への自動追加はしていない。

## 小さい実データ pilot

仮説は実行前に「差は一様でなく、格子の合わせ方や低人口セルの扱いで人口上位候補が変わる」とした。pilot は中心部の10km相当のメッシュ区画 `KEY_CODE` の先頭 `533946` だけ。ほかの地域と土地被覆による不一致の傾向は未測定である。

入力は国勢調査 `T001140` の commit `6c486c8649484e09e549c0c99b5fa89b4f416edb`、GHSL 人口 `R6_C32` の commit `4ee767429ee03ea47a9003c547f92c320474e350`、WorldCover 100m の commit `6f006f64483b65b20f06c775b87db7a8d57a6fda`。2026-10-25 に DuckDB 2.0.0 の `httpfs` と `spatial` でリモート Parquet を読んだ。最初の面積計算は DuckDB が EPSG:4326 の軸順を明示するよう要求して止まった。`SET geometry_always_xy=true` を明示して再実行した。

国勢調査の `prefecture='13'` は1,612行で人口合計14,047,594人、`KEY_CODE` の先頭が `533946` の100行は1,844,515人だった。メッシュ面はカードにあるコードの計算式で JGD2011 の南西角を復元し、緯度30秒・経度45秒の矩形にした。GHSL は `R6_C32` の行399〜413、列1169〜1190から交差セルを取り、交差面積と GHSL セル面積をともに EPSG:6933 で測った。正の交差面積のみを残して100メッシュすべてに対応した。人口は GHSL セルの人数に交差面積比を掛けて合算した。別の基準では GHSL セル中心が入るメッシュに全人数を割り当てた。pilot の GHSL セル窓はこの100メッシュの全範囲を覆うように取ったが、元のラスタと変換版の画素値を再照合したわけではない。

| pilot の量 | 面積按分 | セル中心割当 |
|---|---:|---:|
| 100メッシュへの GHSL 人口合計 | 1,641,601.5人 | 1,644,268.7人 |
| 国勢調査人口との差の絶対値の平均 | 3,745.8人/メッシュ | 6,536.3人/メッシュ |
| 国勢調査人口の上位20メッシュとの重なり | 8/20 | 6/20 |

国勢調査人口1,844,515人との総量差は、この pilot の比較対象域での差である。GHSL の日本全国での過小推計率や独立した予測誤差とは呼ばない。上位20の重なりは、この一区画の探索値であり、提案した主比較の上位10%とは違う。上位10%は pilot 後の研究設計なので、別の地域ブロックで確認する。

同じ pilot 区画の地理的範囲（東経139.75〜139.875度、北緯約35.667〜35.75度）では、WorldCover の100mセルが15,000件あり、優占クラス50の市街地が13,038件、クラス10の樹木が539件だった。`valid_pixels` はこの窓の全セルで100。これは土地被覆データの存在と変動の確認だけで、100個の人口メッシュと重ねて不一致との関連を測った結果ではない。全36万セルでは優占クラス50が236,863件、10が33,607件など複数クラスがあり、東京の補助診断は可能そうだが、海と NoData、矩形端の扱いが要る。

## Critic と論文化の停止条件

形式検査 `validate_candidate.py` は `critic_review`、棄却理由なし。これは採用でも、論文の妥当性の証明でもない。観測した数値は上の小区画に限り、土地被覆と人口差の関係は未測定。GHSL は行政人口を入力としているため、国勢調査との一致を「独立した外部検証」と呼ばない。日本本土の他の地域で候補の入れ替わりが消える、5タイルの覆いが不十分、東京の土地被覆との関係が不安定、と判明したら論文の主張を縮める。論文を書く段階で初めて、保存済みの分析出力・実行条件・図・確認済み文献を対応づける。
