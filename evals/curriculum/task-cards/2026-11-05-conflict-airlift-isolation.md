# 紛争影響人口における救援航空・道路アクセスの二重孤立

区分: 高難易度候補（正式課題ではない）。社会課題: 国連人道航空サービス（WFP UNHAS）や国際赤十字が、戦闘被害地域への緊急物資輸送を行う際、主要道路の途絶と大型貨物機対応滑走路の不在が重複する「陸空双方の孤立地域」を抽出し、事前配備の優先度を決める。

作業仮説: 紛争影響下にある人口（UCDP GED 50km圏内）のうち、大型貨物機が降着可能な滑走路（OurAirports 舗装 6,000 ft 以上）および幹線道路網から遠い地域は、単純な戦闘近接人口ランキングと上位が大きく入れ替わる。入れ替わりが 20% 未満なら仮説を退ける。

問い・対象量: 2021〜2025 年の全世界の H3 r4（22 km）セルにおいて、位置精度が担保された戦闘事件（`where_prec <= 2`）の近傍人口のうち、有効な救援滑走路および幹線道路から 100 km 以上離れた「二重孤立人口」の空間分布。

利用データ: `yuiseki/ucdp-ged@d72fe7eb368fef2d4b804affad07a132571f60f8`、`yuiseki/ourairports-2026-08@6c1d115e83a7865005260e4b1ed70eda86d95107`、`yuiseki/kontur-population-2023-11-01-22km@2e7291f8c2d4b9c06bb4ff0e43be14e538e0600d`、`yuiseki/natural-earth@efdd0668c57c9d42307e12eacbf66d8d151de5b9`。

既存課題との差: [課題 W2](../../tasks/world-visualize/w2.md) はサイクロンと空港、[課題 W3](../../tasks/world-visualize/w3.md) は紛争と位置精度。[dry-run 2026-10-27-un-conflict-airlift-vulnerability.md](../dry-runs/2026-10-27-un-conflict-airlift-vulnerability.md) の議論をタスクカードとして形式化したもの。

主要な判断:
- UCDP の位置精度（`where_prec >= 3` の州代表点を含めると空港近傍が誤って紛争地域と判定される罠）
- 滑走路の `surface` の表記揺れ（ASP, CONC, TURF 等）と有効長（6,000 ft / 8,000 ft）の基準選定
- 空港の運用状況（閉鎖空港・ヘリポートの除外）

提供情報・未再検証: dry-run の pilot では、粗い代表点を除外することで 28 空港の誤判定が解消され、真の孤立人口はコンゴ民主共和国やスーダン等で約 1,000 万人規模と見積もられた。

停止条件: 道路データの全球品質が国ごとに偏り（アフリカ内陸部の未マッピング）、道路網の不在をインフラ不在と誤認するリスクが排除できない場合、航空インフラ（OurAirports）単体でのアクセス評価に限定する。
