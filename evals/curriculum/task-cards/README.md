# タスクカード

タスクカードは、次に調べる価値のある問いを人が一覧・比較できるようにした短い検討記録です。正式な `evals/tasks/hard-tasks.md` の課題でも、分析結果でもありません。カードを追加しても正式課題は増えません。

1 カード 1 ファイルとし、問い、意思決定上の使い道、対象量と単位、利用データと版、既存課題との差、分析上の判断、単純解法では足りない理由、データで分からないこと、検証状態、次の停止条件を記します。候補JSONと dry run があればリンクします。外部エージェントから受け取った pilot の数字は、再現用のコードと出力が確認できるまで「提供情報・未再検証」と明記します。

形式検査の `critic_review` は採用や実データ検証の完了を意味しません。候補を本分析へ進める前に、必須データの結合と問いの意味を小さい pilot で確かめます。正式課題への転記は別の作業として判断します。

カードには検討上の区分を記します。「高難易度候補」は正式課題ではありません。「中難易度課題」は、問いをデータで言える範囲に絞ったうえで [medium-tasks.md](../../tasks/medium-tasks.md) に別途登録されたものです。提供された pilot 数値を、中難易度課題の答えや採点基準へ転記しません。
