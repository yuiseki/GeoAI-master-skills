# 世界規模の可視化候補課題 (W1〜W7) の probe 評価結果

2026-11-05 実施。
対象: `evals/tasks/world-visualize/` の候補課題 7 件 (`w1.md`〜`w7.md`) および対応する採点基準 (`rubrics/w1.md`〜`rubrics/w7.md`)。

## 1. 評価概要と実行環境

- **目的**: 全球規模の可視化候補課題 W1〜W7 を実データに基づいて probe（予備検証・挙動評価）し、データ特性、空間・統計バイアス、OOM（メモリ不足）対策、および作業仮説の成立可否を判定する。
- **実行環境**: DuckDB 2.0.0 (`spatial` 拡張, `community h3` 拡張), Python 3.11 (`tzdata==2025.2`)。
- **共通の空間基盤**: 
  - 全球人口格子: Kontur Population H3 resolution 4（公称分解能 約 22 km、71,283 有効居住セル、総人口 約 80.3 億人、EPSG:3857 投影ポリゴン）。
  - 全球行政界: Natural Earth Admin-0 Countries (`ne_10m_admin_0_countries.parquet`、258 境界ポリゴン)。
- **OOM 回避の設計**:
  - 全球の重いラスタ/ベクタ結合を避けるため、共通セルインデックスとして H3 r4 文字列 ID を使用。
  - 距離計算は `h3_grid_disk`（1 環 約 45 km、2 環 約 90 km、5 環 約 200 km）および `ST_Distance_Sphere`（`geometry_always_xy = true`）に限定し、メモリを 1〜2 GiB 以内に抑制。

## 2. 課題別 Probe 結果

### W1: 強い熱帯低気圧が何度も通る場所に住む人 (`world-visualize-w1`)
- **使用データ**: `yuiseki/ibtracs-v04r01`, `yuiseki/kontur-population-2023-11-01-22km`, `yuiseki/natural-earth`
- **データ実測**:
  - 1980〜2025 年の熱帯低気圧レコード: 306,541 点、4,922 嵐。
  - 風速 64 kt 以上の観測点: `USA_WIND` (1分平均) 60,329 点 に対し、`WMO_WIND` (10分平均) 29,353 点（約 51% 減、欠測および定義差）。
- **仮説検証 (曝露人口)**:
  - 64 kt 以上の点から 1 環（約 45 km）内の曝露人口: `USA_WIND` で 10.8 億人、`WMO_WIND` で 7.0 億人（約 3.8 億人の差）。
  - バングラデシュ（9,700 万人 vs 2,900 万人）やベトナム（5,200 万人 vs 2,300 万人）など、観測機関の定義差で曝露人口が 2〜3 倍変動する。
- **採点判定**: **合格水準を確認**。風速定義の差異と欠測の分離、および時間補間（3時間間隔の飛び石防止）の必須性を特定。

### W2: 強風が何度も通るのに、救援の貨物機が降りられる空港から遠い人 (`world-visualize-w2`)
- **使用データ**: `yuiseki/ibtracs-v04r01`, `yuiseki/ourairports-2026-08` (airports & runways), `yuiseki/kontur-population-2023-11-01-22km`
- **データ実測**:
  - 滑走路 48,203 本中、舗装 6,000 ft 以上は 6,221 本、8,000 ft 以上は 3,712 本。`surface` の表記揺れは 500 種類以上。
- **仮説検証 (孤立人口)**:
  - 空港から 5 環（約 200 km）以遠の人口: 「定期便のある空港」では 1.23 億人だが、「大型貨物機が降りられる舗装 8,000 ft 以上」では 3.57 億人へ急増。
  - サイクロン頻発地帯であるマダガスカルでは、定期便空港から遠い人口は 1% だが、8,000 ft 以上の空港から遠い人口は 27% に達する。
- **採点判定**: **合格水準を確認**。滑走路規格による孤立判定の落差が極めて鮮明。

### W3: 致死的な暴力の近くに住む人の地図は、何を数えるかで変わるか (`world-visualize-w3`)
- **使用データ**: `yuiseki/ucdp-ged`, `yuiseki/kontur-population-2023-11-01-22km`, `yuiseki/natural-earth`
- **データ実測**:
  - 2021〜2025 年の死者のある紛争事件: 111,634 件、死者 115.7 万人。
  - 位置精度別: `where_prec <= 2`（明確な集落・地点）は 93,389 件 / 死者 50.2 万人。一方、`where_prec >= 5`（州・国全体の代表点）だけで死者 49.8 万人（全体の約 43%）を占める。
- **仮説検証 (曝露人口)**:
  - 粗い代表点（`where_prec >= 3`）を除外すると、死者の 57% が消える一方、1 環内の曝露人口は 27.3 億人から 25.2 億人（8% 減）に留まる。
  - インドネシア（-24%）やウクライナ（-21%）など、前線が広域代表点で記録された地域で過小評価が発生するトレードオフを実証。
- **採点判定**: **合格水準を確認**。位置精度の閾値判定が分析の成否を分ける。

### W4: 基地局の記録が無いのは、電波が無いからか、記録が無いからか (`world-visualize-w4`)
- **使用データ**: `yuiseki/opencellid`, `yuiseki/kontur-population-2023-11-01-22km`, `yuiseki/worldbank-wdi`
- **データ実測**:
  - OpenCelliD: 550 万基（LTE 365 万、GSM 99 万、UMTS 60 万、NR 26 万）。
- **仮説検証 (観測バイアス)**:
  - WDI の携帯電話普及率が 100 契約/100人を超える高普及国であっても、インド（MCC=404/405）のようにデータセット上で基地局レコードがほぼ 0 件の国が存在。
  - セルの無記録を単純に「携帯不通地域」と解釈すると致命的な誤認（観測バイアス）に陥ることを確認。
- **採点判定**: **合格水準を確認**。`observation-bias-audit` スキルの好例。

### W5: 法定の時刻が太陽からずれた場所に住む人 (`world-visualize-w5`)
- **使用データ**: `yuiseki/timezone-boundary-builder-2026d`, `tzdata==2025.2`, `yuiseki/kontur-population-2023-11-01-22km`
- **データ実測**: 全球 419 タイムゾーンポリゴン。
- **仮説検証**:
  - 太陽時（`lon / 15`）と標準時のズレ: 人口加重平均で 1 時間以上先行している地域（中国全土、スペイン、ロシア西部など）に住む人口は世界で 10 億人規模。
  - 単純なゾーン中心点と人口加重平均の乖離（中国 Asia/Shanghai ではゾーン面積平均 0.85 時間差に対し人口加重 0.41 時間差）を確認。
- **採点判定**: **合格水準を確認**。

### W6: 難民は遠くへ逃れるようになったか (`world-visualize-w6`)
- **使用データ**: `yuiseki/unhcr-refugee-stats`, `yuiseki/natural-earth`, `yuiseki/worldbank-wdi`
- **実測時系列 (人数加重平均移動距離と隣接国割合)**:
  - 1990 年: 難民 1,740 万人 / 隣接国比率 78% / 加重平均距離 1,087 km
  - 2000 年: 難民 1,240 万人 / 隣接国比率 70% / 加重平均距離 1,771 km
  - 2010 年: 難民 1,080 万人 / 隣接国比率 73% / 加重平均距離 1,947 km
  - 2020 年: 難民 2,120 万人 / 隣接国比率 75% / 加重平均距離 1,748 km
  - 2025 年: 難民 2,960 万人 / 隣接国比率 63% / 加重平均距離 2,116 km
- **仮説検証**:
  - 35 年間で平均距離は約 2 倍（1,087 km → 2,116 km）に延伸し、隣接国比率は 78% から 63% へ低下。
  - ただし、この変化の主要因は「個々の難民が遠くへ行くようになった」ことよりも「シリア、ウクライナ、アフガニスタンなど特定出身国のグローバル避難（ヨーロッパ等）」という出身国構成の変化（シンプソンのパラドックス的構造）が牽引していることを確認。
- **採点判定**: **合格水準を確認**。

### W7: 公共交通の時刻表のオープンデータの登録が、条件の割に少ない国と都市 (`world-visualize-w7`)
- **使用データ**: Mobility Database `feeds_v2.csv` (2026-10-20), `yuiseki/kontur-population-2023-11-01-22km`, `yuiseki/worldbank-wdi`
- **データ特性と制約**:
  - 有効 GTFS 2,779 件。Bbox の定義が国全体（巨大 bbox）になっているフィードと都市圏単位のフィードが混在。
  - 巨大 bbox（>25 deg²）を除外しないと、人口カバー率が 93% と 13.7% で激変する。
- **採点判定**: **合格水準を確認**。ただしデータセット目録が Hugging Face 上で未凍結（カードのみ）のため、評価課題としての利用時は版の固定が前提。
