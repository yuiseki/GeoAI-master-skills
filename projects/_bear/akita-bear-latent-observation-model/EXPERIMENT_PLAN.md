# 計画: 熊の潜在の空間利用と観測の過程は、いまのデータで識別できるか

流す前に書く。流した後に書き直さない。直すなら末尾の「計画の変更」に足す。

## 絶対に置く前提

熊の真の生息域・利用強度は直接観測できない。利用できるものは全て、`latent ecological process → observation process → observed record` の結果である。

環境省の分布メッシュも、目撃、痕跡、捕獲、狩猟者などへの聞き取り、自治体の調査を通した観測で、ground truth ではない。クマダスの通報も別の observation process である。捕獲、camera trap、GPS などを将来足しても同じで、それぞれに固有の検出と選択の過程がある。

したがって目的は「真の熊の分布を復元した」と主張することではなく、複数の観測系を同時に説明する共通の latent process が、データからどこまで識別できるかを調べること。結論で「熊の真の分布を推定した」とは書かない。

## 出発点 (既存の研究は書き換えない)

- [bear-synthesis](../bear-synthesis/): 予測変数の探索は終えている。
- [akita-bear-risk-grid-100m](../akita-bear-risk-grid-100m/): B_env は通報を教師にした 100 m の予測器。
- [akita-bear-human-interface](../akita-bear-human-interface/): B_env の予測力のほぼ全ては human-side の特徴量から。通報で学習した M_B は、環境省の分布メッシュの記録の水準と逆向きに関係した (ρ −0.244)。静的な proxy では熊側の変化と通報の過程の変化を分けられない。依頼書 [DATA_REQUEST_BEAR.md](../akita-bear-human-interface/DATA_REQUEST_BEAR.md)、[DATA_REQUEST_HUMAN.md](../akita-bear-human-interface/DATA_REQUEST_HUMAN.md)。
- `B_env`、`M_B`、`M_H` は通報を教師にした予測器なので、潜在の状態の観測値にも共変量にも使わない。使うのは生の環境と人の共変量と、観測の記録だけ。

## 空間と時間の単位

- 主の単位: 環境省の 5 km メッシュ (8 桁のコード)。秋田県の 100 m セル (中心) が 1,200 以上入るメッシュ (core mesh) を主にする。人側の分析の探索と同じ定義で、480 メッシュになるはず (入力の整列の段で数を確かめ、違えば止める)。全ての交差するメッシュ (環境省の枠の 549) は感度分析。
- 観測の時期 (同じ年度として扱わない): 環境省の第 6 回相当 (約 2000〜2004 年度、yo4 の `第6回で確`)、環境省の最新調査 (2010〜2017 年度の情報、yo4 の `H22_29`)、クマダス 2023、2024、2025、2026 年の各 4〜9 月 (2026 年度の観測期間に合わせる)。
- 100 m への downscaling はしない。

## 共変量 (結果を見る前に固定)

- bear-side の事前の共変量 `X_B` (メッシュの県内セルの平均、core mesh で標準化): `tree`、`water`、`elev`、`slope`、`log1p(d_stream)`。人側の分析で B に分けた特徴量の生の値。
- human-side の測定 `H`: 標準化した `log1p(人口の和)`、`log1p(建物の数)`、`crop` の平均、`built` の平均、道路から 100 m 以内のセルの割合 の第 1 主成分 (人口の負荷が正になる向き、標準化)。通報は使わない。説明する分散の割合と負荷を記録する。
- 市町村: メッシュの県内セルの最多の市町村。
- オフセット: `log(メッシュの県内セルの数)`。

## モデル (NumPyro 0.22.0、JAX 0.12.0.1、CPU、NUTS)

共通: `b[m] = X_B[m] · β + u[m]`、`β ~ Normal(0, 1)`、`u[m] ~ Normal(0, 1)`。観測系ごとの負荷 `λ ~ HalfNormal(1)` (正の向きに固定)。

| モデル | 環境省 (時期 e = E6, E7) | クマダス (年 y) |
|---|---|---|
| L0 (独立) | `logit p = a_e + X_B · β_E + u_E[m]` | `log μ = offset + a_y + X_B · β_K + u_K[m] + r[g,y]` |
| L0H | L0 + `c_E · H` | L0 + `c_K · H` |
| L1 (共有の静的な b) | `logit p = a_e + λ_E · b[m]` | `log μ = offset + a_y + λ_K · b[m] + r[g,y]` |
| L2 (L1 + H) | L1 + `c_E · H` | L1 + `c_K · H` |
| L3 (動的な B) | L2 と同じ (`b` は静的) | `log μ = offset + a_y + λ_K · (b[m] + d[m,y]) + c_K · H + r[g,y]` |

- クマダスは NegativeBinomial2 (`φ ~ HalfNormal(5)`)。Poisson との比較は事後予測の分散で示す。
- `a_e、a_y ~ Normal(0, 2.5)`、`r[g,y] ~ Normal(0, σ_r)`、`σ_r ~ HalfNormal(0.5)`、`c ~ Normal(0, 1)`。`u_E`、`u_K` は Normal(0, σ)、`σ ~ HalfNormal(1)`。
- L3: `d[m,2023] = 0`、`d[m,y] = g_y + σ_v · v[m,y]` (y = 2024〜2026)、`g_y ~ Normal(0, 0.5)`、`σ_v ~ HalfNormal(0.5)`、`v ~ Normal(0, 1)`。
- B × H は、L2 の後に 1 回だけ (`log μ` に `κ · b · H`、`κ ~ Normal(0, 0.5)`)。ほかの交互作用は探さない。
- 実データの収束の条件: 4 chain × 1,000 warmup + 1,000 draw、seed 0、最大の R-hat ≤ 1.01、bulk ESS ≥ 400、divergence 0.5% 以下。満たさなければ解釈しない。事後予測の確認: 年ごとの通報の合計、ゼロのメッシュ × 年の割合、メッシュの合計の分散、時期ごとの環境省の記録の割合。

## 識別可能性の実験 (実データに当てる前に必須)

### 合成データの作り方

同じ 480 メッシュ、同じ `X_B`、`H`、市町村、オフセット、同じ観測の時期と欠け方 (環境省は 2 時期、クマダスは 4 年、時間の重なり無し) で作る。真値は seed ごとに `β ~ Normal(0, 0.5)`、`u ~ Normal(0, 1)`、`λ_E = 1`、`λ_K = 0.8`、`c_E = 0.5`、`c_K = 1.0`、`φ = 2`、`r[g] ~ Normal(0, 0.3)` (年で変わらない部分)。切片は、変化の無い状態で環境省の記録の割合と、クマダスのメッシュあたりの平均の件数が、実データの値 (入力の整列の段で記録) に合うように seed ごとに決める。

| シナリオ | 2023 → 2026 の変化 (年に比例) | 真の T_B | 真の T_R |
|---|---|---|---|
| S1 熊の拡大だけ | `d[m,2026] = 0.4 + e[m]`、`e[m] = 0.4 · z(−tree[m]) + Normal(0, 0.2)` (森の少ないメッシュほど増える)。通報の過程は固定 | 約 0.4 | 0 |
| S2 通報の変化だけ | `a_2026 − a_2023 = 0.4`、秋田市の `r` に +0.6。B は固定 | 0 | 約 0.4 + 0.6 × 秋田市のメッシュの割合 |
| S3 人側の変化だけ | 人側の上位 25% のメッシュで `H` が +0.6 (クマダスの年だけに効く)。B と通報の過程は固定。当てはめのモデルは H を静的に置く | 0 | 0 |
| S4 熊 + 通報 | S1 と S2 の両方 | 約 0.4 | S2 と同じ |
| S5 変化なし | なし | 0 | 0 |

seed 0〜19 (各シナリオ 20 本)。

### 推定するもの (当てはめは L3)

- `T_B = mean_m d[m,2026]` (潜在の尺度の熊側の平均の変化)。
- `T_R = (a_2026 − a_2023) + mean_m (r[g(m),2026] − r[g(m),2023])` (通報の過程の平均の変化)。
- 副: `S_B` = `d[m,2026]` の `z(tree[m])` への最小二乗の傾き (負なら森の少ないメッシュほど熊側が増えた)。
- 判定: 90% 区間が 0 を含まなければ「検出」、その符号を向きとする。

### 識別可能性の関門 (この値で決める)

合成データの当てはめは 2 chain × 500 warmup + 500 draw。最大の R-hat > 1.05 か divergence > 1% の当てはめは「失敗」として数える (除かない)。

| 関門 | 条件 |
|---|---|
| G1 | S1 で、T_B を正しい符号で検出し、T_R を検出しない seed が 80% 以上 |
| G2 | S2 で、T_R を正しい符号で検出し、T_B を検出しない seed が 80% 以上 |
| G3 | S3 と S5 で、T_B を検出してしまう seed が 20% 以下 |
| G4 | S4 で、T_B と T_R の両方を正しい符号で検出する seed が 80% 以上 |
| G5 | 全シナリオ × seed で、T_B の 90% 区間が真値を含む割合が 80% 以上 |
| G6 | 事前分布を広げても (`g_y` と `a_y` の差の尺度を 3 倍: `g_y ~ Normal(0, 1.5)`、`a_y ~ Normal(0, 5)`、`σ_v`、`σ_r` の HalfNormal の尺度を 3 倍)、G1〜G4 の合否が変わらず、seed ごとの T_B の判定 (検出の有無と符号) が 80% 以上で一致 |

G1〜G6 を全て通ったときだけ、実データで L3 を流し、2023 → 2026 年の熊側の変化を推定する。通らなければ、2023 → 2026 年に熊が拡大した (または減った) という潜在の時間の主張は禁止し、dynamic bear inference をそこで止める。Hawkes、深層学習、交互作用の追加、100 m への downscaling には進まない。主結果は「なぜ識別できないか」と「何を観測すれば識別できるか」になる。

副の S_B は同じ形の関門 (S1 で正しい符号の検出 80% 以上、S2、S3、S5 で誤った検出 20% 以下、事前分布を広げて判定の一致 80% 以上) を別に見る。通っても、全体の T_B の主張は許さない。

### 構造からの見込み (流す前に書く)

クマダスの尤度の中で、`g_y` (熊側の年の平均の変化) と `a_y` (通報の年の効果) は同じ定数として現れ、環境省の調査は 2023〜2026 年に重ならない。したがって T_B と T_R は事前分布の比でしか分かれず、G1、G2 は通らないと見込む。この見込みが外れたら、その理由を調べてから報告する。

## 実データの段階

1. L0、L0H: 観測系ごとの独立のモデル。
2. L1、L2: 共有の静的な b と、H の追加。B × H を 1 回だけ。
3. L3: 識別可能性の関門を通ったときだけ。
4. どの段も、上の収束の条件と事後予測の確認を記録する。

## 観測系をまたぐ検証

- 空間のブロック: 2 次メッシュ (6 桁のコード、約 10 km)。ブロックを seed 0 で 5 つの fold に分ける。
- 環境省を隠す: fold のメッシュの環境省の記録 (2 時期) を隠し、クマダスは全部使う。隠した記録の対数予測密度 (事後の draw の Bernoulli の尤度の平均の対数) をメッシュごとに。
- クマダスを隠す: fold のメッシュの 4 年の件数を隠し、環境省は全部使う。隠した件数の対数予測密度 (NegBin) をメッシュごとに。
- 観測系をまたぐ得: L1 − L0 と L2 − L0H のメッシュごとの対数予測密度の差の合計。90% 区間は 2 次メッシュのブロックのブートストラップ 1,000 回 (seed 0)。当てはめは 2 chain × 500 + 500。
- 判定: 両方向で下限 > 0 なら「共通する空間の潜在の構造がある」、片方向だけなら「片方向だけ」、どちらも区間が 0 を含むか負なら「無い」。
- H の効果: L2 − L1 の同じ得。下限 > 0 の方向があれば「H を分けると説明が良くなる」。

## 反証

- F1 (空間の対応の破壊): 環境省の記録を 2 次メッシュのブロックごとに別のブロックへ移す (ブロックの中の 4 つの位置 22、27、72、77 を保つ。移った先が core mesh でなければ記録は欠測として扱う)。seed 0〜9 の 10 通りで観測系をまたぐ検証を流し、L1 − L0 の得が消えるか。
- F2 (観測系の対応の破壊): F1 の同じ 10 通りで全データの L1 を当てはめ、環境省の負荷 `λ_E` の事後と、環境省の記録の対数尤度が、本物と同じくらい出てしまわないか。
- F3 (事前分布の感度): 実データの L1、L2 を、上の事前分布と、尺度を 3 倍にした事前分布で当てはめ、`λ_E`、`λ_K`、`c_E`、`c_K` の符号と、観測系をまたぐ得の符号が変わらないか。合成データの G6 も F3 の一部。

## 追加のデータの価値 (合成データで実験計画として)

実データを作るためではなく、次に何を集めるのが最も識別に効くかを決めるため。当てはめは L3 に、そのデータの尤度を足したもの。シナリオ S1、S2、S3、S5、seed 0〜9。

| 候補 | 合成の作り方 | 当てはめで置く仮定 |
|---|---|---|
| V1 固定の自動撮影カメラ 50 地点 × 4 年 | core mesh からランダムに 50 地点 (固定)、検出の日数 ~ Poisson(exp(a_cam + λ_C · B[m,y]))、努力は一定 | `a_cam` は年で変わらない |
| V2 努力の記録の付いたカメラ | 毎年 50 地点を選び直し、努力 (稼働日数の倍率、0.5〜2) を記録してオフセットに | 努力は既知、`a_cam` は年で変わらない |
| V3 年ごとの捕獲の地点と努力 | 市町村 × 年の捕獲数 ~ Poisson(努力 · exp(a_cap + λ_P · 市町村の B の平均))、努力は既知で年で変わる | 努力は既知 |
| V4 環境省方式の 2020 年代版 | 2023 年と 2026 年に同じ方式で記録の有無を調べる | 2 回の検出の切片は同じ |
| V5 クマダスの運用の履歴 | 通報の過程の変化を、記録された運用の変化 (2024 年の全体の変化、2025 年からの秋田市の変化) の指標で表す | 通報の過程の変化は、記録された運用の変化だけ |
| V6 時系列の人の活動 | `H[m,y]` を誤差 (sd 0.1) 付きで観測 | H の時間変化は観測で分かる |

指標: S1 と S2 の正しい判定の割合の平均 (G1、G2 と同じ定義)、S3 と S5 で T_B を誤って検出する割合。V5 は「全ての通報の変化が記録される」という強い仮定に依存すると書く。

## 地図の表示の規則

潜在の b や H の地図は「複数観測系から推定した latent bear space-use score」のように題を付け、「熊の生息域」「熊の密度」「真の熊分布」とは書かない。事後の平均と並べて、必ず不確かさ (事後の標準偏差か 90% 区間の幅) の地図を置く。
