# 熊の観測データの棚卸し: 観測の過程で並べる

[report.md](report.md) の結論は「いまの観測の構造では、2023〜2026 年の熊側の変化と通報の過程の変化を分けられない」で、合成データの上では、通報と独立で努力の分かる熊の観測 (V1〜V3) を足したときだけ分けられた ([voi_summary.json](outputs/voi_summary.json))。この棚卸しは、われわれが使った、公開した、候補として名前を挙げた熊関連のデータを、データセットの名前ではなく観測の過程で並べ直し、V1〜V3 に当たるものが実際にあるかを確かめるためのもの。

新しいモデルも新しい分析もしていない。新しい公開データも探していない。読んだのは、このリポジトリの report.md、計画、記録、2 つの依頼書 ([DATA_REQUEST_BEAR.md](../akita-bear-human-interface/DATA_REQUEST_BEAR.md)、[DATA_REQUEST_HUMAN.md](../akita-bear-human-interface/DATA_REQUEST_HUMAN.md))、[bear-synthesis](../bear-synthesis/report.md)、`_bear` の各プロジェクトのデータの節、`.agents/skills/dataset-discovery/references/` の熊と秋田のカード、それと環境省の分布メッシュの Hugging Face のカード (自分たちで公開したもの、rev 7f635cb) だけ。表の中の「未確認」は、この範囲で書かれていないという意味で、存在しないという意味ではない。

## 前提

熊の真の生息域の正解 (golden data) は無い。下の全ての行は、人が見た、カメラが検出した、わなで捕まえた、痕跡を調べた、聞き取った、などの観測の過程を通った記録である。記録の有無 (presence / absence) の多さで質を決めない。この棚卸しで最も重く見るのは、観測の努力と、0 (非検出) の意味が分かるかである。

評価の 4 つの軸:

- A 努力: 分母 (わなの日数、カメラの稼働日数、調査の回数、踏査の距離など) が記録されているか。
- B 0 の意味: 0 が「調べて見つからなかった」か、「調べていない」「記録が欠けた」「公開されていない」かを区別できるか。
- C 通報との独立: クマダスなどの住民の通報から派生していないか。派生していれば independent bear observation と扱わない。
- D 時間変化: 複数年あり、方法が比べられ、努力が分かるか。満たさなければ「静的な空間の構造には使えるが、時間の推定 (dynamic inference) には使えない」と書く。

列の略: 努力 = effort known?、0 の意味 = zero meaning、方法の安定 = protocol stability、通報と独立 = independence from Kumadas、潜在の変化への有用性 = usefulness for latent change。VOI は [report.md の図 4](report.md#図-4-追加のデータの価値) の候補 V1〜V6 のどれに近いか。

## 現在すでに持っているもので何ができるか

- 静的な空間の分析 (static spatial analysis): 5 km メッシュの latent bear space-use score の当てはめ、通報の 100 m の順位の予測 (B_env)。ただし、共有の score は、環境省の記録を共変量と H だけより良くは予測しなかった ([report.md](report.md))。
- 観測系をまたぐ比較 (cross-observation comparison): 環境省の分布メッシュとクマダスの空間の対応 (λ_E) と、観測系をまたぐ予測の検証。どちらも 1 時点の環境省の記録との静的な比較に限る。
- 通報の予測 (reporting prediction): 通報の場所 (100 m の順位)、市町村 × 週の件数、県 × 年の量。予測の対象は通報で、熊ではない。
- 年の水準の説明の材料: ブナの豊凶の県 × 年の指数。

## 現在のデータでは何ができないか

- 2023〜2026 年の熊側の時間変化の識別。いま持っている熊の観測は、努力の無い通報 (クマダス) と、2017 年度で止まった記録の有無 (環境省) だけで、2023〜2026 年に繰り返された、通報と独立で努力の分かる熊の観測は 1 つも無い。このため、クマダスの年の定数の中で、熊側の変化 $g_y$ と通報の過程の年の効果 $a_y$ の和しか決まらない。これは関門の不通過 ([report.md](report.md)) の原因そのもので、モデルを変えても直らない。
- 通報の 0 を熊の不在として読むこと。クマダスにも環境省の記録にも、0 を「調べて見つからなかった」と読める努力の記録が無い。
- 通報の過程の変化 (秋田市の割合の急増など) の原因を確かめること。運用の履歴 (H1) が無い。
- 熊の数や密度、真の分布の推定。どの観測も ground truth ではなく、そもそもこの研究の目的にしない。

## 次に取得価値が高いデータ

VOI の結果と、実際にありそうか (努力の記録、複数年、空間の粒度、利用の可能性) の両方で順位を付けた。どれも詳細は未確認で、順位は確かめた結果で入れ替わりうる。

1. 秋田県の捕獲の記録 (有害捕獲と狩猟を分けたもの、市町村 × 年度以下) と、その努力 (わなの数、設置日数、出猟の日数)。VOI は最も高い (V3、S1 と S2 の正答 0.8)。県の管理計画の資料に複数年の捕獲数がある見込みが最も高く、VOI の V3 と同じ市町村 × 年の粒度で足りる。ただし、有害捕獲の努力は出没や通報に反応して動くので、VOI の「努力は既知で通報と独立」という仮定がそのままは成り立たない。努力が年ごとに記録されていて、有害と狩猟を分けられることが、1 位に置く条件である。捕獲数だけなら、通報と同じ問題を持つ観測がもう 1 つ増えるだけになり、2 位より下がる。
2. 秋田県の生息数推定などの自動撮影カメラ (とヘア・トラップ) の地点 × 年の検出と稼働日数。観測の設計は最も良い (通報と独立、稼働中の不検出が意味を持つ)。VOI は V2 が S1 正答 0.7、V1 が 0.5 で、捕獲に近い。1 位より下にしたのは、存在、年、地点の数、公開の可否のどれも確かめていないから。1 回きりの調査なら時間の推定には使えず、静的な較正 (Sun 2019 の形) にしか使えない。
3. 3 件目は置かない。残りの候補 (V4 の再調査、V5 の運用の履歴、V6 の人側の時系列、人身被害、GPS) は、VOI で S1 正答を 0.1 以下にとどめるか、熊側の地域の変化の観測にならない。運用の履歴 (H1) は通報の過程の説明 (S2) には効くので、熊側の識別とは別の目的で取る価値はある。

## 次の調査タスク: V1〜V3 の未確認事項

V1〜V3 に当たるデータは、存在が示唆されているが詳細が未確認だった。この棚卸しはここで止め、次の調査で次のことを確かめる。新しい分析は、これの答えが出るまでしない。

1. 秋田県の第二種特定鳥獣管理計画 (ツキノワグマ) と、そのモニタリングの報告に、捕獲数が何の粒度 (県、地域、市町村、メッシュ) と何年分載っているか。
2. 有害捕獲と狩猟 (と、もしあれば個体数調整の捕獲) が分けて記録されているか。
3. 捕獲の努力 (わなの数、設置日数、許可件数、出猟の日数、狩猟者の数) が年ごとに記録、公表されているか。
4. 秋田県の生息数推定の方法 (カメラ、ヘア・トラップ、DNA、その他) と、実施した年、地点の数、地点が年をまたいで固定か。
5. カメラの地点 × 年の稼働日数と検出の記録が、報告書の集計としてではなく地点ごとに残っているか。
6. 上の 1〜5 の利用の条件 (公開、申請が要る、非公開) と、再配布の可否。
7. 環境省の次回のクマ類の分布調査の予定 (V4 は VOI が低いので、予定の有無を確かめるだけ)。

## 判断

今あるデータだけで次の分析へ進むべきではなく、データの取得と公開の状況の確認を先にするべきだと判断する。いま持っている熊の観測は、努力の無い通報と、2017 年度で止まった記録の有無だけで、関門の不通過の原因 (熊側の年の変化と通報の過程の年の効果の和しか決まらない) は、どの分析を足しても解けない構造の問題だからである。VOI で効いた 3 つの候補 (捕獲と努力、努力付きのカメラ、固定のカメラ) はどれも、存在は示唆されているが粒度、年、努力の記録、利用の条件が確かめられていない。特に捕獲は、努力が通報に反応するかどうかで価値が大きく変わる。上の 7 つの未確認事項を確かめ、捕獲の努力の記録か、繰り返しのカメラの調査の少なくとも 1 つが実在すると分かってから、それを足した L3 の関門を合成データで流し直すのが次の分析になる。
