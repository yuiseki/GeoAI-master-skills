# データ要求: bear-side の時間変化を通報と独立に測る

このプロジェクトで使った特徴量は全て静的 (1 時点) で、熊の分布が年でどう変わったかは測れない。通報の位置の年度の移動 (2025 → 2026 で、両方の proxy の水準が少し低いセルへ) を、熊の分布の変化 (仮説 A) と通報の過程の変化 (仮説 D) に分けるには、通報と独立に熊の存在や活動を年ごとに観測したデータが要る。このファイルは、データセットを作る別のエージェントへの依頼書。ダウンロードと Hugging Face 化はこのプロジェクトではしない。

## 前提: 熊の生息域の正解のデータは無い

人が持っているのは、人が観測できた熊の情報だけで、熊の生息域の正解 (ゴールデンデータ) はありえない。下の候補も全て人の観測の記録で、観測の機会 (人の出入り、調査の方法と体制) に左右される。通報と比べるときも「正解との比較」ではなく「観測の過程の違う 2 つの記録の比較」として扱う。片方に記録が無いことは、熊がいないことの証拠ではない。

### 公開済み: 環境省の分布メッシュ (2026-10-31)

候補 2 は [`yuiseki/env-biodic-bear-distribution-mesh-jp`](https://huggingface.co/datasets/yuiseki/env-biodic-bear-distribution-mesh-jp) (rev 7f635cb) として公開された。秋田県の 100 m セルの中心を 5 km メッシュに割り当てて最新の調査 (yo4、平成 22〜29 年度の情報) と突き合わせると (2026-10-31、探索、出力は未保存):

- 格子にかかる 550 メッシュのうち 549 が yo4 の枠にあり、2010〜2017 年の情報があるのは 508、第 6 回 (2000〜2004 年頃) と両方で確認が 397、2010〜2017 年だけが 111、どちらの記録も無いのが 41。
- 秋田県はほぼ全域に記録があり、県の中で「記録のある所と無い所」の対比はほとんど無い。期間は 2017 年度までで、通報の 2023〜2026 年と重ならない。
- したがって 2023〜2026 年の変化 (仮説 A と D の区別) には使えない。使えるのは、2 つの観測の過程の比較 (2010〜2017 年に新しく記録されたメッシュに、2023〜2026 年の通報がどう出ているか) と、bear-side proxy が別の観測の記録とどれだけ合うかの確認まで。

## 何を確かめるために必要か

1. 2023〜2026 年に、通報と独立の熊の観測の位置が、bear-side proxy の高い所から低い所 (平野、市街地の縁) へ広がったか。広がっていれば A と整合し、広がっていなければ「通報の位置の移動は熊の分布の変化ではない」側の根拠になる。
2. 同じ観測の年度の水準 (捕獲数、検出率) と通報の数が同じ向きに動いたか。通報だけが増えた年は D の候補。
3. 静的な M_B のスコアが、通報と独立の熊の観測をどこまで当てるか (bear-side proxy の妥当性の外部の確かめ)。

## 必要な形

- 1 行 1 件、日付 (年月日)、座標 (経緯度、測地系を明記) またはメッシュコード、種別、出典の行。
- 版を固定し、取得日と元の URL と配布元の sha256 を記録する。
- 個人を特定できる情報 (氏名、住所の番地) は入れない。位置を丸めて公開されているなら、丸めの単位を書く。

## このデータが無いと言えないこと

- 「熊の生息域が 2023〜2026 年に広がった」とは言えない。このプロジェクトで言えるのは「通報のセルが、bear-side proxy と human-side proxy の両方が少し低いセルへ移った」まで。
