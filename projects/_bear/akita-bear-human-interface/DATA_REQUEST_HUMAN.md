# データ要求: human-side の時間変化と、通報の過程を測る

このプロジェクトの human-side の特徴量 (人口 WorldPop 2020、建物と道路 OSM 2026-08、市街地と農地 WorldCover 2021) は 1 時点の値で、人の分布や行動が年で変わったか (仮説 B)、通報のされ方が変わったか (仮説 D) は測れない。通報の順位の予測力のほぼ全て (B_env の 96〜98%) が human-side から来ていたので、「人が多い所ほど通報されやすい」という説明を、人の側の時間変化と通報の過程のデータで確かめる必要がある。このファイルは、データセットを作る別のエージェントへの依頼書。ダウンロードと Hugging Face 化はこのプロジェクトではしない。

## 何を確かめるために必要か

1. 2025 → 2026 の秋田市の通報の割合の急増 (16.6% → 30.1%) が、人の分布の変化、通報の窓口や周知の変化、熊の出方の変化のどれと同じ時期に起きたか。
2. 人の出入りの多い場所ほど通報が多いこと (human-side の第 5 分位に通報の 90〜94%) が、人の数で割ると消えるか (通報の機会で割った率)。
3. 耕作放棄や人口の減少が進んだ場所 (人の側の境目が退いた場所) で、通報のセルが増えたか (仮説 C の時間変化)。

## 必要な形

- 版 (調査年、取得日) を固定し、元の URL と sha256 を記録する。
- メッシュは JIS のメッシュコードのまま渡す。100 m のセルへの按分はこちらで行い、量 (人口) と水準 (率) を区別する。
- 有料のデータと、再配布の禁止されたデータは取らない。

## このデータが無いと言えないこと

- 「human-side の予測力は、熊が人里に出ているからではなく、人が多いから通報されやすいだけ」という代替の説明を否定も肯定もできない。
- 2026 年の秋田市の急増が通報の過程によるものか、熊の出方によるものか区別できない。
