# 計画: B_env の予測力は bear-side、human-side、interface のどこから来ているか

流す前に書く。流した後に書き直さない。直すなら末尾の「計画の変更」に足す。

## 出発点 (前のプロジェクトで分かっていること、再実行しない)

- [akita-bear-risk-grid-100m](../akita-bear-risk-grid-100m/): 静的な 28 特徴量だけの勾配ブースティング B_env が、翌年度の 100 m セルの通報の順位をよく当てる。capture@5% は B1 (2023 → 2024) 0.534、B2 (2023+2024 → 2025) 0.552、B3 (2023〜2025 → 2026 年 4〜9 月) 0.539。
- 過去の通報の密度を足しても良くならない (B2 −0.011、B3 −0.024)。
- 年の豊凶 × ブナ・ナラ類の植生も良くならない ([akita-bear-mast-exposure](../akita-bear-mast-exposure/))。
- 季節内の直前の通報による活性化は、翌年度の確認で再現しない (R043、R044)。
- 市町村 × 週の短期予測は前週の値を安定して超えない ([japan-bear-sighting-forecast](../japan-bear-sighting-forecast/))。
- 予測変数の探索は [bear-synthesis](../bear-synthesis/) で終えている。

この研究は予測変数を足さない。B_env の 28 特徴量を役割で分け、部分集合のモデルの当たりと、2 つの部分モデルのスコアが張る平面の上の通報の位置を記述する。

## 問い

B_env の通報の順位の予測力は、熊が利用しやすい場所の proxy、人が利用しやすい場所の proxy、両者が接する場所の proxy のどこから来ているか。その平面の上で、通報のあったセルの分布は年度ごとにどう動いているか。

### 用語

直接観測しているのは通報だけ。次の呼び方を使い、真の潜在量の名前では呼ばない。

- bear-side environmental proxy: B 群の特徴量だけで学習したモデル M_B のスコア。熊の生息確率ではない。
- human-side environmental/activity proxy: H 群だけのモデル M_H のスコア。人の活動の強さではない。
- interface proxy: 元から森林と人の場所の境目を表す特徴量 (I 群)。
- phase space: 各セルを (M_B のスコアの県内 percentile、M_H のスコアの県内 percentile) に置いた平面。

### 候補仮説

| 記号 | 仮説 | 静的な proxy と通報だけで言えること | 言えないこと |
|---|---|---|---|
| A | bear-side の空間分布が変わった | 通報のセルが bear-side proxy の高い所へ移ったかどうか | 熊の分布が実際に広がったか。静的な特徴量は年で変わらないので、熊の分布の変化そのものは測れない |
| B | human-side の空間分布・活動が変わった | 通報のセルが human-side proxy の高い所へ移ったかどうか | 人の分布や行動が変わったか。人口と建物は 1 時点の値 |
| C | 両者の interface が変わった | 通報のセルが両方の proxy の中〜高の組合せへ移ったかどうか | 境目そのもの (耕作放棄、藪の伸び) が変わったか |
| D | reporting / observation process が変わった | info_type、市町村、人口・建物、セルあたりの通報の数の年度の構成が変わったか | 通報の出やすさが変わったのか、熊の出方が変わったのか。同じ構成の変化はどちらでも起こる |

A、B、C は「通報の位置が proxy の平面のどちらへ動いたか」までしか区別できない。どの方向へ動いても、熊が動いたのか、人が動いたのか、通報する人が変わったのかは、時間で変わる独立のデータが無いと分けられない。この表は結果を見る前に書いた見込みで、結果で範囲が変わったら報告に書く。

## 特徴量の役割

28 特徴量を B (bear-side)、H (human-side)、I (interface)、X (どちらとも決められない、分解から外す) に分ける。分類は [feature_roles.csv](feature_roles.csv) に、結果や特徴量の重要度を見る前に固定し、モデルを流す前に commit する。分類の考え方:

- B: 森林、標高、傾斜、地形の起伏、水面、山の沢。熊が使う場所の環境に近いもの。
- H: 人口、建物、道路 (一般の道路)、農地、市街地。人が使う場所。
- I: 元から境目を表すものだけ。B と H の組合せから作らない。
- X: 熊側とも人側とも一意に読めないもの。無理に B か H に入れない。

## モデル

B_env と同じ `HistGradientBoostingClassifier` (max_iter 300、learning_rate 0.05、max_leaf_nodes 63、min_samples_leaf 500、l2_regularization 1.0、early_stopping なし)、random_state 0、全セル、重みなし、同じラベル (熊の年度に 1 件以上)。ハイパーパラメータは調整しない。特徴量の列だけを替える。

| モデル | 特徴量 |
|---|---|
| M_B | B 群 |
| M_H | H 群 |
| M_BH | B + H |
| M_BHI | B + H + I |
| M_FULL | 28 個全て = 既存の B_env。保存済みのスコアを読む |
| M_I、M_BI、M_HI (副) | B、H、I の 3 群の Shapley 分解のためだけ |

実装の確認: 同じ関数で 28 個全てを B1 で学習し直し、保存済みの B1 の B_env のスコアと一致すること (最大の絶対差 1e-6 以下、capture@5% 0.5341823056)。一致しなければ止める。

## 評価

- 分割は既存のまま: B1 (2023 → 2024、開発)、B2 (2023+2024 → 2025、確認)、B3 (2023〜2025 → 2026 年 4〜9 月、確認)。
- 主指標 capture@5%。副指標 capture@1%、capture@10%、AP、AUC。順位の同順位の扱いは既存の `metrics.rank_order` (seed 0)。
- 差の区間: 10 km ブロックのブートストラップの 90% 区間 (既存の `metrics.bootstrap_diff`)、B1 は 500 回、B2 と B3 は 1,000 回、seed 0。
- 主な比較: M_B − M_H、M_BH − (B1 で良かった方の単独モデル)、M_BHI − M_BH、M_FULL − M_BHI。良かった方の単独モデルは B1 で決め、B2 と B3 ではそれを固定する。
- B_env の予測力のうち各モデルが担う割合: s(X) = (capture@5%(X) − 0.05) / (capture@5%(M_FULL) − 0.05)。0.05 は無作為に選んだときの期待値。
- 副: B、H、I の 3 群の Shapley 値 (7 つの部分集合のモデルの capture@5% から、空集合は 0.05)。X は M_FULL − M_BHI として別に書く。

### 判定 (B2 と B3 の両方で決める。B1 は開発で判定に使わない)

「明確に上回る」= 差の 90% 区間の下限が B2 と B3 の両方で 0 を超える。

- Pattern A: M_B が M_H を明確に上回る。両方で差が 0.10 以上なら「≫」、そうでなければ「上回るが差は小さい」。
- Pattern B: M_H が M_B を明確に上回る。「≫」の基準は A と同じ。
- Pattern C: M_BH が、B1 で決めた良い方の単独モデルを明確に上回る。
- Pattern D: M_BHI が M_BH を明確に上回る、または B×H の積の項 (下の診断) が加法の組合せを明確に上回る。
- Pattern E: M_FULL が M_BHI を明確に上回る (分解に入れなかった X 群に、B、H、I で置けない予測力がある)。
- 当てはまる Pattern は全て書く。どれにも当てはまらなければ「区別できない」と書く。

## B × H の積の項 (1 回だけ)

M_B と M_H のスコアの logit を z_B、z_H とし、ロジスティック回帰 (C 1.0、標準化) で次の 2 つを比べる。

- 加法: z_B + z_H
- 積あり: z_B + z_H + z_B × z_H

meta-model の学習には cross-fit したスコアを使う。学習年度のセルを 10 km ブロックで 5 つに分け (ブロックの割り当ては seed 0)、4 つで M_B と M_H を学習して残り 1 つを予測する。meta-model はその out-of-fold のスコアで学習し、試験年度には全学習年度で学習した M_B と M_H のスコアを入れる。B1、B2、B3 で 1 回ずつ流し、判定は B2 と B3 で上の規則。ほかの交互作用は探さない。

## Phase space

- 各軸: M_B と M_H のスコアを、県内の全セル (1,168,211) の中の percentile (同順位は平均順位 / セル数) に変える。
- ビン: 各軸を 5 等分 (q1〜q5、q5 が高い)、5 × 5 = 25 ビン。これより細かくしない。
- 各年度に使うスコアは、その年度を学習していないモデルのもの。
  - 年度ごとの表: 2024 は B1 のモデル、2025 は B2、2026 は B3。2023 には前の年度が無いので、2024+2025 で学習したモデル (後ろ向き、報告で印を付ける)。
  - 年度の間の比較: 比べる 2 年度のどちらも学習していない共通の軸を使う。軸のモデルは残りの 2 年度で学習する。(2023, 2024) は 2025+2026、(2023, 2025) は 2024+2026、(2023, 2026) は 2024+2025、(2024, 2025) は 2023+2026、(2024, 2026) は 2023+2025、(2025, 2026) は 2023+2024 (= B2 のモデル)。主は隣り合う 3 組、特に 2025 → 2026。
- 陽性のセル: 主は 4〜9 月に 1 件以上 (2026 年度は 4〜9 月しかないため、4 年度を同じ季節で比べる)。副は熊の年度全体 (2023〜2025)。
- 各ビンについて年度ごとに: 全セル数、陽性セル数、陽性率、全陽性に占める割合。

### 領域の名前 (結果を見る前に決める)

ビンを (b, h) で書く。b は bear-side の 5 分位 (1 が低い)、h は human-side。25 ビンを次の 6 領域に分ける。

| 領域 | ビン | 読み方 (proxy の組合せとして) |
|---|---|---|
| bear_core | b 4〜5、h 1〜2 | bear-side proxy が高く human-side proxy が低い (熊側の奥の候補) |
| contact | b 4〜5、h 4〜5 | 両方が高い (強い接触の interface の候補) |
| boundary | (3, 3)、(3, 4)、(4, 3) | 両方が中〜やや高い (里山・境界の候補) |
| human_core | b 1〜2、h 4〜5 | bear-side proxy が低く human-side proxy が高い (人側の中心) |
| low_both | b 1〜2、h 1〜2 | 両方が低い |
| other | 残りの 6 ビン (3, 1)、(3, 2)、(1, 3)、(2, 3)、(3, 5)、(5, 3) | 中間 |

主張は「bear-side proxy と human-side proxy の組合せ」として書く。「熊の生息地」とは書かない。

## 年度ごとの移動 (記述、因果ではない)

各比較の共通の軸の上で、2 つの年度の陽性セルについて次を出す。

- bear-side と human-side の percentile の分布 (Q1、中央値、Q3)
- Cliff's delta (後の年度 − 前の年度、正なら後の年度が高い) と KS 統計量
- 25 ビンの構成の Jensen–Shannon divergence (底 2、0 で同じ、1 で重ならない。R040 と同じ定義)
- 6 領域の割合の変化

方向を言う規則: |Cliff's delta| ≥ 0.147 (小さい効果の慣例の境) で、かつ F3 のブロック単位の入れ替えの両側 p < 0.05 の軸だけ「その軸の高い (低い) 方へ動いた」と書く。2 軸の組合せで読む。b 上がり h 下がり = より bear-side proxy の高い所へ、b 下がり h 上がり = より human-side proxy の高い所へ、両方上がり = 両方の高い組合せへ、両方下がり = 両方の低い所へ。どれも「通報のセルが、その proxy の高い場所へ移った」までで止め、熊の分布の拡大とは書かない。

## 反証と負の対照

- F1 (役割の入れ替え): B と H の 22 特徴量を、大きさ (B の数、H の数) を保って無作為に 2 つに分ける。seed 0〜19 の 20 通り。各分け方で 2 つの半分のモデルを B2 と B3 で学習し (80 回の学習)、(1) 2 つの capture@5% の差の絶対値、(2) 2 つのスコアの percentile の Spearman 相関、(3) 2025 と 2026 の陽性セルの 25 ビンの構成と全セルの構成の JSD (平面がどれだけ陽性を偏らせるか) を本物の分け方と比べる。本物の値が 21 個の中で上から 2 番目以内 (≥ 90% 点) でなければ、B と H の意味づけは任意の分け方と区別できないと書き、名前に頼った解釈を弱める。
- F2 (空間ブロックの入れ替え): 陽性セルを 10 km ブロック (100 × 100 セル) ごとに、ブロックの中の配置を保ったまま別のブロックへ移す (ブロックの並べ替え、200 回、seed 0)。移った先が県外のセルは捨て、残った数を書く。陽性と全セルの構成の JSD と 6 領域の割合が、本物と比べてどれだけ残るか。
- F3 (年度ラベルの入れ替え): 共通の軸の上で、2 つの年度の陽性セルの年度ラベルを 10 km ブロックごとにまとめて確率 0.5 で入れ替える (1,000 回、seed 0)。Cliff's delta (2 軸) と JSD の本物の値が、入れ替えの分布のどこにあるか。両側 p は |値| が本物以上の割合。セルごとの入れ替え (空間の依存を無視する、甘い) も参考に書く。F3 で年度の差が入れ替えと同程度なら、年度の移動の解釈を弱める。

### 2026-10-31、R005 と R006 を見た後に足した探索 (結果を見て決めたので、確認ではない)

R005 で M_B と M_H の percentile の相関が 0.79〜0.84 あり、4〜9 月の陽性セルの 95〜98% が等分の 5 分位の contact に入った。陽性は両軸の上位 10% 前後に集まり、等分のビンでは年度の違いが読めない。そこで次の 2 つを探索として足す。規則による「動いた」の判定はしない。

- 上に寄せたビン: 各軸を percentile 0.50、0.80、0.90、0.95 で切った 5 × 5 (25 ビンのまま)。年度ごとの陽性の構成と、隣り合う年度の JSD (F3 のブロック入れ替えの p つき)。事前に決めた 6 領域の名前はこのビンには当てない。
- 対角の分解: 各セルの m = (b + h) / 2 (両方の proxy の水準) と d = b − h (bear-side 寄りか human-side 寄りか)、b と h は percentile。年度の間の Cliff's delta と F3 のブロック入れ替えの p。d が動かず m だけが動けば「どちらかの側へ」ではなく「両方の proxy が低い (高い) セルへ」と読む。

### 2026-10-31、環境省の別の観測系との整合の診断 (流す前に固定、探索、1 回だけ)

熊の生息域の正解のデータは無い。環境省の分布メッシュも人が観測できた熊の記録で、観測の機会に左右される。ここでは「熊の分布を検証する」のではなく、観測の過程の違う 2 つの記録 (環境省の分布メッシュと、こちらの通報で学習した proxy) がどの程度合うかを見る。

- データ: `yuiseki/env-biodic-bear-distribution-mesh-jp` rev 7f635cbfb92be5093fa707dbe6afec0e37d240f4 の yo4 (要注意鳥獣生息分布調査、平成 22〜29 年度の情報、5 km メッシュ) の `H22_29` と `第6回で確`。
- 単位: 秋田県の 100 m セルの中心が入る 5 km メッシュのうち、県内のセルがメッシュの面積の半分以上 (1,200 セル以上) のもの。メッシュのコードはセルの経緯度 (EPSG:6668) からデータのカードの規則で計算し、秋田県にかかる yo4 のポリゴンの中心がそのコードと一致することを確かめる。
- 記録の水準 (順序): 0 = 2010〜2017 年の情報も第 6 回の確認も無い、1 = どちらか一方、2 = 両方。
- proxy のメッシュの値: そのメッシュの県内セルの M_B、M_H のスコアの県内 percentile の平均。主は B3 のモデル (2023〜2025 年度で学習)、同じ実行の中で B2 のモデルも並べる。参考に、2023〜2026 年度の通報のあったセルの割合 (通報そのもの) も並べる。
- 主の統計: 記録の水準とメッシュの値の Spearman の ρ。比較は ρ(M_B) − ρ(M_H)。90% 区間は 2 次メッシュ (6 桁のコード、約 10 km) を単位にしたブロックのブートストラップ 1,000 回、seed 0。
- 副の統計: 2010〜2017 年の情報の有無の AUC、2010〜2017 年に情報のあるメッシュの中で「第 6 回にも確認」と「2010〜2017 年だけ」の AUC。区間は付けず、記述だけ。
- 読み方の規則 (主の統計、B3 の軸で決める): ρ(M_B) − ρ(M_H) の下限 > 0 なら「M_B は環境省の記録と M_H より整合し、bear-side という名前に限られた外的妥当性がある」。上限 < 0 なら「環境省の記録はむしろ human-side proxy と合う (別の観測系も観測の機会を引きずる)」。区間が 0 を含めば「差は無く、M_B も通報の過程をかなり引きずっている」と読む。B2 の軸で向きが逆なら、それも書く。
- 限界: 秋田県は大半のメッシュに記録があり、記録の無いメッシュは少ない。期間は 2017 年度までで、通報 (2023〜2026 年) と重ならない。どの結果も熊の分布の正しさの検証ではない。
