# 計画: ブナの豊凶の地点 × 年を、地形と年ごとの気象から当て、観測の無い地点へ広げられるか

流す前に書く。流した後に書き直さない。直すなら末尾の「計画の変更」に足す。要らない欄は消さずに「なし: <理由>」と書く。

## 問いと使い道

- 問い: 地点 × 年のブナの結実の評価 (0〜3) は、`mast(site, year) = f(前年の結実, 地形(site), 気象(site, year), 地形 × 気象)` の形で、学習に使っていない年と、学習に使っていない地点の両方で当てられるか。
- 使い道: 観測の無い場所 (県の全域の格子など) のブナの豊凶を、地形と気象のラスタだけで作る面 (空間に連続な豊凶の代わりの値、proxy) が作れるかを決める。作れると判断できたときだけ、次の段 (北海道 4 地点での別の地域の検証、衛星の植生の値、秋田県の全域の面、クマの環境の値との結合) に進む。クマの出没の予測は、この段の目的ではない。
- 評価の作り方は使い道から決まる。proxy の面は「観測の無い地点の、まだ来ていない年」に使うので、決め手は未知の地点 × 未知の年 (C) の評価。未知の年 (A) と未知の地点 (B) は、どこで崩れるかを分けて見るために並べる。
- 問いの種類: 予測。気象や地形を変える介入は無いので、因果の主張はしない。「地形によって気象への応じ方が違う」は、交互作用の項を入れると未知の地点 × 年の予測が良くなるか、という意味に限る。

## 単位と行

- 1 行 = 1 地点 × 目的の年 t (t = 1990〜2008)。目的変数は t の評価。前年の結実は t − 1 の評価なので、t = 1989 は目的にしない。
- 開発期間: t = 1990〜1999。確認期間: t = 2000〜2008。開発期間の選択は、開発期間の行だけで学習し、開発期間の行だけで採点する。確認期間の行は、選択を凍結するまで計算も表示もしない。
- 確認期間の採点では、各 fold の学習に開発期間の行も使ってよい (下の分け方の規則に従う)。凍結するのは特徴量の形と選んだ版で、係数は fold ごとに当て直す。
- 1999 年は 54 地点 (ID 49〜102) が -1 なので、t = 1999 の行と、自分の地点の前年を使う t = 2000 の行の多くが欠ける。欠けで落ちた行は、分け方ごとに数える。

## 特徴量 (先に固定)

気象は、地点を含む AgERA5 の 0.1 度のセルの値 (前のプロジェクトと同じく、最も近いセルの中心が地点の 0.05 度以内であることを確かめる)。偏差は、その地点のセルの 1981〜2010 年の平均からの差。

| 名前 | 定義 |
|---|---|
| F_lag | 前年 t − 1 の評価。A では自分の地点の値。B と C では、学習側の地点 (自分を除く) のうち t − 1 の評価がある最も近い 5 地点の平均 (距離は EPSG:6691 の平面で) |
| Ts(y) | y 年の 7〜8 月の月平均最高気温の平均の偏差 (°C) |
| ΔT | Ts(t − 1) − Ts(t − 2) |
| Tsp | t 年の 4〜5 月の月平均最低気温の平均の偏差 (°C) |
| P, PET | t − 1 年の 6〜8 月の降水、基準蒸発散量の合計の偏差 (mm) |
| WB | P − PET (t − 1 年の 6〜8 月、偏差、mm) |
| elev | Dryad の Altitude (m)。交互作用では学習側の平均を引いて km にする |
| slope, northness, eastness | 地点から 100 m 以内の DEM の画素に平面を当てた傾き (度) と、斜面の向き a の cos a、sin a |
| relief_r | 半径 r の中の DEM の最大 − 最小 (m) |
| tpi_r | 地点の DEM の値 − 半径 r の中の DEM の平均 (m) |

- r は 300 m と 1,000 m の 2 つだけ。どちらかを開発期間で選ぶ (B1)。ほかの半径は試さない。
- 地形の計算は、Web メルカトルの画素を EPSG:6691 (JGD2011 / UTM 54N) の m に移してから行う。
- 目的の年 t の秋の結実に対して、全ての特徴量は t 年の 5 月末までに決まる (Tsp は t 年の 4〜5 月、ほかは t − 1 年以前)。

## モデル (先に固定)

全て最小二乗の線形 (地点の切片も年の切片も持たない。未知の地点と未知の年に同じ形で当てるため)。予測は 0〜3 に切る (全てのモデルで同じ)。

| モデル | 中身 |
|---|---|
| M0 | 地点の基準。A では、その地点の学習側の年の平均。B と C では、学習側の最も近い 5 地点の、学習側の年の平均の平均 |
| M1 | F_lag |
| M2 | M1 + ΔT |
| M3 | M2 + elev + slope + northness + eastness + relief_r + tpi_r |
| M4 | M3 + 水分。版 w1: WB。版 w2: P + PET。どちらかを B1 で選ぶ |
| M5 | M4 + ΔT × elev + WB × elev + WB × northness |

- 補助 (判断に使わない): M7 = M1 + Ts(t − 1) + Ts(t − 2) + Tsp (前のプロジェクトの形)。B の評価だけで、M1y = M1 + 年の切片 (その年の学習側の地点の観測から年の揃いを借りる。調査がある年の内挿の参考)。
- 高次元の機械学習と、特徴量の自動選択は使わない。

## 評価の分け方 (A、B、C)

全ての分け方で、同じ分け方の中では、全てのモデルを同じ行 (全てのモデルの特徴量がそろう行) で採点する。

- A 未知の年: 年を 1 つずつ伏せる。t を試験するとき、学習から t と t + 1 の行を除く (t + 1 の行の F_lag が t の評価を含むため)。地点は学習と試験の両方にある。
- B 未知の地点: 空間のブロック。EPSG:6691 の 50 km 四方の格子で地点をブロックに分け、ブロックを 5 つの fold に無作為に割る (repeat 10 回、種 0〜9)。試験の fold の地点から 15 km 以内の地点は学習から除く (緩衝帯。AgERA5 の 1 つのセルの対角 約 13 km より広くし、同じセルの気象を学習と試験で共有しないため)。年は学習と試験の両方にある。
- C 未知の地点 × 未知の年: B の fold と A の年の組。fold f と年 t を試験するとき、学習は fold f と緩衝帯の外の地点の、年が t でも t + 1 でもない行。試験は fold f の地点の t の行。
- 開発期間 (B1) では、A、B、C のどれも、開発期間の行だけで学習し採点する。

## 指標と不確かさ

- 主の指標: RMSE (評価 0〜3)。補助: MAE、Spearman の順位相関。
- B と C の repeat: 各行は repeat ごとに 1 回試験される。行ごとの二乗誤差を repeat で平均してから、指標と差を計算する。
- 不確かさ: 試験の年を単位にした復元抽出 (同じ年の全ての地点を一緒に動かす。2,000 回、種 0) で、RMSE の差の 90% 区間。同じ年の地点どうしは共通の年の揺れを受けるので、地点 × 年を独立に扱わない。

## 区画

### B0: 健全性 (sanity)

- 目的変数: 98 地点 × 20 年の評価の数 (0〜3 の 1,843 セル、-1 と NULL を除く。2026-10-28 の実測) と、年ごとの有効な地点の数。北海道の 4 地点を読んでいないこと。
- 地形: Mapterhorn の標高と Dryad の Altitude の差の分布。|差| > 100 m の地点は、補わずに記録に挙げる (位置か標高のどちらかの食い違い)。
- 気温と水分: 98 地点のセルが地点を含むこと、1981〜2010 年と 1988〜2008 年の全ての月に値があること (NULL を数える)。AgERA5 の Ts(y) と Dryad の T.HSM の地点 × 年の相関 (同じ夏の暑さを測っているかの照合。目的変数ではない)。
- 分け方: fold ごとの学習、試験、緩衝帯で除いた地点の数。

### B1: 開発期間での選択 (exploratory)

- mode: exploratory。開発期間 (t = 1990〜1999) の行だけ。
- 選ぶもの (4 通りだけ): 地形の半径 r (300 m、1,000 m) × 水分の版 (w1、w2)。
- 選び方: C の分け方での M5 の RMSE が最小の組。差が 0.001 未満なら、r は 1,000 m、水分は w1 (項の少ない方)。
- G* の選び方: 選んだ組で、C の分け方の RMSE が M4 と M5 で小さい方。差が 0.001 未満なら M4。
- 選んだ結果をファイル (`outputs/b1_frozen_choice.json`) に書き、sha256 を記録してから B2 に進む。
- 補助 (判断に使わない): 開発期間の A、B、C の全てのモデルの RMSE。

### B2: 確認期間 (confirmatory、決め手)

- claim tested: C1、C2、C3、G
- mode: confirmatory (C1 は上の注意により、報告では探索として扱う)。確認期間の行で、地形と水分の特徴量と結果の関係は、どれも計算していない。
- data: 確認期間 (t = 2000〜2008) の行を試験に使う。学習は分け方の規則に従い、開発期間の行も使う。
- observable quantity: 比べる 2 つのモデルの、同じ行での RMSE の差 (前 − 後ではなく、候補 − 比べる相手。負なら候補が良い)。
- comparator: C1 は M1、C2 は M2、C3 は M4、G は M1。
- evaluation: C1 は A、C2 は B、C3 は C (B は補助)、G は B と C の両方。
- uncertainty: 試験の年の復元抽出 (確認期間の 9 年)。年が少なく、区間は広くなる。
- decision rule: 下の「判断の規則」。
- failure interpretation: 退けられたら、この評価と規則のもとで、その特徴量は未知の年や地点の当たりを良くしなかった。救済に使わない変更: 地形の半径の追加、気象の月の範囲、緩衝帯とブロックの大きさ、近い地点の数、モデルの形 (順序のモデル、正則化、機械学習)、行の除き方、期間の分け方。
- alternative explanation: 偶然 (確認期間は 9 年)、空間のリーク (近い地点が学習側にある)、年の揃いだけで当たる (どの地点も同じ年に豊作)。B3 で試す。

### B3: 反証と頑健性 (確認期間、G* で。B2 の結果によらず流す)

- F1 気象の年の並べ替え (C の分け方): 気象の特徴量 (ΔT、P、PET、WB、交互作用はそこから作り直す) の年を、全ての地点でまとめて並べ替える (200 回、種 0)。各年の空間の模様と値の分布は保ち、年との対応を壊す。主張が正しければ、実際の RMSE は並べ替えの RMSE の 5% 点より小さい。気象が年の当たりに効いていない (地形と前年の結実だけで当たっている) なら、並べ替えても変わらない。
- F2 地形の地点の並べ替え (B の分け方): 地形の 6 つの値の組を、地点の間で並べ替える (200 回、種 0)。主張が正しければ、実際の RMSE は並べ替えの 5% 点より小さい。
- 頑健性 (判断に使わない): 緩衝帯 0 km (近い地点のリークがどれだけ点数を良く見せるか)、ブロック 30 km、F_lag の近い地点の数 3 と 10。
- 残差: G* の C の残差の、年ごとの Moran's I (近い 5 地点、行の和を 1 にした重み) の平均と範囲。

## 仮定

- AgERA5 の 0.1 度のセルの年ごとの気温と水分の上下は、林の中の上下に沿う。値の水準は合わなくてよい (偏差を使う)。確かめられない。T.HSM との相関で一部を照合する。
- Dryad の位置 (小数 5 桁が大半) は、評価した林分の位置を示す。地形の 100 m と r の中の値は、その林分の地形を代表する。確かめられない。
- 評価 0〜3 は目視の 4 段階で、間隔の尺度として扱う (最小二乗)。順序のモデルは使わない。
- 地点の数は 98 で、学習の行は数百。モデルの項は最大 15 程度で、行の数に比べて小さい。

## 判断の規則

| claim_id | 区画 | 規則 |
|---|---|---|
| C1 | B2 (A) | RMSE(M2) − RMSE(M1) の 90% 区間の上限 < 0 なら支持。点推定 ≥ 0 なら退ける。それ以外は判断できない |
| C2 | B2 (B) | RMSE(M3) − RMSE(M2) に同じ規則 |
| C3 | B2 (C) | RMSE(M5) − RMSE(M4) に同じ規則 (B の同じ差は補助) |
| G | B2 (B と C) | B と C のそれぞれで、RMSE(G*) − RMSE(M1) の 90% 区間の上限 < 0、かつ repeat 10 回のうち 9 回以上で repeat ごとの差が負。B と C の両方で満たせば支持 (proxy の枝を次の段へ)。どちらかで満たさなければ、地点別の豊凶を環境のラスタから空間に連続な proxy にする仮説は、このデータでは支持されないとして枝を閉じる |
| F1、F2 | B3 | 実際の RMSE < 並べ替えの RMSE の 5% 点なら、その特徴量の効きは並べ替えで壊れる (反証を通る) |

数の閾値 (意味のある最小の差) は置かない。根拠が無い。「安定して」は、年の区間と repeat の符号で決める。

## 流す前に決めたこと

- 決めた日時: 2026-10-28
- 読んだ生のデータ: 98 地点の位置と Altitude (最も近い地点までの距離の中央値 8.0 km、5 km 未満の組 13、10 km 未満の組 55、座標は小数 5 桁が大半)、年ごとの評価の有効な地点の数 (1999 年は 44、2004 年は 84、ほかは 90〜98)。評価の値の分布と豊作の多い年 (2000、1995、2005 年) は reference で読んだ。AgERA5 の水分のコレクションの単位と期間を目録で読んだ。
