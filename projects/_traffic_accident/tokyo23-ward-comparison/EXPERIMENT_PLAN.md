# 計画: 東京 23 区の交通事故の比較

## 問いと使い道

- 問い: 2019〜2025 年の警察記録の人身事故で、東京 23 区は区ごとにどう違うか。量 (人口、道路、面積あたり)、推移、構成 (誰が、どんな道で)、時間、場所の集まり方、死亡事故のそれぞれで、区を並べ、区の型を言葉にする。
- 使い道: 都と区の交通安全担当が、自分の区がどの区と似ていて、どこが違うかを知り、施策を参考にする区を選ぶ材料にする。区ごとの詳しい報告 (`<区>-accident-trends-by-role`) への入口にする。
- 種類: 記述 (比較)。因果の問いは扱わない。区の施策の効果は推定しない。

## 読み方と主の規則

| 言葉 | 主の読み方 | 並べる読み方 | 主にする理由 |
|---|---|---|---|
| 区の事故 | 本票の `市区町村コード` (警察が付けた区) | 点が区の面に入る事故 | 区ごとの分析と、公表の統計の数え方に合わせる |
| 年 | ファイルの年 | なし | 区ごとの分析と同じ |
| 区分 (生活道路、歩行者、自転車、高齢、若い人、夜、交差点、特定小型原付、首都高速) | 区ごとの分析 (台東区の型) と同じ式 | なし | 区ごとの報告と数字を照らせるようにする |
| 量の分母 | 夜間人口 (2020 年国勢調査、jp-admin) | 道路延長 (OSM 2026-08-31 の車道)、面積 | 人口は公表の率の分母。昼の人口と交通量は無いので、都心の区の人口あたりは過大に出る。3 つを並べ、1 つで順位を断定しない |
| 推移 | 2025 年 / 2019 年 の件数の比。Poisson の 95% 区間が重ならない年だけを増えた、減ったと書く | 2022〜2025 年の平均 / 2019 年 | 区ごとの分析と同じ規則 |
| 場所の集まり方 | 区の事故のうち、30 m の地点の上位 15 に入る割合 | 町丁の件数の上位 10% が持つ割合 | 区ごとの分析の地点と同じ選び方 |
| 区の型 | 構成と時間の割合 (下の特徴量) を標準化して k-means と Ward 法の階層で分ける | DPMM で群の数を見る | 量の率は分母の偏りが大きいので型に入れず、型と並べて読む |

型の特徴量 (割合、23 区のそれぞれで同じ式): 歩行者、自転車、高齢の歩行者、若い歩行者・自転車、生活道路 (狭い読み)、夜、交差点、自転車の単独 (自転車 × 相手なし・物件)、事業用の乗用車が当事者 A、貨物車が当事者 A、土日、首都高速。

既知の区分 (型との ARI を見る相手、結果を見る前に決めた): 都心・副都心 (千代田、中央、港、新宿、渋谷、豊島)、東部 (台東、墨田、江東、荒川、足立、葛飾、江戸川)、その他 (文京、品川、目黒、大田、世田谷、中野、杉並、北、板橋、練馬)。

## 主張と区画

| 区画 | mode | 測る量と相手 | 判断の規則 | 悪い結果の意味 |
|---|---|---|---|---|
| C1 量 | exploratory | 年あたりの件数を、人口千人、道路 1 km、面積 1 km² で割った値と、死者の人口 10 万人あたり。3 つの分母の順位の一致 (Spearman) | 分母で順位が大きく変わる区は、どの分母でも上位とは書かない | 量の多寡は分母の選び方で決まる、と書く |
| C2 推移 | exploratory | 区ごとの 2019 年から 2025 年への比と、23 区全体との差 | 区間の規則で、増えた / 減った / 区別できない、の 3 つに分ける | 多くの区が区別できないなら、推移で区を分けない |
| C3 構成と時間 | exploratory | 上の 12 の割合を区ごとに並べ、23 区の平均からの標準化した差 (z) を表と図にする | 標準化した差の絶対値が 1 以上を、その区の目立つ点と書く | |
| C4 場所の集まり方 | exploratory | 上位 15 地点の割合、町丁の上位 10% の割合 | 順位で書く | |
| C5 区の型 | exploratory | k を 2〜6 で k-means と階層、安定性 (8 割の抜き出しの ARI)、手法どうしの ARI、既知の区分との ARI、隣り合う区どうしが同じ群になる割合 (並べ替えと比べる) | 安定性 ARI が 0.6 以上で、2 つの手法の ARI が 0.6 以上の設定だけに群の名前を付ける。満たす設定が無ければ、型は見つからなかったと書き、C3 の目立つ点で区を言葉にする | 23 区は少ないので、群は不安定になりうる |
| C6 区ごとの言葉 | exploratory | C1〜C5 の出力から、区ごとに 2〜3 行の特徴を書く | 出力に数えた値があるものだけを書く。区ごとの報告にリンクする | |

## 流す順

1. 東京の本票と 23 区の面を、区ごとの分析と同じピンで読む。区ごとの件数を、区ごとの分析の yearly.csv と照らす (同じ式なら一致する)。
2. 区分の判定と地点の選び方は、台東区の型の関数をそのまま使う (テスト済み)。新しく書く関数 (標準化、比の区間、群の評価) にテストを書く。
3. C1 から C5 を流し、出力を `outputs/` に置く。
4. 図を描き、report.md と区ごとの言葉 (C6) を書く。

## 仮定と未確認

- 位置の精度は分からない。区の境界の近くの事故は、コードと面で入れ替わる。
- 人身事故だけ。交通量、昼の人口、観光客の数は無い。量の率は危険の高さとは限らない。
- 23 区は 23 の単位しかない。群と順位の差は、偶然で動く。

## 流す前に決めたこと

- 日付: 2026-11-03。これまでに 15 区 (台東、文京、新宿、渋谷、中央、墨田、江東、品川、目黒、中野、大田、千代田、港、世田谷の旧版を含む) の区ごとの報告と、そこに写した 23 区の構成の表 (wards.csv) を読んでいる。各区が 23 区の中の何位かを見たうえで、この計画を書いた。型の特徴量、既知の区分、判断の規則は、群を計算する前に決めた。群、標準化した差、量の 3 つの分母の順位は計算していない。
