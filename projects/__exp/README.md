# __exp: 主題に分けていないプロジェクト

ほかの主題のまとまりに入らない、単発の検証や手法の監査の置き場所。大きな生成物は `artifacts/__exp/<名前>/`。

| プロジェクト | 問い |
|---|---|
| [hokkaido-forest-biomass-survey](hokkaido-forest-biomass-survey/) | 東北海道で、推定 AGB の低下が大きく、森林分類と品質の条件を変えても残る現地照合の候補はどこか |
| [japan-climate-analysis](japan-climate-analysis/) | 日本の月別気候データの地域差、異常月、予測と予測区間を、気候適応計画に使うときの限界 |
| [japan-grid-population-audit](japan-grid-population-audit/) | 格子の人口推計を国勢調査の代わりに使うと、候補地区はどれだけずれるか |
| [record-vs-occurrence](record-vs-occurrence/) | 記録の多い区画と、人口あたりの発生の多い区画は同じか (調査回数の偏り) |
| [tokyo-town-types](tokyo-town-types/) | 東京の地区を統計、POI、街路画像で類型化できるか。`tmp/source` に、ほかのプロジェクトも使う元のコードを置く |
