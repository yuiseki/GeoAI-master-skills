# _benchmark: 定番の課題でスキルの手順を確かめる

新しい種類の手法 (深層学習の切り出し、グラフのニューラルネットワーク、軌跡の予測など) をスキルにする前に、答えの分かっている定番の課題で、論文の数字を再現できるかを確かめるプロジェクトの置き場所。再現できた手順だけをスキルに書く。大きな生成物は `artifacts/_benchmark/<名前>/` に置く。
