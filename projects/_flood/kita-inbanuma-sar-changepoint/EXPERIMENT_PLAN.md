# 計画: 北印旛沼の Sentinel-1 時系列で、画素ごとの変化点を当てる

流す前に書く。流した後に書き直さない。直すなら末尾の「計画の変更」に足す。要らない欄は消さずに「なし: <理由>」と書く。

## 問いと使い道

- 問い: Sentinel-1 の同じ軌道の 2026 年 3〜10 月の撮影を並べ、画素ごとに「平均の明るさが変わった撮影日」を検定で決めると、令和8年台風第25号の浸水は、浸水した所で、浸水の始まった撮影日に、浸水していない農地よりはっきり多く変化点として出るか。水が引いた日も出るか。
- 使い道: 災害の前後の 2 枚を選ぶ代わりに、普段から撮り溜めた時系列で「いつ、どこが変わったか」を自動で拾えるかを確かめる。2 枚の差 (兄弟のプロジェクト [kita-inbanuma-sar-replication](../kita-inbanuma-sar-replication/)) より何が得で、何に弱いかを示す。
- 問いの種類: 記述 (検知の手法の検証)。予測でも因果でもない。国土地理院の浸水推定図も推定なので、比べた数字は推定図との一致度で、真の精度ではない。

## 結果を見る前に知っていたこと

- 撮影 (Planetary Computer sentinel-1-rtc、Sentinel-1C だけ、2026-11-03 に検索): 軌道 39 (上り、08:41 UTC = 17:41 JST) は 17 枚 (3/09〜10/30。6/13、6/25、7/14、10/06 は RTC が無い)。軌道 141 (上り、08:33 UTC) は 20 枚 (3/04〜10/25。6/20 が無い)。
- 推定図の版は 9/22 14 時、9/24 14 時、9/25 11 時、10/01 16 時。軌道 39 の 9/24 と軌道 141 の 10/01 は、どちらも推定図の版と同じ日の 3 時間ほど後の撮影。
- 決壊の時刻は、手元の資料 (国土地理院のページ) に無い。9/22 14 時には浸水していた。軌道 39 の 9/12 は兄弟のプロジェクトで「前」として使い、干拓地は暗くなっていなかった。軌道 141 の 9/19 (17:33 JST) が浸水の前か後かは分からない。
- 兄弟のプロジェクトの結果: 9/12 と 9/24 の 2 枚、VV だけの判定は、9/24 の推定図の浸水域の 61.1 % を水とした。船形干拓の中心部 (10/01 の輪郭線の中) は 89.2〜94.6 %。RTC 版は地図に対して 2 画素ほどずれ、ずれは日によって 0.8 画素ほど違った (9/12 と 9/24 の列で 1.717 と 2.5)。
- 手法の模擬 (scripts/test_cp.py、実データの前に流した): 最初の変化までは日ごとの誤警報が α。誤警報の後は基準がその 1 枚になるので、次の日も「戻った」と判定されやすく、17 枚で日ごとの誤警報は約 1.3 α。ENL を実際より大きく仮定すると、また平均そのものが日ごとに 1 dB (標準偏差) 揺れると、誤警報は 2 α を超える。同じ 3 dB の低下でも、基準が 12 枚なら 1 枚のときより多く検出する。

## 手法

画素ごとに、Conradsen ら (2016) の逐次の尤度比検定 (omnibus test の、強度だけの VV と VH を独立とみなす場合) を、撮影の順に当てる。最後の変化からの n 枚の平均と、次の 1 枚の平均が等しいかを検定し、p 値が α 未満なら、その日を変化点とし、基準をその日から作り直す。p 値は、帰無仮説の下で正確に分かるベータ分布から引いた帰無分布で出す (scripts/cp.py)。変化の向きは、VV のその日と基準の平均の比 (dB) の符号で決める (負 = 暗くなった)。

基準の手法 (baseline): 隣り合う 2 枚の差。前の撮影からの VV か VH の差の絶対値が閾値以上なら変化点。

## 範囲と画素の組

全て RTC の格子 (EPSG:32654、10 m、兄弟のプロジェクトと同じ 27 × 17 km)。どの組からも、WorldCover 2021 のクラス 80 (恒常的な水域) と、その日の値が欠けた画素を除く。

| 組 | 定義 | 役割 |
|---|---|---|
| IN39 | 9/24 14 時の輪郭線の中 | 軌道 39 の浸水した所 |
| IN141 | 10/01 16 時の輪郭線の中 | 軌道 141 の浸水した所 |
| RECEDED | 9/24 の輪郭線の中で、10/01 の輪郭線の外 | 10/01 までに水が引いた所 |
| CTRL | WorldCover 30 (草地) か 40 (農地)、DEM < 10 m、4 版の輪郭線のどれからも 300 m 以上 | 浸水しなかった低地の農地 (同じ季節の農作業や雨の変化を受ける対照) |
| STABLE | WorldCover 10 (樹林)、DEM ≥ 15 m、輪郭線から 300 m 以上 | 台地の林 (変化の少ないはずの所、誤警報の目安) |

## 区画

### B0: 実データでの誤警報 (sanity)

- claim tested: C0
- mode: confirmatory。変化の検定は実データでまだ流していない
- data / analysis unit: 軌道 39 と 141 の RTC、画素 (10 m)。STABLE の画素
- observable quantity: 浸水の前の各撮影日 (軌道 39 は 9/12 まで、軌道 141 は 9/07 まで) の、変化点のある画素の割合の平均
- comparator / control: 模擬の誤警報 (scripts/test_cp.py の test_false_alarms_come_in_pairs と同じ設定で、その軌道の枚数で模擬した値)
- evaluation population / split principle: STABLE の全画素。分けない (評価に学習が無い)
- primary metric: 日ごとの割合の平均 ÷ 模擬の誤警報
- uncertainty: 画素どうしは空間に相関するので区間を付けない。日ごとの割合を並べて報告する
- planned settings: α = 0.01、ENL は下の決め方
- decision rule: 比が 2 以下なら支持。2 を超えたら退ける
- failure interpretation: 退けたら、台地の林でも仮定 (一定の ENL、時間で変わらない平均) が崩れていて、変化点の数をそのまま誤警報の率として読めない。C1〜C4 は判断するが、B0 の結果を添える。α や ENL を結果を見てから変えて救済しない
- alternative explanation being tested: ENL の誤り、植生の水分の揺れ、日ごとの位置のずれ
- falsification / robustness: 頑健性の表 (下) の ENL の 3 段
- priority / run order: sanity、順番 1

### B1: 軌道 39 の浸水の始まり (decisive)

- claim tested: C1
- mode: confirmatory
- data / analysis unit: 軌道 39 の 17 枚、画素
- observable quantity: IN39 の画素のうち、9/24 に暗くなる変化点がある割合 (p_in)。CTRL の画素の同じ割合 (p_ctrl)
- comparator / control: CTRL (同じ日の、浸水しなかった低地の農地)
- evaluation population / split principle: IN39 と CTRL の全画素
- primary metric: p_in
- uncertainty: 区間を付けない (画素の相関)。頑健性の表で設定を変えた値を並べる
- planned settings: α = 0.01、VV と VH、ENL は下の決め方、3/09 からの全ての撮影
- decision rule: p_in ≥ 0.5 かつ p_in ≥ 3 p_ctrl なら支持。どちらかを外れたら退ける。0.5 は、兄弟のプロジェクトの 2 枚の VV だけの判定 (61.1 %) より 10 ポイント以上悪くないこと。3 倍は、変化点の多くが浸水によるもので、季節の変化の上乗せでないこと
- failure interpretation: p_in が低ければ、9/24 より前の基準が短い (夏の農作業で基準が作り直される) か、浅い浸水で暗くならない。p_ctrl が高ければ、9/24 の変化点は浸水の印として弱い (同じ日に稲刈りや大雨で変わる)。α、ENL、組の定義を変えて救済しない
- alternative explanation being tested: 季節の農作業と大雨による変化 (CTRL)、誤警報 (B0)
- falsification / robustness: CTRL が反証の対照。頑健性の表
- priority / run order: decisive、順番 2

### B2: 軌道 141 での再現 (decisive)

- claim tested: C2
- mode: confirmatory
- data / analysis unit: 軌道 141 の 20 枚、画素
- observable quantity: IN141 の画素のうち、9/19 か 10/01 に暗くなる変化点がある割合 (p_in)。CTRL の同じ割合。9/19 と 10/01 の内訳
- comparator / control: CTRL
- evaluation population / split principle: IN141 と CTRL の全画素
- primary metric: p_in
- uncertainty: B1 と同じ
- planned settings: B1 と同じ
- decision rule: B1 と同じ規則 (p_in ≥ 0.5 かつ p_in ≥ 3 p_ctrl)。日を 2 つ合わせるのは、9/19 が浸水の前か後かを知らないため。内訳は記述として報告し、判断に使わない
- failure interpretation: B1 は支持で B2 が退けられたら、軌道 39 の結果は撮影の条件に依る
- alternative explanation being tested: 撮影の向き (軌道) による見え方の違い
- falsification / robustness: 頑健性の表
- priority / run order: decisive、順番 3

### B3: 水が引いた日 (decisive)

- claim tested: C3
- mode: confirmatory
- data / analysis unit: 軌道 39、画素
- observable quantity: RECEDED の画素で 9/24 に暗くなる変化点がある画素のうち、10/18 に明るくなる変化点がある割合
- comparator / control: CTRL の画素で 9/24 に暗くなる変化点がある画素の、10/18 に明るくなる割合 (参考。判断には使わない)
- evaluation population / split principle: 上の画素
- primary metric: 上の割合
- uncertainty: B1 と同じ
- planned settings: B1 と同じ
- decision rule: 0.5 以上なら支持
- failure interpretation: 水が引いた後も、泥、倒れた稲、湿った土で暗いままの所が多い。時系列の変化点で「引いた日」を決めるには、10/18 の 1 枚では足りない
- alternative explanation being tested: 浸水の後の地面の状態
- falsification / robustness: 頑健性の表
- priority / run order: decisive、順番 4

### B4: 隣り合う 2 枚の差との比較 (decisive)

- claim tested: C4
- mode: confirmatory
- data / analysis unit: 軌道 39、画素
- observable quantity: IN39 の、9/24 に変化点がある割合 (向きを問わない)。時系列の検定と、隣り合う 2 枚の差
- comparator / control: 隣り合う 2 枚の差 (VV か VH の差の絶対値が閾値以上)
- evaluation population / split principle: 閾値は、STABLE の浸水の前の日 (9/12 まで) の、日ごとの変化点の割合の平均が、時系列の検定と等しくなる値に決める (0.01 dB 刻み)。IN39 は閾値の決定に使わない
- primary metric: 割合の差 (時系列の検定 − 2 枚の差)
- uncertainty: B1 と同じ
- planned settings: 時系列の検定は B1 と同じ
- decision rule: 差が 0.05 以上なら支持。それ未満なら退ける
- failure interpretation: 退けたら、この浸水のような大きな変化では、時系列を撮り溜めても 2 枚の差より多くは拾えない
- alternative explanation being tested: 誤警報の率の違いによる見かけの差 (率をそろえて除く)
- falsification / robustness: 閾値を CTRL でそろえた版も並べる (判断には使わない)
- priority / run order: decisive、順番 5

## ENL の決め方 (結果を見る前に固定)

ENL は、scripts/03_quality.py の enl_ratio (CTRL と同じ定義の低地の農地の、10 × 10 画素の区画の、隣り合う 2 枚の比の対数の分散から逆算した L) の、両方の軌道、全ての日、両方の偏波の中央値とする。比をとると、時間で変わらない模様 (texture) が消えるので、区画の中の不均一さで ENL が小さく出る誤りを避けられる。区画の中で実際に変化した所があると小さく出る (保守的、誤警報が減る向き)。値は小数点以下 1 桁に丸める。

## 頑健性 (結果を見る前に固定、判断には使わない)

| 設定 | 主分析 | 代わり |
|---|---|---|
| α | 0.01 | 0.001、0.05 |
| ENL | 上の決め方 | 0.75 倍、1.25 倍 |
| 偏波 | VV と VH | VV だけ |
| 時系列の始まり | 3 月から全て | 7 月から (基準の短い場合) |
| 位置のずれ | 全ての画素 | WorldCover のクラスの境界から 20 m 以内の画素を除く |

## 仮定

- 確かめられる: 日ごとの位置がそろっている (03_quality.py の coreg で測る。0.5 画素を超える日があれば報告し、頑健性の境界を除く版で効き方を見る)。STABLE で誤警報が α の近くに収まる (B0)。
- 確かめられない: 推定図の浸水域が真の浸水域であること。推定図の撮影時刻 (14 時、16 時) と衛星 (17 時半ごろ) の間の変化。

## 関門

- 座標と距離: 全て EPSG:32654 の 10 m 格子。300 m と 20 m の距離は格子の上で測る。
- 量と水準: 割合は画素の数の比 (面積の比)。足し合わせない。
- 空間の依存: 画素は隣と似る (スペックルの相関は 03_quality.py の corr で測る)。割合に区間を付けず、面積の比として書く。
- 基準: 隣り合う 2 枚の差 (B4)、CTRL、模擬の誤警報。
- MAUP: 単位はセンサーの画素で、分析者が選んだ集計の単位ではない。結論は推定図の輪郭線の中の面積の比で、格子の大きさの掃引は流さない。
- 報告: 画素の変化点を、個々の圃場や建物の浸水として書かない。推定図との一致度で、真の精度ではないと書く。
