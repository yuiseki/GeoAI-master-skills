# 計画: 令和元年東日本台風 (台風第 19 号) の東京の浸水を Sentinel-1 で見て、浸水実績図と A31a に突き合わせる

## 問いと使い道

- 問い: 2019-10-12〜13 の台風第 19 号で、東京都の浸水実績図に記録された浸水の区域は、雨の止んだ約 7 時間後 (10-13 05:43 JST) の Sentinel-1 で、変わらなかったはずの所より多く「暗くなった」(水面になった) か。記録された区域の半分以上を拾えるか。SAR が暗くなった所は、A31a (洪水浸水想定区域、想定最大規模) の区域に寄るか。
- 使い道: 大雨の直後に、無料の SAR で「どこが浸水したか」を見積もり、浸水実績の記録や浸水想定と突き合わせられるかを確かめる。外れるなら、どんな所 (市街地の内水、河道) で外れるかを記録する。GeoAI-flood の最終目的 (浸水実績から作る予測と A31a の比較) で、SAR を浸水の観測として足せるかの下調べでもある。
- 問いの種類: 記述 (検知の手法の検証)。予測でも因果でもない。浸水実績図は「おおよその区域」(配布元の注記) で、真の浸水の全部ではない。比べた数字は記録との一致度で、真の精度ではない。

- 雨 (気象庁の時間雨量、jma-rain-tokyo): 世田谷、府中、八王子、東京などで 10-12 の 6 時から 21 時まで 1 時間に 2〜40 mm、22 時に 2〜13 mm、23 時に 0〜3 mm、10-13 の 0 時から 6 時は 0 mm。10-12 17:41 の撮影は雨の最中、10-13 05:43 は雨が止んで約 7 時間後。

- 外の知識 (確かめていない): 台風第 19 号では、多摩川の水位が上がり、世田谷区玉川や狛江市などで排水の樋門から逆流した内水と、無堤部からの溢水があったと報じられた。市街地の浸水は、SAR では建物と水面の二回反射でかえって明るくなることがあると知られている。
- SAR の画素の値はまだ読んでいない。

## 範囲と画素の組

格子: EPSG:32654、10 m。箱は経度 139.18〜139.70、緯度 35.55〜35.75 を UTM に移した外接の箱を 10 m に外へ丸めたもの (scripts/common.py)。画素の組は、画素の中心で決める。全ての組は東京都 (N03、2026-01-01、都道府県コード 13) の中、WorldCover 2021 のクラス 80 (恒常的な水) でない画素に限る。

| 組 | 定義 | 役割 |
|---|---|---|
| REC | 2019 年の浸水実績の面 (85) に中心が入る画素 | 記録された浸水 |
| CHANNEL | OSM の多摩川 (waterway=river、name=多摩川) の中心線から 300 m 以内で、A31a の想定最大規模のどの区域にも入らず、REC でない画素 | 河道。堤防の間の高水敷は大雨で水をかぶったはずなので、手法が水を見られるかの陽性の対照 |
| A31A | A31a の想定最大規模のどれかの区域に入り、REC でも CHANNEL でもない画素 | 想定の区域で、記録の無い所 |
| CTRL | A31a の区域にも CHANNEL にも入らず、2019 年の記録の面から 300 m 以上離れた画素 | 浸水しなかったはずの所 (同じ日、同じ撮影の条件) |

## 手法

- 前の平均: 同じ軌道の雨の前の撮影 (軌道 46 は 6 回、軌道 39 は 7 回) の線形の強度の平均。後: 雨の後の 1 回。それぞれ 3 × 3 画素の箱で平滑化 (nan を除いた平均) してから比をとる。
- 変化: ΔVV = 10 log10 (後 / 前の平均)、VV。暗くなった = ΔVV ≤ −3 dB。明るくなった = ΔVV ≥ +3 dB。
- 主分析の撮影は軌道 46 の 10-13 05:43。軌道 39 の 10-12 17:41 (雨の最中) は同じ手順の記述として並べる。
- 土地被覆の標準化: 組によって土地被覆の割合が違う (REC は市街地が多いはず) ので、CTRL の率は、WorldCover のクラスごとの CTRL の率を REC (または比べる組) のクラスの割合で重み付けして足す (直接法)。CTRL の画素が 1,000 に満たないクラスは、そのクラスを両方から除き、除いた割合を書く。
- 区間: 画素は隣と似るので、画素を独立に引き直さない。REC は 8 近傍でつながった塊を単位に、CTRL と CHANNEL と A31A は 1 km のブロックを単位に引き直す (2,000 回、種 0)。90 % 区間を添える。判断は点の値で行う。
- 位置: 各軌道の前の平均の VV (dB) と WorldCover の水 (80) の面を位相相関で比べ、ずれを測る。どちらかの向きで 1 画素を超えたら、主分析ではその軌道の全ての撮影を整数の画素だけ戻してから比をとり、戻さない版を頑健性に並べる。
- 衛星の違い: 軌道 46 の後は S1B、前は S1A。CTRL の ΔVV の中央値を報告する。主分析では補正しない。補正した版 (CTRL の中央値を引く) を頑健性に並べる。

## 区画

### B0: 河道の陽性の対照 (decisive、関門)

- claim tested: C0
- mode: confirmatory
- data / analysis unit: 軌道 46、前の 6 回と 10-13 05:43、画素
- observable quantity: CHANNEL の暗くなった画素の割合 p_ch、CTRL の CHANNEL の土地被覆で標準化した率 p_ctrl_ch
- comparator / control: CTRL
- evaluation population / split principle: 組の全画素。分けない (学習が無い)
- primary metric: p_ch と p_ch / p_ctrl_ch
- uncertainty: 1 km ブロックの引き直しの 90 % 区間
- planned settings: 3 dB、3 × 3
- decision rule: p_ch ≥ 0.3 かつ p_ch ≥ 3 p_ctrl_ch なら支持
- failure interpretation: 退けたら、雨の 7 時間後には高水敷の水が引いていたか、草地の水面が風や植生で暗く出なかったか、手順が水を見られない。C1〜C4 は「見えなかった」としか読めない
- alternative explanation being tested: 雨の後はどこでも暗くなる (CTRL)
- falsification / robustness: 頑健性の表
- priority / run order: decisive、順番 1

### B1: 記録された浸水の検出 (decisive)

- claim tested: C1、C2
- mode: confirmatory
- data / analysis unit: B0 と同じ
- observable quantity: REC の暗くなった画素の割合 p_rec、CTRL の REC の土地被覆で標準化した率 p_ctrl_rec
- comparator / control: CTRL
- evaluation population / split principle: 組の全画素
- primary metric: p_rec / p_ctrl_rec (C1)、p_rec (C2)
- uncertainty: REC は塊の、CTRL は 1 km ブロックの引き直しの 90 % 区間

## 仮定

- 確かめられる: 日ごとの位置がそろっている (位相相関)。S1A と S1B の明るさの差が小さい (CTRL の中央値)。

## 関門

- 座標と距離、面積: SAR は EPSG:32654 の 10 m 格子。記録 (EPSG:4612)、A31a (EPSG:6668)、N03、OSM は経緯度から UTM に移して画素の中心で判定する。300 m、1 km は UTM の上で測る。面積は画素の数 × 100 m²。
- 量と水準: 率は画素の数の比 (面積の比)。標準化は率の重み付きの平均で、足し合わせない。
- 空間の依存とリーク: 画素は隣と似るので、塊とブロックで引き直す。学習が無く、閾値は結果を見る前に決めたのでリークは無い。
- 基準と雑音の上限: CTRL (標準化)、無作為 (リフト 1)。記録の面の位置の雑音の上限は測れないと書く。
- 残差と頑健性: 頑健性の表。MAUP: 画素は SAR の格子で決まり、結論は面積の比なので単位の掃引は流さない。平滑化の大きさは頑健性で変える。
- 報告: 一致度で、真の精度ではないと書く。1 つの台風、1 つの撮影の結果で、ほかの大雨に一般化しない。暗くなった所を「浸水した」と断定しない。
