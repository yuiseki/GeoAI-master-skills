# 計画: 局所の時間雨量で、床上浸水の割合は跳ね上がるか。気象庁の雨量は、雨量計からどの距離で強い雨を見落とすか

流す前に書く。流した後に書き直さない。直すなら末尾の「計画の変更」に足す。問いと予想は [proposal](../../../evals/curriculum/proposals/2026-10-30-tokyo-overfloor-flood-transition.md) (2026-10-30) のもの。

## 問いと使い道

- 問い: 東京都の浸水実績 (1974〜2019 年) で、都の雨量計の最大時間雨量が強い記録ほど、浸水した建物のうち床上浸水の割合は高いか。その跳ね上がりは、一部の災害や期間に偏らずに見えるか。あわせて、気象庁の観測所の雨量が強い雨を見落とす割合は、観測所からの距離で変わるか。
- 使い道: 区市町村の水防の担当者が、止水板や床上浸水の対策の助成を、時間雨量のどの強さを基準に考えるかを決める。気象庁の観測所だけで警戒を判断してよい範囲を決める。
- 問いの種類: 記述と関連。雨量と被害の比は、地域、時代、排水の整備の違いを含んだままの関連で、因果は主張しない。

## 結果を見る前に知っていたこと

proposal の pilot は、全期間をまとめた次の数字を出している。これらは既に見た結果なので、同じ切り方を確かめても新しい証拠にならない。この計画は、pilot で見ていない切り方 (期間ごと、災害ごとの再標本化、1 つの災害を抜く、距離) で試す。

- 23 区の内水で、時間雨量 70 mm/h 以上の記録は床上の割合が 40.1%、それ未満の帯は 17%〜20%。
- 23 区の溢水では、30 mm/h 未満の記録でも床上の割合が 78.0%。
- 都の雨量計で 50 mm/h 以上の災害日 51 日のうち、気象庁の本土 11 観測所のどこでも 50 mm/h に届かなかった日が 26 日。

下調べ (結果ではない) で分かったことは次のとおり。

- 入力は tokyo23-flood-record-vs-a31a の 01_fetch.py が固定版で取ったもの。浸水実績は tokyo-flood-record-jp@354b0d9 の flood_area (5,845 行)、気象庁は jma-rain-tokyo@4391f76 の daily と stations。
- 次の 7 列で束ねると 2,249 の調査単位になる: layer、munic、dis_name、dis_date_s、district (無ければ district0)、area、tot_bldg。そのうち dis_date_s の無い単位は 197。

- 気象庁の本土 (緯度 35.5 度以上) で、時間最大雨量が全期間にあるのは 10 観測所 (調布は 1976 年に終わる)。
- 23 区の内水の単位は前半 (1974〜1996 年) 1,048、後半 (1997〜2019 年) 280。後半の災害日は 41 日。

## 測り方 (結果を見る前に固定)

### 単位と値

- 単位: 上の 7 列で束ねた調査単位。dis_date_s の無い単位は除く。
- 雨量: nro_60min の先頭の数値。`(280)` のように括弧で始まる値、`-` と空は欠測とする。単位の中で値が違うときは最大を使う。
- 棟数: utf_bldg (床下) と otf_bldg (床上) の先頭の整数。読めなければ 0。単位の中では最大を使う。
- 床上の割合: 帯の中の otf の合計 ÷ (utf + otf の合計)。床上と床下の両方が 0 の単位は分母に入らない。
- 23 区: munic が「区」で終わる単位。内水: reason が「内水」に一致。溢水: reason に「溢水」を含む (「内水溢水」なども含む)。
- 期間: dis_date_s の年が 1996 年以前を前半、1997 年以降を後半とする。

### 再標本化

- 災害日 (dis_date_s) を単位に、復元抽出で 2,000 回 (seed 0)。90% 区間は百分位。
- 同じ日の記録は同じ雨の中にあるので、記録を独立に数えない。

### 気象庁の雨量 (B3)

- 雨量計の事象: dis_date_s、nro_name、雨量の組で束ねる。nro_flag が 0 (その区市町村の中の雨量計) の単位だけを使う。位置は事象に属する単位の面の重心の平均。
- 最寄りの観測所: 緯度 35.5 度以上で、dis_date_s から dis_date_e (無ければ dis_date_s) の間に max1h_mm がある観測所のうち、位置に最も近いもの。距離は球面で測る。
- 見落とし: 最寄りの観測所のその期間の max1h_mm の最大が 50 mm/h 未満。
- 近いと遠い: 使う事象の距離の中央値で 2 つに分ける。中央値ちょうどは近い側。

## 区画

### B1: 70 mm/h での床上の割合の跳ね上がり (C1)

- 対象: 23 区の内水で、雨量の読める単位。
- 値: 床上の割合の差 d = (70 mm/h 以上) − (70 mm/h 未満)。参考に 30、50 mm/h で区切った 4 つの帯の割合も出す。
- 支持の条件 (全てを満たす):
  1. 災害日の再標本化で、d の 90% 区間の下限が 0 より大きい。
  2. 前半と後半のそれぞれで d > 0。どちらかの期間で 70 mm/h 以上の単位が 5 未満なら、その期間は「判定できない」とし、C1 は支持にしない。
  3. 災害日を 1 日ずつ抜いた d の最小が 0 より大きい。
- 退ける: 1 の区間の上限が 0 以下、または 2 で片方の期間の d が 0 以下。それ以外の不成立は「判定できない」。

### B2: 溢水と内水の床上の割合 (C2)

- 対象: 23 区で雨量が 50 mm/h 未満の単位。
- 値: 床上の割合の差 (溢水 − 内水)。
- 支持の条件: 災害日の再標本化の 90% 区間の下限が 0 より大きく、前半と後半のそれぞれで差 > 0。
- 退ける: 区間の上限が 0 以下。

### B3: 気象庁の見落としと距離 (C3)

- 値: 遠い側の見落としの割合 − 近い側の見落としの割合。全体の見落としの割合も出す。
- 再標本化は雨量計の事象の日で行う。
- 支持の条件: 差の 90% 区間の下限が 0 より大きい。
- 退ける: 区間の上限が 0 以下。区間が 0 をまたげば「判定できない」。

## 頑健性

主張の判定には使わず、並べて報告する。

- 束ねずに元の行で数えた場合。
- nro_flag が 0 の単位だけの場合 (B1、B2)。
- 床上の割合を、単位ごとの割合の平均で数えた場合 (大きな単位の重みを外す)。
- 跳ね上がりの境を 60 mm/h、80 mm/h にした場合 (B1)。

## 仮定

- nro_60min は、記録に書かれた雨量計の、その災害の最大の時間雨量とみなす。何分おきの移動窓かは記録に無い。気象庁の max1h_mm は 10 分おきの移動窓で、窓の取り方の違いは差に含まれる。
- 浸水実績は、都が集めた被害の記録で、全ての浸水を網羅しない。年代で集め方が違いうる。
