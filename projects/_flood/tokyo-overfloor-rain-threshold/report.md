# 局所の時間雨量と床上浸水の割合、気象庁の雨量の見落とし

## 問い

東京都の浸水実績 (1974〜2019 年) で、都の雨量計の時間雨量が 70 mm/h 以上の記録は床上浸水の割合が跳ね上がるか、気象庁の観測所が強い雨を見落とす割合は観測所から遠いほど高いか。

## 結論

- C1 (70 mm/h での跳ね上がり) は計画の規則では支持だが、跳ね上がりの大半は期間の違いで説明できる。23 区の内水 1,250 単位で、床上の割合の差 (70 mm/h 以上 − 未満) は 0.21 [0.02, 0.33] で、どの 1 日を抜いても 0.13 より大きい。しかし期間ごとに見ると、前半は 0.002 [−0.10, 0.11]、後半は 0.085 [0.017, 0.21]。期間をそろえた差は 0.047 [−0.02, 0.15] で、区間が 0 をまたぐ。
- 期間の違いとは次のことを指す。後半は全ての帯で床上の割合が高く (全帯で 0.53、前半は 0.18)、70 mm/h 以上の 138 単位のうち 74 単位が後半にある。全期間をまとめると、後半の高さが 70 mm/h 以上の帯に集まって見える (図 1)。proposal の「70 mm/h で床上の割合が倍増する」は、期間をまとめた数え方の結果と読むのが妥当。
- C2 (溢水は内水より床上の割合が高い) は計画の規則では支持。50 mm/h 未満の 23 区で、差は 0.29 [0.09, 0.48]。ただし差は前半 (0.31 [0.10, 0.49]) のもので、後半は 0.03 [−0.03, 0.13] と区別できない。
- C3 (気象庁の見落としは遠いほど多い) は判定できない。都の雨量計が 50 mm/h 以上を記録した 119 の事象で、最寄りの気象庁の観測所が 50 mm/h に届かなかったのは 54% [42%, 67%]。距離の中央値 6.1 km より遠い側は 61%、近い側は 47% で、差 0.14 [−0.01, 0.28] は 0 をわずかにまたぐ。本土の観測所のどこでも 50 mm/h に届かなかった事象は 30%。
- 使い道への答え: 70 mm/h を床上浸水の対策の境として使う根拠は、この記録からは弱い。同じ期間の中では、雨の強さで床上の割合はほとんど変わらないか、変わっても小さい。気象庁の観測所だけで警戒を判断すると、都の雨量計の 50 mm/h 以上の半分ほどを見落とす。距離 6 km の内側でも半分近くを見落とす。

### 頑健性

| 読み方 | 結果 |
|---|---|
| nro_flag が 0 の単位だけ | B1 の差 0.24、前半 0.046、後半 0.019 で規則の上では支持。B2 は後半が −0.02 で判定できない |
| 境を 60 mm/h | 後半の差が −0.001 で、規則の上では退ける |
| 境を 80 mm/h | 支持。ただし前半の 80 mm/h 以上は 13 単位、3 日だけ |
| 単位ごとの割合の平均 | 差 0.14 [−0.01, 0.26]、前半 −0.03、後半 0.13 |

境を 60、70、80 mm/h と動かすと、規則の判定が入れ替わる。跳ね上がりの位置が決まっていないことと合う。

## データ

| データ | 版 | 使ったこと |
|---|---|---|
| tokyo-flood-record-jp | 354b0d9 の flood_area (5,845 行) | 調査単位、雨量計の時間雨量 (nro_60min)、床下と床上の棟数、浸水の原因 |
| jma-rain-tokyo | 4391f76 の daily と stations | 本土の観測所の日の最大 1 時間雨量 |

## 方法

- 調査単位: 分割して収録された面を、layer、区市町村、災害名、開始日、地区、面積、総棟数の 7 列で束ねた。日付のある単位は 2,052。
- 床上の割合: 帯の中の床上の棟数の合計 ÷ (床上 + 床下の合計)。
- 区間: 災害日を単位に、復元抽出で 2,000 回引き直した 5% 点と 95% 点。同じ日の記録は同じ雨の中にあるので、独立に数えない。
- 気象庁: nro_flag が 0 (区市町村の中の雨量計) の事象ごとに、面の重心から最も近く、災害の期間に値のある本土の観測所を選び、その期間の最大 1 時間雨量を比べた。
- 計画: [EXPERIMENT_PLAN.md](EXPERIMENT_PLAN.md) (流す前に固定。期間の中の差は結果の後に足した探索で、計画の変更に記録)。記録: [EXPERIMENT_TRACKER.md](EXPERIMENT_TRACKER.md)。結果: [outputs/blocks.json](outputs/blocks.json)、[outputs/within_period.json](outputs/within_period.json)。

## 確かめていないこと

- 後半に床上の割合が高い理由。後半は記録の数が少なく (23 区の内水は前半 1,048 単位、後半 280 単位)、軽い床下浸水を記録しなくなった、調査の仕方が変わった、半地下の建物が増えた、などの説明がありうるが、どれも試していない。
- 雨量計の時間雨量の窓の取り方。nro_60min が何分おきの移動窓かは記録に無く、気象庁の 10 分おきの移動窓との違いは、見落としの割合に含まれる。
- 見落としは、浸水が起きた事象だけで数えている。浸水が起きなかった強い雨は記録に無いので、気象庁の観測所が強い雨一般をどれだけ見落とすかは、この記録からは分からない。
- 棟数の括弧付きの値 (`12(2)` など) の括弧の中の意味は確かめず、先頭の数を使った。
