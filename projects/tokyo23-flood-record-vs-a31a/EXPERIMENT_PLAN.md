# 計画: 23 区の浸水の起こりやすさの地図と、国の洪水浸水想定 (A31a) の比較

流す前に書く。流した後に書き直さない。直すなら末尾の「計画の変更」に足す。

## 問いと使い道

- 問い: 東京 23 区の 100 m のセルごとに、標高、河川、土地被覆、雨から「浸水が記録されやすい場所」を予測する地図を作り、後の期間に記録された浸水を、国土数値情報の洪水浸水想定区域 (A31a) と同じ面積の予算でどれだけ捉えるかを比べる。
- 使い道: 浸水への備え (点検、周知、対策) の重点を 23 区のどこに置くかを決めるとき、A31a の区域だけを見ればよいか、記録から学んだ地図が別の場所を教えるかを判断する。重点にできる面積は限られるので、評価は面積の予算での捕捉率 (capture@k) で行う。未来の浸水を当てる使い道なので、評価は時間で分ける (前の期間で学び、後の期間で試す)。
- 問いの種類: 予測 (と、既存の地図との比較)。因果の主張はしない。特徴量の効き方を原因と書かない。

## 前提として読んだこと (結果ではない)

- 浸水実績 (tokyo-flood-record-jp、354b0d9) のうち 23 区の面と交わる面は 4,759、42 年。原因は 内水 4,116、溢水 344、両方 248 など。1981〜1993 年に多く、1995 年以降は 1999、2004、2005 年を除いて年に 40 面未満。
- A31a (ksj-a31a-flood-tokyo23、5b22592) は河川の氾濫 (外水) の想定で、内水を含まない (配布元)。記録の大半は内水なので、A31a が記録を捉えないことは、A31a の誤りを意味しない。比較は「記録された浸水に対して、どちらの地図が重点の置き場所として当たるか」に限って書く。
- 雨 (jma-rain-tokyo、4391f76) の本土の観測所は 11 (23 区の中は 5)。1974〜1975 年は東京の 1 地点だけ。

## 区画

### B1: 静的な地図 対 A31a (決め手)

- claim tested: C1
- mode: confirmatory。決め手の結果 (試験の期間の捕捉率) は見ていない
- data / analysis unit: 23 区の中心が区の面に入る 100 m セル (EPSG:6677)。陽性は、試験の期間 1997〜2019 年の記録の面と交わる (重なりの面積が正の) セル
- observable quantity: capture@k_A。k_A は A31a 想定最大規模の区域 (浸水深のランクを問わない) に中心が入るセルの割合
- comparator: A31a 想定最大規模の区域 (区域の中を浸水深の最大ランクで並べ、計画規模、乱数の順で同点を崩す)。でたらめ (= k)。標高の低い順。学習の期間の記録の密度
- evaluation population / split principle: 学習 1974〜1996 年、試験 1997〜2019 年。全ての地図を同じセル、同じ陽性で採点する
- primary metric: capture@k_A。補助に capture@1%、5%、10%、20%、件数 (面の数) で数えた捕捉、AUC
- uncertainty: 2 km 四方のブロックを 1,000 回引き直し、上位を決め直した差の 90% 区間 (種 0)
- planned settings: HistGradientBoosting の分類 (scikit-learn、既定の設定、max_iter 300、種 0〜4 の 5 つの平均の順位)。特徴量は下の「特徴量」の固定の一覧。A31a は特徴量に入れない
- decision rule: 差 (モデル − A31a) の点の推定が正で 90% 区間が 0 を含まなければ支持。負で区間が 0 を含まなければ退ける。それ以外は判断できない
- failure interpretation: 退けられたら、この特徴量と単位では、記録から学んだ地図は A31a より重点の置き場所として劣る。救済に使わない変更: 特徴量の追加と削除、セルの大きさ、期間の切れ目、陽性の読み方、ブロックの大きさ、モデルの設定。変えた比較は探索として残す
- alternative explanation: 期間の水準の違い (試験の期間は記録が少ない)、空間の依存による偶然 (ブロックの区間で見る)、単位の選び方
- falsification / robustness: 下の頑健性の表
- run order: decisive、3

### B2: A31a 対 でたらめ

- claim tested: C2
- mode: confirmatory
- 指標と区間は B1 と同じ。比較は capture@k_A − k_A
- decision rule: 90% 区間が 0 を含まず正なら支持、含むなら判断できない、負なら退ける
- 加えて記述: 全期間の記録の面積のうち A31a の区域に入る割合を、原因 (内水、溢水) 別に
- run order: baseline、2

### B3: 雨を足したセル × 年のモデル

- claim tested: C3
- mode: confirmatory
- data / analysis unit: セル × 年 (1976〜2019 年。1974〜1975 年は本土のアメダスが無いので除く)。陽性はその年の記録の面と交わるセル
- 雨の特徴量: セルに最も近い本土の観測所 (その年に値のある所) の、その年の最大 1 時間雨量、最大日雨量、1 時間 30 mm 以上の時間数。距離はセルの中心から観測所まで (平面直角座標)
- comparator: 同じセル × 年で、雨の列を入れない (静的な特徴量と、年の効果も入れない) モデル
- split: 学習 1976〜1996 年、試験 1997〜2019 年
- primary metric: 試験のセル × 年を全てまとめた平均適合率 (AP)。補助に log loss、年ごとの陽性数と予測の合計の順位相関
- uncertainty: 2 km ブロックの引き直し 1,000 回 (年は束ねたまま)
- decision rule: 差 (雨あり − 雨なし) の AP が正で 90% 区間が 0 を含まなければ支持。負で含まなければ退ける。それ以外は判断できない
- failure interpretation: 退けられたら、観測所の雨 (点、まばら) では、年ごとのどこで浸水するかを当てる上乗せが見えない。雨の重要性を否定するものではない (雨の場の解像度が足りない)
- falsification: 雨の列を、観測所ごとに年の間で並べ替えたモデル。値の分布と観測所の違いは保ち、年との対応を壊す。雨が効いているなら、並べ替えたモデルは雨なしと同程度に落ちる。並べ替えても落ちないなら、上乗せは年の対応ではなく、観測所の違い (場所) かモデルの容量から来ている
- run order: decisive、4

### B4: 履歴の上乗せ (探索)

- claim tested: C4
- mode: exploratory
- 学習の期間の記録を、年ごとの総数で割った密度 (セルと周り 300 m、1 km) を特徴量に足す。比較は B1 のモデル。反証は履歴の列をセルの間で並べ替えたモデル
- run order: 5

## 仮定

- 確かめられる: 記録の面の位置は、100 m のセルの判定に足りる (配布元は「おおよそ」とする。250 m、500 m で結論が保たれるかで見る)。
- 確かめられない: 記録の付き方 (調査の努力) が期間と区で同じ。標高 (DEM5A)、河川 (2026 年の OSM)、土地被覆 (2021 年) は記録の時点の状態ではない。今の状態で過去の記録を説明している。
