# 計画: 千城台東の団地の解体を Sentinel-1 の時系列で日付けし、周りのタイルの変化を順位付けする

流す前に書く。流した後に書き直さない。直すなら末尾の「計画の変更」に足す。要らない欄は消さずに「なし: <理由>」と書く。

## 問いと使い道

- 問い A: 千葉市若葉区千城台東 2 丁目の扇形の街区で、低層の集合住宅の棟が全て消えた (地理院の年度別空中写真で、2019 年度にあり 2024 年度に無い)。Sentinel-1 の同じ軌道の時系列に画素ごとの変化点の検定を当てると、この街区で、写真の間の期間に、周りの変わらなかった市街地より多く「暗くなる」変化点が出るか。その日付は、光学の Sentinel-2 から別に決めた日付と合うか。
- 問い B: この街区を含む約 6 km 四方の、ズーム 16 の地理院タイル (1 枚約 500 m 四方) 120 枚を、2019 年度と 2024 年度の SAR の平均の明るさの差で順位付けすると、写真の見比べで「多数の人工物の変化」とした タイルを、上位の少ない枚数で拾えるか。土地被覆だけで決める素朴な順位より多く拾えるか。
- 使い道: オルソ画像を全域で定期的に買い直す代わりに、無料の SAR で「変化の大きかったタイル」を先に絞り込み、そこだけ新しい画像を買う (またはタイルを更新する) 判断に使えるかを確かめる。
- 問いの種類: 記述 (検知の手法の検証)。予測でも因果でもない。正解は写真の見比べと OSM の工事区域で、真の変化の全部ではない。

## 結果を見る前に知っていたこと

- 写真 (scripts/01_fetch_photos.py、2026-11-03 取得): 調べる場所のタイルで年度別空中写真があるのは 2009、2019、2024 年度だけ。2019 年度は棟があり、2024 年度は全て消えて平らな面になっている。撮影日は分からない (地理院の単写真の索引にこの場所の 2019 年度と 2024 年度の写真は無い。2009 年度は 2009-04-23)。
- 正解 (labels/labels.csv、SAR の値を読む前に付けてコミット 9893775): 120 タイルのうち 2 が 18、1 が 17、0 が 85。両端の列 24 枚は写真が片方の年で欠けるので除いた。
- 場所の輪郭 (labels/site.geojson): OSM の way 1423054131 (landuse=construction、construction=commercial、版 1、2025-08-18 の編集)。棟が消えた扇形の街区の一部 (南西寄り) で、街区の全部ではない。
- 工事の時期の一次資料 (千葉市の発表、入札) は Web の検索では見つけられなかった。千葉市営住宅長寿命化・再整備計画の概要 (平成 22 年 12 月の入居戸数の表) に、準耐火構造の千城台第 1〜第 3 団地が用途廃止や建替えの対象として載っている。この街区がそのどれかは確かめていない。
- Sentinel-1 (Planetary Computer sentinel-1-rtc、2026-11-03 に検索): この場所を欠けなく撮り続けているのは軌道 46 (下り、20:43 UTC = 05:43 JST)。2014-10-20 から 2026-10-24 まで 319 item (318 日、2024-06-17 は 2 item)。衛星はほとんど S1A (S1B 1、S1C 2、S1D 11 は 2026 年)。2017-01-25 までは VV だけ。軌道 39 と 141 (上り) は 2022〜2024 年が欠ける。
- Sentinel-2 (sentinel-2-l2a、54SVE、雲量 60 % 未満): 718 item (2017-01-28 から)。
- 前の例 (../../_flood/kita-inbanuma-sar-changepoint) で分かった検定の性質: 誤警報の後は基準が 1 枚になるので誤警報が対で出る。ENL を大きく仮定すると誤警報が増える (台地の林で模擬の 2.3〜2.5 倍、ENL を 0.75 倍にすると合った)。
- SAR の画素の値はまだ読んでいない。

## 手法

### A: 画素ごとの変化点 (前の例の scripts/cp.py をそのまま使う)

Conradsen ら (2016) の逐次の尤度比検定 (強度だけ、VV と VH を独立とみなす)。最後の変化からの n 枚の平均と次の 1 枚が等しいかを検定し、p 値が α 未満ならその日を変化点として基準を作り直す。向きは VV の比の符号 (負 = 暗くなった)。撮影の数が多い (2017-02 から約 190 枚) ので α を前の例より小さくする。

### A の光学の日付 (Sentinel-2)

場所の輪郭の中の画素の、SCL が 4 (植生)、5 (裸地)、6 (水)、7 (分類なし) の画素だけで、B02、B03、B04、B08、B11、B12 の反射率 (処理の版 04.00 以降は 1000 を引いて 10000 で割る) の平均を日ごとに出す。輪郭の中の画素の 80 % 以上がこの SCL の日だけを使う。同じ日に 2 item あれば有効な画素の多い方。6 つの帯域をそれぞれ全期間の標準偏差で割り、期間 W の中で、平均の違う 2 つの区間に分ける最小二乗の切れ目 (両側に 5 日以上) を探す。切れ目の日付 D_opt は 2 つ目の区間の最初の日。

### B: タイルの点数

画素ごとに、2019 年度 (2019-04-01〜2020-03-31) と 2024 年度 (2024-04-01〜2025-03-31) の軌道 46 の全ての撮影の線形の強度の平均をとり、比の dB の絶対値が 3 dB 以上 (VV か VH のどちらか) なら「変わった画素」とする。タイルの点数は、タイルに中心が入る画素 (WorldCover 2021 のクラス 80 の水を除く) のうち変わった画素の割合。1 年分の平均は 25〜30 枚の平均なので、スペックルによる dB の差の揺れは 1 dB 未満 (ENL 4.4 で標準偏差約 0.5 dB)。3 dB を超える差は、ほぼ地表の変化か、季節では消えない年の違い (作物の違いなど) による。

素朴な基準 (baseline): WorldCover 2021 のクラス 50 (市街地) の画素の割合で順位を付ける (「市街地ほど変わりやすいので、市街地から買う」)。もう 1 つは無作為 (上位 k 枚で拾える期待値は全体の k / 120)。

## 範囲と画素の組

RTC の格子 (EPSG:32654、10 m)。範囲はタイル 144 枚の外接の箱に 200 m を足したもの (scripts/common.py の box_utm)。

| 組 | 定義 | 役割 |
|---|---|---|
| SITE | labels/site.geojson の輪郭に中心が入る画素 | 棟が消えた所 |
| CTRL | WorldCover 50 (市街地)、正解が 0 のタイル、SITE の輪郭の重心から 1.5 km 以内、輪郭から 100 m 以上 | 変わらなかった近くの市街地 (同じ日、同じ撮影の条件) |

## 区画

### A1: 解体の検出 (decisive)

- claim tested: C1
- mode: confirmatory
- data / analysis unit: 軌道 46 の RTC、2017-02-01 以降の全ての撮影 (VV と VH)、画素
- observable quantity: SITE の画素のうち、W の中に「暗くなる変化点」(変化点で、VV の比が負) が 1 つ以上ある割合 p_site。CTRL の同じ割合 p_ctrl
- comparator / control: CTRL
- evaluation population / split principle: SITE と CTRL の全画素。分けない (学習が無い)
- primary metric: p_site
- uncertainty: 画素どうしは空間に相関するので区間を付けない。頑健性の表の値を並べる
- planned settings: α = 0.001、ENL = 4.4 (item の sar:looks_equivalent_number)
- decision rule: p_site ≥ 0.5 かつ p_site ≥ 2 p_ctrl なら支持
- failure interpretation: p_site が低ければ、低層の棟が消えても下りの軌道から見た明るさは大きく下がらない (棟の向きと電波の向きによっては二回反射が弱い) か、工事の重機や仮囲いで明るさが保たれた。p_ctrl が高ければ、市街地では誤警報か小さな変化が多く、暗くなる変化点は解体の印として弱い
- alternative explanation being tested: 市街地一般の誤警報、季節の変化 (CTRL)
- falsification / robustness: 頑健性の表
- priority / run order: decisive、順番 1

### A2: 日付の答え合わせ (decisive)

- claim tested: C2
- mode: confirmatory
- data / analysis unit: A1 と同じ。Sentinel-2 の場所の輪郭の中の平均
- observable quantity: D_sar (SITE の画素の、W の中の暗くなる変化点のうち比が最も負の日、の中央値。変化点の無い画素は除く)。D_opt (上の光学の日付)
- comparator / control: D_opt
- evaluation population / split principle: SITE
- primary metric: |D_sar − D_opt| (日)
- uncertainty: D_sar の画素の間の四分位範囲を添える。D_opt は切れ目の前後の残差の二乗和の曲線を図で示す
- planned settings: A1 と同じ。光学は上の決め方
- decision rule: |D_sar − D_opt| ≤ 90 日なら支持
- failure interpretation: 合わなければ、どちらかが解体以外の変化 (工事の始まり、更地の整地、季節) を拾っている。図で両方の系列を並べ、どちらが何を拾ったかを記述する。どちらが正しいかは、この計画では決めない
- alternative explanation being tested: SAR の変化点が解体でなく別の工事の段階を拾っている
- falsification / robustness: 頑健性の表 (α、ENL)
- priority / run order: decisive、順番 2

### B1: 調べる場所のタイルの順位 (decisive)

- claim tested: C3
- mode: confirmatory
- data / analysis unit: 軌道 46、2019 年度と 2024 年度の撮影、ズーム 16 のタイル 120 枚
- observable quantity: タイル 58289_25820 の点数の順位 (1 が最大。同点はタイルの番号の小さい方を上にする)
- comparator / control: 他の 119 枚
- evaluation population / split principle: 正解の付いた 120 枚
- primary metric: 順位
- uncertainty: なし: 1 枚の順位で、区間は意味を持たない。頑健性の表の順位を並べる
- planned settings: 3 dB、VV か VH
- decision rule: 順位 ≤ 6 なら支持
- failure interpretation: 退けたら、輪郭の外の部分 (タイルの大部分は変わらない住宅地) に薄められ、街区 1 つの解体ではタイルの点数が上がりきらない。点数の単位 (タイルの大きさ) が粗い
- alternative explanation being tested: なし: 記述の確認
- falsification / robustness: 頑健性の表
- priority / run order: decisive、順番 3

### B2: 上位で拾える割合 (decisive)

- claim tested: C4
- mode: confirmatory
- data / analysis unit: B1 と同じ
- observable quantity: 点数の上位 24 枚に入る正解 2 のタイルの数 ÷ 正解 2 のタイルの数 (recall@20 %)。同じ値を市街地の割合の順位で
- comparator / control: 市街地の割合の順位 (baseline)、無作為 (期待値 0.2)
- evaluation population / split principle: 120 枚。分けない (点数に学習が無い。閾値 3 dB は結果を見る前に決めた)
- primary metric: recall@20 % の差 (SAR − baseline)
- uncertainty: 無作為に 24 枚を選んだとき、同じ数以上の正解 2 が入る確率 (超幾何分布) を添える。タイルは隣と似る (道路の工事は隣のタイルにまたがる) ので、この確率は独立を仮定した目安
- planned settings: B1 と同じ
- decision rule: SAR の recall@20 % ≥ 0.5 かつ SAR − baseline ≥ 0.2 なら支持
- failure interpretation: 退けたら、2019 年度と 2024 年度の平均の差では、写真で分かる変化 (太陽光、造成、道路、建物) の半分も上位に出ない。畑の年の違いが点数の上位を占めているかを、上位のタイルの正解の内訳で記述する
- alternative explanation being tested: 「市街地ほど変わる」だけで説明できる (baseline)
- falsification / robustness: 頑健性の表。調べる場所のタイルとその 8 近傍を除いた版
- priority / run order: decisive、順番 4

## 仮定

- 確かめられる: 日ごとの位置がそろっている (02_grid.py の後に、時系列の中央値に対する位置のずれを位相相関で測る。0.5 画素を超える日があれば報告する)。同じ日の 2 item は同じ格子 (違えば止める)。
- 確かめられない: 写真の撮影日 (年度の中のいつか)。輪郭 (OSM) が、棟の消えた範囲をどれだけ覆うか。正解の付け方の一致度 (1 人で付けた)。

## 関門

- 座標と距離、面積: SAR は EPSG:32654 の 10 m 格子。タイルは Web メルカトルの区切りで、画素の中心の経緯度でタイルに入れる (面積は画素の数で数え、メルカトルの値を面積にしない)。1.5 km と 100 m は UTM の上で測る。
- 量と水準: 点数と p は画素の数の比 (面積の比)。足し合わせない。
- 空間の依存とリーク: 隣のタイルは似る。B2 の超幾何の確率は目安と書く。点数に学習が無く、正解は SAR の前に固定したのでリークは無い。調べる場所のタイルは付ける前から変化を知っていたので、除いた版を並べる。
- 基準と雑音の上限: CTRL、市街地の割合の順位、無作為。正解の雑音 (1 人の目視) の上限は測れないと書く。
- 残差と頑健性: 頑健性の表。MAUP: タイルの大きさはオルソを買う単位 (ズーム 16) で使い道から決めた。ズーム 17 の正解は無いので、大きさの掃引は流さない。
- 報告: タイルの点数を、個々の建物の変化として書かない。正解との一致度で、真の精度ではないと書く。
