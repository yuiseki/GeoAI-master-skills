# OWLv2 CPU 推論の比較計画

2026-11-13。パリ画像E2Eの保存済み水平ビューをファイル名順に8枚選び、同じ OWLv2 と同じ3テキスト・0.15閾値・入力・出力条件で、逐次1ワーカー4スレッド、2ワーカー各2スレッド、1ワーカー4スレッド・バッチ2を比較する。4 CPU相当、メモリ8 GiB・swapなしの個別 cgroup を各実行に設定し、同時に実行しない。画像とモデルをキャッシュに準備した後、各条件とも別プロセスで開始する。

各条件でモデル読込から全画像の検出結果書出しまでの経過時間、cgroup memory.peak（全子プロセスを含む）、件数を記録する。基準を逐次とし、ビュー・クエリごとに矩形の最大IoUで一対一照合し、欠落・追加、最小IoU、スコア差を報告する。厳密に同値でない場合も隠さず表示する。誤差や検出数が変わるなら速度だけで採用しない。画像の透視切出し・傾き・植生・入出力以外のパイプライン全体の高速化は測らない。標本8枚は速度計測用で、精度の代表標本ではない。3条件とも1回の探索で、時間変動の一般化はしない。
