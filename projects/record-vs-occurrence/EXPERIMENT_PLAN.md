# 計画: 記録の多さと発生の多さ

流す前に書く。流した後に書き直さない。直すなら末尾の「計画の変更」に足す。

## 問いと使い道

- 問い: 100 区画 (1 km 四方) の出来事の記録から、人口あたりの発生が多い区画はどこか。対象はこの 100 区画だけ。
- 使い道: 対策の優先順位を決める。総数を優先するか、人口あたりのリスクを優先するかで答えが変わるため、主の読み方は人口あたりの発生率とし、総数 (面積あたり) は代替の読み方として並べる。
- 問いの種類: 関連・構造 (記述)。因果ではない。

## 主張の地図

| claim_id | 主張 (結果の数字で確かめられる形) | 効く判断 | 区画 |
|---|---|---|---|
| C1 | 西の記録の多さは調査回数の多さと整合し、記録/回は東が西より高い。西が発生多いとは言えない。 | 生の記録数を優先順位の根拠にしない | B1 |
| C2 | 東の北 3 行 (row 0-2) は、同じ 4 回調査の東の南 7 行より、人口あたりの記録率が高い。 | 北東を候補にするか | B2, B4 |
| C3 | 西と東の発生率の比は、検出模型なしには識別できない。西が高い・等しい・東が高いのどれも成り立つ。 | 西東の順位を断定しない | B3 |
| C4 | 西の中では、人口あたりの記録率は行によらずほぼ一定。南西の記録の多さは人口 (発生の機会) による。 | 総数の優先順位を人口と分けて読む | B1 |

## 区画

### B1: 記録の総数と分母

- claim tested: C1, C4
- mode: confirmatory。決め手の集計値はまだ計算していない (生の表は読んだ)。
- data / analysis unit: `data/units.csv`、1 行 = 1 区画 (1 km 四方)、100 行。
- observable quantity: 西/東の記録の合計、調査回数の合計、記録/回、人口 1,000 人あたりの記録、人口の合計。西の中の行ごとの人口あたり記録率。
- comparator / control: 西と東。生の記録、記録/回、記録/人口の 3 つの分母。
- evaluation population / split principle: 100 区画全体。分割はしない (記述)。
- primary metric: 記録/回の西東比。
- uncertainty: 集計値なので区間は付けない。率の比は B2 で区間を付ける。
- planned settings: 面積は 1.0 km² で一定。人口を発生の機会とする (代替は面積)。
- decision rule: C1 を支持するのは、西の記録合計 > 東の記録合計、西の調査回数/東の調査回数 ≥ 4、東の記録/回 > 西の記録/回 の 3 つが成り立つとき。C4 を支持するのは、西の中の行ごとの人口あたり記録率の最大/最小 < 1.2 のとき。
- failure interpretation: 東の記録/回 ≤ 西の記録/回 なら、努力だけでは説明できない。それでも発生の結論にはしない。分母を変えて結論を救済しない。
- alternative explanation being tested: 観測の努力、発生の機会 (人口)、面積 (一定)。
- falsification / robustness: 分母を生の記録、記録/回、記録/人口、記録/面積で変える。西と東で人口構成が同じことを確かめる。
- priority / run order: baseline、順番 2。

### B2: 東の中の北 3 行と南 7 行

- claim tested: C2
- mode: exploratory。北東の 3×5 区画は生の表を見て示唆されたため、確認には数えない。
- data / analysis unit: 東の 50 区画 (col 5-9)。1 行 = 1 区画。行単位の集計 (10 行) も使う。
- observable quantity: 東の北 3 行 (row 0-2) と南 7 行 (row 3-9) の、人口 1,000 人あたり記録率の比。
- comparator / control: 東の南 7 行。負の対照として、西の北 3 行と南 7 行の同じ比。
- evaluation population / split principle: 東の 50 区画。行単位の並べ替え (10 行から 3 行を選ぶ 120 通り) で、行のまとまりを保つ。
- primary metric: 人口あたり記録率の比 (北東/東南)。
- uncertainty: ポアソン回帰の 95% 区間、行単位の正確な並べ替え p、行を 1 つずつ抜く感度。
- planned settings: 人口を offset にしたポアソン回帰。過分散なら負の二項分布。行の並べ替えは 3 行 vs 7 行の全 120 通り。
- decision rule: 比 > 1 で、北 3 行の東の率が南 7 行の全てより高い (正確な片側 p = 1/120 = 0.0083) か、ポアソン回帰の 95% 区間が 1 を除くとき、仮説として支持。どちらも満たさなければ支持しない。
- failure interpretation: 支持されなければ、北東を優先候補にしない。行を抜く、分母を変える、モデルを変える、で差を作らない。
- alternative explanation being tested: 観測の努力 (東内では 4 回で一定)、人口に依存する検出率 (低人口の北で検出しやすい)、偶然、1 行/1 区画への依存、発生の機会の取り方。
- falsification / robustness: 西の北 vs 南が同じように高いなら、北東固有でなく北一般の効果。行を 1 つずつ抜く、区画を 1 つずつ抜く、2 行ずつにまとめる、面積を分母にする、ポアソンと負の二項を比べる。
- priority / run order: decisive、順番 3。

### B3: 西東の発生率の識別

- claim tested: C3
- mode: confirmatory (論理)。決め手の値はまだ計算していない。
- data / analysis unit: 西 50 区画と東 50 区画の集計。
- observable quantity: 西東の記録/人口比、記録/回比。検出模型ごとに導かれる真の発生率の比。
- comparator / control: 線形検出 (記録 ∝ 訪問回数)、完全検出 (記録 = 発生)、共通の飽和検出 (1-(1-p)^訪問回数) の 3 つ。
- evaluation population / split principle: 西と東の集計。分割はしない。
- primary metric: 真の西東発生率の比。
- uncertainty: 2 つの努力水準しかないため、模型の形と発生率の比を分けられない。比の範囲を書く。
- planned settings: 検出は訪問回数に対して単調非減少と仮定する。3 つの模型はどれも西東の集計を同じように説明する。
- decision rule: 真の西東比の範囲が 1 をまたぐ (下も上も取れる) なら「識別できない」と判定する。全ての模型が同じ向きなら、その向きを報告する。
- failure interpretation: 外部の検出模型や反復調査が無い限り、西東の順位は断定しない。模型を選んで結論を救済しない。
- alternative explanation being tested: 検出模型、訪問の割り当てが発生に依存する内生性、同じ出来事の重複記録、出来事の定義。
- falsification / robustness: 3 つの模型で真の比の向きが変わることを確かめる。訪問回数を連続の共変量にしたポアソン回帰も、仮定依存の 1 つの模型として並べる。
- priority / run order: decisive、順番 3。

### B4: 頑健性

- claim tested: C2, C3
- mode: exploratory (感度)。
- data / analysis unit: B1-B3 と同じ。
- observable quantity: C2 の比の、行抜き・区画抜き・集計・モデル・分母を変えた値。C3 の模型ごとの比。
- comparator / control: B2 の主の推定。
- evaluation population / split principle: 100 区画。行単位のまとまりを保つ。
- primary metric: C2 の比、C3 の模型ごとの西東比。
- uncertainty: 行を 1 つずつ抜いた範囲、区画を 1 つずつ抜いた範囲。
- planned settings: 行抜き 10 通り、区画抜き 100 通り、2 行ずつに集計、面積分母、ポアソン/負の二項、3 つの検出模型。
- decision rule: C2 は、行抜き・区画抜きの全てで比 > 1 なら頑健。C3 は、3 つの模型で比の向きが変わるなら「識別できない」を維持。
- failure interpretation: 比が 1 をまたぐ条件があれば、その条件を結論に書く。
- alternative explanation being tested: 偶然、1 行/1 区画への依存、単位と尺度、モデルの設定。
- falsification / robustness: 上記。
- priority / run order: robustness、順番 4。

### B5: 空間の診断

- claim tested: なし (記述)
- mode: exploratory。
- data / analysis unit: 100 区画。
- observable quantity: 記録、調査回数、人口あたり記録率、B1 の主効果モデルの Pearson 残差の Moran's I。
- comparator / control: k = 4 (上下左右) と k = 8 (周囲) の近傍。
- evaluation population / split principle: 10×10 格子。並べ替え 999 回。
- primary metric: Moran's I。
- uncertainty: 近傍の取り方 (k=4, k=8) と並べ替え p。
- planned settings: 行・列の索引を平面座標として使う。距離はセル隣接。ローカル Moran は使わない。
- decision rule: 記述として報告。空間的自己相関の有無で C1-C3 の判断を変えない。
- failure interpretation: なし (診断)。
- alternative explanation being tested: 空間の依存そのものではなく、設計された人口勾配と努力のブロックを確認する。
- falsification / robustness: k を 4 と 8 で比べる。
- priority / run order: optional、順番 5。

## 仮定

- 1 行 = 1 km 四方の区画。面積は一定。
- `observed` は重複しない出来事の数。訪問が同じ出来事を再記録する場合、記録/回は検出率に比例しない (未確認)。
- 人口は出来事の発生の機会。出来事が人に紐づかないなら、面積が発生の機会になる (代替)。
- 調査回数は観測の努力。訪問が多いほど検出は増えるか変わらない (単調)。関数の形は不明。
- 訪問の割り当ての理由は不明。発生の多い所に多く訪問したなら、努力は内生。
- 100 区画が対象の全体。区間と p はこの格子の中の記述で、別の地域への一般化ではない。

| C2 | B2 | 北東/東南の率比 > 1 かつ (北 3 行が南 7 行より全て高い、または 95% 区間が 1 を除く) | 行の並べ替えは全 120 通りで正確 |

| C4 | B1 | 西の行ごとの人口あたり率の最大/最小 < 1.2 | 記述的な一様性の目安 |

## 反証

| 別の説明 | 区画 | 保つもの | 壊すもの | 別の説明が正しいときの結果 | 主張が正しいときの結果 |
|---|---|---|---|---|---|
| 北一般の効果 | B2 | 東の 4 回訪問 | 北東固有性 | 西の北 vs 南も高い | 西の北 vs 南は差が小さい |
| 面積分母 (人口でない) | B2 | 区画の形 | 発生の機会の定義 | 北東/東南の比が 1 未満 (南が高い) | 人口あたりでは北東が高い |
| 人口に依存する検出 | B2 | 訪問回数 4 回 | 検出率が行で一定という仮定 | 北東の差が消える/説明できる | 北東の差が残る |
| 1 行/1 区画への依存 | B4 | 他の行/区画 | 問題の行/区画 | 抜くと比が 1 以下 | 抜いても比 > 1 |
| 検出模型 | B3 | 西東の集計 | 検出の形 | 模型で西東の向きが変わる | どの模型でも同じ向き |

試さなかった別の説明: 訪問の内生性 (訪問の割り当て理由のデータが無い)、重複記録 (出来事 ID が無い)、時間の変化 (期間の内訳が無い)。

## 流す前に決めたこと

- 決めた日時: 2026-10-25
- その時点で読んだ生のデータ: 100 行の表全体 (unit_id, row, col, area_km2, population, survey_visits, observed)。集計・率・モデルは未計算。
- その時点で見ていた結果 (決め手の指標の値など): なし。生の表だけ。
- 確認に使う部分を分けて見ないでおいたか: いいえ。C2 は表から示唆されたため探索として報告する。C1 と C3 は設計と論理から決めた記述で、確認として扱う。
- 主の読み方: 人口あたりの発生率。代替: 総数 (面積あたり)。人口が区画で 1,000〜4,600 人と 4.6 倍違うため、リスクと総数を分ける。
- 検出模型の候補: 線形 (記録 ∝ 訪問回数)、飽和 (1-(1-p)^訪問回数)、完全検出 (記録 = 発生)。2 つの努力水準の集計を同じように説明するため、西東の比は識別できない。東の中の比は、共通の検出因子が打ち消されるため、検出模型に依存しない (行ごとの検出差は残る)。
