# 計画: Sentinel-1 で測るため池の水面の割合は、Sentinel-2 の水面の割合と合い、変化を追えるか

流す前に書く。流した後に書き直さない。直すなら末尾の「計画の変更」に足す。

## 問いと使い道

- 問い: 3 つの範囲 (香川、福山、淡路。`tameike-cascade-pairs` と同じ) のため池で、Sentinel-1 RTC の VV から測る池の中の水面の割合は、近い日の Sentinel-2 の NDWI から測る割合と、どの大きさの池まで合い、池ごとの増減を追えるか。
- 使い道: 雲に左右されない Sentinel-1 で、ため池の水の減りを見張れるか、見張れる池の大きさの下限を決める。前のプロジェクト `sar-drought-drawdown-monitoring` (取り下げ) は、比べる相手が無く、池の形も使わずに減水を判定していた。ここでは、Sentinel-2 を独立の比べる相手にし、池の形 (DEM5A の水面の穴) の中だけを数える。
- 問いの種類: 関連 (測定の一致)。

## 主張の地図

|---|---|---|---|

## 区画

### B0: 位置のずれと陽性の対照 (sanity)

- claim tested: C0
- mode: confirmatory
- data / analysis unit: 範囲ごとの、S1 の全撮影の中央値の画像と、DEM5A の水面の穴 (`tameike-cascade-pairs` と同じ方法で作る) を 10 m の格子にしたもの
- observable quantity: S1 の中央値 (dB) の暗さと、穴の 0/1 の相互相関の最大の位置 (行と列のずれ)。S2 も同じく、NDWI の中央値と穴で測る。ずれを整数の画素で直した後の、5 ha 以上の池の内側の水の割合の中央値 (S1、S2)
- comparator / control: ずれを直さない場合
- evaluation population / split principle: 範囲ごとの全ての穴
- primary metric: 5 ha 以上の池の内側の、S1 と S2 の水の割合の、池と日の中央値
- uncertainty: なし: 記述
- planned settings: 相互相関は ±5 画素の範囲。S1 の水は VV < -15 dB。S2 の水は NDWI = (B03 − B08) / (B03 + B08) > 0
- decision rule: S1 と S2 の両方で中央値が 0.8 以上なら先へ進む。下回れば、手順が水を見られていないので止め、閾値や位置を見直す (そのときは探索に移る)
- failure interpretation: 大きな池が水と判定されないなら、その先の比較を読まない
- alternative explanation being tested: なし: 健全性
- falsification / robustness: なし
- priority / run order: sanity、順番 1

### B1: 水の割合の差と池の大きさ (decisive)

- claim tested: C1
- mode: confirmatory
- data / analysis unit: 池と日の組 (S1 の撮影日と、その ±2 日の S2 の撮影の組)。池は、台帳の点が 30 m 以内に対応づいた DEM5A の穴
- observable quantity: 組ごとの |S1 の割合 − S2 の割合|
- comparator / control: 池の大きさの階級 (穴の面積で 0.1〜0.5 ha、0.5〜1 ha、1〜5 ha、5 ha 以上) どうし
- evaluation population / split principle: 両方の衛星で、池の内側の画素が 4 つ以上あり、S2 で池の画素の 90% 以上が雲と雲の影でない組
- primary metric: 階級ごとの差の中央値
- uncertainty: 池で引き直すブートストラップ (1,000 回、種 0) の 95% 区間
- planned settings: 池の内側は、穴を 10 m の格子に移してから 1 画素削ったもの。S1 と S2 の格子は、どちらも EPSG:32653 の 10 m で、穴を各衛星の格子に最近傍で移す
- decision rule: 差の中央値が、階級が大きくなるほど小さくなれば (隣り合う階級で区間の重なりを問わず向きが単調なら) 支持。向きが崩れれば退ける
- failure interpretation: 退けられたら、大きさで下限を決められない。閾値や階級の切り方を変えて救済しない
- alternative explanation being tested: 位置のずれ (B0 で直す)、境界の混ざり (内側だけを数える)
- falsification / robustness: 閾値 (S1 -13、-17 dB。S2 NDWI 0.1、-0.1)、削らない池の内側、S2 の SCL の水 (6) を水とする定義
- priority / run order: decisive、順番 2

### B2: 増減を追えるか (decisive)

- claim tested: C2
- mode: confirmatory
- data / analysis unit: B1 と同じ組
- observable quantity: S1 と S2 の割合から、それぞれ池ごとの平均と日ごとの平均を引いた残り (二方向の平均を除いた値) の相関
- comparator / control: S1 の日付を池の中で並べ替えた相関 (200 回、種 0)。池の平均だけを除いた相関 (補助)
- evaluation population / split principle: B1 と同じ。組が 3 つ以上ある池
- primary metric: 階級ごとの、二方向の平均を除いた相関 (Pearson)
- uncertainty: 池で引き直すブートストラップの 95% 区間 (1,000 回、種 0)
- planned settings: 日ごとの平均は、範囲ごとに引く (風や霞は範囲の全体に効く)
- decision rule: 1〜5 ha と 5 ha 以上の両方の階級で、区間の下端が 0 より大きければ支持。どちらかで 0 をまたげば、その階級では支持されない
- failure interpretation: 支持されなければ、S1 で池ごとの減水を見張れるとは言えない。前のプロジェクトのような単独の池の変化からの判定を、この結果で正当化しない
- alternative explanation being tested: 日付の効果 (風で S1 が明るくなり、霞で S2 の NDWI が変わる) が両方に同じ向きに効いて、相関が出る。日ごとの平均を除くことで試す
- falsification / robustness: 並べ替えの相関の分布が 0 の周りにあること。B1 と同じ閾値の変え方
- priority / run order: decisive、順番 3

## 仮定

- DEM5A の水面の穴は、満水に近い時点の池の広がり。測量の時点は場所ごとに違い、確かめていない
- S1 RTC は線形の γ0。dB にしてから閾値を当てる。位置は 2 画素ほどずれることがある (dataset-discovery の sentinel-1)
- S2 L2A の B03、B08 は 10 m、SCL は 20 m (最近傍で 10 m にする)。S2 の位置は穴とそろっているかを B0 で測る
- S1 は 06 時頃、S2 は 11 時頃 (日本時間) の撮影。±2 日の間に池の水位が大きく変わらないと仮定する (確かめられない)
- 2024 年の 1 年。S1 は香川と福山が相対軌道 90、淡路が 17 (どれも下り)。範囲を覆う撮影の数で選んだ
