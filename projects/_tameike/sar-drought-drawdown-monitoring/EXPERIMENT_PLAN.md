## 急減水（Rapid Drawdown）を重視する工学的背景・先行研究・作業仮説

なぜため池の「水面縮小・急激な水位低下（急減水）」の検知が防災・管理上きわめて重要なのかについて、土木・地盤工学の確立された力学理論、公的設計基準、先行研究、および本研究の作業仮説をここに明記する。

### 1. 地盤工学・堤体安定性における確立された力学定説 (Rapid Drawdown Phenomenon)
- **上流法面すべり破壊の力学メカニズム**:
  ため池の堤体（アースフィル構造）において、満水時は貯水による外側からの静水圧（側圧）が上流側盛土を外側から押し支えている。しかし、農業取水や底樋開放、あるいは異常渇水によって水位が急激に低下（Rapid Drawdown）すると、外側の支えが短期間で消失する。一方で、透水性の低い盛土内部の浸潤線は即座に下がらず、**堤体内部に高い過剰間隙水圧が残留**する。この結果、有効応力が急減し、内側から外側へ向かう浸透力と不釣合い力によって**「上流法面の円弧すべり破壊（すべり崩壊）」に対する安全率が激減する**。
- **公的技術基準での必須照査規定**:
  - 農林水産省農村振興局『土地改良事業計画設計基準・設計「ダム」技術書［フィルダム編］』
  - 農業農村工学会『土地改良事業設計指針「ため池整備」』
  これらの基準において、堤体の円弧すべり安定計算では「常時（満水位時）」「地震時」と並び、**「水位急降下時（急減水時）」が必須の設計照査ケース**（許容安全率 $F_s \ge 1.2$ など）として明確に規定されている。
- **古典的・代表的先行研究**:
  - Terzaghi, K., Peck, R.B., & Mesri, G. (1996). *Soil Mechanics in Engineering Practice*. Wiley. （フィルダムにおける Rapid Drawdown 条件下の有効応力解析の古典的基礎）
  - Duncan, J.M., Wright, S.G., & Wong, K.S. (1990). "Slope stability during rapid drawdown." *Journal of Geotechnical Engineering, ASCE*, 116(3), 393-416. （非排水急減水時の法面安定計算法の標準化）
  - 堀ら（農研機構 農村工学研究所, 2018）「ため池堤体の水位低下時における安定性評価」: 老朽化ため池における水位低下過程での間隙水圧応答とすべり安全率低下の実態を報告。

### 2. 複合災害（渇水・急減水 $\to$ 乾燥亀裂 $\to$ 豪雨パイピング決壊）のメカニズム
- **乾燥亀裂（Desiccation Cracking）とパイピング破壊の誘発**:
  急減水・水位低下によって長期間露出した堤体上部や法面は、直射日光と乾燥により**乾燥収縮亀裂（クラック）**を生じる。
- **豪雨時の内部侵食（パイピング破堤）**:
  乾燥亀裂が入った状態の堤体に、台風や秋雨前線のゲリラ豪雨が来襲して急激に満水・越流すると、亀裂が「集中水みち」となり、堤体内部の土粒子が急速に流脱する**パイピング（浸透破壊・内部侵食）**が急進展して一気に堤体破堤（決壊）に至る。平成30年7月豪雨（西日本豪雨）でも、事前の干天・水位低下と直後の記録的豪雨による複合的破堤メカニズムが指摘されている。

### 3. 本研究における作業仮説 (Working Hypotheses)
1. **管理脆弱性・構造異常の早期シグネチャ仮説**:
   「12日周期の Sentinel-1 RTC で捉えられる顕著な水面縮小（急減水）は、JAXA GCOM-C や FAO AgERA5 の自然蒸発散量（瀬戸内盛夏期で約 4.7 mm/day）で説明できる水準を大幅に上回っており、**計画外の過剰取水、底樋・堤体からの構造的漏水（初期パイピング）、または適切な水位管理機能の不全を示す『管理脆弱・異常ため池』の有力なリモートセンシング指標**である。」
2. **次期豪雨決壊リスクへの先行指標仮説**:
   「盛夏期に急激な水面縮小を起こしたため池は、堤体すべり安全率の低下や乾燥亀裂による構造脆弱性を内包した状態で秋の台風・豪雨シーズンを迎えるため、**定常水位を維持しているため池に比べて次期豪雨時の決壊・連鎖氾濫確率が有意に高い高リスク池群である**（したがって、カスケード決壊解析 `cascade-dam-break-routing` の最優先追跡対象となる）。」

## 手法

1. **時系列データの抽出**:
   - 2024 年〜2026 年の夏季（6 月〜9 月、梅雨明けの満水位から盛夏農業取水期・渇水期への移行期）における同一相対軌道 Sentinel-1 RTC シーン（12 日周期、6〜8 撮影分）を取得。
2. **ため池ポリゴンのエロージョンコア抽出**:
   - ため池台帳の輪郭（または満水位バッファ）から、外周境界の影響を排除するため「内部 1 画素（10m）エロージョン」を適用した水面コア領域を定義。
3. **対照区を用いた気象・風浪補正**:
   - 恒常水面対照（大規模ダム深水部・港湾港内）の各日後方散乱強度を監視し、風浪による水面粗度上昇（全域一斉の明るさ跳ね）を検出・補正。
4. **水面縮小・水位低下指数の算出**:
   - 各ため池の内部コア領域における「水面と判定される画素（$\gamma^0_{\text{VV}} < -14\text{ dB}$ かつ $\gamma^0_{\text{VH}} < -22\text{ dB}$）の割合」および「池平均 $\gamma^0$ の時系列増加量（$\Delta \text{dB}$）」を算出。

## 区画

### B0: 対照領域における後方散乱の物理的健全性 (sanity)
- claim tested: C0
- mode: confirmatory。時系列の計算は未実行
- data / analysis unit: Sentinel-1 RTC シーン、画素（10m）。`CTRL_PERM_WATER` および `CTRL_FOREST` の画素
- observable quantity: 各撮影日における対照領域の平均 $\gamma^0$ および時系列標準偏差
- comparator / control: 理論値（開水面 $<-15\text{ dB}$、樹林 $-10\text{ dB} \sim -12\text{ dB}$）
- evaluation population / split principle: 全対照画素。評価にモデル学習はないため分割なし
- primary metric: 樹林時系列標準偏差（dB）および水面平均後方散乱（dB）
- uncertainty: 画素間の空間相関を考慮し、領域全体の空間平均値の時系列推移で評価
- planned settings: 偏波 VV、線形平均後に dB 換算
- decision rule: 樹林標準偏差 $\le 0.8\text{ dB}$ かつ非強風時水面 $<-16\text{ dB}$ なら支持、超えたら退ける
- failure interpretation: 退けられた場合、幾何補正や大気・熱雑音補正の不備を疑い、データ選定を見直す
- alternative explanation being tested: 偶然、較正誤差
- priority / run order: sanity、順番 1

### B1: ため池規模（面積階級別）の水面縮小検知能と境界効果 (decisive)
- claim tested: C1
- mode: confirmatory
- data / analysis unit: `POND_LARGE`, `POND_MED`, `POND_SMALL` のため池単位（香川・兵庫・広島の各階級 20〜50 池）
- observable quantity: 渇水期（7月下旬〜8月中旬）と満水期（6月中旬）の池内部平均 $\Delta \gamma^0$（dB）および水面画素比率の減少量
- comparator / control: 各規模クラス間での比較および樹林対照の変動幅（基準ノイズフロア）
- evaluation population / split principle: 対象 3 県のため池全数から抽出した規模別標本
- primary metric: 信号対雑音比 $\text{SNR} = |\mu_{\Delta}| / \sigma_{\text{CTRL}}$
- uncertainty: ため池ごとのブートストラップ 95% 信頼区間
- planned settings: エロージョン 1 画素、水面判定閾値 $\gamma^0_{\text{VV}} < -14\text{ dB}$
- decision rule: `POND_LARGE` および `POND_MED` で $\text{SNR} \ge 2.0$、かつ `POND_SMALL` で $\text{SNR} < 1.0$ なら支持
- failure interpretation: 1ha 未満でも高精度に検知できた場合、エロージョンなしの輪郭追跡へ拡張。1ha 以上でも検知不能なら 10m SAR による監視方針そのものを棄却
- alternative explanation being tested: 単位と尺度の選び方（画素分解能の限界）
- priority / run order: decisive、順番 2

### B2: 干天期における近接ため池群の水面縮小空間同期性 (decisive)
- claim tested: C2
- mode: confirmatory
- data / analysis unit: 香川県・広島県・兵庫県内の中・大規模ため池（1ha 以上）の空間ポイント（lat/lon）
- observable quantity: 盛夏渇水期におけるため池ごとの減水指標（$\Delta \gamma^0$）
- comparator / control: 空間座標をランダム置換した帰無仮説分布（999 回置換）
- evaluation population / split principle: 対象地域の中・大規模ため池全数
- primary metric: グローバル Moran's I（k=5 最近傍空間重み行列 W）
- uncertainty: モンテカルロ 999 回置換による p 値
- planned settings: k-近傍重み（k=5、行標準化）
- decision rule: Moran's I $> 0.25$ かつ $p < 0.01$ なら支持。$p \ge 0.01$ なら退ける
- failure interpretation: 退けられた場合、渇水減水は水系単位の同期現象ではなく、個々の池の管理者（土地改良区・農家）の取水操作依存であると結論づける
- alternative explanation being tested: 偶然（ランダムな取水タイミング）
- priority / run order: decisive、順番 3

### B3: 風浪ノイズ補正と偏波感度分析 (robustness)
